# 图层核心概念

## 图层类型

| 类型     | 作用                                         | 效果示例                                             |
| :------- | :------------------------------------------- | :--------------------------------------------------- |
| 影像图层 | 为天体表面覆盖真实影像纹理，控制外观显示效果 | 加载地球卫星影像后，可显示大陆、海洋的真实色彩与轮廓 |
| 高程图层 | 定义地形的高低起伏形态，控制三维立体感       | 加载月球高程数据后，可呈现环形山、月海的真实地形起伏 |

## 图层优先级规则说明

### 核心规则

在【三维地形全局管理】列表中，**图层排列越靠下，在三维场景中的显示层级越高**。后渲染的图层会覆盖先渲染图层的重叠区域。高程图层与影像图层均遵循此优先级规则：多层高程数据叠加时，列表下方的高程图层的地形起伏效果，会覆盖上方高程图层的效果。

### 规则解读

软件按「从上到下」的顺序遍历图层列表并渲染。列表位置靠下的图层会在靠上图层之后绘制，因此会叠加或覆盖在靠上图层之上。

如下图所示，19级高清影像图层位于13级图层下方，在三维场景中会覆盖在13级图层之上。

![图层优先级规则示意图](./media/02-图层核心概念/image-20260423155625137.png)

### 应用建议

- **基础数据置顶**：低分辨率的基础底图、全局高程数据，建议置于列表上方，以保证场景快速加载与全局显示。
- **精细数据置底**：高分辨率的局部影像、精细高程数据，建议置于列表下方，叠加在基础图层之上，实现细节升级，同时避免被基础图层遮挡。
