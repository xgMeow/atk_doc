# 图层添加

## 前置准备

确认已准备好对应天体的地形数据，支持以下格式：

- `.tif`：TIFF格式单文件影像/高程数据
- `.xml`：TMS瓦片服务配置文件
- `.tdb`：TDB格式瓦片数据库文件

## 操作步骤

1. 在【三维地形全局管理】界面中，选中目标天体（如“地球”）。

2. 点击界面左上角的<kbd>添加</kbd>按钮，弹出【选择类型】对话框。

3. 在对话框中选择图层类型：
   - 需添加影像纹理 → 选择<kbd>影像</kbd>
   - 需添加地形高程 → 选择<kbd>高程</kbd>

   | 类型     | 作用                                         | 效果示例                                             |
   | :------- | :------------------------------------------- | :--------------------------------------------------- |
   | 影像图层 | 为天体表面覆盖真实影像纹理，控制外观显示效果 | 加载地球卫星影像后，可显示大陆、海洋的真实色彩与轮廓 |
   | 高程图层 | 定义地形的高低起伏形态，控制三维立体感       | 加载月球高程数据后，可呈现环形山、月海的真实地形起伏 |

4. 在弹出的【文件选择】对话框中，选择对应格式的地形数据文件。

5. 确认后，图层将自动添加到目标天体的图层列表中，并在三维场景中生效。
