

# 视点沿向量方向

## 功能概述

**视点沿向量方向**功能允许您将三维视图的观察位置（相机）精确地设置在**某个参考点**的**特定方向**上。通过指定参考对象、方向向量及相关参数，您可以快速将视角定位到所需的位置，例如从地球中心向外看星空、从卫星位置沿轨道法向观察地球等。


## 操作步骤

- 在三维视图窗口，点击工具栏中的 **局部视点![image-20260319151855849](./media/02-视点沿向量方向/image-20260319151855849.png)** 按钮即可弹出 **视点选择窗口**，进入配置界面。

- 在视点选择窗口中，视图选择“沿一个方向”，进入 **视点沿向量方向** 设置区域。该区域包含以下可配置项：

![视点延向量方向](./media/02-视点沿向量方向/image-20260319151947065.png)


## 配置项详解

### 从点（参考点）

- **定义**：选择作为位置基准的天体或对象。视点的最终位置将基于该对象的中心点，沿指定方向移动一段距离得到。
- **可选对象**：
  - **系统内置天体**：例如地球、太阳、月球等，可直接选择。
  - **飞行器对象**：当前场景中所有的卫星、飞机等对象。
- **作用**：相当于确定“起点”。例如，选择“地球”作为从点，则视点将从地球中心开始计算。

### 方向

- **向量选择**：您需要指定一个方向向量，用于确定视点相对于**从点**的偏移方向。点击输入框旁边的 ![image-20260319120431245](./media/02-视点沿向量方向/image-20260319120431245.png)按钮，打开 **添加组件** 窗口，进行向量选择。

  ![选择方向](./media/02-视点沿向量方向/image-20260319152154424.png)

- **向外 / 向内**：

  - **向外**：视点将沿向量方向远离参考点移动。适用于从参考点向外观察（例如从地球看向深空）。
  - **向内**：视点将沿向量反方向朝向参考点移动。适用于从外部看向参考点（例如从太空看向地球）。

### 参考坐标系

- **定义**：指定方向向量所依赖的坐标系统。同一个向量在不同坐标系下指向的空间方向可能完全不同。例如，您希望从地球中心沿X轴方向看出去，但X轴在不同坐标系中指向不同：在地心地固系中，X轴指向格林尼治子午线与赤道的交点；在地心惯性系中，X轴指向春分点。若不指定正确的坐标系，最终视点位置可能完全错误。

- **默认行为**：当您选择某个“从点”时，系统会自动将参考坐标系切换为该对象对应的默认坐标系，例如：
  - 选择地球 → 默认可选坐标系为“地球 国际天球惯性系 坐标”和“地球 天体固连系 坐标”。
  - 选择卫星1 → 默认坐标系为“卫星1 ICR 坐标”。

- **自定义坐标系**：如果默认坐标系不满足需求，您可以点击 **“添加”** 按钮，从列表中选择其他坐标系（如国际天球参考系、天体惯性系等）。

![添加参考坐标](./media/02-视点沿向量方向/image-20260319152354406.png)

### 限制向上向量

- **定义**：锁定相机的“头顶”方向，防止视图在移动过程中发生倾斜或颠倒。您可以从六个方向中选择一个作为固定的世界向上方向：**+X、-X、+Y、-Y、+Z、-Z**。
- **作用**：
  - 保持画面稳定，避免因视点旋转导致晕眩或方向感丢失。
  - 确保您始终以固定的“上”方向观察场景（例如始终让地球的北极朝上）。
