# 仿真时间
仿真时间是ATK场景属性的核心配置项，用于定义航天任务仿真的**时间区间**与**参考历元**，为轨道计算、任务推演等仿真操作提供统一的时间基准。

![仿真时间](./media/01-仿真时间/image-20260325113145980.png)

## 仿真区间
仿真区间用于精准设定仿真任务的时间跨度，包含**开始历元**与**结束历元**两个核心参数，共同界定仿真分析的时间范围。
- **开始历元**：设置仿真任务的起始时间，为仿真计算的时间起点；
- **结束历元**：设置仿真任务的结束时间，为仿真计算的时间终点；
- **时间格式下拉框**：可自由选择开始/结束历元的时间基准与显示格式，不同格式适配不同仿真场景，具体说明参见 [历元格式说明](#历元格式说明)。

## 参考历元
参考历元作为场景中所有时间计算的对比基准，其对应的日期和时间将映射为**零历元秒**，是仿真内部时间换算的核心依据。

通过界面下拉框可选择以下5种参考时间模式，适配不同的时间计算需求：
- **参考时分秒**：以`时:分:秒`格式定义参考时间，直观易读，适配常规仿真场景；
- **参考秒**：以秒数形式定义参考时间，秒数自指定历元起算，适配仿真内部高精度时间步长计算；
- **参考UTCG**：以UTC世界协调时格式定义参考时间，为航天任务通用时间基准；
- **参考北京时**：以北京时间（UTC+8）定义参考时间，适配国内航天任务与地面系统交互场景；
- **参考TDT**：以地球动力学时定义参考时间，适配高精度轨道力学计算、星历解算场景。

## 历元格式说明
ATK支持多种主流航天时间格式，不同格式对应不同的时间基准与显示规则，可根据仿真任务类型灵活选择，各格式详细说明如下：

| 格式名称     | 全称/详细说明                                              | 适用场景                     |
| :----------- | :---------------------------------------------------------- | :--------------------------- |
| **UTCG_MM**  | UTC世界协调时，格式为 `YYYY-MM-DD HH:MM:SS`                 | 高精度地面观测、航天任务调度 |
| **UTCG**     | UTC世界协调时，格式为 `DD MMM YYYY HH:MM:SS`                | 常规航天任务时间记录、上报   |
| **BJT**      | 北京时间（UTC+8），显示格式与UTC保持一致                    | 国内地面系统、用户交互场景   |
| **BDT**      | 北斗时（BeiDou Time），与国际原子时（TAI）保持33秒偏差      | 北斗卫星导航系统相关仿真     |
| **BDTG**     | 北斗时（带日期格式），适配北斗系统全流程任务时间标注         | 北斗卫星任务专属时间基准     |
| **GPS**      | GPS时（GPS Time），以1980-01-06为起点，显示为周数+秒数      | GPS卫星轨道、导航仿真        |
| **GPSG**     | GPS时（带日期格式），兼顾GPS时间基准与常规日期显示           | GPS任务综合时间管理          |
| **TDTG**     | 地球动力学时（Terrestrial Dynamic Time），现更名“地球时”    | 高精度轨道力学、星历计算     |
| **JDate**    | 儒略日（Julian Date），以连续计日数表示时间                  | 天文计算、长期轨道预报       |
| **ModJDate** | 简化儒略日（Modified Julian Date），JDate减去2400000.5       | 航天任务长期时间序列分析     |
| **EpSec**    | 历元秒，自用户指定参考历元起算的累计秒数                    | 仿真内部时间步长、实时计算   |
