# 对象插入工具
对象插入工具是ATK中创建**所有场景对象与附加对象**的统一入口，支持按对象类型、所属天体、插入方式灵活配置，满足各类航天任务仿真的快速建模需求。

## 通用操作说明
单击 <img src="./media/01-对象插入工具/image97.png" alt="" no-view /> 图标，弹出 **【插入对象】** 对话框。
支持在当前场景中插入两大类对象：

- **场景对象**：高级接近分析、飞机、区域目标、链路、集群、覆盖定义、地面站、车辆、火箭、导弹、行星、卫星、卫星集群、卫星系统、舰船、恒星、潜艇等
- **附加对象**：天线、品质因子、接收器、传感器、发射器等

## 操作步骤
1. **选择对象类型**：在对象列表中选中需要插入的对象；
2. **选择中心天体**：指定该对象所属的天体（如地球、月球等）；
3. **选择插入方式**：根据对象类型选择对应的添加方式（详见下文）；
4. **完成插入**：单击 <kbd>插入...</kbd> 按钮执行对象创建。

![插入对象](./media/01-对象插入工具/image-20260324160345230-1774510884580-23.png)

## 插入方式说明
系统为不同对象提供多种快速创建方式，支持默认创建、文件导入、数据库加载等：

| 插入方式           | 说明 |
|--------------------|--------------------------------------|
| **插入默认**       | 使用系统默认参数快速创建对象 |
| **从数据库**       | 从内置标准对象数据库中检索并加载对象 |
| **从TLE文件**      | 通过TLE两行星历文件导入卫星 |
| **从外部星历文件** | 通过 `.e` 格式星历文件导入卫星 |
| **轨道生成向导**   | 通过可视化向导创建卫星，支持圆轨道、椭圆轨道等多种类型 |
| **选择国家和地区** | 通过行政区划快速添加区域目标 |
| **从城市数据库**   | 从内置城市库中选择位置创建地面站 |
