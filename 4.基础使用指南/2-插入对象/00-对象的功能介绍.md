# 对象介绍
ATK软件中的各类对象是航天任务仿真的核心组成单元，涵盖航天、航空、地面、天体等多类模型，可按需插入场景完成仿真建模，各类对象的图标、名称及功能描述如下表所示：

| 图标                                             | 对象名称（中文/英文）| 功能描述                                                     |
| :---------------------------------------------- | :--------------------------- | :----------------------------------------------------------- |
| ![](./media/00-对象的功能介绍/update2601-49.png) | 高级接近分析/AdvCat          | 对多颗卫星及双线元素（TLE）集开展接近进程分析                 |
| ![](./media/00-对象的功能介绍/image276.png)      | 飞机/Aircraft                | 模拟飞机沿大弧线（通常在地球表面上空）飞行的特性与运动行为     |
| ![](./media/00-对象的功能介绍/update2601-50.png) | 区域目标/AreaTarget          | 建模地球表面的区域面状目标，用于覆盖、观测等相关分析           |
| ![](./media/00-对象的功能介绍/image274.png)      | 链路/Chain                   | 构建仿真中的数据/信号链路模型，支撑通信、传输相关仿真         |
| ![](./media/00-对象的功能介绍/update2601-51.png) | 集群/Constellation           | 对一组存在关联关系的仿真模型进行统一集群管理                   |
| ![](./media/00-对象的功能介绍/update2601-48.png) | 覆盖定义/CoverageDefinition  | 支持同时对多个区域开展覆盖分析，自定义覆盖分析的规则与范围     |
| ![](./media/00-对象的功能介绍/update2601-57.png) | 地面站/Facility              | 模拟地球表面的地面测控站、观测设施等地面模型                   |
| ![](./media/00-对象的功能介绍/image278.png)      | 车辆/GroundVehicle           | 建模地面各类车辆模型，适配地面移动目标相关仿真                 |
| ![](./media/00-对象的功能介绍/update2601-52.png) | 火箭/LaunchVehicle           | 模拟火箭的发射、飞行等全流程特性与运动模型                     |
| ![](./media/00-对象的功能介绍/update2601-53.png) | 导弹/Missile                 | 建模导弹的飞行、制导等特性与运动行为                           |
| ![](./media/00-对象的功能介绍/image283.png)      | 行星/Planet                  | 构建太阳系各类行星天体模型，支撑深空探测等相关仿真             |
| ![](./media/00-对象的功能介绍/image273.png)      | 卫星/Satellite               | 核心航天对象模型，可自定义轨道、姿态等参数，适配各类卫星仿真   |
| ![](./media/00-对象的功能介绍/image279.png)      | 卫星集群/SatelliteCollection | 对同类型的多颗卫星进行批量建模，单个卫星不单独显示在对象浏览器 |
| ![](./media/00-对象的功能介绍/update2601-54.png) | 卫星系统/SatelliteSystem     | 建模由多颗卫星组成的卫星系统，支撑星座、组网等系统级仿真       |
| ![](./media/00-对象的功能介绍/image277.png)      | 舰船/Ship                    | 模拟海面各类舰船模型，适配海上测控、移动目标相关仿真           |
| ![](./media/00-对象的功能介绍/image281.png)      | 恒星/Star                    | 构建恒星天体模型，支撑天文观测、深空导航等相关仿真             |
| ![](./media/00-对象的功能介绍/image282.png)      | 潜艇/Submarine               | 建模水下潜艇模型，适配水下测控、隐蔽目标相关仿真               |
| ![](./media/00-对象的功能介绍/update2601-55.png) | 天线/Antenna                 | 建模各类天线模型，定义发射/接收的波束、增益等关键参数           |
| ![](./media/00-对象的功能介绍/update2601-56.png) | 品质因子/FigureOfMerit       | 构建品质因子模型，用于评估仿真中观测、通信等任务的效果指标     |
| ![](./media/00-对象的功能介绍/image285.png)      | 接收器/Receiver              | 建模信号/数据接收器模型，定义接收灵敏度、频段等核心参数         |
| ![](./media/00-对象的功能介绍/image284.png)      | 传感器/Sensor                | 建模各类观测、探测传感器模型，适配卫星、飞机等平台的探测仿真   |
| ![](./media/00-对象的功能介绍/image286.png)      | 发射器/Transmitter           | 模拟发射机的工作特性，结合天线与工作环境完成信号/数据发射建模   |
