# 天线

天线属性设置包括：基本属性和约束。

## 基本属性

基本属性包括：定义、指向。

定义设置包含类型以及对应的参数设置，天线类型有:

|  天线类型  |
| :--------: |
|  高斯天线  |
|  全向天线  |
| 抛物面天线 |
|  外部天线  |

指向设置包含指向类型以及对应的参数设置，此外还包含位置偏移量设置，可以设置X轴、Y轴、Z轴的偏移量，单位为米。指向类型有：

|  指向类型   |
| :---------: |
| 方位-高度角 |
|   欧拉角    |
|   四元数    |
|    YPR角    |
