# 恒星

恒星属性主要用于配置天球背景中的恒星目标，包含 **基本属性** 和 **可视化** 两部分。

---

## 基本属性

在 **J2000 惯性系** 下定义恒星的天文参数：

| 选项 | 含义 |
| ---- | ---- |
| 位置赤经 | J2000 惯性系下恒星位置的赤经，单位：deg |
| 位置赤纬 | J2000 惯性系下恒星位置的赤纬，单位：deg |
| 自行赤经 | 赤经方向自行，单位：arcsec/year |
| 自行赤纬 | 赤纬方向自行，单位：arcsec/year |
| 星等 | 恒星星等 |
| 年视差 | 恒星年视差 |

---

## 可视化

- **显示**：是否显示恒星、是否显示标签、颜色设置
- **数据显示**：配置同 [飞机的属性设置](./飞机.md) 三维视图部分，不再赘述。
