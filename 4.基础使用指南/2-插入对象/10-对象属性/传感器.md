# 传感器

传感器属性设置包括：基本属性、二维视图、三维视图和约束。

### 基本属性

定义设置包括敏感器的类型、定义参数设置、相对位置设置。敏感器类型包括:

| 敏感器类型 |
| :--------: |
|  简单圆锥  |
|    矩形    |
|  复杂圆锥  |
|   半功率   |
|    SAR     |

敏感器类型为简单圆锥时，定义参数包括半锥角的设置。

![简单圆锥敏感器定义参数设置界面](./media/传感器/update2601-98.png)

敏感器类型为矩形时，定义参数设置包括垂直半角和水平半角设置。

![矩形敏感器定义参数设置界面](./media/传感器/update2601-99.png)

敏感器类型为复杂圆锥时，定义参数包括半锥角和钟角设置。

![复杂圆锥敏感器定义参数设置界面](./media/传感器/update2601-100.png)

敏感器类型为半功率时，定义参数包括频率和直径设置。

![半功率敏感器定义参数设置界面](./media/传感器/update2601-101.png)

敏感器类型为SAR时，定义参数包括地面仰角、排除角、是否跟踪父对象高度、高度设置。

![SAR敏感器定义参数设置界面](./media/传感器/update2601-102.png)

指向设置中包括指向类型以及类型对应参数的设置。指向类型包括:

| 指向类型 |
| :------: |
| 固定指向 |
|   旋转   |
| 目标定向 |
| 入射高度 |
|   外部   |

### 二维视图

二维视图显示设置包括是否显示、是否填充、显示相交类型选择、颜色及线宽设置。

|     选项     |            含义            |
| :----------: | :------------------------: |
|     显示     | 勾选代表在视图中显示传感器 |
|     填充     |    勾选代表填充指定颜色    |
|     颜色     |          填充颜色          |
| 显示相交类型 |  可选：无、中心天体、地形  |
|     线宽     |          设置线宽          |

### 三维视图

三维视图设置包括：空间投影、脉冲、向量、数据显示。

空间投影设置包含空间投影距离设置以及是否使用距离约束。

|     选项     |           含义           |
| :----------: | :----------------------: |
|   空间投影   | 设置空间投影（单位：km） |
| 使用距离约束 |   勾选代表使用距离约束   |

脉冲设置包括是否显示脉冲，振幅、脉冲长度、频率值，是否反向，重置为缺省值等相关参数设置。

|     选项     |       含义       |
| :----------: | :--------------: |
|     显示     | 勾选代表显示脉冲 |
|     振幅     |     脉冲振幅     |
|   脉冲长度   |     脉冲长度     |
|    频率值    |    脉冲频率值    |
|     反向     | 勾选代表脉冲反向 |
| 重置为缺省值 |   重置所有参数   |

向量和数据显示设置部分详情见[飞机的属性设置](#飞机的属性设置)对应部分，这里不再赘述。
