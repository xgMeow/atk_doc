# 编辑

点击 **【编辑】** 菜单，可展开以下功能工具集。各功能默认置灰不可用，在左侧对象窗口中选中某个对象后，方可进行操作：

![编辑菜单工具集](./media/02-编辑/image-20260324165459861.png)

## 通用操作方式

选中对象后，可通过以下两种方式执行编辑操作：

- **方式一**：点击工具栏中的功能图标
- **方式二**：右键单击对象，在弹出菜单中选择对应操作

![操作示例](./media/02-编辑/image-20260324170255038.png)

## 功能说明

| 功能     | 说明                           |
| -------- | ------------------------------ |
| **复制** | 将选中对象复制到剪贴板         |
| **粘贴** | 将剪贴板中的对象粘贴至当前位置 |
| **删除** | 移除选中的对象                 |
| **属性** | 查看或修改选中对象的属性信息   |
