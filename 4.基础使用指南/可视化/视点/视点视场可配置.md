

# 视点视场配置说明

## 功能概述

**视点视角**（也称为视场角，Field of View，简称FOV）是指从观察者的眼睛（或虚拟相机）出发，能够看到的场景范围所对应的**角度大小**。通过调整视场角，可以改变观察的视野广度，模拟不同焦距的镜头效果——视场角越大，视野越宽，物体显得越小；视场角越小，视野越窄，物体显得越大、越聚焦。本功能允许您自定义视场角度及其单位，以满足不同精度和习惯的需求。

## 操作步骤

1. **进入三维视图配置窗口** 

   在三维视图界面，点击工具栏中的 **属性** 按钮（图标示例：![属性](./media/视点视场可配置/image-20260319093811367.png))，打开三维视图属性配置窗口。

2. **定位到高级设置模块** 

   在配置窗口中，找到 **高级设置** 模块，点开该模块即可看到 **视场** 栏目。

3. **配置视场参数**  
   - **视场角度**：在输入框中填写数值，表示所需的视场角大小。  
   - **视场单位**：从下拉菜单中选择角度的单位。支持的单位包括：  
     - `deg`：度（最常用）  
     - `rad`：弧度  
     - `arcMin`：角分（1度 = 60角分）  
     - `arcSec`：角秒（1角分 = 60角秒）  
     - `revs`：转数（1转 = 360度）  

4. **保存与应用**  
   - 点击 **确定**：保存当前设置并关闭配置窗口。  
   - 点击 **应用**：使设置立即生效，但不关闭窗口，方便继续调整其他参数。

![视点视场配置示例](./media/视点视场可配置/image-20260319095543280.png)

## 单位说明

| 单位符号 | 单位名称 | 换算关系             |
| -------- | -------- | -------------------- |
| deg      | 度       | 1° = 1°              |
| rad      | 弧度     | 1 rad ≈ 57.2958°     |
| arcMin   | 角分     | 1' = 1/60°           |
| arcSec   | 角秒     | 1" = 1/60' = 1/3600° |
| revs     | 转数     | 1 rev = 360°         |
