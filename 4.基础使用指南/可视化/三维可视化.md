# 三维可视化

## 功能介绍

三维可视化功能可有效提升ATK软件的使用体验，用户可在动态3D图形环境中直观感知场景信息。该功能通过展示三维空间、地球天体、地面站、传感器投影、卫星轨道轨迹等三维视图，为复杂任务与轨道几何仿真提供直观可视化效果，三维可视化界面由ATK几何引擎的精确验证数据驱动渲染。

## 使用方法

### 三维视图打开方式

在菜单工具栏依次点击<kbd>视图</kbd> → <kbd>三维视图</kbd>，即可打开三维可视化窗口。

### 三维工具栏

三维窗口工具栏共包含8个功能按钮，分别为属性、快照、三维录屏、局部视点、固定视点、惯性视点、三维视图窗口中心天体、地形管理。

![三维工具栏](./media/三维可视化/update2601-90.png)

1. **属性**

  点击<kbd>属性</kbd>，弹出【三维属性视图】对话框，可在其中设置细节、光照、注释、星体等相关参数。

![三维视图属性页面](./media/三维可视化/update2601-91.png)

2. **快照**

  点击<kbd>快照</kbd>可对当前三维视图进行截图，随后弹出【另存为】对话框，支持自定义保存路径、文件名及文件格式。

3. **三维录屏**

  点击<kbd>三维录屏</kbd>，弹出【三维录屏】窗口，可开启录制功能并配置相关输出参数。

4. **局部视点**

  默认以地球地惯系为主要视点，点击<kbd>局部视点</kbd>可在仿真过程中切换至指定中心天体或配置对象作为主视点。

5. **固定视点**

  点击<kbd>固定视点</kbd>，三维视图将以当前中心天体的固连系作为主视点。

6. **惯性视点**

  点击<kbd>惯性视点</kbd>，三维视图将以当前中心天体的国际天球惯性系作为主视点。

7. **三维视图窗口中心天体**

  点击<kbd>三维视图窗口中心天体</kbd>，可选择指定天体作为三维视图窗口的背景天体。

8. **地形管理**

  点击<kbd>地形管理</kbd>，可对所有中心天体的地形数据执行添加、删除、修改操作。

### 三维视图鼠标操作

| 鼠标按键 | 操作方式 | 功能效果                             |
| -------- | -------- | ------------------------------------ |
| 左键     | 按住拖动 | 以当前中心点为基准，上下左右旋转视角 |
| 中键     | 滚动滚轮 | 对视点中心进行放大、缩小             |
| 右键     | 按住拖动 | 快速放大、缩小视点中心对象           |

### 三维地形全局管理

依次点击菜单工具栏<kbd>视图</kbd> → <kbd>三维视图</kbd>打开三维窗口，再点击<kbd>地形管理</kbd>，打开【三维地形全局管理】界面。

![三维地形全局管理界面](./media/三维可视化/GlobeManager(2).jpg)

> [!NOTE]
>
> 支持数据格式
>
> - 高程图层与影像图层均支持 TIFF 数据（`.tif`）
> - 支持 TMS 数据（`.xml`）
> - 支持 ATK 专有 TDB 数据（`.tdb`）

#### 地球基础影像切换

1. 勾选【三维地形全局管理】界面中地球的`Earth_img_Base_TDB`图层，可显示高清TDB格式地球影像纹理。

![TDB格式地球影像纹理](./media/三维可视化/GlobeManager(3).jpg)

2. 取消勾选`Earth_img_Base_TDB`图层，将关闭TDB格式影像，仅显示下一层TIFF格式基础地球影像纹理。

![TIFF格式地球影像纹理](./media/三维可视化/GlobeManager(4).jpg)

#### 图层添加步骤

1. 在【三维地形全局管理】界面中选择**地球**选项；
2. 点击<kbd>添加</kbd>按钮，弹出【地形添加】对话框；

![添加图层步骤](./media/三维可视化/GlobeManager(5).jpg)

3. 在对话框中选择图层类型：
   - 需添加影像纹理 → 选择<kbd>影像</kbd>
   - 需添加地形高程 → 选择<kbd>高程</kbd>

![选择图层类型对话框](./media/三维可视化/GlobeManager(6).jpg)

4. 在【文件选择】对话框中选择对应数据格式：
   - TIFF格式数据 → 选择`.tif`
   - TMS格式数据 → 选择`.xml`
   - TDB格式数据 → 选择`.tdb`

![图层具体的后缀格式选择对话框](./media/三维可视化/GlobeManager(7).jpg)

![选择xml格式](./media/三维可视化/GlobeManager(8).jpg)

> [!NOTE]
>
> **图层说明**
>
> - 高程图层：控制三维地形的高低起伏形态
> - 影像图层：为地形表面覆盖真实影像纹理

> [!TIP]
>
> **图层显示优先级**
>
> - 左侧【三维地形全局管理】界面中，图层排列越靠下，在三维场景中显示层级越靠上
> - 示例：19级高清影像图层位于13级图层下方，场景中会覆盖在13级图层之上

![高程图层和影像图层](./media/三维可视化/GlobeManager(9).jpg)

#### 图层显示控制

取消勾选高程图层，对应区域地形将从真实起伏地形切换为纯平面地形。

![高程图层取消勾选](./media/三维可视化/GlobeManager(10).jpg)

#### 图层删除操作

1. 在【三维地形全局管理】界面选中目标图层；
2. 点击<kbd>删除</kbd>按钮，即可将该图层从三维场景中彻底移除。

![GlobeManager(11)](./media/三维可视化/GlobeManager11.jpg)
