
# 地球数据

地球数据用于设置地球方向参数（Earth Orientation Parameters，EOP），这些参数描述了地球自转轴相对于空间固定参考系的变化，对于高精度轨道计算和地面目标定位至关重要。

![地球数据配置界面](./media/02-地球数据/image-20260325171748501.png)

## 地球数据设置项说明

| 设置项       | 说明                                       |
| ------------ | ------------------------------------------ |
| **开始时间** | 地球方向参数数据的起始历元，需与场景[仿真时间](./01-仿真时间.md)的时间范围匹配。 |
| **结束时间** | 地球方向参数数据的结束历元，需与场景[仿真时间](./01-仿真时间.md)的时间范围匹配。 |
| **数据文件** | 选择地球方向参数数据文件，支持 `.dat` 格式，文件需包含完整的EOP参数数据。 |

> 地球数据的时间范围需与[仿真时间](./01-仿真时间.md)保持一致，否则会影响轨道计算与目标定位的精度。
>
> 场景属性相关总配置可参考：[场景属性配置](../README.md)
