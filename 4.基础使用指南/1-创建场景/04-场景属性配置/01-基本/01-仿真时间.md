# 仿真时间

仿真时间用于定义场景的仿真时间和参考历元。

![仿真时间](./media/01-仿真时间/image-20260325113145980.png)

## 仿真区间
仿真区间用于设定仿真的起始历元和结束历元，即分析时段的总跨度。

- **开始历元**：设置仿真任务的起始时间
- **结束历元**：设置仿真任务的结束时间
- **时间格式下拉框**：用于选择开始/结束历元的时间基准与表示格式，具体参见 [历元格式说明](#历元格式说明)

## 参考历元
参考历元用作场景中所有其他时间的对比基准，历元的日期和时间对应零历元秒。

通过下拉框可选择以下参考时间模式：

- **参考时分秒**：以时分秒格式定义参考时间
- **参考秒**：以秒数形式定义参考时间（自指定历元起算）
- **参考UTCG**：以 UTC 格式定义参考时间
- **参考北京时**：以北京时间（UTC+8）定义参考时间
- **参考TDT**：以地球动力学时定义参考时间

## 历元格式说明

| 格式名称     | 全称/说明                                                  | 适用场景                   |
| ------------ | ---------------------------------------------------------- | -------------------------- |
| **UTCG_MM**  | UTC 格式，格式为 `YYYY-MM-DD HH:MM:SS`                     | 高精度地面观测、任务调度   |
| **UTCG**     | UTC 格式，格式为 `DD MMM YYYY HH:MM:SS`                    | 常规航天任务时间记录       |
| **BJT**      | 北京时间（UTC+8），格式同 UTC                              | 国内地面系统、用户交互场景 |
| **BDT**      | 北斗时（BeiDou Time），与 TAI 保持 33 秒偏差               | 北斗卫星导航系统相关仿真   |
| **BDTG**     | 北斗时格式（带日期）                                       | 北斗任务时间基准           |
| **GPS**      | GPS 时（GPS Time），自 1980-01-06 起算的周数+秒数          | GPS 卫星轨道、导航仿真     |
| **GPSG**     | GPS 时格式（带日期）                                       | GPS 任务时间基准           |
| **TDTG**     | 地球动力学时（Terrestrial Dynamic Time），现改名为“地球时” | 轨道力学、星历计算         |
| **JDate**    | 儒略日（Julian Date），连续计日数                          | 天文计算、长期轨道预报     |
| **ModJDate** | 简化儒略日（Modified Julian Date），JDate 减去 2400000.5   | 航天任务长期时间序列分析   |
| **EpSec**    | 自指定历元起算的秒数                                       | 仿真内部时间步长计算       |

> 场景时间相关配置可在 [场景属性配置](../README.md) 中查看更多选项。
