## 案例想定

自由返回轨道是从地球出发，在中途不施加机动的情况下，能够安全返回地球的轨道，包括地月转移和月地返回两部分。此类轨道安全性较高，常被用于载人月球探测任务中。本案例将介绍航天器从近地轨道出发，到达高度为100km的近月点，然后返回至高度为50km的近地点，并满足轨道倾角为43度的自由返回过程。

本案例介绍基于自由返回轨道的地月转移部分，施加轨道机动进入100km的环月轨道的设计过程。

## 任务控制序列段说明

为了设计基于自由返回轨道的地月转移过程，我们需要构建以下任务序列：

一个 **瞄准序列段**：其中包含一个初始段、一个机动段和两个预报段得到航天器的自由返回轨道。

## 创建任务场景

1. 运行ATK.exe，点击 <kbd>新建一个想定文件</kbd> 新建一个想定“exLunarFreeReturn”。

2. 设置仿真时间：在【ATK：新建想定向导】对话框中设置【开始历元】为2028-06-24 16:24:55.000，【结束历元】为2028-06-30 02:00:00.000。

| 开始历元 | 结束历元 |
| ----------------------- | ----------------------- |
| 2028-06-24 16:24:55.000 | 2028-06-30 02:00:00.000 |

3. 点击 <kbd>确定</kbd> 完成场景建立。

## 创建对象

1. 创建及编辑卫星对象

    - 点击工具栏【开始】中的 <kbd>插入</kbd><img src="./media/3.4.4基于自由返回轨道的地月转移/image97.png" alt="插入" no-view /> 创建卫星对象；

    - 选择【想定对象】—【卫星】![卫星](./media/3.4.4基于自由返回轨道的地月转移/image129.png)，【选择插入方式】—【插入默认类型】，点击 <kbd>插入…</kbd>，点击 <kbd>关闭</kbd>；

    - 在左侧【对象】页面上，右键单击卫星“卫星1”，选择 <kbd>重命名</kbd><img src="./media/3.4.4基于自由返回轨道的地月转移/image170.png" alt="image170" no-view />，将其命名为“exLunarFreeReturn”；

    - 在左侧【对象】页面上，右键单击卫星“exLunarFreeReturn”，选择【属性】，出现卫星参数设置界面，选择【轨道预报器】—【机动规划】。

## 设计自由返回轨道

1. 定义瞄准序列段
    - 删除默认初始段

    - 点击 <kbd>新增</kbd><img src="./media/3.4.4基于自由返回轨道的地月转移/image57.png" alt="新增" no-view /> 添加一个“瞄准序列段”<img src="./media/3.4.4基于自由返回轨道的地月转移/image471.jpeg" alt="瞄准序列段" no-view />，命名为“地月自由返回轨道规划”；

2. 定义初始段

    - “地月自由返回轨道规划”嵌入一个“初始段”![初始段图标](./media/3.4.4基于自由返回轨道的地月转移/image401.jpeg)，命名为“初始状态”。设置【轨道历元（UTCG）】—“24 Jun 2028 16:25:59.184”。选择【坐标系】—【Earth J2000】，【坐标类型】—【轨道根数】，轨道根数设置如下表:

    | 参数 | 数值 |
    | ---- | ---- |
    | 半长轴 | 6548151m |
    | 偏心率 | 0 |
    | 轨道倾角 | 21° |
    | 升交点赤经（RAAN） | 149° |
    | 近拱点角距 | 185° |
    | 真近点角 | 14° |

3. 定义机动段

    - 点击 <kbd>新增</kbd><img src="./media/3.4.4基于自由返回轨道的地月转移/image57.png" alt="新增" no-view /> 在“初始段”后插入一个“机动段”<img src="./media/3.4.4基于自由返回轨道的地月转移/image481.jpeg" alt="机动段" no-view />，命名为“地月转移机动”。

    - 选择【机动类型】—【脉冲】，【推力坐标轴】—【VNC】，坐标类型选择【直角坐标】。
    - 设置【速度增量 Vx】—“3160m/s”，【速度增量 Vy】—“0m/s”，【速度增量 Vz】—“0m/s”。

2. 定义预报段

    - 点击 <kbd>新增</kbd><img src="./media/3.4.4基于自由返回轨道的地月转移/image57.png" alt="新增" no-view /> 在“地月转移机动”<img src="./media/3.4.4基于自由返回轨道的地月转移/image481.jpeg" alt="机动段" no-view /> 后插入一个“预报段”<img src="./media/3.4.4基于自由返回轨道的地月转移/image421.jpeg" alt="预报段" no-view />，命名为“预报到近月点”。

    - 点击【轨道预报】—<kbd>高级设置…</kbd>，选择【中心天体】—【Earth】，【引力】中选择【引力场模型】—【WGS84】，【次数】—“20”，【阶数】—“20”，不勾选【大气阻力摄动】、勾选【太阳光压摄动】，勾选【三体摄动】—【太阳】、【月球】，并选择【点质量】模型；点击 <kbd>确定</kbd>。

    - 在【停止条件】中，点击 <kbd>新建</kbd><img src="./media/3.4.4基于自由返回轨道的地月转移/image44.png" alt="新建" no-view /> 图标，选择【近拱点】【CAsStopPeriapsis】作为停止条件，【中心天体】设置为“Moon”，【重复次数】设置为“1”。

3. 定义预报段

    - 点击 <kbd>新增</kbd><img src="./media/3.4.4基于自由返回轨道的地月转移/image57.png" alt="新增" no-view /> 在“预报到近月点”<img src="./media/3.4.4基于自由返回轨道的地月转移/image421.jpeg" alt="预报段" no-view /> 后插入一个“预报段”<img src="./media/3.4.4基于自由返回轨道的地月转移/image421.jpeg" alt="预报段" no-view />，命名为“月地返回”

    - 点击【轨道预报】—<kbd>高级设置…</kbd>，设置项与上一步的设置一样。

    - 在【停止条件】中，点击 <kbd>新建</kbd><img src="./media/3.4.4基于自由返回轨道的地月转移/image44.png" alt="新建" no-view /> 图标，选择【历元时刻】【CAsStopEpoch】作为停止条件，【触发值】设置为“2028-06-30 02:01:04.184000”；
    - 新建【近拱点】【CAsStopPeriapsis】作为停止条件，【中心天体】设置为“Earth”，【重复次数】设置为“1”。

4. 选择变量

    - 在“初始状态”段中，点击【轨道历元】文字段后方![图标](./media/3.4.4基于自由返回轨道的地月转移/image135.png)、【升交点赤经】文字段后方![图标](./media/3.4.4基于自由返回轨道的地月转移/image135.png)，将其勾选为 **设计变量**![设计变量](./media/3.4.4基于自由返回轨道的地月转移/image136.png)。

    - 在“地月转移机动”段中，点击【速度增量 Vx】文字段后方![图标](./media/3.4.4基于自由返回轨道的地月转移/image135.png)，将其勾选为 **设计变量**![设计变量](./media/3.4.4基于自由返回轨道的地月转移/image136.png)。

    - 右键点击“预报到近月点”段，选择【约束配置…】，双击选择【开普勒根数】—【近拱点高度】作为目标变量，【中心天体】设置为“Moon”，点击 <kbd>确定</kbd>。

    - 右键点击“月地返回”段，选择【约束配置…】，双击选择【开普勒根数】—【近拱点高度】和【倾角】作为目标变量，【中心天体】均设置为“Earth”，点击 <kbd>确定</kbd>。

5. 设置瞄准器

    - 选中“地月自由返回轨道规划”，在【配置】中，点击 <kbd>新建</kbd><img src="./media/3.4.4基于自由返回轨道的地月转移/image44.png" alt="新建" no-view /> 图标，选择【微分修正】；若默认已有【微分修正】，则无需新建。

    - 双击【微分修正】图框，进入瞄准器设置界面。分别点击【控制变量】和【约束】中【使用】栏下的方框勾选使用的控制变量和约束。

| 控制变量 | 约束 |
| ---- | ---- |
| UTC | CStateCalcAltitudeOfPeriapsis |
| RAAN | CStateCalcAltitudeOfPeriapsis |
| ImpulseX | CStateCalcInclination |

    - 【控制变量】保持默认选项。

    - 【约束】—【CStateCalcAltitudeOfPeriapsis-瞄准序列段.预报到近月点】—【期望值】一栏中填写为 100000m，收敛误差为 100m

    - 【约束】—【CStateCalcAltitudeOfPeriapsis-瞄准序列段.月地返回】的近地点高度的期望值为 50000m，收敛误差为 100m

    - 【约束】—【CStateCalcInclination-瞄准序列段.月地返回】的轨道倾角的期望值为 43 度，收敛误差为 0.1 度。

    - 【摄动量】、【最大步长】等参数可选择为默认参数；

    - 设置完毕后点击 <kbd>确定</kbd>，然后再进入瞄准器设置界面即可看到用户设置后的结果。
