# 运行环境需求

## 硬件配置

| 硬件 | 最低配置 | 推荐配置 |
|------|---------|---------|
| 处理器 | Intel 酷睿系列 | Intel i5 或更高 |
| CPU 频率 | 2 GHz 及以上 | 3 GHz 及以上 |
| 内存 | 3 GB 及以上 | 8 GB 及以上 |
| 硬盘空间 | 3 GB 可用空间 | 10 GB 可用空间 |
| 显卡 | NVIDIA GeForce GT 1030 及以上 | NVIDIA GTX 1060 或更高 |
| 显示器 | 支持 1920×1080 分辨率 | 27 英寸，1920×1080（软件默认适配此分辨率） |

> ⚠️ **高分屏注意**：ATK 默认适配 27 英寸 1920×1080 分辨率。高分屏笔记本可能出现界面缩放异常，请参考[安装后常见问题 → 高分屏显示异常](04-安装后常见问题/02-高分屏显示异常.md)调整设置。

## 操作系统

### Windows 系统

- Windows 11
- Windows 10
- Windows 8
- Windows 7 Service Pack 1（SP1）及以上
- Windows Server 2012
- Windows Server 2008 R2

### 麒麟操作系统（Linux）

- 麒麟操作系统 V10 及以上
- 支持 x86_64 和 arm64 架构

> 请根据 CPU 架构选择对应安装包（x86_64 或 arm64），架构不匹配将导致软件无法启动。

## 软件依赖

- **Windows 版**：无额外依赖，绿色免安装，解压即用
- **麒麟 deb 包**：需系统已安装 `dpkg` 包管理工具（麒麟系统默认已安装）
- **麒麟压缩包**：无额外依赖，解压后赋予可执行权限即可运行
