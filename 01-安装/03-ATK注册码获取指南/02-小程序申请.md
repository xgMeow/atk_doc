# 小程序申请

## 申请流程

### 1. 扫码进入小程序

打开微信扫描下方二维码，进入 ATK 注册码申请小程序。

![ATK注册码自助计算小程序](./media/小程序申请/image-20260330091449542.png)

::: tip 备用方式
若二维码无法识别，可在微信搜索小程序 **"AerospaceToolKit"** 直接进入。
:::

### 2. 填写申请信息

扫码进入表单页面后，按要求填写以下信息：

![填写表单](./media/小程序申请/image-20260422185754279.png)

::: warning 重要提醒
请仔细核对机器码，**输入错误将导致注册码无法使用**。
:::

### 3. 获取注册码

确认信息无误后，点击 **申请注册码**。申请完成后，可在页面中查看该微信账号下所有已申请生成的注册码。

![我的注册码](./media/小程序申请/image-20260422190807402.png)

::: tip 保存建议
建议点击整体复制按钮直接复制，避免手动输入错误。未来还可以通过小程序查看已申请的注册码。
:::
