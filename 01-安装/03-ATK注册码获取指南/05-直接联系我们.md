# 直接联系我们

## 联系方式

如需人工协助，可添加工作人员微信：

> **微信号**：`LXKTATK`

![工作人员微信二维码](./media/直接联系我们/image-20260422194212981.png)

扫码或搜索微信号添加好友：

![添加好友](./media/直接联系我们/image-20260422193759905.png)

::: tip 验证信息
添加好友时建议备注 **"ATK注册码申请"**，方便工作人员快速处理。
:::

## 申请步骤

添加微信后，请发送以下信息：

1. **机器码**：注册机界面显示的 16 位字符
2. **单位名称**：您所在的工作单位全称
3. **联系人**：申请人姓名
4. **联系电话**：可联系到您的手机号码

::: warning 重要提醒
请仔细核对机器码，**输入错误将导致注册码无法使用**。建议直接从注册机界面复制粘贴发送。
:::

## 等待回复

工作人员将尽快通过微信发送注册码（工作时间内）。

::: warning 注意
- 建议工作日 8:00-17:30 联系，非工作时间可能延迟回复
- 若超过 2 个工作日未收到回复，请检查微信消息是否被屏蔽，或尝试 [邮件申请](./03-邮件申请.md)
:::
