# 高分屏显示异常

> **适用场景**：高分屏笔记本（分辨率高于 1920×1080）、4K 显示器、Windows 缩放比例大于 100% 的设备

::: tip 如何判断是否需要调整
若打开 ATK 后出现以下现象，请按本文档调整：
- 界面文字或图标显示模糊
- 按钮重叠或显示不全
- 窗口比例异常，部分内容被截断
:::

## 调整步骤

1. 找到桌面 ATK 快捷方式，右键单击，选择 <kbd>属性</kbd>；

2. 在弹出的【属性】对话框中，切换至「兼容性」选项卡；

3. 找到并点击 <kbd>更改高DPI设置</kbd>；

4. 在【高DPI设置】对话框中，勾选 **替代高DPI缩放行为**；

5. 在「缩放执行」下拉菜单中，将默认「应用程序」改为 **系统** 或 **系统增强**；

6. 依次点击 <kbd>确定</kbd> 保存设置，**重启 ATK 软件** 生效。

![ATK 显示兼容性设置](./media/界面缩放异常/image-1-1776847027471-8.png)

::: warning 注意
- 修改后必须**重启 ATK** 才能生效，仅关闭窗口再打开无效
- 若使用绿色版，建议修改 ATK.exe 的属性；若使用 deb 包安装的快捷方式，建议修改快捷方式属性
:::

## 若仍有问题

若按上述步骤调整后问题仍未解决，请尝试：

1. 将 Windows 显示缩放比例临时调整为 **100%**（系统设置 → 显示 → 缩放与布局）；
2. 重启 ATK 查看是否正常；
3. 若正常，可尝试逐步调高缩放比例，找到兼顾清晰度与可用性的平衡点；
4. 若均无效，请 [直接联系我们](../03-ATK注册码获取指南/05-直接联系我们.md) 获取技术支持。
