# 软件无法启动如何排查

本文档介绍 ATK 软件无法启动时的常见原因及排查方法。

## Windows 系统

### 1. 未注册导致无法启动

首次使用 ATK 需完成注册激活。若软件未弹出注册界面，请检查：

- 确认是否已获取注册码（参考 [ATK 注册码获取指南](../03-ATK注册码获取指南/README.md)）
- 检查软件是否被防火墙或安全软件拦截
- 尝试以**管理员身份**运行 `ATK.exe`

### 2. 显卡驱动不匹配导致闪退

打开软件后立即闪退，无法进入界面，这种情况很大概率是因为**显卡驱动不匹配**导致的。系统默认提供的 OpenGL 版本较低，无法支持二维、三维视图打开所需的库版本。

#### 验证方法

1. 找到 ATK 安装目录下的配置文件：

   ```
   ATK-v4.0.0-windows-x64\ATK-4.0.0\config\systemConfig.ini
   ```

2. 使用文本编辑器（如记事本）打开该文件；

3. 找到 `[OPEN SETTING]` 段落，将 `Open3D=true` 改为 `Open3D=false`：

   ```ini
   [OPEN SETTING]
   Open3D=false
   ```

4. 保存文件后重新启动 ATK。

> 💡 若软件可以正常打开，则证明故障原因为**显卡驱动问题**。

#### 解决方案

更新显卡驱动至最新版本：
- **NVIDIA 显卡**：访问 [NVIDIA 官网](https://www.nvidia.cn/drivers/) 下载对应型号驱动
- **其他显卡**：前往显卡厂商官网获取最新驱动

此问题十分常见，更新驱动后通常可解决。

## 麒麟系统

### 1. 未注册导致无法启动

首次使用 ATK 需完成注册激活。若软件未弹出注册界面，请检查：

- 确认是否已获取注册码（参考 [ATK 注册码获取指南](../03-ATK注册码获取指南/README.md)）
- 检查软件是否被系统安全策略拦截
- 确认已正确执行 `chmod +x` 赋予可执行权限

### 2. 显卡驱动不匹配导致闪退

打开软件后立即闪退，无法进入界面，这种情况很大概率是因为**显卡驱动不匹配**导致的。系统默认提供的 OpenGL 版本较低，无法支持二维、三维视图打开所需的库版本。

#### 验证方法

1. 找到 ATK 安装目录下的配置文件：

   ```
   /opt/ATK/ATK-v4.0.0-kylin-x86_64/ATK-4.0.0/config/systemConfig.ini
   ```

   > ⚠️ 注意：实际路径可能因版本号不同而有所变化，请根据您的安装版本调整。

2. 使用 `vim` 或其他文本编辑器打开该文件：

   ```bash
   sudo vim /opt/ATK/ATK-v4.0.0-kylin-x86_64/ATK-4.0.0/config/systemConfig.ini
   ```

3. 找到 `[OPEN SETTING]` 段落，将 `Open3D=true` 改为 `Open3D=false`：

   ```ini
   [OPEN SETTING]
   Open3D=false
   ```

4. 保存文件后重新启动 ATK。

> 💡 若软件可以正常打开，则证明故障原因为**显卡驱动问题**。

#### 解决方案

更新显卡驱动至最新版本：
- 麒麟系统可通过**系统设置 → 显示 → 显卡驱动**检查更新
- 或访问显卡厂商官网（如 NVIDIA、AMD、Intel）下载 Linux 版驱动
- 也可使用系统包管理器更新：`sudo apt update && sudo apt upgrade`

此问题十分常见，更新驱动后通常可解决。
