# 压缩包

## 安装

> 压缩包后缀：`tar.gz` / `zip` / `rar` 等

### 1. 前置条件

- 操作系统：麒麟操作系统 V10 及以上
- CPU 架构：x86_64 或 arm64

::: warning 重要提醒
架构不匹配将导致软件无法启动。请通过 `uname -m` 命令确认系统架构，再下载对应安装包。
:::

### 2. 解压安装包

将压缩包解压至任意目录。

::: tip 建议
建议解压至用户主目录下的独立文件夹，例如 `~/ATK`（目录名可自定义），避免路径中包含中文、空格及特殊符号。
:::

解压后目录结构如下：

    <解压目录>/               # 主程序目录
    ├── ATK.sh                # 启动脚本
    ├── AstroData/            # 天体数据目录
    ├── config/               # 配置文件目录
    ├── Help/                 # 帮助文档目录
    ├── IntegratingWithATK/   # 外部集成接口目录
    ├── licenses/             # 开源许可证目录
    ├── platforms/            # 平台插件目录
    ├── translations/         # 界面翻译文件目录
    └── ...                   # 其他运行依赖文件

#### 重要目录说明

| 目录 | 说明 |
|------|------|
| `config/` | 存放软件配置文件，包含界面布局、用户设置等 |
| `Help/` | 帮助文档目录，内置软件使用说明与示例（详见下方） |
| `IntegratingWithATK/` | 外部系统集成相关文件，供二次开发或接口调用使用 |
| `translations/` | 多语言翻译文件，支持中英文界面切换 |
| `licenses/` | 第三方开源组件的许可证文件 |

#### Help 目录说明

`Help` 目录存放软件内置帮助文档及相关资源，结构如下：

    Help/
    ├── Examples/        # 示例文件目录，包含软件功能演示案例
    ├── html/            # HTML 格式离线版帮助文档
    └── VC运行库/        # Visual C++ 运行库依赖（Windows 环境所需）

> 其中 `Examples/` 目录内置了多个典型场景的示例文件，用户可直接打开参考学习；`html/` 目录包含软件帮助手册的网页版本。

### 3. 启动软件

1. 打开终端，使用 `cd` 命令进入解压后的主程序目录：

        cd <解压目录>

2. 执行启动命令：

        ./ATK.sh

3. 若提示无运行权限，先赋予可执行权限：

        sudo chmod +x ./ATK ./ATK.sh

   赋予权限后，重新执行 `./ATK.sh`。

### 4. 软件注册

ATK 采用 **免费使用模式**，但**首次使用必须完成注册**，否则功能将无法正常使用。

::: warning 重要提醒
注册前请确保已获取注册码。如尚未获取，请参考 [ATK 注册码获取指南](../../03-ATK注册码获取指南/README.md)。
:::

1. 执行 `./ATK.sh` 启动软件，自动弹出【ATK使用协议】对话框；

2. 仔细阅读协议后，勾选 **我已经认真阅读该协议**，点击 <kbd>同意</kbd>，进入【ATK注册机】界面；

3. 注册机界面中**机器码**将自动生成，无需手动修改；

4. 在注册码输入框填写获取到的注册码，点击 <kbd>注册</kbd> 完成激活。

## 卸载

压缩包方式安装的 ATK 无需执行卸载命令，直接删除解压目录即可清理。

::: warning 注意
删除前请确保已备份重要数据文件（如想定文件、报告等）。软件运行期间产生的数据文件默认存放于 **用户文档目录下的 ATK 文件夹中**（路径如 `~/文档/ATK/` 或 `~/Documents/ATK/`，具体取决于系统语言设置），不在安装目录内。
:::
