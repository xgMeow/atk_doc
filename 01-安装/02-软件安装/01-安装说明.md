# 安装说明

请根据计算机 CPU 架构（`x86_64` / `arm64`）下载对应安装包。

::: warning 重要提醒
架构不匹配将导致软件无法启动！请务必确认下载的安装包与您的 CPU 架构一致。
:::

> 💡 如何查看 CPU 架构：
> - **Windows**：命令行输入 `echo %PROCESSOR_ARCHITECTURE%`，输出 `AMD64` 即 x86_64
> - **麒麟系统**：终端输入 `uname -m`，输出 `x86_64` 或 `aarch64`（即 arm64）

## 下载安装包

前往 [ATK 官网下载页面](https://www.osredm.com/atknudt/atk/about#/) 获取对应版本的安装包。

下载完成后，请根据您的操作系统选择安装指南：

- [Windows 系统安装（绿色版）](./Windows系统安装（绿色版）.md)
- [麒麟系统安装 — 压缩包](./麒麟系统安装/压缩包.md)
- [麒麟系统安装 — deb 包](./麒麟系统安装/deb包.md)

::: tip 多版本共存说明
如果使用麒麟压缩包或 Windows 绿色版安装，不同版本的 ATK 不会互相覆盖。如需清理旧版本，请手动删除对应文件。
:::
