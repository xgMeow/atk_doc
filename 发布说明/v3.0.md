# v3.0 发布说明

## [3.0.0] - 2024-11-11

### 🚀 新增 (Added)

#### 内核
- 轨道机动微分修正算法进一步提升，预报器算法增加 HPOP-v2 选项
- 卫星系统对象、火箭对象、卫星集群对象
- 卫星对象新增 TOD、MOD 等坐标系
- 机动规划丰富坐标系统
- 点对象的状态、姿态、协方差接口
- 矢量几何

#### 界面
- 矢量几何界面
- 再入回收工具
- 外部数据导入星历文件工具
- 深色皮肤

#### 可视化
- 三维展示效果增强，增加 CBI、黄道面、赤道面、射线等效果展示
- 三维局部视点增加点与坐标选择、OverLay 对象
- 三维对象增加光照调节功能
- 三维对象点大小设置功能
- 卫星系统以点形式展示效果

#### 二次开发
- 支持 Python 语言的二次开发
- 支持 MATLAB 组件模式二次开发（通过 Java 调用 ATK，支持 Java 类型上下行转换）

### 🔧 改进 (Changed)

#### 内核
- 轨道生成向导
- 机动规划的微分修正求解器
- 机动规划段的概要报告：参考坐标系可任意选择，增加部分概要数据

#### 界面
- 插入对象对话框增加中心天体选择
- 发射机对象、接收机对象简单模型算法对应界面修改
- 二维工具栏增设横纵比 2:1 按钮
- 卫星 HPOP、三体引力与机动规划三体引力模型算法完善
- ATK 程序重启逻辑调整

#### 可视化
- 二维增加 Miller 和 Sinusoidal 投影方式
- 二维优化卫星系统绘制
- 可见性覆盖模块多对多异步并行计算功能相关界面功能改进
- 三维优化地面站、地面车辆等局部视点显示效果，实现以飞机、地面站、船等实体为中心的全局坐标轴向量绘制

### 🛠️ 修复 (Fixed)

- 局部视点部分区域天体不可见的问题
