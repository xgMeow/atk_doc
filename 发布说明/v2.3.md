# v2.3 发布说明

## [2.3.0] - 2024-07-23

### 🚀 新增 (Added)

- 二三维视图支持切换中心天体
- 二三维窗口名称及属性页名称设置计数和中心天体
- 三维增加仿真对象光照效果、窗口背景颜色、时间属性显示等属性设置
- 行星星体绘制，行星对象轨迹颜色等可配置
- 界面深色皮肤
- 再入回收工具模块
- Component 模式新增支持 Java 语言接口
- Connect 实现支持 Python 调用，支持函数与变量、富文本、二维曲线图、读文件 load、整理返回二维数组（支持 txt、csv）

### 🔧 改进 (Changed)

- 固定系、惯性系轨迹统一到轨道系统中
- 卫星、飞机等空中目标局部视点数据，采用天体操作器实现
- 界面优化 dock 全屏和取消全屏效果，优化可视化窗口 dock 全屏和窗口模式切换
- 可见性覆盖模块多对多异步并行计算功能相关界面功能改进

### 🛠️ 修复 (Fixed)

- 修复界面若干已知问题
- 优化 ATK 选中操作不友好问题
