# v3.0.0 发布说明


下载链接：<https://smsat.space/#/download>

## 内核

- 新增：轨道机动微分修正算法进一步提升，预报器算法增加HPOP-v2选项
- 新增：卫星系统对象、火箭对象、卫星集群对象
- 新增：卫星对象新增TOD、MOD等坐标系
- 新增：机动规划丰富坐标系统
- 新增：实现点对象的状态、姿态、协方差接口
- 新增：矢量几何
- 改进：不同天体坐标系下的可视化位置速度数据进行缓存
- 改进：力模型的地球引力场的引力场阶次显示对应不上的bug
- 改进：解决局部视点部分区域天体不可见的bug

## 界面

- 新增：矢量几何界面
- 新增：再入回收工具
- 新增：外部数据导入星历文件工具
- 新增：更新了深色皮肤


## 可视化

- 新增：三维展示效果增强，增加了CBI、黄道面、赤道面、射线等效果展示
- 新增：三维局部视点增加点与坐标选择，OverLay对象
- 新增：三维对象增加了光照调节功能
- 新增：三维增加三维对象点大小设置功能，
- 新增：三维效果增加卫星系统以点形式展示效果。
- 改进：ATK程序重启逻辑调整
- 改进：卫星HPOP、三体引力与机动规划三体引力模型算法完善
- 改进：插入对象对话框增加中心天体选择，发射机对象、接收机对象简单模型算法对应界面修改、二维工具栏增设横纵比2:1按钮
- 改进：二维增加Miller和Sinusoidal投影方式、二维优化卫星系统绘制、可见性覆盖模块多对多异步并行计算功能相关界面功能改进
- 改进：三维优化地面站、地面车俩等局部视点显示效果，实现以飞机、地面站、船等实体为中心的全局的坐标轴向量绘制

## 二次开发

- 新增：支持python语言的二次开发
- 新增：支持matlab组件模式二次开发（通过java调用ATK，支持java类型上下行转换）
