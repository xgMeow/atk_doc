## [2.1.0.0] - 2024-03-29

### 🚀 新增 (Added)

- about 窗口支持显示每次版本发布修改的功能点信息
- 三维增加属性页，可修改背景颜色和显示仿真时间
- 二维视图增加米勒投影、摩尔维特投影和正弦投影，增加时间显示框
- Connect 模式增加 RPO 参数设置与获取功能
- Connect 模式增加 Lambert 段操控功能
- Connect 模式增加卫星集群操控功能
- Component 模式 Python 实现（依赖目录 `IntegratingWithATK/component/Python`）
- Connect 模式 Python 实现（依赖目录 `IntegratingWithATK/connect/Python`）
- 初始段坐标系属性
- VC 运行库安装程序

### 🔧 改进 (Changed)

- 优化界面显示，同界面表格与其他编辑区域添加分离器隔离
- 轨道生成向导星下点界面中调整纬度设置与轨道倾角的联动响应
- 当对象节点颜色按钮打开颜色设置窗口并编辑 Alpha 通道后，点击颜色设置窗口以外区域无法隐藏窗口的问题
- 对象重命名空格规范：不允许单独一个空格，但名字内可组合空格
- 卫星属性界面的力模型弹出窗口中大气阻力摄动模型选项，修改为与机动规划预报段轨道预报高级设置窗口中的模型选项一致
- 更新 component 文件夹
- 更新二次开发使用手册
- 添加 Connect 模式场景、卫星、卫星集群属性介绍
- 添加 Connect 模式机动规划段属性介绍
- 添加 Component 模式卫星机动规划类接口介绍
- 更新案例

### 🛠️ 修复 (Fixed)

- 主界面下拉框样式不生效，点击选择后编辑框内空白的问题
- 碰撞规避模块翻译错误问题
- 可见性覆盖模块因报告窗口添加 dock 容器初始化导致首次打开模块主界面卡顿的问题
- 传感器对传感器可见性计算崩溃问题
- Windows 系统显示百分比设置导致字体大小不合适的问题
- 右键卫星集群节点打开可见性崩溃问题
