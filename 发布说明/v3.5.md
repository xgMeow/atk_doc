# v3.5 发布说明

## [3.5.2] - 2025-04-16

### 🚀 新增 (Added)

- 机动规划支持自定义脚本的计算结果
- 机动规划增加继承关系、继承状态、传递状态
- 时空几何新增一些预定义元素
- ATK 集成新增 Console Notebook
- 高级接近分析增加自定义报告
- 场景历元秒的日期格式
- ATK 命令行参数

### 🔧 改进 (Changed)

- 脚本工具增加运行错误提示信息
- ATK 脚本解释器支持链式比较、逻辑运算、流程控制、自增减运算
- 二维视图支持根据 OpenGL 版本动态加载相应版本动态库
