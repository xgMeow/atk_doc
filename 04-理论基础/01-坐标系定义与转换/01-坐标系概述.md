# 坐标系概述

## 什么是坐标系

坐标系是描述空间中点、向量或物体位置和方向的数学框架。在航天任务分析与设计中，坐标系是表达轨道状态、姿态、相对几何关系的基础工具。

一个完整的坐标系包含三个核心要素：
- **原点（Origin）**：坐标系的参考起点，通常选取天体质心、航天器质心、太阳系质心（SSB）或地表某一点
- **坐标轴（Axes）**：一组相互正交的单位向量，定义了空间方向的基准，通常满足右手定则

> **参考架与坐标系的区别**：在精密航天应用中，参考架（Reference Frame）指由一组精确测定的基准源（如射电源、恒星）实现的天球参考系统，而坐标系（Coordinate System）则是基于该参考架建立的数学描述框架。ICRF（国际天球参考架）即为前者的典型代表。

## 坐标系的分类

在 ATK 中，坐标系按照应用场景可分为以下几大类：

### 1. 惯性坐标系（Inertial Frames）

惯性坐标系是不随时间旋转（无加速旋转）的坐标系（在牛顿力学意义下），通常以太阳系质心或地球质心为原点，用于描述天体的绝对运动。惯性坐标系是动力学方程成立的基础。

常见惯性坐标系包括：
- **ICRF**（国际天球参考架，International Celestial Reference Frame）—— 由 IAU 定义，以遥远射电源位置实现，是天体测量和航天任务的首选惯性基准
- **GCRF**（地心天球参考架，Geocentric Celestial Reference Frame）—— ICRF 的地心实现，仅通过坐标平移（无任何旋转）与 ICRF 对齐，是所有地球卫星轨道计算的标准惯性基准
- **J2000**（J2000.0 历元平赤道平春分点坐标系）—— 以 J2000.0（JD 2451545.0 TDB）时刻的地球平赤道面和平春分点为参考，是经典动力学中的常用惯性系
- **各中心天体的 Inertial 坐标系**（如 `Mars.Inertial`、`Moon.Inertial`）—— 与 ICRF 保持完全相同的轴指向（无旋转），仅原点平移到对应天体的质心，作为对应天体动力学分析的惯性基准

### 2. 中心天体固连坐标系（Body-Fixed Frames）

与中心天体固连的坐标系，随天体一起旋转，用于描述相对于天体表面的位置和方向。此类坐标系通过天体定向参数（如极移、自转角等）与对应的惯性坐标系关联。

常见固连坐标系包括：
- **Fixed**（固定坐标系）—— 由 IAU 推荐的天体固连坐标系实现（如 `Earth.Fixed` 基于 ITRF，`Moon.Fixed_IAU2003` 基于 IAU 2003 月球定向模型）
- **TrueOfDate**（真赤道真春分点坐标系）—— 以当前时刻的瞬时赤道面和瞬时春分点定义，反映章动效应
- **MeanOfDate**（平赤道平春分点坐标系）—— 以当前时刻的平赤道面和平春分点定义，仅包含岁差而不含章动

### 3. 轨道局部坐标系（Trajectory-Based Frames）

以航天器轨道运动为基础定义的坐标系，常用于描述轨道相对几何、编队飞行、交会对接、相对导航等场景。此类坐标系需要指定参考对象（中心天体、航天器等）。

常见轨道局部坐标系包括：
- **LVLH**（当地垂当地平坐标系，Local Vertical Local Horizontal）—— x 轴由地心指向航天器质心（径向向外），y 轴指向航天器速度方向，z 轴指向轨道角动量方向，构成右手系
- **VVLH**（飞行器速度当地水平坐标系，Vehicle Velocity Local Horizontal）—— z 轴指向地心，y 轴指向轨道面负法向，x 轴构成右手系（近似迹向）
- **RIC**（径向-迹向-法向坐标系，Radial-InTrack-CrossTrack）—— R 轴沿径向（由中心天体指向航天器），I 轴沿飞行方向（迹向），C 轴沿轨道面法向，构成右手系
- **VNC**（速度-法向-共法向坐标系，Velocity-Normal-CoNormal）—— V 轴沿速度方向，N 轴沿轨道面法向，C 轴构成右手系（共法向）


### 4. 表面局部坐标系（Surface-Based Frames）

以中心天体表面某参考点（如经度、纬度、高度）为基础定义的坐标系，常用于描述地面站、着陆点、目标点等局部几何关系。

常见表面局部坐标系包括：
- **NorthEastDown**（北东下坐标系，NED）—— x 轴指向正北，y 轴指向正东，z 轴指向地心（向下），是航天地面站常用坐标系
- **EastNorthUp**（东北上坐标系，ENU）—— x 轴指向正东，y 轴指向正北，z 轴指向天顶（向上），是民用导航、机器人领域最常用的右手坐标系
- **TopoCentric**（站心坐标系）—— 以观测站为原点，基本平面为当地水平面，z 轴指向天顶，x 轴指向正北或正东（取决于约定）
- **RadialCentric**（径向中心坐标系）—— 以任意点为原点，z 轴沿该点的地心径向方向向外（指向天顶），x 轴在当地水平面内指向正北，y 轴指向正东，用于航天器表面部件安装、行星着陆器本地导航

### 5. 历元坐标系（Epoch-Based Frames）

在特定历元时刻定义的坐标系，该坐标系在该历元时刻与对应的时变坐标系对齐，但之后不随时间旋转（即"冻结"在该历元状态）。广泛用于 TLE/SGP4 轨道预报和高精度轨道积分。

常见历元坐标系包括：
- **AlignmentAtEpoch**（历元对齐坐标系）—— 在指定历元与参考坐标系对齐，之后保持固定指向
- **MeanOfEpoch**（历元平赤道坐标系）—— 在指定历元与 MeanOfDate 对齐后冻结
- **TrueOfEpoch**（历元真赤道坐标系）—— 在指定历元与 TrueOfDate 对齐后冻结
- **TEMEOfEpoch**（历元真赤道平春分点坐标系，True Equator Mean Equinox of Epoch）—— 在指定历元，赤道面取瞬时真赤道面，春分点取平春分点，是 SGP4/SDP4 轨道预报模型的标准输出坐标系

### 6. 黄道坐标系（Ecliptic Frames）

以黄道面（地球绕日公转轨道面）为基准定义的坐标系，分为地心黄道坐标系和日心黄道坐标系，常用于行星际任务、深空探测和太阳系天体动力学分析。

常见黄道坐标系包括：
- **MeanEclpJ2000**（J2000.0 历元平黄道坐标系）—— 以 J2000.0 时刻的平黄道面和平春分点定义，原点可为地心或日心，是航天工程最常用的黄道坐标系
- **TrueEclpDate**（当前时刻真黄道坐标系）—— 以指定历元时刻的瞬时真黄道面和瞬时真春分点定义，包含岁差和章动的全部影响当前时刻的瞬时黄道面和瞬时春分点定义
- **J2000_Ecliptic**（J2000 黄道坐标系）—— 即 MeanEclpJ2000 的通用别名，以 J2000.0 历元的平黄道面为参考平面，x 轴指向 J2000.0 平春分点方向，原点可为地心或日心

## 坐标系的命名规则

在 ATK 中，坐标系名称通常遵循以下命名模式：

```
[中心天体].[坐标系类型]
```

例如：
- `Earth.Fixed` — 地球固定坐标系
- `Moon.MeanEarth` — 月球平均地球坐标系
- `Satellite1.LVLH` — 卫星1的LVLH轨道坐标系

## 坐标系选择指南
在实际任务分析中，选择合适的坐标系至关重要：
| 应用场景 | 推荐坐标系 | 选择理由 |
|---------|-----------|---------|
| 描述绝对轨道状态 | ICRF / GCRF 或 J2000 | 惯性基准，动力学方程形式简洁 |
| 描述相对于地球表面的位置 | Earth.Fixed | 与地面特征固定，便于地理定位 |
| 编队飞行相对运动分析 | LVLH 或 RIC | CW 方程在 LVLH 系中形式简洁 |
| 交会对接相对导航 | LVLH 或 VVLH | 直观反映接近走廊和制动方向 |
| 地面站可见性与观测几何 | NorthEastDown 或 TopoCentric | 便于计算方位角与仰角 |
| 行星际转移轨道设计 | MeanEclpJ2000 或 ICRF | 黄道面内运动为主，ΔV 评估直观 |
| 月球表面任务 | Moon.MeanEarth 或 Moon.Fixed_IAU2003 | IAU 推荐的月球定向模型 |
| TLE 轨道预报 | TEMEOfEpoch | SGP4/SDP4 的标准坐标系 |
| 姿态确定与控制 | 与轨道积分一致的惯性系 | 保证参考基准统一 |
| 深空探测器导航 | ICRF | 与 DSN 测轨数据处理的参考架一致 |

## 常用坐标系关系概览

```
ICRF（国际天球参考架，准惯性基准）
  │
  ├── GCRF（地心天球参考架，与 ICRF 无旋转平移）
  │     │
  │     ├── J2000（地心惯性，与 GCRF 仅有微小常值偏差：~17 mas 量级框架偏移）
  │     │
  │     ├── Earth.Inertial（与 GCRF 固定旋转，即地球定向基准）
  │     │     │
  │     │     ├── Earth.Fixed（ITRF，随地球自转）
  │     │     │     ├── TrueOfDate（瞬时赤道 + 瞬时春分点）
  │     │     │     ├── MeanOfDate（平赤道 + 平春分点，仅岁差）
  │     │     │     └── TEMEOfDate（瞬时赤道 + 平春分点）
  │     │     │
  │     │     └── TrueOfEpoch / MeanOfEpoch / TEMEOfEpoch（在特定历元冻结）
  │     │
  │     └── 轨道局部坐标系（与具体航天器对象绑定）
  │           ├── LVLH
  │           ├── RIC / ICR
  │           ├── VNC
  │           └── VVLH
  │
  ├── 其他中心天体 Inertial（如 Mars.Inertial、Moon.Inertial）
  │     └── 对应天体的 Fixed / TrueOfDate / MeanOfDate
  │
  ├── 黄道坐标系
  │     ├── MeanEclpJ2000
  │     └── TrueEclpDate
  │
  └── 表面局部坐标系
  ├── NorthEastDown / NorthWestUp
  ├── TopoCentric
  └── RadialCentric
```


> **注意**：
> - 上述层次关系表示概念上的推导关系和转换链路，实际的数学转换可能涉及多个中间步骤（如极移矩阵、自转矩阵、章动矩阵、岁差矩阵的顺次乘积）。
> - J2000 与 GCRF/ICRF 之间存在约 17 毫角秒量级的框架偏差（frame bias），在高精度应用中不可忽略。
> - 具体转换方法参见 [坐标转换方法](./06-坐标转换方法.md)。
