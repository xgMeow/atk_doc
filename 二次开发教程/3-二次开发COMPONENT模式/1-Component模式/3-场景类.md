# 场景类

## 类 IScenario

> [!info]
> 类 IScenario，继承自类 IAtkObject

 

举  例： 
```cpp
IScenario* pIScen = (IScenario*)pIAtkObjectCollection->New(eScenario, "Scenario1");
```

说  明： `pIAtkObjectCollection` 为 `IAtkObjectCollection` 类指针

 

### SetTimePeriod()

 

函数说明：设置场景时间

输入类型： `std::string` ，`std::string`

输入说明： 开始时间，结束时间，例： `"2 Jan 2000 00:00:00.000"`

举  例： 
```cpp
pIScen->SetTimePeriod("5 Nov 2022 00:00:00.000", "6 Nov 2022 00:00:00.000");
```
 

### SetEpoch()

 

函数说明：设置场景当前时间

输入类型： `std::string`

输入说明：场景时间，例： `"2 Jan 2000 00:00:00.000"`

举  例： 
```cpp
pIScen->SetEpoch("5 Nov 2022 00:00:00.000");
```
 

### GetEpoch()/Epoch

 

函数说明：获得场景当前时间

返回参数类型： `std::string`

返回参数说明：场景时间

举  例： 
```cpp
std::stringstrEpoch = pIScen->GetEpoch();
```
```cpp
std::string strEpoch = pIScen->Epoch;
```
