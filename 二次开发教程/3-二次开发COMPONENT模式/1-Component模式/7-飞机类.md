 

## 类 IVeWaypointsCollection


###  Add()

函数说明： 复制 Cobj 路径集合的最后一个元素，添加到集合最后；再用 Cobj 路径集合的新增元素，构建 Iobj 路径集合的新增元素

输出类型： IVeWaypointsElement*

输出说明： 路径点

举  例： 
```cpp
IVeWaypointsElement* pIVeWaypointsElement = pIVePropagatorGreatArc->GetWaypoints()->Add();
```

###  Contains ()

 

函数说明： 确定集合是否包含指定时间的路径点

输入类型： double time

输入说明： 指定时间

输出类型： bool

输出说明： 是否包含指定时间的路径点

举  例： 
```cpp
bool isContains = pIVePropagatorGreatArc->GetWaypoints()->Contains(wpv[1]->Time);
```
 

###  IndexOf ()

 

函数说明： 确定集合是否包含指定的路径点并返回现有路径的索引。索引< 0 表示在集合中不存在的方式点。

输入类型： double time

输入说明： 指定时间

输出类型： int

输出说明： 指定时间在集合中的索引

举  例： 
```cpp
int index = pIVePropagatorGreatArc->GetWaypoints()->IndexOf(123456);
```
 

###  RemoveAll ()

 

函数说明： 从集合中删除所有元素

举  例： 
```cpp
pIVePropagatorGreatArc->GetWaypoints()->RemoveAll ();
```

 

###  RemoveAt ()

 

函数说明： 使用指定索引从集合中删除元素

输入类型： int index

输入说明： 删除索引

举  例： 
```cpp
pIVePropagatorGreatArc->GetWaypoints()->RemoveAt(1);
```
 

###  ToArray ()

 

函数说明： 返回一个包含方法点的二维数组。每个子数组都表示一个选择 点。元素的顺序是时间、纬度、经度、高度、速度、加速度、旋转半径

输出类型： `std::vector<IVeWaypointsElement*>`

输出说明： 路径点指针 Vector

举  例： 
```cpp
std::vector<IVeWaypointsElement*> wpv = pIVePropagatorGreatArc->GetWaypoints()->ToArray()
```
 

###  GetCount()/G_Count

 

函数说明：获得路径点计数

返回参数类型： int

返回参数说明： 路径点计数

举  例： 
```cpp
pIVeWaypointsCollection->GetCount();

```
 

###  Item ()

 

函数说明： 给定索引,返回集合中的一个元素(扩展函数)

输入类型： int index

输入说明： 索引

输出类型： IveWaypointsElement*

输出说明： 路径点指针

举  例： 
```cpp
IVeWaypointsElement* pIVeWaypointsElement = pIVeWaypointsCollection->Item(0);
```
