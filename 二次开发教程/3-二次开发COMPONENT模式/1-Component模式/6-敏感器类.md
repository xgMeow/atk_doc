### AssignO


函数说明： 设置定向


###  AssignEulerAngles()

 

函数说明： 设置欧拉角定向

输入类型： EEulerOrientationSequence sequence, double a, double b, double c 

输入说明： 欧拉角序列, 欧拉角 a, 欧拉角 b, 欧拉角 c

举  例： 
```cpp
pISnPtFixed->GetOrientation()->AssignEulerAngles (e121, 11.31, 8.97, 11.31) ;
```
 

###  AssignQuaternion()

 

函数说明： 设置四元数定向

输入类型： double x, double y, double z, doubles

输入说明： 四元数 x, 四元数 y, 四元数 z, 四元数 s

举  例： 
```cpp
pISnPtFixed->GetOrientation()->AssignQuaternion(0.2, 0.08, 0, 1) ;
```
 

###  ConvertTo()

 

函数说明： 转换坐标类型， new 一个子类新空间返回，自身值不改变

输入类型： EOrientationType newType

输入说明： 转换类型

输出类型： Iorientation*

输出说明： 转换后类型指针

举  例： 
```cpp

```
 

###  QueryEulerAngles()

 

函数说明： 获得辅助定向方法使用欧拉角

举  例： 
```cpp

```

输入说明： 半锥角, 点之间的角分离

输出类型： IsnSimpleConicPattern*

输出说明： 圆锥传感器类型指针

举  例： 
