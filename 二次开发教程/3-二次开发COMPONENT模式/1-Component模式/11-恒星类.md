# 恒星类



 

## 类IStar, 继承自类IAtkObject

 

属性类型：恒星

举  例： 
```cpp
IStar* pIStar = (IStar*)pIScen->GetChildren()->New(eStar, "IStar");
```
 

### GetLocationRightAscension()/LocationRightAscension

 

函数说明：获得位置赤经(deg)

返回参数类型： double

返回参数说明： 位置赤经(deg)

举  例： 
```cpp
pIStar->GetLocationRightAscension();

pIStar->LocationRightAscension;
```
 

### SetLocationRightAscension()

 

函数说明： 设置位置赤经(扩展函数)

输入类型： double

输入说明： 位置赤经

举  例： 
```cpp
pIStar->SetLocationRightAscension (11);
```
