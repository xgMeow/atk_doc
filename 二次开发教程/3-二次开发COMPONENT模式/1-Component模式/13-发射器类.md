# 发射器类


## 类ITransmitter

 

属性类型：发射器

举  例： 
```cpp
ITransmiter*pITransmitter=(ITransmitter*)plFacility->GetChildren()->New(eTransmitter,"ITransmitter");
```
 

### SetModel()

 

函数说明：按名称设置当前发送模型

输入类型： `std:string`

输入说明：发送模型名称(简单模型：`"Simple Transmitter Model"`)

举  例： 
```cpp
plTransmitter->SetModel("Simple Transmitter Model ");
```


### GetModel()/Model

 

函数说明：获得发送模型

返回参数类型： `ITransmitterModel*`

返回参数说明：发送模型

举  例 ：
```cpp
ITransmitterModel*plTransmitterModel    =pITransmitter->Get- Model();

ITransmiterModel*pITransmitterModel=pITransmitter->Model;
```
