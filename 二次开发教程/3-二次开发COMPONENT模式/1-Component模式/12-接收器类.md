# 接收器类

## 类 IReceiver ，继承自类 IAtkObject

属性类型： 接收器

举  例： 
```cpp
IReceiver* pIReceiver = (IReceiver*)pIFacility->GetChildren()->New(eReceiver, "IReceiver");
```

###  SetModel()


函数说明： 按名称设置当前接收模型

输入类型： std::string

输入说明： 接收模型名称(简单模型： "Simple Receiver Model")

举  例： 
```cpp
pIReceiver->SetModel("Simple Receiver Model");
```
 

###  GetModel()/Model

 

函数说明：获得接收模型

返回参数类型： IReceiverModel *

返回参数说明： 接收模型

举  例： 
```cpp
IReceiverModel *pIReceiverModel = pIReceiver->GetModel();

IReceiverModel *plReceiverModel =pIReceiver->Model;
```
