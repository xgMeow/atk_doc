# 工具类

## 类IATKBatchCrdnTransform

属性类型：批量坐标转换工具

举    例：
```cpp
IATKBatchCrdnTransform* pCrdn = pIAtkObjectRoot->GetBatchCrdnTransform();
```

### SetUTCTime()

函数说明：设置批量坐标转换时间参数

输入类型：`EUTCTime`

输入说明：时间格式类型

举    例：
```cpp
pCrdn->SetUTCTime(eUTCG);
```

### GetUTCTime()

函数说明：获取批量坐标转换时间格式

输出类型：`EUTCTime`

输出说明：时间格式

举    例：
```cpp
EUTCTime utc = pCrdn->GetUTCTime();
```

### SetCrdnTransformParam()

函数说明：设置批量坐标转换转换参数

输入类型：`std::vector<ECrdnTransformParam>`

输入说明：转换参数，Time默认参数

举    例：
```cpp
pCrdn->SetCrdnTransformParam(vecCrdnTransformParam);
```

::: note 示例

```
std::vector<ECrdnTransformParam> vecCrdnTransformParam;
vecCrdnTransformParam.clear();
vecCrdnTransformParam.push_back(ePosition);
```
:::

### GetCrdnTransformParam()

函数说明：获取批量坐标转换转换参数

输出类型：`std::vector<ECrdnTransformParam>`

输出说明：转换参数

举    例：
```cpp
std::vector<ECrdnTransformParam> vecCrdnTransformParam = pCrdn->GetCrdnTransformParam();
```

### Compute()

函数说明：批量坐标转换根据输入文件内容及参数计算目标坐标系坐标

输入类型：`std::string`

输入说明：输入文件全路径

举    例：
```cpp
pCrdn->Compute
("C:\\Users\\Desktop\\Release-ATK-v###0-20240430\\AtkInput\\CoordTrans\\LCI.txt");
```

### Export()

函数说明：批量坐标转换为批量坐标转换数据保存到文件

举    例：
```cpp
pCrdn->Export();
```

### SetLCParam()

函数说明：批量坐标转换设置LC发射系参数

输入类型：`double`,`double`,`double`,`double`

输入说明：发射方位角,发射点经度,发射点纬度,发射点高度

举    例：
```cpp
pCrdn->SetLCParam(0, 0, 0, 0);
```

### SetLCIParam()

函数说明：批量坐标转换设置LC发射惯性系参数

输入类型：`std::string`,`double`,`double`,`double`,`double`

输入说明：发射时间,发射方位角,发射点经度,发射点纬度,发射点高度

举    例：
```cpp
pCrdn->SetLCIParam("22 Mar 2022 00:00:00.000", 0, 0, 0, 0);
```

### SetENUParam()

函数说明：批量坐标转换设置LC发射系参数

输入说明：测控点经度,测控点纬度,测控点高度

举    例：
```cpp
pCrdn->SetENUParam(0, 0, 0);
```
