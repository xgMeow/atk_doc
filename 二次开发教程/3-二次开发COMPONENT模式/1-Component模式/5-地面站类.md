# 地面站类

## 类IFacility, 继承自类IAtkObject
 

属性类型： IFacility* 地面站

举  例： 
```cpp
IFacility* plFacility = (IFacility*)pIScen->GetChildren()->New(eFacility,"Facility1");
```

##  类 IPosition,  继承自类ILocationData

 

### Assign()

 

函数说明：设置位置

输入类型：`Iposition* plIPosition`

输入说明：位置信息

举  例 ：
```cpp
plFacility->GetPosition()->Assign(posc);
```
 

###  AssignCartesian()

 

函数说明：设置笛卡尔位置

输入类型： `double x, double y, double z`

输入说明： 笛卡尔坐标 x, 笛卡尔坐标 y, 笛卡尔坐标 z

举  例： 
```cpp
pIFacility->GetPosition()->AssignCartesian(-2127, 5266, 3000);
```
 

###  AssignGeodetic()

 

函数说明：设置经纬高位置

输入类型： `double lat, double lon, double alt`

输入说明： 地理位置纬度，地理位置经度，地理位置高度

举  例： 
```cpp
pIFacility->GetPosition()->AssignGeodetic(28, 112, 50);
```
 

###  ConvertTo()

 

函数说明：转换位置

输入类型： `EPositionType converType`

输入说明： 转换类型

输出类型： `IPosition*`

输出说明： 转换后类型指针

举  例： 
```cpp
IPosition* posc = pIFacility->GetPosition()->ConvertTo(eCartesian);
```
 

###  QueryCartesian()

 

函数说明：获取笛卡尔位置

输入类型： `double & x, double & y, double & z`

输入说明： 笛卡尔坐标 x, 笛卡尔坐标 y, 笛卡尔坐标 z

举  例： 
```cpp
pIFacility->GetPosition()->QueryCartesian(x, y, z);
```
 

###  GetPosType()/PosType

 

函数说明：获得坐标类型

返回参数类型： `EPositionType`

返回参数说明： 坐标类型

举  例： 
```cpp
EPositionType type = pIFacility->GetPosType();

EPositionType type = pIFacility->PosType;
```
