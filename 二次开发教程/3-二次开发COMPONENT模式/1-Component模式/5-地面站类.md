# 地面站类

> [!info]
> 类 IFacility, 继承自类IAtkObject

属性类型： IFacility* 地面站

举  例： 
```cpp
IFacility* plFacility = (IFacility*)pIScen->GetChildren()->New(eFacility,"Facility1");
```

##  类 IPosition
 
> [!info]
> 类 IPosition,  继承自类ILocationData

### Assign()

函数说明： 设置位置

输入类型： `IPosition*`

输入说明： 位置信息

举  例 ：
```cpp
plFacility->GetPosition()->Assign(posc);
```

###  AssignCartesian()

函数说明： 设置笛卡尔坐标位置

输入类型： `double`, `double`, `double`

输入说明： 笛卡尔坐标 x, 笛卡尔坐标 y, 笛卡尔坐标 z

举  例： 
```cpp
pIFacility->GetPosition()->AssignCartesian(-2127, 5266, 3000);
```
  
###  AssignGeodetic()
 
函数说明：设置地理坐标位置

输入类型： `double`, `double`, `double`

输入说明： 地理位置纬度lat，地理位置经度lon，地理位置高度alt

举  例： 
```cpp
pIFacility->GetPosition()->AssignGeodetic(28, 112, 50);
```
 
###  ConvertTo()

函数说明：转换位置坐标类型

输入类型： `EPositionType`

输入说明： 转换类型

输出类型： `IPosition*`

输出说明： 转换后类型指针

举  例： 
```cpp
IPosition* posc = pIFacility->GetPosition()->ConvertTo(eCartesian);
```
 
###  QueryCartesian()

函数说明：获取笛卡尔坐标位置

输入类型： `double`, `double`, `double`

输入说明： 笛卡尔坐标 x, 笛卡尔坐标 y, 笛卡尔坐标 z

举  例： 
```cpp
pIFacility->GetPosition()->QueryCartesian(x, y, z);
```

###  GetPosType()

函数说明：获得坐标类型

返回参数类型： `EPositionType`

返回参数说明： 坐标类型

举  例： 
```cpp
EPositionType type = pIFacility->GetPosType();
```

## 地面站二维

### 类IFaGraphics

举    例：
```cpp
IFaGraphics* pIFaGraphics = pIFacility->GetGraphics();
```

说    明：pIFacility为IFacility类指针

#### GetIsObjectGraphicsVisible()

函数说明： 获得对象是否在二维显示

返回参数类型： `bool`

返回参数说明： 是否显示

举    例：
```cpp
 bool bIsShow = pIFaGraphics->GetIsObjectGraphicsVisible();
```

####  SetIsObjectGraphicsVisible()

函数说明： 设置对象是否在二维显示

输入类型： `bool`

输入说明： 是否显示

举    例：
```cpp
pIFaGraphics->SetIsObjectGraphicsVisible(bIsShow); 
```

#### GetColor()

函数说明： 获得二维显示颜色

返回参数类型： `int`

返回参数说明： 二维显示颜色

举    例： 
```cpp

```

####  SetColor()

函数说明： 设置二维显示颜色

输入类型： `int`

输入说明： 二维显示颜色，例如绿色-65280
