# 链类

## 类IChain, 继承自类IAtkObject

属性类型：链

举  例： 
```cpp
IChain*plChain=(IChain*)plScen->GetChildren()->New(eChain, "IChain");
```

### GetObjectsO/Objects


函数说明：获得链中的对象集合


返回参数类型： `IObjectLinkCollection*`

返回参数说明： 链中的对象集合

举  例： 
```cpp
IObjectLinkCollection* pIObjectLinkCollection = pIChain->GetObjects();

IObjectLinkCollection* pIObjectLinkCollection = pIChain->Objects;
```

 
## 类 IObjectLinkCollection

 

### Add()
 

函数说明： 增加链接对象通过对象路径名称

输入类型： std::string

输入说明： 对象路径名称

举  例： 
```cpp
pIObjectLinkCollection->Add(strObjPathName);
```
 

### AddObject()

 

函数说明： 增加链接对象通过对象指针

输入类型： `IAtkObject*`

输入说明： 对象指针

举  例： 
```cpp
pIObjectLinkCollection->AddObject(pIAtkObject);
```
 

### Contains()

 

函数说明： 搜索链接对象路径名称是否存在

输入类型： `std::string`

输入说明： 对象路径名称

举  例： 
```cpp
pIObjectLinkCollection->Contains(strObjPathName);
```
 

### IndexOf()

 

函数说明： 获得链接对象索引

输入类型： `std::string`

输入说明： 对象路径名称

举  例： 
```cpp
pIObjectLinkCollection->IndexOf(strObjPathName);
```
 

### Remove()


函数说明： 通过索引移除链接对象

输入类型： int

输入说明： 对象索引

举  例： 
```cpp
pIObjectLinkCollection->Remove(index);
```
 

### RemoveAll()


函数说明： 移除所有链接对象

举  例： 
```cpp
pIObjectLinkCollection->RemoveAll();
```
 

### RemoveName()


函数说明： 通过对象路径名称移除链接对象

输入类型： `std::string`

输入说明： 对象路径名称

举  例： 
```cpp
pIObjectLinkCollection->RemoveName(strObjPathName);
```
 

### RemoveObject()

 

函数说明： 通过对象指针移除链接对象

输入类型： `IAtkObject*`

输入说明： 对象指针

举  例： 
```cpp
pIObjectLinkCollection->RemoveObject(pIAtkObject);
```
 

### AvailableObjects()

 

函数说明： 获取所有链接对象

举  例： 
```cpp
pIObjectLinkCollection->AvailableObjects();
```
 

### GetCount()

 

函数说明： 获得链接对象数量

举  例： 
```cpp
pIObjectLinkCollection->GetCount();
```
 

### Item()


函数说明： 通过索引获得链接对象

输入类型： int

输入说明： 对象索引
 

举  例： 
```cpp
IObjectLink* pIObjectLink = pIObjectLinkCollection->Item(index);
```

```cpp
pIObjectLink->Name;
```

### GetPath()/Path

返回参数类型： `std::string`

返回参数说明： 路径名称

举  例： 
```cpp
pIObjectLink->GetLinkedObject();

pIObjectLink->Path;
```
