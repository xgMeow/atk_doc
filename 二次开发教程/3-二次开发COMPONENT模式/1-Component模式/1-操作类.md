# 操作类

## 类IAtkObject

 

### GetAccessConstraints()


函数说明：获得对象约束

返回参数类型： `IAccessConstraintCollection*`

返回参数说明：对象约束指针

举例： 
```cpp
IAccessConstraintCollection* pAccCnstrColl = pISate->GetAccessConstraints();
```

说明： pISate 为 ISatellite 类指针 

### GetChildren()
 

函数说明：获得对象子对象指针

返回参数类型：`IAtkObjectCollection*`

返回参数说明：对象的子对象指针

举例： 
```cpp
IAtkObjectCollection* pIAtkObjColl = pISate->GetChildren();
```

说明： pISate 为 ISatellite 类指针

 

### SetChildren()
 

函数说明： 设置子对象

输入类型： `IAtkObjectCollection*`

输入说明： 子对象指针
 

举例： 
```cpp
pISate->SetChildren(pIChilColl);
```

说明： `pISate` 为 `ISatellite` 类指针， `pIChilColl` 为 `IAtkObjectCollection` 类指针

```cpp
std::string strClassName = pIScen->ClassName;
```

## 类IAtkObjectRoot

 
### NewScenario()

函数说明：新建场景

输入类型： `std::string`

输入说明：场景名称

举例： 
```cpp
pIAORoot->NewScenario("Scenario1");
```
说明： `pIAORoot` 为 `IAtkObjectRoot` 类指针

 
### CloseScenario()

函数说明：关闭场景

举例： 
```cpp
pIAORoot->CloseScenario();
```
说明： `pIAORoot` 为 `IAtkObjectRoot` 类指针

 

### GetObjectFromPath()

 

函数说明：通过路径获得对象

输入类型： `std::string`

输入说明： 截断路径，例： `"Satellite/Satelite1"`

返回参数类型： `IAtkObject` 指针

返回参数说明： 对象属性指针


举例： 

```cpp
ISatellite* pISate2 = (ISatellite*)pIAORoot->GetObjectFromPath("Satellite/Satellite1");
```

说明： `pIAORoot` 为 `IAtkObjectRoot` 类指针

 

### SupportedChildTypes

 

属性类型： `std::vector<int>`

举例： 
```cpp
pIScen->GetChildren()->SupportedChildTypes;
```
 

### ObjectExists()

 

函数说明：判断对象是否存在

输入类型： `std::string`

输入说明： 截断路径，例： `"Satellite/Satelite1"`

返回参数类型： `bool`

返回参数说明： `true` - 对象存在

举例： 
```cpp
bool bRet = pIAORoot->ObjectExists("Satellite/Satellite1");
```

说明： `pIAORoot` 为 `IAtkObjectRoot` 类指针

 

### SaveScenario()

 

函数说明：保存场景

```cpp
pIAORoot->SaveScenario();
```

说明： `pIAORoot` 为 `IAtkObjectRoot` 类指针


说明： `pIScen` 为 `IScenario` 类指针

### New()
 

函数说明： 新建对象

输入类型： `EATKObjectType` ，`std::string`

输入说明： 插入对象的类的类型，插入对象的名称

返回参数类型： `IAtkObject` 类指针

返回参数说明：对象属性类指针

举例： 
```cpp
ISatellite* pISate = (ISatellite*) pIAtkObjectCollection->New(eSatellite,"Satellite1");
```
 

### Count
 

属性类型： int

属性说明： 包含子对象个数

举例： 
```cpp
int nCount = pIAtkObjectCollection->Count;
```
 

### Item()
 

函数说明：获得对象

输入类型： `int`/`std::string`

输入说明：子对象顺序/子对象名称

举例： 
```cpp
ISatellite* pISate = (ISatellite*)pIAtkObjectCollection->Item(0);
```
 

### SupportedChildTypes

属性类型： `std:vector<int>`

属性说明：对象所支持添加的子对象类型

举例：
```cpp
std:vector<int> vecTypes  =plAtkObjectCollection->SupportedChildTypes;
```
