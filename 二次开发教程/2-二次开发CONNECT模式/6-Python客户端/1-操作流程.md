# 操作流程


以轨道快速转移场景为例，此案例实现是从半径为6700km的近地停泊轨道（LEO轨道）快速转移到半径为42164.197km的地球同步轨道（GEO轨道）的轨道机动规划设计。以下通过Python客户端与ATK软件连接，发送Connect命令完成新建想定并设置参数的使用介绍。

::: warning 注意
- 使用 Matlab 向 ATK 发送命令前，必须打开 ATK，不需要打开场景；
- 若需新建场景，需将已打开的场景关闭。
:::


![ATK 打开界面](media/1-操作流程/image0108-1.png)

## 将Python库函数复制到使用目录
![使用文件目录](media/1-操作流程/image0120-2.png)

## 从命令窗口新建场景

::: warning 注意
- 若有已打开场景，请先关闭场景。
:::
        
### 第一步：导入ATK通信接口模块中需要的接口函数
![导入接口函数](media/1-操作流程/image0120-3.png)

### 第二步：输入新建命令，新建想定并设置场景分析时间

以新建快速转移轨道场景为例，使用 [`New`](../2-Connect命令库/1-场景.md#new) 命令

![新建场景命令](media/1-操作流程/image0120-4.png)

执行命令后，相应界面如下。

![新建的场景](media/1-操作流程/新建的场景.png)

使用 [`SetAnalysisTimePeriod`](../2-Connect命令库/1-场景.md#setanalysistimeperiod) 命令设置场景开始结束时间；

使用 [`Animate`](../2-Connect命令库/1-场景.md#animate) 命令设置场景仿真状态

![设置场景属性命令](media/1-操作流程/image0120-5.png)

### 第三步：新建卫星对象并设置对象属性

可以通过 [`New`](../2-Connect命令库/1-场景.md#new) 命令新建对象。以新建卫星，并设置轨道类型机动规划为例。

![新建卫星命令](media/1-操作流程/image0120-6.png)

执行命令后，相应界面如下。

![新建的卫星](media/1-操作流程/新建的卫星.png)

以设置卫星属性为例，具体命令格式请参考Connect命令库。

![设置卫星的属性命令](media/1-操作流程/image0120-7.png)

执行命令后，可在界面右键点击对象，选择属性按钮，查看设置结果。

![卫星属性界面](media/1-操作流程/image0120-10.png)

### 第四步：开始仿真；属性设置完成后，请关闭连接

![场景仿真界面](media/1-操作流程/场景仿真界面.png)

使用 [`Save`](../2-Connect命令库/1-场景.md#save) 命令保存场景，若保存脚本文件，请在客户端界面点击保存按钮

![场景保存命令](media/1-操作流程/image0120-8.png)

场景及对象设置完成后，使用 [`atkClose`](./README.md#atkclose) 命令与 ATK 断开连接。

![与ATK断开连接](media/1-操作流程/image0120-9.png)
