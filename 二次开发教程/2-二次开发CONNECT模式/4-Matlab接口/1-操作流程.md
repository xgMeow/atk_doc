# 操作流程

以轨道倾角改变场景为例，此案例实现是从初始近地轨道到指定半径的地球同步轨道的转移轨道机动规划。以下为通过Matlab客户端在ATK软件中新建想定并设置参数的使用介绍。

:::warning
- 使用 Matlab 向 ATK 发送命令前，必须打开 ATK，不需要打开场景；

- 若需新建场景，需将已打开的场景关闭。ATK 网络通信端口为 `6655`
:::


![ATK 打开界面](media/1-操作流程/image0108-1.png)


## 将Matlab库加入到运行路径

```
addpath('C:\Users\ATK-4.0-dev-master\IntegratingWithATK\connect\Matlab\Win_2015b')
```

:::warning 注意
- Matlab库文件在ATK安装目录 .\IntegratingWithATK\connect\Matlab\Win_2015b
:::


## 从命令窗口新建场景
 
:::warning 注意
- 若有已打开场景，请先关闭场景。
:::

### 第一步：打开 Matlab，在命令行窗口输入命令与 ATK 进行连接

与 ATK 进行连接使用 [`atkOpen`](./README.md#atkopen) 命令。

![与ATK连接](media/1-操作流程/image-1.png)

### 第二步：输入新建命令，新建想定并设置场景分析时间

以新建轨道倾角改变场景为例，[`New`](../2-Connect命令库/1-场景.md#New) 命令。

![新建场景命令](media/1-操作流程/image-2.png)

执行命令后，相应界面如下。

![新建的场景](media/1-操作流程/image0108-7.png)

使用 [`SetAnalysisTimePeriod`](../2-Connect命令库/1-场景.md#setanalysistimeperiod) 命令设置场景开始结束时间；

使用 [`Animate`](../2-Connect命令库/1-场景.md#animate) 命令设置场景仿真状态。

![设置场景属性命令](media/1-操作流程/image-4.png)

### 第三步：新建卫星对象并设置对象属性

可以通过 [`New`](../2-Connect命令库/1-场景.md#New) 命令，新建对象，以新建卫星为例。

![新建卫星命令](media/1-操作流程/image-5.png)

执行命令后，相应界面如下

![新建的卫星](media/1-操作流程/image0108-10.png)

以设置卫星属性为例，具体命令格式请参考Connect命令库。

![设置卫星的属性命令](media/1-操作流程/image-7.png)

执行命令后，可在界面右键点击对象，选择属性按钮，查看设置结果

![右键点击卫星，属性按钮位置](media/1-操作流程/image0108-12.png)


![卫星属性界面](media/1-操作流程/image0108-13.png)

### 第四步：开始仿真；属性设置完成后，请关闭连接

![ 场景仿真界面](media/1-操作流程/image0108-17.png)

使用 [`Save`](../2-Connect命令库/1-场景.md#save) 命令保存场景，若保存脚本文件，请在客户端界面点击保存按钮。

![场景保存命令](media/1-操作流程/image-11.png)

场景及对象设置完成后，使用 [`atkClose`](./README.md#atkclose) 命令与 ATK 断开连接。

![与 ATK 断开连接](media/1-操作流程/image-12.png)

## 从输入脚本窗口新建场景

:::warning 注意
- 除去逐条运行命令新建场景外，也可以多条命令批量处理。

- 若有已打开场景，请先关闭场景。
:::

### 第一步：打开 Matlab，在主页菜单栏下点击新建脚本按钮或新建按钮。

![新建脚本和新建按钮位置](media/1-操作流程/image-13.png)

### 第二步：输入多条命令，新建想定以及对象，并对其属性进行设置

1. 与 ATK 进行连接使用 [`atkOpen`](./README.md#atkopen) 命令。

2. 以新建 InclinationChange 场景为例，使用 [`New`](../2-Connect命令库/1-场景.md#new) 命令新建场景。

3. 
    使用 [`SetAnalysisTimePeriod`](../2-Connect命令库/1-场景.md#setanalysistimeperiod)命令设置场景开始结束时间；
    
    使用  [`Animate`](../2-Connect命令库/1-场景.md#animate) 命令设置场景仿真状态。

4. 新建卫星对象，设置卫星为机动规划类型，并设置每个段的参数后运行算例。

5. 使用 [`Save`](../2-Connect命令库/1-场景.md#save) 命令保存场景。

6. 使用 [`atkClose`](./README.md#atkclose)  命令与 ATK 断开连接。


![输入脚本命令](media/1-操作流程/image-14.png)

### 第三步：点击运行按钮，保存文件，即可开始仿真。

![运行按钮位置](media/1-操作流程/image-15.png)

![修改文件名字并保存](media/1-操作流程/image-16.png)
