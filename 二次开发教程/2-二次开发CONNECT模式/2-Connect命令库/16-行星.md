# 行星命令

## Define

作用：设置行星中心天体

::: note 用法
```
Define <PlanetObjectPath> CentralBody {CBName} 
```
:::

::: info 说明
- `{CBName}`包括天体名称`Mercury`, `Venus`, `Earth`,`Mars`,`Jupiter`,`Saturn`,`Uranus`,`Neptune`,`Pluto`,`Moon`,`Sun`
:::

::: tip 举例
```
Define */Planet/Planet1 CentralBody Jupiter
```
:::



## Set Constraint
 
作用：设置行星约束

::: details 详细说明（点击展开）

基本约束：
 

| ConstraintName   | Parameters                                                   |
| ---------------- | ------------------------------------------------------------ |
| LineOfSight      | `{On \| Off}`                                                  |
| TerrainMask      | `{On \| Off}`                                                  |
:::


::: note 用法
```
SetConstraint <ObjectPath> {ConstraintName} {State}
```
:::

::: tip 举例
```
SetConstraint */Planet/Jupiter LineOfSight On
```
:::
