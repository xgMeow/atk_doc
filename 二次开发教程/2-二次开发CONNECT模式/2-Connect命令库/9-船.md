# 船命令

## AddWaypoint

作用：设置船航线属性

::: note 用法
```
AddWaypoint <VehObjectPath> {AddMethod} <Parameters> [<TurnRadius>]
```
:::

::: info 说明 

| AddMethod         | Parameters                             |
| ----------------- | -------------------------------------- |
| DetTimeAccFromVel | `[{MapGridSpec}] {PointDef}  <Velocity>` |
| DetVelFromTime    | `[{MapGridSpec}] {PointDef}  <DateTime>` |

:::

::: info 说明
 
| MapGridSpec | PointDef                           |
| ----------- | ---------------------------------- |
| LatLon      | `<Latitude> <Longitude>  <Altitude>` |

:::

::: note 举例
```
AddWaypoint */Ship/Ship1 DetTimeAccFromVel LatLon 42.5 15 0.0 1.0
```
:::


 
## Graphics

### Graphics Label

作用：设置船标签属性

::: note 用法
```
Graphics <ObjectPath> Label {Options}
```
:::

::: info 说明

| Options          | 说明           |
| ---------------- | -------------- |
| `Show {on \| off}` | 显示或隐藏标签 |

:::

::: note 举例
```
Graphics */Ship/Ship1 Label Show on
```
:::



### Graphics SetColor 

作用：设置船轨迹标签颜色

::: note 用法
```
Graphics <ObjectPath> SetColor {Color} [{Item}]
```
:::

::: info 说明
- `Color` 可用属性请查看常用设置格式-常用图形格式
:::

::: note 举例
```
Graphics */Ship/Ship1 SetColor 4
```
:::



### Graphics Show

作用：设置船是否在窗口显示

::: note 用法
```
Graphics <ObjectPath> Show {On | Off}
```
:::

::: note 举例
```
Graphics */Ship/Ship1 Show Off
```
:::



## Set Constraint

作用：设置约束

::: note 用法
```
SetConstraint <ObjectPath> {ConstraintName} <Parameters>
```
:::

::: details 约束参数设置说明（点击展开）

- 基本约束：

| ConstraintName   | Parameters                                                   |
| ---------------- | ------------------------------------------------------------ |
| AzimuthAngle     | `{Off \| Min <Value1> Max <Value2>} [ExcludeIntervals \|  IncludeIntervals]` |
| ElevationAngle   | `{Off \| Min <Value1> [\|] Max  <Value2>} [ExcludeIntervals \| IncludeIntervals]` |
| Range            | `{Off \| Min <Value1> [\|] Max  <Value2>} [ExcludeIntervals \| IncludeIntervals]` |
| AzimuthRate      | `{Off \| Min <Value1> [\|] Max  <Value2>} [ExcludeIntervals \| IncludeIntervals]` |
| ElevationRate    | `{Off \| Min <Value1> [\|] Max  <Value2>} [ExcludeIntervals \| IncludeIntervals]` |
| RangeRate        | `{Off \| Min <Value1> [\|] Max  <Value2>} [ExcludeIntervals \| IncludeIntervals]` |
| AngularRate      | `{Off \| Min <Value1> [\|] Max  <Value2>} [ExcludeIntervals \| IncludeIntervals]` |
| Altitude         | `{Off \| Min <Value1> [\|] Max  <Value2>} [ExcludeIntervals \| IncludeIntervals]` |
| PropagationDelay | `{Off \| Min <Value1> [\|] Max  <Value2>} [ExcludeIntervals \| IncludeIntervals]` |
| LineOfSight      | `{On \| Off}`                                                  |
| FieldOfView      | `{On \| Off}`                                                  |

- 太阳约束： 

| ConstraintName     | Parameters                                |
| ------------------ | ----------------------------------------- |
| SunElevationAngle  | `{Off \| Min  <Value1> [\|] Max  <Value2>}` |
| SunGroundElevAngle | `{Off \| Min  <Value1> [\|] Max <Value2>}`  |
| LunarElevationAngle | `{Off \| Min  <Value1> [\|] Max  <Value2>}` |
| LOSSunExclusion     | `{Off \|  <Value1>}`                        |
| LOSLunarExclusion   | `{Off \|  <Value1>}`                        |

:::

::: tip 注意
当输入 AzimuthAngle 值时， 最大值和最小值必须同时输入
:::

::: note 举例
```
SetConstraint */Ship/Ship1 AzimuthAngle Min 10.0 Max 60.0 ExcludeIntervals
```

```
SetConstraint */Ship/Ship1 ElevationAngle Min 10.0
```

```
SetConstraint */Ship/Ship1 SunElevationAngle Min 10
```
::: 



## VO

### VO Model

作用：设置船 3D 模型属性

::: note 用法
```
VO <ObjectPath> Model {Options} 
```
:::

::: info 说明

| Options          | 说明           |
| ---------------- | -------------- |
| `Show {on \| off}`            | 显示或隐藏3D模型 |
| `file {"<FilePath>"}`         | 导入模型文件     |

:::

::: note 举例
```
VO */Ship/Ship1 Model Show on
```
:::



### VO ModelOffset

作用：设置船 3D 模型标签偏移量和平移补偿

::: note 用法
```
VO <ObjectPath> ModelOffset {OffsetOption} {On | Off} [<X> <Y> <Z>]
```
:::

::: info 说明
- 目前`{OffsetOption}`包括属性 `Label` 和 `Translational`
:::

::: note 举例
```
VO */Ship/Ship1 ModelOffset Label On 10 20 30
```

```
VO */Ship/Ship1 ModelOffset Translational off
```
:::



### VO ScaleLog

作用：设置船 3D 模型比例大小

::: note 用法
```
VO <ObjectPath> ScaleLog <value>
```
:::

::: info 说明
- `<value>`用于调整模型大小
:::

::: note 举例
```
VO */Ship/Ship1 ScaleLog 3
```
:::


### VO Point

作用：设置船 3D 模型点属性

::: note 用法
```
VO <ObjectPath> Point {Options} <value>
```
:::

::: info 说明

| Options          | 说明           |
| ---------------- | -------------- |
| `Show {on \| off}`  | 显示或隐藏3D模型点 |
| `size {value}`      | 设置点属性大小     |

:::

::: note 举例
```
VO */Ship/Ship1 Point show on
```

```
VO */Ship/Ship1 Point size 3
```
:::




## VO SetVectorGeometry

作用：设置船向量

::: note 用法
```
VO <ObjectPath> SetVectorGeometry Modify "<ReferenceCrdn>" [{DisplayOption} <DisplayValue>...]
```
:::

::: details 详细说明（点击展开）
| 可视化— 向量   | ReferenceCrdn |
| -------------- | ------------- |
| 向量           | Sun Vector    |
| 向量           | Moon Vector    |               
| 向量           | Zenith  Vector |               
| 向量           | North Vector   |               
| 向量           | East Vector    |               
| 坐标系         | Body Axes     |
| 坐标系         | LH Axes        |               
| 坐标系         | J2000 Axes     |               
| 坐标系         | ECF Axes       |      

:::

::: tip 注意
`ReferenceCrdn` 必须使用双引号
:::
 
::: details 详细说明（点击展开）
| DisplayOption | DisplayValue |
| ------------- | ------------ |
| Show      | `{On \| Off}`                     |
| ShowLabel | `{On \| Off}`                     |
| ArrowType | `{2D \| 3D \| Point}`             |
| Color     | 请参考常用设置格式—常用图形格式 |

:::

::: note 举例
```
VO */Ship/Ship1 SetVectorGeometry Modify "Sun Vector" Show On ShowLabel On ArrowType Point Color 15
```

```
VO */Ship/Ship1 SetVectorGeometry Modify "Body Axes" Show On
```
:::
