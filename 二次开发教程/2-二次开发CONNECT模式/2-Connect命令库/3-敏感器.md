# 敏感器命令

## Define

作用：设置敏感器类型及其参数

::: note 用法
```
Define <SensorObjectPath> {Type} <TypeData>
```
:::

::: info 说明

| Type        | TypeData                                                                                                                                   |
| ----------- | ---------------------------------------------------------------------------                                                                |
| SimpleCone  | `<ConeAngle>`                                                                                                                              |
| Rectangular | `<VerticalHalfAngle>  <HorizontalHalfAngle>`                                                                                               |
| Conical     | `<InnerConeHalfAngle> <OuterConeHalfAngle> <MinClockAngle> <MaxClockAngle>`                                                                |
| HalfPower   | `<Frequency> <Diameter>`                                                                                                                   |
| SAR	      | `<MinElevationAngle> <MaxElevationAngle> <ForwardExclusionAngle> <AftExclusionAngle> {<ParentAltitude> \| TrackParentAltitude {On \| Off}` |

:::

::: warning 注意
- 输入角度值默认单位为度
:::

::: tip 举例
```
Define */Satellite/Satellite1/Sensor/Sensor1 Rectangular 25.1 36.8
```
:::



## Detect

作用：设置敏感器探测对象

::: note 用法
```
Detect <SensorObjectPath> {Option} <TruncObjectPath>
```
:::

::: info 说明
- `{Option}`包括 `Add` 和 `Delete`
:::

::: warning 注意
- `<TruncObjectPath>`为截断路径
:::

::: tip 举例
```
Detect */Satellite/Satellite1/Sensor/Sen1 Add Satellite/Sate2
```
:::

### Graphics Projection

作用：设置投影属性

::: note 用法
```
Graphics <SensorObjectPath> Projection {Option}
```
:::

::: info 说明

| Option                               | 说明                     |
| ----------------------------------   | ------------------------ |
| `Altitudes  <Alt>`                   | 输入固定半径默认单位是 m |
| `Object{On\|Off}  <TruncObjectPath>` | 输入对象路径为截断路径   |

:::

::: tip 举例

```
Graphics */Satellite/Satellite1/Sensor/Sensor1 Projection Altitudes 500000
```
```
Graphics */Satellite/Satellite1/Sensor/Sensor1 Projection object on Satellite/Satellite2
```

:::

## Point Fixed
 
作用：设置固定指向属性

::: note 用法
```
Point <SensorObjectPath> Fixed {OrientMethod} <MethodData>
```
:::

::: info 说明

| OrientMethod5 | MethodData                        | 说明                                                         |
| ------------- | --------------------------------- | ------------------------------------------------------------ |
| AzEl          | `<Azimuth> <Elevation>`              | 方位角，高度角   |
| Quaternion    | `<q1>  <q2> <q3> <q4>`              | `<Q1>` `<Q2>` `<Q3>`设置 `qx`， `qy` ，`qz` ，`<Q4>`设置 `qs`    |
| Euler         | `<Sequence> <Rot1>  <Rot2>  <Rot3>` | `<Sequence>`可输入值包括  121 ，123 ，131 ，132 ，212，  213 ，231 ，232 ，312 ，313，  321 ，323，其中 1 是旋转轴 x 轴， 2 是旋转轴 y 轴， 3 是旋转轴 z 轴 |
| YPR           | `<Sequence> <Yaw> <Pitch> <Roll>`              | 偏航角，俯仰角，滚转角，转序序列 包括值RPY,RYP,PRY,PYR,YPR,YRP  |
| matrix        | `<d11><d21><d22><d31><d32><d33>`   | `N/A`                                                          |

:::

::: tip 举例
```
Point */Satellite/Satellite1/Sensor/Sensor1 Fixed Quaternion 0.0 0.0 0.0 1.0
```
:::



## Point Spinning
 
作用：设置旋转指向属性

::: note 用法
```
Point <SensorObjectPath> Spinning <Azimuth> <Elevation> <ConeAngle> {ScanMethod} [<ScanMethodParams>] <Rate> <Offset>
```
:::

::: info 说明

| ScanMethod          | Parameters                       |
| ------------------- | ---------------------------------|
| Continuous          | `N/A`                            | 
| Unidirectional      | `<StartAngle> <StopAngle>`       | 
| Bidirectional       | `<StartAngle> <StopAngle>`       | 

:::

::: tip 举例
```
Point */Satellite/Satellite1/Sensor/Sensor1 Spinning 0 -90 90 Continuous 6 360
```
:::



## Point Targeted

作用：设置目标指向属性

::: note 用法
```
Point <SensorObjectPath> Targeted {OrientMethod} <MethodData>
```
:::

::: info 说明

| OrientMethod      | MethodData                       |    说明                       |
| ----------------- | ---------------------------------|  ---------------------------------|
| Tracking          | `<TruncObjectPath> [{AboutBoresight} [{TrackMode}]]`  |   `{AboutBoresight}`为视轴，包括`hold`，`rotate`和`level`；{TrackMode}为追踪模式，包括`transpond`，`transmit`和`receive`        | 
| Fixed             | `<TruncObjectPath> {OrientMethod} <MethodData>`       |   `<MethodData>`请参考[`Point Fixed`](./3-敏感器.md#point-fixed) 命令       | 

:::

::: tip 举例
```
Point */Satellite/Sat1/Sensor/Sensor1 Targeted Tracking Facility/testFac1 Hold Receive
```
:::

## VO Pulse
 
作用：设置脉冲属性

::: note 用法
```
VO <SensorObjectPath> Pulse {PulseOption1} <Value1> [{PulseOption2} <Value2>...]
```
:::

::: info 说明

| PulseOption | Value        | 说明                                  |
| ----------- | -----------  | ------------------------------------- |
| Show        | `{On \| Off}`| 若输入值为 Off，则其他属性不可设 置。 |
| Amplitude   | `<AmpValue>`    | 脉冲透明度输入值应介于 0.0 至 1.0       |
| PulseLength | `<LengthValue>` | 输入脉冲长度值应大于等于 0.000001m      |
| Frequency   | `{<Value>}`     | 输入脉冲频率值应介于 0.0 至 100.0 之 间 |
| FreqReverse | `{On \| Off}`   | 若输入之为 On，则实现脉冲反向           |

:::

::: tip 举例
```
VO */Satellite/Satellite1/Sensor/Sensor1 Pulse Show On Amplitude 0.67 PulseLength 100 Frequency 2.1 FreqReverse on
```
:::



## Set Constraint

作用：设置约束

::: note 用法

```
SetConstraint <ObjectPath> {ConstraintName} <Parameters>
```

:::

::: details 详细说明（点击展开）

- 基本约束：

| ConstraintName   | Parameters                                                   |
| ---------------- | ------------------------------------------------------------ |
| AzimuthAngle     | `{Off \| Min <Value1> Max <Value2>} [ExcludeIntervals \|  IncludeIntervals]` |
| ElevationAngle   | `{Off \| Min <Value1> [\|] Max  <Value2>} [ExcludeIntervals \| IncludeIntervals]` |
| Range            | `{Off \| Min <Value1> [\|] Max  <Value2>} [ExcludeIntervals \| IncludeIntervals]` |
| AzimuthRate      | `{Off \| Min <Value1> [\|] Max  <Value2>} [ExcludeIntervals \| IncludeIntervals]` |
| ElevationRate    | `{Off \| Min <Value1> [\|] Max  <Value2>} [ExcludeIntervals \| IncludeIntervals]` |
| RangeRate        | `{Off \| Min <Value1> [\|] Max  <Value2>} [ExcludeIntervals \| IncludeIntervals]` |
| AngularRate      | `{Off \| Min <Value1> [\|] Max  <Value2>} [ExcludeIntervals \| IncludeIntervals]` |
| Altitude         | `{Off \| Min <Value1> [\|] Max  <Value2>} [ExcludeIntervals \| IncludeIntervals]` |
| PropagationDelay | `{Off \| Min <Value1> [\|] Max  <Value2>} [ExcludeIntervals \| IncludeIntervals]` |
| LineOfSight      | `{On \| Off}`                                                  |
| fieldofview      | `{On \| Off}`                                                  |

- 太阳约束：

| ConstraintName      | Parameters                                |
| ------------------- | ----------------------------------------- |
| SunElevationAngle   | `{Off \| Min  <Value1> [\|] Max  <Value2>}` |
| SunGroundElevAngle  | `{Off \| Min  <Value1> [\|] Max  <Value2>}` |
| LunarElevationAngle | `{Off \| Min  <Value1> [\|] Max  <Value2>}` |
| LOSSunExclusion     | `{Off \|  <Value1>}` |
| LOSLunarExclusion   | `{Off \|  <Value1>}` |
| BSSunExclusion      | `{Off \|  <Value1>}` |
| BSLunarExclusion    | `{Off \|  <Value1>}` |

:::

::: warning 注意
- 当输入 AzimuthAngle 值时，最大值和最小值必须同时输入
:::

::: tip 举例
```
SetConstraint */Satellite/Sate1/Sensor/Sen1 AzimuthAngle Min 10.0 Max 60.0 ExcludeIntervals
```

```
SetConstraint */Satellite/Satellite1/Sensor/Sen1 ElevationAngle Min 10.0
```

```
SetConstraint */Satellite/Sate1/Sensor/Sen1 BSSunExclusion 30
```
:::
 


## VO SetVectorGeometry

作用：设置敏感器向量

::: note 用法
```
VO <ObjectPath> SetVectorGeometry Modify "<ReferenceCrdn>" [{DisplayOption} <DisplayValue>...]
```
:::

::: details 详细说明（点击展开） 

| 可视化— 向量      | ReferenceCrdn |
| ----------------- | ------------- |
| 向量              | Sun Vector    |
| 向量              | Moon Vector       |               
| 向量              | Nadir Vector      |               
| 向量              | Velocity  Vector  |               
| 向量              | Boresight  Vector |               
| 坐标系            | Body Axes     |
| 坐标系            | VVLH Axes         |  
| 坐标系            | J2000 Axes        |  
| 坐标系            | ECF Axes          |  

::: warning 注意
- ReferenceCrdn 必须使用双引号
:::

::: info 说明

| DisplayOption | DisplayValue                    |
| ------------- | ------------------------------- |
| Show          | `{On \| Off}`                     |
| ShowLabel     | `{On \| Off}`                     |
| Thickness     | `{<Value>}`             |
| Color         | 请参考常用设置格式—常用图形格式    |

:::

::: tip 举例

```
VO */Satellite/Satellite1/Sensor/Sensor1 SetVectorGeometry Modify "Sun Vector" Show On ShowLabel On ArrowType Point Color 15
```

```
VO */Satellite/Satellite1/Sensor/Sensor1 SetVectorGeometry Modify "Body Axes" Show On
```

:::
