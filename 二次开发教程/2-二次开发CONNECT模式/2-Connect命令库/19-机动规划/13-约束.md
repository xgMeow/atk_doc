# 约束


作用：为段设置约束条件，设置段约束的属性值

::: note 用法
```
Astrogator <Satellite Object Path> SetValue <Attribute Path>.Results <List of Results>
```
:::

::: info 说明
设置属性使用约束名称
:::

::: tip 举例
```
Astrogator */Satellite/FastTransfer SetValue MainSequence.SegmentList.Target_Sequence.SegmentList.Maneuver.Results "Radius Of Apoapsis"
```

```
Astrogator */Satellite/FastTransfer SetMCSConstraintValue MainSequence.SegmentList.Target_Sequence.Profiles.Differential_Corrector Maneuver RadiusOfApoapsis Active true
```
:::
