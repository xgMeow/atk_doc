# 机动段

## MnvrType


作用：设置机动类型

::: note 用法
```
Astrogator <Satellite Object Path> SetValue <Astrogator ObjectPath>.MnvrType <Maneuver Type>
```
:::

::: info 说明
- `Maneuver Type` 包括属性 `Impulsive` 和 `Finite`
:::

::: tip 举例
```
Astrogator */Satellite/Satellite1 SetValue MainSequence.SegmentList.Maneuver.MnvrType Impulsive
```
:::

## Coordinate Values 

作用：设置坐标属性值

::: note 用法
```
Astrogator <Satellite Object Path> SetValue <Astrogator ObjectPath>.<Coordinate Type>.<Attribute> <Value> <Unit>
```
:::

::: info 说明
- `Coordinate Type` 包括属性 `Cartesian` 和 `Spherical`。当 `<Coordinate Type>`  输入值为 `Cartesian` 时， `<Attribute>` 包括属性 `X` ，`Y` ，`Z`，当 `<Coordinate Type>` 输入值为 `Spherical` 时， `<Attribute>` 包括属性 `Azimuth` ，`Elevation`, `Magnitude`
:::

::: warning 注意
- Cartesian 默认单位是 m/sec ，Spherical 中 Azimuth ，Elevation 默认单位为 Rad ，Magnitude 默认单位为 m/sec
- 当 MnvrType 类型为 Finite 时， Cartesian 没有单位， Spherical 只包括属性 Azimuth ，Elevation
:::

::: tip 举例
```
Astrogator */Satellite/Satellite1 SetValue MainSequence.SegmentList.Maneuver.ImpulsiveMnvr.Spherical.Azimuth 30 deg
```
:::

## SegmentColor

作用：设置机动段颜色

::: note 用法
```
Astrogator <Satellite Object Path> SetValue <Attribute Path>.SegmentColor <Value>
```
:::

::: info 说明
- 颜色设置从`-1` 到 `-16777216` 是透明度为 255 时颜色 255255255 到 000000000，按照 RGB 格式进行满 255 进 1，例如红色 255000000，透明度为 255，则有 `255000000 ： -256^3+255*256^0= -16776961` ，`000255000：-256^3+255*256^1= -16711936`

- 从 0 到 4294967295 是透明度为 000 时颜色 000000000 到透明度 255  时颜色 255255255，例如红色 255000000，透明度为 255，则有 `255000000255：255*256^3+255*256^0=4278190335`
:::

::: tip 举例
```
Astrogator */Satellite/Satellite1 SetValue MainSequence.SegmentList.Maneuver.SegmentColor -16712191
```
:::
