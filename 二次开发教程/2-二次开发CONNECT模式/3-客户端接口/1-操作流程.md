# 操作流程

以轨道倾角改变场景为例，此案例实现是从初始近地轨道到指定半径的地球同步轨道的转移轨道机动规划。以下为通过C++客户端在ATK软件中新建想定并设置参数的使用介绍。

使用C++方式与ATK进行连接，首先需要打开ATK。不需要打开场景；若需新建场景，需将已打开的场景关闭，ATK.Connect模式仅支持加载一个场景。

::: warning
- 使用客户端方式与 ATK 进行连接，首先需要打开 ATK。
- 若需新建场景，需将已打开的场景关闭。
:::

![ATK打开界面](media/1-操作流程/image0108-1.png)

## 从输入脚本窗口新建场景

除去逐条运行命令新建场景外，也可以多条命令批量处理。

::: warning 注意
若有已打开场景，请先关闭场景。
:::

### 第一步：在菜单栏选择集成菜单，再选择客户端窗口

![集成按钮位置](media/1-操作流程/image0108-2.png)

![客户端按钮位置](media/1-操作流程/image0108-3.png)

点开客户端后，界面如下。

![客户端界面](media/1-操作流程/image0108-4.png)

### 第二步：点击 New 按钮新建脚本文件

![New 按钮位置](media/1-操作流程/image0108-18.png)


### 第三步：输入脚本命令，新建想定以及对象，并对其属性进行设置


1. 与 ATK 进行连接使用 [`atkOpen`](./README.md#atkopen) 命令。
2. 以新建轨道倾角改变场景为例，使用 [`New`](../2-Connect命令库/1-场景.md#new) 命令新建场景，新建卫星对象。
3. 使用 [`SetAnalysisTimePeriod`](../2-Connect命令库/1-场景.md#setanalysistimeperiod) 命令设置场景开始结束时间；使用 [`Animate`](../2-Connect命令库/1-场景.md#Animate) 命令设置场景仿真状态；
4. 以设置卫星轨道属性为例，具体命令格式请参考Connect命令库。
5. 使用 [`Save`](../2-Connect命令库/1-场景.md#save) 命令保存场景，若保存脚本文件，请在客户端界面点击保存按钮。
6. 使用 [`atkClose`](./README.md#atkclose) 命令与 ATK 断开连接。

![输入的命令及保存脚本文件按钮位置](media/1-操作流程/image0108-19.png)


### 第四步：点击 Run 按钮，即可开始仿真

场景及对象属性设置完成后，即可运行脚本

![Run 按钮位置](media/1-操作流程/image0108-20.png)

脚本运行结束后，相应界面如下。

![场景仿真界面](media/1-操作流程/image0108-21.png)
