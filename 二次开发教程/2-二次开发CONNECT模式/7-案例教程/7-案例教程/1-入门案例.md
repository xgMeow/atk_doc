# 入门案例

通过二次开发 Connect 模式，创建入门案例场景，必须保持 ATK 为打开状态，具体命令分类包括：

1. 与 ATK 进行连接。
2. 新建场景并进行属性设置。
3. 新建卫星并进行属性设置。
4. 查看二维和三维场景
5. 查看输出报告。
6. 保存场景后与 ATK 断开连接。

## 脚本展示

### 与 ATK 进行连接

```atks
#1, 与 ATK 进行连接
conID = atkOpen();
```

### 新建场景并进行属性设置

```atks
#2, 创建任务场景并进行属性设置
atkConnect(conID, 'New', '/ Scenario SimpleExample');
atkConnect(conID, 'SetAnalysisTimePeriod', '* "2026-03-06 00:00:00.000" "2026-03-09 00:00:00.000"');
atkConnect(conID, 'Animate', '* Reset');
```

### 新建卫星并进行属性设置

```atks
#3, 插入卫星并进行属性设置
atkConnect(conID, 'New', '/ Satellite Satellite1');
atkConnect(conID, 'SetState', '*/Satellite/Satellite1 Classical HPOP "2026-03-06 00:00:00.000" "2026-03-09 00:00:00.000" 60 ICRF "2026-03-06 00:00:00.000" 6878137.000 0 45 0 0 0');
```

### 新建二维场景和三维场景

```atks
#4, 新建二维场景和三维场景
atkConnect(conID, 'Window2D','/ Create');
atkConnect(conID, 'Window3D','/ CreateWindow Normal');
```

### 查看输出报告

```atks
#5, 查看输出报告
print(atkConnect(conID,'Report_RM', '*/Satellite/Satellite1 Style "Keplerian.RAAN"  TimePeriod 2026-03-06 00:00:00.000" "2026-03-09 00:00:00.000"'))
```

### 保存场景后与 ATK 断开连接

```atks
#6，保存场景后与 ATK 断开连接
atkConnect(conID, 'Save', '/ *')
atkClose(conID)
```

## 完整脚本

```atks
#1, 与 ATK 进行连接
conID = atkOpen();
#2, 创建任务场景并进行属性设置
atkConnect(conID, 'New', '/ Scenario SimpleExample');
atkConnect(conID, 'SetAnalysisTimePeriod', '* "2026-03-06 00:00:00.000" "2026-03-09 00:00:00.000"');
atkConnect(conID, 'Animate', '* Reset');
#3, 插入卫星并进行属性设置
atkConnect(conID, 'New', '/ Satellite Satellite1');
atkConnect(conID, 'SetState', '*/Satellite/Satellite1 Classical HPOP "2026-03-06 00:00:00.000" "2026-03-09 00:00:00.000" 60 ICRF "2026-03-06 00:00:00.000" 6878137.000 0 45 0 0 0');
#4, 新建二维场景和三维场景
atkConnect(conID, 'Window2D','/ Create');
atkConnect(conID, 'Window3D','/ CreateWindow Normal');
#5, 查看输出报告
print(atkConnect(conID,'Report_RM', '*/Satellite/Satellite1 Style "Keplerian.RAAN"  TimePeriod 2026-03-06 00:00:00.000" "2026-03-09 00:00:00.000"'))
#6，保存场景后与 ATK 断开连接
atkConnect(conID, 'Save', '/ *')
atkClose(conID)
```
