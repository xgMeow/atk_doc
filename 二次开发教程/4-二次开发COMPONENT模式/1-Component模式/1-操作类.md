# 操作类

## 类IAtkObject

 ### Unload()


函数说明：删除对象

举例： 
```cpp
pISate->Unload();
```

### GetAccessConstraints()


函数说明：获得对象约束

返回参数类型： `IAccessConstraintCollection*`

返回参数说明：对象约束指针

举例： 
```cpp
IAccessConstraintCollection* pAccCnstrColl = pISate->GetAccessConstraints();
```

说明： pISate 为 ISatellite 类指针 

### GetChildren()
 

函数说明：获得对象子对象

返回参数类型：`IAtkObjectCollection*`

返回参数说明：对象的子对象指针

举例： 
```cpp
IAtkObjectCollection* pIAtkObjColl = pISate->GetChildren();
```

说明： pISate 为 ISatellite 类指针 

### GetOrbitData()
 

函数说明：获得历史数据

参数类型：`std::vector<double>&`，`std::vector<CCoord>&`

参数说明：仿真消耗时间，仿真位置

返回参数类型：`bool`

返回参数说明： 数据获取是否成功

举例： 
```cpp
std::vector<double> vecEpsec;
std::vector<CCoord> vecPos;
bool isSucceed = pISate->GetOrbitData(vecEpsec,vecPos);
```

说明： pISate 为 ISatellite 类指针 

### GetAccess()
 

函数说明：获得可见性计算对象

参数类型：`std::string`

参数说明：计算对象路径

返回参数说明：可见性计算对象

举例： 
```cpp
IAtkAccess* pIAtkAccess = pISate->GetAccess("Satellite/Satellite1");
```

说明： pISate 为 ISatellite 类指针

## 类IAtkObjectRoot

 
### NewScenario()

函数说明：新建场景

输入类型： `std::string`

输入说明：场景名称

```cpp
pIAORoot->NewScenario("Scenario1");
```
说明： `pIAORoot` 为 `IAtkObjectRoot` 类指针

 
### CloseScenario()

函数说明：关闭场景

举例： 
```cpp
pIAORoot->CloseScenario();
```
说明： `pIAORoot` 为 `IAtkObjectRoot` 类指针


### LoadScenario()

函数说明：加载场景文件

输入类型： `std::string`

输入说明：场景文件路径

```cpp
pIAORoot->LoadScenario('C:/ATK/Scenario1.xml');
```
说明： `pIAORoot` 为 `IAtkObjectRoot` 类指针

 

### GetObjectFromPath()

 

函数说明：通过路径获得对象

输入类型： `std::string`

输入说明： 截断路径，例： `"Satellite/Satelite1"`

返回参数类型： `IAtkObject` 指针

返回参数说明： 对象属性指针


举例： 

```cpp
ISatellite* pISate2 = (ISatellite*)pIAORoot->GetObjectFromPath("Satellite/Satellite1");
```

说明： `pIAORoot` 为 `IAtkObjectRoot` 类指针

 

### ObjectExists()

 

函数说明：判断对象是否存在

输入类型： `std::string`

输入说明： 截断路径，例： `"Satellite/Satelite1"`

返回参数类型： `bool`

返回参数说明： `true` - 对象存在

举例： 
```cpp
bool bRet = pIAORoot->ObjectExists("Satellite/Satellite1");
```

说明： `pIAORoot` 为 `IAtkObjectRoot` 类指针

### OutputDataReport()

 

函数说明： 输出数据报告

输入类型： `IAtkObject*`，`std::string`，`std::string`，`std::string`

输入说明： 对象指针，报告类型，开始时间，结束时间

输出类型：`std::string`

输出说明： 输出报告路径

举例： 
```cpp
std::string strReportFilePath = pIAORoot->OutputDataReport(pISate, "J2000 Position Velocity", "5 Nov 2022 00:00:00.000", "6 Nov 2022 00:00:00.000");
```

说明： `pIAORoot` 为 `IAtkObjectRoot` 类指针，`pISate` 为 `ISatellite` 类指针

### New()
 

函数说明： 新建对象

输入类型： `EATKObjectType` ，`std::string`

输入说明： 插入对象的类的类型，插入对象的名称

返回参数类型： `IAtkObject` 类指针

返回参数说明：对象属性类指针

举例： 
```cpp
ISatellite* pISate = (ISatellite*) pIAtkObjectCollection->New(eSatellite,"Satellite1");
```
 

### Count()
 

属性类型： int

属性说明： 包含子对象个数

举例： 
```cpp
int nCount = pIAtkObjectCollection->GetCount();
```
 

### Item()
 

函数说明：获得对象

输入类型： `int`/`std::string`

输入说明：子对象顺序/子对象名称

举例： 
```cpp
ISatellite* pISate = (ISatellite*)pIAtkObjectCollection->Item(0);
```
 

### GetSupportedChildTypes

属性类型： `std:vector<int>`

属性说明：对象所支持添加的子对象类型

举例：
```cpp
std:vector<int> vecTypes  =plAtkObjectCollection->GetSupportedChildTypes();
```
