# 船舰类


## 类 IShip 
 
> [!info]
> 类 IShip ，继承自类 IAtkObject

属性类型：船

举  例： 
```cpp
IShip* pIShip = (IShip*)pIScen->GetChildren()->New(eShip, "IShip");
```
 

### GetGreatArcVehicle()

函数说明：获得船舰轨道预报器

返回参数类型： `IGreatArcVehicle*`

返回参数说明：轨道预报器

举  例： 
```cpp
IGreatArcVehicle* pIGreatArcVehicle = plShip>GetGreatArcVehicle();
```
  
### GetGraphics()

函数说明：获得二维属性

返回参数类型：`IShGraphics*`

返回参数说明：二维属性指针

举    例：
```cpp
IShGraphics* pIShGraphics = pIShip->GetGraphics();
```
  
### GetVO()

函数说明：获得三维属性

返回参数类型：`IShVO*`

返回参数说明：三维属性指针

举    例：
```cpp
IShVO* pIShVO = pIShip->GetVO();
```
