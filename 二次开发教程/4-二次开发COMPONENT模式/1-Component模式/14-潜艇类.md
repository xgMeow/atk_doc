# 潜艇类

## 类 ISubmarine
 
> [!info]
> 类 ISubmarine,  继承自类IAtkObject

属性类型：潜艇

举   例： 

```cpp
ISubmarine* plSubmarine = (ISubmarine*)plScen->GetChildren)->New(eSubmarine,"ISubmarine");
```

### GetGreatArcVehicle()

函数说明：获得潜艇轨道预报器

返回参数类型： `IGreatArcVehicle*`

返回参数说明：潜艇轨道预报器

举    例： 
```cpp
IGreatArcVehicle* pIGreatArcVehicle = plSubmarine->GetGreatArcVehicle();
```
 
### GetGraphics()

函数说明：获得二维属性

返回参数类型：`ISuGraphics*`

返回参数说明：二维属性指针

举    例：
```cpp
ISuGraphics* pISuGraphics = pISubmarine->GetGraphics();
```
 
### GetVO()

函数说明：获得三维属性

返回参数类型：`ISuVO*`

返回参数说明：三维属性指针

举    例：
```cpp
ISuVO* pISuVO = pISubmarine->GetVO();
```
