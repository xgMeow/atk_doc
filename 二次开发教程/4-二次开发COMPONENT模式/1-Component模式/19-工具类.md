# 工具类

## 批量坐标转换工具

### 类IATKBatchCrdnTransform

属性类型：批量坐标转换工具

举    例：
```cpp
IATKBatchCrdnTransform* pCrdn = pIAtkObjectRoot->GetBatchCrdnTransform();
```


#### SetCrdnTransformParam()

函数说明：设置批量坐标转换转换参数

输入类型：`std::vector<ECrdnTransformParam>`

输入说明：转换参数，Time默认参数

```cpp
pCrdn->SetCrdnTransformParam(vecCrdnTransformParam);
```

#### SetLCParam()
