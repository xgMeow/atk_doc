# 场景类

## 类 IScenario

> [!info]
> 类 IScenario，继承自类 IAtkObject

举  例： 
```cpp
IScenario* pIScen = (IScenario*)pIAtkObjectCollection->New(eScenario, "Scenario1");
```

说  明： `pIAtkObjectCollection` 为 `IAtkObjectCollection` 类指针

### SetTimePeriod()

函数说明：设置场景时间

输入类型： `std::string` ，`std::string`

输入说明： 开始时间，结束时间，例： `"2 Jan 2000 00:00:00.000"`

举  例： 
```cpp
pIScen->SetTimePeriod("5 Nov 2022 00:00:00.000", "6 Nov 2022 00:00:00.000");
```

### SetStartTime()

函数说明：设置场景开始时间

输入类型： `std::string`

输入说明：开始时间，例： `"2 Jan 2000 00:00:00.000"`

举  例： 
```cpp
pIScen->SetStartTime("5 Nov 2022 00:00:00.000");
```
 
### GetStartTime()

函数说明：获得场景开始时间

返回参数类型： `std::string`


返回参数说明：开始时间

举  例： 
```cpp
std::string strStartTime = pIScen->GetStartTime();
```
 
### SetStopTime()

函数说明：设置场景结束时间

输入类型： `std::string`

输入说明：结束时间，例： `"2 Jan 2000 00:00:00.000"`

举  例： 
```cpp
pIScen->SetStopTime("5 Nov 2022 00:00:00.000");
```
 
### GetStopTime()

函数说明：获得场景结束时间

返回参数类型： `std::string`

返回参数说明：结束时间

举  例： 
```cpp
std::string strStopTime = pIScen->GetStopTime();
```

### GetStartTimeBACC()

函数说明：获得场景开始时间BACC格式

返回参数类型： `std::string`

返回参数说明：开始时间

举  例： 
```cpp
std::string strStopTime = pIScen->GetStartTimeBACC();
```

### GetStopTimeBACC()

函数说明：获得场景结束时间BACC格式

返回参数类型： `std::string`

返回参数说明：结束时间

举  例： 
```cpp
std::string strStopTime = pIScen->GetStopTimeBACC();
```
