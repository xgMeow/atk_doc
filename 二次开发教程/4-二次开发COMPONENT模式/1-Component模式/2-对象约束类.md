# 对象约束类

## 类 IAccessConstraintCollection


举  例： 
```cpp
IAccessConstraintCollection* pIACColl = pISate->GetAccessConstraints();
```
说  明： `pISate` 为 `ISatellite` 类指针

 

###  AddConstraint()

函数说明：通过类型添加约束，约束已激活则返回空

输入类型： `EAccessConstraints`

输入说明： 约束类型

返回参数类型： `IAccessConstraint*`

返回参数说明： 约束属性指针

举  例： 
```cpp
IAccessCnstrAngle* pIACAngle = (IAccessCnstrAngle*)pIACColl->AddConstraint(eCstrLOSSunExclusion);
```
 

###  AddNamedConstraint()

函数说明：通过名称添加约束，约束已激活则返回空
 

输入类型：`std::string`

输入说明： 约束名称

返回参数类型： `IAccessConstraint*`

返回参数说明：约束属性指针

举  例： 
```cpp
IAccessCnstrMinMax* pIACMinMax1 = (IAccessCnstrMinMax*)pIACColl->AddNamedConstraint("Range");
```
 

###  AvailableConstraints()

 

函数说明：对象所支持的约束名称

返回参数类型： `std::vector<std::string>`

返回参数说明： 所支持的约束名称

举  例： 
```cpp
std::vector<std::string> vecStrACC = pIACColl->AvailableConstraints();
```
 

###  GetActiveConstraint()

 

函数说明：通过类型获得已激活的约束，约束未激活则返回空

输入类型： `EAccessConstraints`

输入说明： 约束类型

返回参数类型： `IAccessConstraint*`

返回参数说明：约束属性指针

举  例： 
```cpp
IAccessCnstrMinMax* pIACMinMax = (IAccessCnstrMinMax*)pIACColl->GetActiveConstraint(eCstrAzimuthRate);
```
 

###  GetActiveNamedConstraint()
 

函数说明：通过名称获得已激活的约束，约束未激活则返回空 

输入类型： `std::string`

输入说明： 约束名称

返回参数类型： `IAccessConstraint*`

返回参数说明：约束属性指针

举  例： 
```cpp
IAccessCnstrMinMax* pIACMinMax = (IAccessCnstrMinMax*)pIACColl->GetActiveNamedConstraint("Range");
```
 

###  IsConstraintActive()

函数说明：判断此类型约束是否激活


输入类型： `EAccessConstraints`

输入说明： 约束类型

返回参数类型： `bool`

返回参数说明： `true`-约束激活

举  例： 
```cpp
bool bIsAct = pIACColl->IsConstraintActive(eCstrAzimuthRate);
```
 

###  IsConstraintSupported()
 

函数说明：判断对象是否支持此类型约束

输入类型： `EAccessConstraints`

输入说明： 约束类型

返回参数类型： `bool`

返回参数说明： true-支持约束类型

举  例： 
```cpp
bool bIsSup = pIACColl->IsConstraintSupported(eCstrNone);
```
 

###  IsNamedConstraintActive()

 

函数说明：判断此名称约束是否激活

输入类型： `std::string`

输入说明： 约束名称

返回参数类型： `bool`

返回参数说明： `true`-约束激活

举  例：

###  IsNamedConstraintSupported()
 

函数说明：判断对象是否支持此名称约束

输入类型： `std::string`

输入说明： 约束名称

返回参数类型： `bool`

返回参数说明： `true`-支持约束类型

举  例： 
```cpp

```

###  Item()

 

函数说明：按添加顺序，获得第 `nIndex` 个约束

输入类型： `int`

输入说明： 第 `nIndex` 个约束

返回参数类型： `IAccessConstraint*`

返回参数说明： 约束属性指针

举  例： 
```cpp

```
 

###  GetCount()

 

函数说明：获得对象约束个数

返回参数类型： `int`

返回参数说明： 对象约束个数

举  例： 
```cpp

```
