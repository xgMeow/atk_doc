# 恒星类

## 类 IStar
 
> [!info]
> 类 IStar, 继承自类 IAtkObject

属性类型：恒星

举  例： 
```cpp
IStar* pIStar = (IStar*)pIScen->GetChildren()->New(eStar, "IStar");
```

### GetLocationRightAscension()

函数说明：获得位置赤经(deg)

返回参数类型： `double`

返回参数说明： 位置赤经(deg)

举  例： 
```cpp
double dLRA = pIStar->GetLocationRightAscension(); 
```

举  例： 

## 恒星二维

举    例：
```cpp

```
