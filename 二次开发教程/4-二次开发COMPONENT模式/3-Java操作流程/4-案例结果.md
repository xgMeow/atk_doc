# 案例结果

1. 成功执行Java案例脚本ATKComponentJavaTest.java，会在cmd命令框中输出数据报告目录

![cmd命令框输出](media/4-案例结果/cmd命令框输出.png)


2. 同时生成的还有，卫星数据报告J2000 Position Velocity.txt和卫星机动规划数据修正报告CorrectionsData.txt，以及轨道快速转移想定文件FastTransfer.xml，以上文件均存放在输出目录Output。

![生成的想定文件与数据报告](media/4-案例结果/生成的想定文件与数据报告.png)


3. 打开ATK检查生成的想定文件，选择轨道快速转移想定文件FastTransfer.xml，点击“开始”按钮运行动画，拉动下方时间轴查看二维视图下的轨迹效果。

![二维视图下的轨道快速转移效果图](media/4-案例结果/二维视图下的轨道快速转移效果图.png)


4. 点击ATK“三维视图”按钮切换至三维视图，查看三维效果。

![三维视图下的轨道快速转移效果图](media/4-案例结果/三维视图下的轨道快速转移效果图.png)
