# 载人航天任务建模过程

## 新建项目

打开 MagicDraw 软件，选择 `File` -> `New Project` 新建项目，如下图所示：

![新建项目](./media/2-载人航天任务建模过程/image4.png)

## 构建系统架构

创建 BDD（块定义图）图，构建系统架构，如下图所示：

![创建 BDD 图构建系统架构](./media/2-载人航天任务建模过程/image5.png)

## 新建行为图

右键点击“新一代载人飞船系统”Block，选择 `Create Diagram`，根据需要新建状态机图或活动图，如下图所示：

![新建状态机图或活动图](./media/2-载人航天任务建模过程/image6.png)
