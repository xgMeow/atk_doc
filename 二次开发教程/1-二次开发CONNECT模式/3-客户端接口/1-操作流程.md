# 操作流程

::: warning
使用客户端方式与 ATK 进行连接，首先需要打开 ATK。

不需要打开场景；若需新建场景，需将已打开的场景关闭。
:::

![ATK打开界面](media/1-操作流程/image-1.png)

## 从命令窗口新建场景

注意：若有已打开场景，请先关闭场景。

### 第一步：在菜单栏选择集成菜单，再选择客户端窗口

![集成按钮位置](media/1-操作流程/image-2.png)

![客户端按钮位置](media/1-操作流程/image.png)

点开客户端后，界面如下。


![客户端界面](media/1-操作流程/image-3.png)

### 第二步：在命令窗口输入命令，与 ATK 进行连接

与 ATK 进行连接使用 [`atkOpen`](./README.md#atkOpen) 命令

![输入命令位置](media/1-操作流程/image-4.png)


### 第三步：输入新建命令，新建想定并设置场景分析时间

以新建北斗场景为例，使用 [`New`](../2-Connect命令库/1-场景.md#New) 命令

![新建场景命令](media/1-操作流程/image-5.png)


执行命令后，相应界面如下

![新建的场景](media/1-操作流程/image-6.png)

使用 [`SetAnalysisTimePeriod`](../2-Connect命令库/1-场景.md#setanalysistimeperiod) 命令设置场景开始结束时间；使用 [`Animate`](../2-Connect命令库/1-场景.md#animate) 命令设置场景仿真状态。

![设置场景属性命令](media/1-操作流程/image-7.png)

### 第四步：新建卫星对象

可以通过 [`NewMulti`](../2-Connect命令库/1-场景.md#newmulti) 命令，一次新建多个对象，以新建多个卫星为例

![新建多个卫星命令](media/1-操作流程/image-8.png)

执行命令后，相应界面如下：

![新建的卫星](media/1-操作流程/image-9.png)

### 第五步：设置对象属性

以设置卫星 M1 属性为例，具体命令格式请参考 [`SetState SGP4`](../2-Connect命令库/2-卫星.md#setstate-sgp4)。


![设置卫星的属性命令](media/1-操作流程/image-10.png)

执行命令后，可在界面右键点击对象，选择属性按钮，查看设置结果

![右键点击卫星，属性按钮位置](media/1-操作流程/image-11.png)

![卫星属性界面](media/1-操作流程/image-12.png)

### 第六步：开始仿真，属性设置完成后，请关闭连接

使用 [`SetAnalysisTimePeriod`](../2-Connect命令库/1-场景.md#setanalysistimeperiod) 命令设置场景开始结束时间；使用 [`Animate`](../2-Connect命令库/1-场景.md#animate) 命令设置场景仿真状态。

![设置场景属性命令](media/1-操作流程/image-13.png)

![场景仿真界面](media/1-操作流程/image-14.png)

使用 [`Save`](../2-Connect命令库/1-场景.md#save) 命令保存场景，若保存脚本文件，请在客户端界面点击保存按钮。

![场景保存命令](media/1-操作流程/image-15.png)

场景及对象设置完成后，使用 [`atkClose`](./README.md#atkclose) 命令与 ATK 断开连接

![与 ATK 断开连接](media/1-操作流程/image-16.png)

## 多条命令处理新建场景

除去逐条运行命令新建场景外，也可以多条命令批量处理。

注意：若有已打开场景，请先关闭场景。

### 第一步：在菜单栏选择集成菜单，再选择客户端窗口

![集成按钮位置](media/1-操作流程/image-2.png)

![客户端按钮位置](media/1-操作流程/image.png)

点开客户端后，界面如下。


![客户端界面](media/1-操作流程/image-3.png)

### 第二步：点击 New 按钮新建脚本文件

![New 按钮位置](media/1-操作流程/image-17.png)


### 第三步：输入多条命令，新建想定以及对象，并对其属性进行设置


1. 与 ATK 进行连接使用 [`atkOpen`](./README.md#atkopen) 命令。
2. 以新建北斗场景为例，使用 [`New`](../2-Connect命令库/1-场景.md#new) 命令新建场景，使用 [`NewMulti`](../2-Connect命令库/1-场景.md#newmulti) 命令新建多个卫星。
3. 使用 [`SetAnalysisTimePeriod`](../2-Connect命令库/1-场景.md#setanalysistimeperiod) 命令设置场景开始结束时间；使用
4. 以设置卫星轨道属性为例，具体命令格式请参考 [`SetState SGP4`](../2-Connect命令库/2-卫星.md#setstate-sgp4) 。
5. 使用 [`Save`](../2-Connect命令库/1-场景.md#save) 命令保存场景，若保存脚本文件，请在客户端界面点击保存按钮。
6. 使用 [`atkClose`](./README.md#atkclose) 命令与 ATK 断开连接。

![输入的命令及保存脚本文件按钮位置](media/1-操作流程/image-18.png)


### 第四步：点击 Run 按钮，即可开始仿真

场景及对象属性设置完成后，即可运行脚本

![Run 按钮位置](media/1-操作流程/image-19.png)

脚本运行结束后，相应界面如下。

![场景仿真界面](media/1-操作流程/image-14.png)
