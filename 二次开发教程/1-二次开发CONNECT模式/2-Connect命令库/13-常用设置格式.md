# 常用设置格式命令



## 常用图形格式

 

| 选项  | 说明                                                         | 举例                        |
| ----- | ------------------------------------------------------------ | --------------------------- |
| Color | 有四种颜色格式： <br><br> 1. 输入英文颜色 <br><br> 2. 输入数字 0-27， 共有 28 种颜色， 若输入大于 27， 则颜色会重复使用 <br><br> 3. 输入%RRRGGGBBB。每部分最大值为 255，若输入值大于 255，则默认为  255。若输入位数不够，则默认补 0。 <br><br>  4. 输入十六进制#RRGGBB。每部分输入值 应介于 00 到 FF。若输入位数不够，则默认补 0。 | `Red` <br> <br> `6` <br> <br> `%255000000` <br> <br> `#ff0000` |
| LineStyle | 有两种线形格式： <br><br> 1.输入线形名字，目前包括 `solid`, `dashed`, `dotted`, `dashdot`, `lmsdash` <br><br> 2. 输入线形数字， 0 是 `solid` ，1 是 `dashed` 等 | `LineStyle dotted` <br> `LineStyle Solid` <br> `LineStyle 2` |

## 常用日期/时间格式

 

- 若输入 Time Interval 时使用以下列表格式：
 

| Time Interval                              | 说明                                                         | 举例                                                         |
| ------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `UseScenarioInterval` <br>(暂未实现)              | 输入此关键字设置为场景当前时间                              | `UseScenarioInterval`                                          |
| `"<TimeInstantComponentSpec>"` <br> (暂未实现)   | 语法是`"<TruncPath>   <Name>  Time Instant"`<br><br>  `<TruncPath>`是对象的截 断路径, `<Name>`是时刻名字 | `"Satellite/Satellite1  EphemerisTimeSpan.Start Time  Instant"` <br><br> `"Missile/Missile1  EphemerisTimeSpan Interval"` |
| `"<StartTime>"  "<StopTime>"`                | 输入一个开始时间和一 个结束时间。时间必须按顺序输入，并且不能相同 | 请查看以下表格                                               |

- 若输入`"<StartTime>"` 或者`"<StopTime>"`时使用以下列表格式：
 

| `"<StartTime>"` or  `"<StopTime>"`         | 说明                                                         | 举例                                                         |
| -------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `"<DateTime>"`                           | 输入时间值使用当前连接日期格式                              | UTCG 格式：  "01 Sep 2011  12:00:00.000"  <br><br> GPSTime 格式： (暂未实现)  "1651:234315.000" |
| `"<TimeInstantComponent>"` <br> (暂未实现)  | 语法是`"<TruncPath>  <Name>  Time Instant"` <br><br> `<TruncPath>`是对象的截断路径， `<Name>`是时刻 名字 | `"Satellite/Satellite1  EphemerisTimeSpan.Start Time  Instant"` <br><br> `"Missile/Missile1  EphemerisTimeSpan Interval"` |
| `"{TimeConstant}"` <br> (暂未实现)            | 进入固定时间。可设置的属性值包括 `Today`, `Tomorrow`, `Now`, `UseAnalysisStartTime`, `UseAnalysisStopTime` <br><br> Today, Tomorrow 表示当天或第二天的午夜。<br>  Now 设置为当前系统时间。<br>  UseAnalysisStartTime 设置为当前场景开始时间 <br> UseAnalysisStopTime  设置为当前场景结束时间 | "Today"  "UseAnalysisStopTime" |
| `"+n {Unit}"` | 设置为固定增加的时间，只对`"<StopTime>"`有 效，会为开始时间增加 一段时间。 <br><br> `{Unit}`可设置的值为：  `Day`, `Days`, `Hour`, `Hours`, `Hr`, `Hrs`, `Min`, `Mins`, `Minute`, `Minutes`, `Sec`, `Secs`, `Second`, `Seconds` | "+1 day" |
