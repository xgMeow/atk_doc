# 发射窗口分析案例

## 案例想定

本案例进行一对多的高级接近分析及结果展示介绍。

## 创建任务场景

1. 新建想定

运行 ATK.exe，点击【新建一个想定文件】新建一个想定“高级接近窗口分析”。

2. 设置仿真时间

- 在“ATK：新建想定向导”弹窗中设置时间段。

| 开始历元(UTCG)      | 结束历元(UTCG)      |
| ------------------- | ------------------- |
| 2023-02-13 00:00:00 | 2023-02-18 00:00:00 |

- 点击【确定】完成场景建立

![创建想定](media/3.17高级接近分析案例/image3-17-1.png)

## 插入卫星并进行属性设置

插入一颗卫星，卫星属性设置如图所示。

![插入卫星](media/3.17高级接近分析案例/image3-17-2.png)

![卫星属性](media/3.17高级接近分析案例/image3-17-3.png)

## 插入高级接近分析对象并进行属性设置

1. 插入高级接近分析对象，如图所示。

![插入高级接近分析对象](media/3.17高级接近分析案例/image3-17-4.png)

2. 在左侧对象视图双击高级接近分析对象或右键选择“属性”，打开属性界面。

3. 设置需要分析的时间段，这里可不勾选使用场景区间，转而自行设置，此处使用默认的场景区间。

4. 设置主目标，在左上方框中选中“卫星1”，点击向右箭头。

5. 设置次目标，在左下方框上方“类型”处，点击下拉框选择库目标，如图所示，点击新出来的“添加”按钮，导入待分析的空间目标数据库，文件目录为：...\bin\AtkInput\CAT\TLE20230212.txt;在左下方框中选中“卫星1”，点击向右箭头。

![类型下拉框](media/3.17高级接近分析案例/image3-17-5.png)

![导入库目标](media/3.17高级接近分析案例/image3-17-6.png)

6. 高级配置，将属性界面从“主配置”切换至“高级”，将“轨道历元过期门限”和“轨道路径”勾选。

7. 其他参数保持默认，设置完成的主配置和高级配置如同所示。

![高级接近分析主配置](media/3.17高级接近分析案例/image3-17-7.png)

![高级接近分析高级配置](media/3.17高级接近分析案例/image3-17-8.png)

3. 点击计算；

## 结果分析

计算完成后，点击“详细”展示计算结果，包括最近时刻、最近距离、碰撞概率等信息；

![结果显示](media/3.17高级接近分析案例/image3-17-9.png)
