案例想定

考虑到速度增量的大小，霍曼转移是两个共面圆轨道之间转移的最有效的两脉冲机动方法，霍曼转移使用椭圆转移轨道，其近拱点在内轨道，远拱点在外轨道。通过机动规划模块的脉冲机动建模和瞄准器设置，可以实现这一类问题的求解。

本案例将介绍航天器从半径 6700 km 的圆轨道转移至半径为 42238 km 的圆轨道的霍曼转移设计过程。

任务控制序列说明

为了设计一个从半径为 6700 km 的停泊轨道转移到半径为 42238 km 的目标轨道的转移轨道，我们需要构建以下任务控制序列：

  • 一个 初始段：定义半径为 6700 km 的初始停泊轨道；
  • 一个 预报段：对停泊轨道进行外推；
  • 一个 瞄准序列段：包含一个脉冲机动使航天器进入椭圆转移轨道；
  • 一个 预报段：用于将航天器轨道外推至椭圆轨道的远地点；
  • 一个 瞄准序列段：包含一个脉冲机动使航天器进入目标圆轨道；
  • 一个 预报段：用于对目标圆轨道上的航天器轨道外推。

创建任务场景

  1. 运行 ATK 软件，选择上方【开始】工具栏，点击 新建，创建一个想定文件“HohmannTransfer”。

  2. 在【ATK: 新建想定向导】对话框中设置【开始历元】与【结束历元】：

开始历元 (UTCG_MM)结束历元 (UTCG_MM)
2022-11-05 00:00:00.0002022-11-07 00:00:00.000
  1. 点击 确定 完成场景创建。

插入卫星

  1. 点击【开始】工具栏下的 插入，打开【插入对象】对话框。

  2. 选择【卫星】对象，再选择【插入默认类型】方式，点击 插入...，将对象插入场景。

  3. 右键单击新插入的【卫星】对象，点击 重命名，将其命名为“霍曼转移”。

定义初始轨道参数

  1. 双击“霍曼转移”对象，进入【属性】设置界面。

  2. 点击【轨道预报器】下拉框，选择【机动规划】。如果任务控制序列已经有默认的初始段，则直接进行定义，否则点击 新增 添加一个“初始段”，将其命名为“InitialState”。

  3. 选中“InitialState”序列，点击【坐标系】右侧的 ...，打开【选择坐标系】对话框，然后在左侧栏中选择【地球】，在右侧栏中选择【J2000】坐标系，点击 确定。

  4. 点击【坐标类型】下拉框，选择【轨道根数】，对轨道根数进行设置：

轨道根数数值
半长轴6700 km
偏心率0
轨道倾角0 deg
升交点赤经0 deg
近拱点角距0 deg
真近点角0 deg
  1. 点击右下角的 应用，完成初始轨道参数设置。

设置初始轨道预报段

  1. 如果任务控制序列已经有默认的预报段，则直接进行定义，否则点击 新增 添加一个“预报段”，将其命名为“ParkingOrbit”。

  2. 轨道预报器设置

    • 点击【轨道预报】右侧的 高级设置…；
    • 点击【中心天体】右侧的 ...，并选择【Earth】；【引力 - 模型】下拉框中选择【JGM3】；勾选【大气阻力摄动】、【太阳光压】、【三体引力 - 月球】、【三体引力 - 太阳】复选框；其余参数保持默认；
    • 点击 确定。

  3. 停止条件设置

    • 如果“ParkingOrbit”预报段已经有默认的“Duration”停止条件，则直接进行定义，否则在【停止条件】栏中，点击 新建，选择【预报时长】作为停止条件；
    • 设置【触发值】为 7200 sec；
    • 点击 应用。

机动进入椭圆转移轨道

  1. 定义瞄准序列段

    • 点击 新增 添加一个【瞄准序列段】，命名为 “StartTransfer”；
    • 鼠标左键单击“StartTransfer”下的，然后点击 新增，在“StartTransfer”序列下嵌入一个【机动段】，将其重命名为“DV1”。

  2. 选择变量

    • 右键点击该机动段“DV1”，选择【约束配置…】，双击选择【开普勒根数 - 远拱点半径】作为目标变量，点击 确定；
    • 点击【机动类型】下拉框，选择【脉冲】；点击【推力坐标轴】右侧的 ...，选择【VNC】坐标；勾选【直角坐标】复选框；
    • 点击【速度增量Vx】文字段后方的勾选图标，将其勾选为 设计变量。

  3. 设置瞄准器。选中“StartTransfer”，如果右侧已经有默认的【微分修正】瞄准器，则直接进行定义，否则点击【配置 - 新建】，选择【微分修正】，点击 确定；双击【配置 - 微分修正】栏目，进入瞄准器设置界面。

    • 分别点击【控制变量】和【约束】方框中【应用】栏下的复选框，勾选使用的变量和约束；
    控制变量约束
    ImpulseXStateCalcRadiusOfApoapsis

    • 在【约束 - 期望值】一栏中填写远地点地心距的期望值为 42238 km，其余参数保持默认；

    • 点击 确定。

设置椭圆转移轨道预报段

  1. 定义预报段。点击 新增 在“StartTransfer”后添加一个“预报段”，命名为“EllipseTransfer”，即为过渡的椭圆轨道。

  2. 轨道预报器设置

    • 点击【轨道预报】右侧的 高级设置…；
    • 点击【中心天体】右侧的 ...，并选择【Earth】；【引力 - 模型】下拉框中选择【JGM3】；勾选【大气阻力摄动】、【太阳光压】、【三体引力 - 月球】、【三体引力 - 太阳】复选框；其余参数保持默认；
    • 点击 确定。

  3. 停止条件设置。

    • 如果“EllipseTransfer”预报段已经有默认的“Duration”停止条件，则先选中该条件，然后点击 删除；
    • 在【停止条件】栏中，点击 新建，选择【远拱点】作为停止条件；
    • 点击 应用。

机动进入目标圆轨道

  1. 定义瞄准序列段

    • 点击 新增 在“EllipseTransfer”后插入一个【瞄准序列段】，将其命名为“FinalTransfer”；

    • 鼠标左键单击“FinalTransfer”下的，然后点击 新增，在“FinalTransfer”序列下嵌入一个【机动段】，将其重命名为“DV2”。

  2. 选择变量

    • 右键点击该机动段“DV2”，选择【约束配置…】，双击选择【开普勒根数 - 偏心率】作为目标变量，点击 确定；
    • 点击【机动类型】下拉框，选择【脉冲】；点击【推力坐标轴】右侧的 ...，选择【VNC】坐标；勾选【直角坐标】复选框；
    • 点击【速度增量Vx】文字段后方的勾选图标，将其勾选为 设计变量。

  3. 设置瞄准器。选中“FinalTransfer”，如果右侧已经有默认的【微分修正】瞄准器，则直接进行定义，否则点击【配置 - 新建】，选择【微分修正】，点击 确定；双击【配置 - 微分修正】栏目，进入瞄准器设置界面。

    • 分别点击【控制变量】和【约束】方框中【应用】栏下的复选框，勾选使用的变量和约束；
    控制变量约束
    ImpulseXStateCalcEccentricity

    • 在【约束 - 收敛误差】一栏中更改偏心率的收敛误差为0.001，其余参数保持默认；

    • 点击 确定。

设置目标圆轨道预报段

  1. 定义预报段。点击 新增 在“FinalTransfer”后添加一个“预报段”，命名为“FinalOrbit”。

  2. 轨道预报器设置

    • 点击【轨道预报】右侧的 高级设置…；
    • 点击【中心天体】右侧的 ...，并选择【Earth】；【引力 - 模型】下拉框中选择【JGM3】；勾选【大气阻力摄动】、【太阳光压】、【三体引力 - 月球】、【三体引力 - 太阳】复选框；其余参数保持默认；
    • 点击 确定。

  3. 停止条件设置。

    • 如果“FinalOrbit”预报段已经有默认的“Duration”停止条件，则直接进行定义，否则在【停止条件】栏中，点击 新建，选择【预报时长】作为停止条件；
    • 设置【触发值】为 172800 sec；
    • 点击 应用。

运行任务控制序列

当整个任务控制序列构建完毕后，可以点击【预报段】和【机动段】右侧的白框选择颜色，完整任务控制序列如图所示：
