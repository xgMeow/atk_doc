# LEO 到 GEO 快速转移轨道

## 案例想定

本案例的目的是将一颗卫星从半径 6700km 的近地停泊轨道转移到半径为 42164.197km 的地球静止轨道。

虽然霍曼转移是在这种情况下使用的最有效的双脉冲机动，但它同时也是最慢的机动之一。当规划中减少飞行时间是最重要的任务时（例如交会或者拦截），可以采取快速轨道转移。这种机动比霍曼转移要快得多，同时也会消耗更多燃料。

## 任务控制序列说明

为了设计一个从半径为 6700km 的近地停泊轨道转移到半径为 42164.197km 的目标轨道的快速转移轨道，我们需要构建以下任务序列。

- 一个**初始段**：定义半径为 6700km 的初始停泊轨道；
- 一个**预报段**：对停泊轨道进行外推；
- 一个**瞄准序列段**：包含一个脉冲机动使航天器进入大椭圆转移轨道；
- 一个**预报段**：用于将航天器轨道外推至椭圆轨道的指定点；
- 一个**瞄准序列段**：包含一个脉冲机动使航天器缩短转移轨道并进入外圆轨道（快速转移）；
- 一个**预报段**：用于对目标圆轨道上的航天器轨道外推。

## 创建任务场景与对象

1. 新建想定

   运行 ATK.exe，点击【新建一个想定文件】新建一个想定“Fast Transfer”。

2. 设置仿真时间

   - 在“ ATK ： 新建想定向导” 中设置 “ 开始历元” 为 2022-11-05 00:00:00.000000，“结束历元”为 2022-11-07 00:00:00.000000；

   - 点击【确定】完成场景建立。

3. 创建及编辑卫星对象

   - 点击工具栏【开始】中的【插入![](./media/3.4.2LEO到GEO快速转移轨道/image8.png)】创建卫星对象；

   - 选择“想定对象”——“卫星![](./media/3.4.2LEO到GEO快速转移轨道/image73.png)”，“选择插入方式”——“插入默认类型”，点击【插入…】，点击【关闭】；

   - 在左侧“对象”页面上，右键单击卫星“Satellite1”，选择【重命名<img src="./media/3.4.2LEO到GEO快速转移轨道/image74.jpeg" style="zoom:80%;" />】，将其命名为“FastTransfer”；

   - 在左侧“对象”页面上，右键单击卫星“FastTransfer”，选择【属性<img src="./media/3.4.2LEO到GEO快速转移轨道/image22.jpeg" style="zoom:33%;" />】，出现卫星参数设置界面，选择“轨道预报器”——“机动规划”。

## 定义初始轨道参数

如果任务控制序列已经有默认的初始段，则直接进行定义，否则点击【新增![](./media/3.4.2LEO到GEO快速转移轨道/image57.png)】按钮添加一个“初始段<img src="./media/3.4.2LEO到GEO快速转移轨道/image76.png" style="zoom:60%;" />”，将其命名为“Inner Orbit”。

1. 轨道历元设置

   设置“轨道历元（UTCG）”——“5 Nov 2022 00:00:00.000 ”。

2. 坐标相关设置

   选择“坐标系”——“Earth CAsJ2000Axes”，“坐标类型”——“轨道根数”，轨道根数设置如下表：

   |                    |        |
   | ------------------ | ------ |
   | 半长轴             | 6700km |
   | 偏心率             | 0      |
   | 轨道倾角           | 0°     |
   | 升交点赤经（RAAN） | 0°     |
   | 近拱点角距         | 0°     |
   | 真近点角           | 0°     |

## 设置初始轨道预报段

1. 定义预报段

   如果任务控制序列已经有默认的预报段，则直接进行定义，否则点击【新增![](./media/3.4.2LEO到GEO快速转移轨道/image57.png)】按钮添加一个“预报段![](./media/3.4.2LEO到GEO快速转移轨道/image54.png)”，将其命名为“Parking Orbit”。

2. 轨道预报器设置

   - 点击“轨道预报”——【高级设置…】；

   - 选择“中心天体”——“Earth”，“引力”中选择“引力场模型”——“JGM3”，勾选“大气阻力摄动”——“采用”、“太阳光压摄动”——“采用”，勾选“三体摄动”——“太阳”、“三体摄动”——“月球”，并选择“点质量”模型；

   - 点击【确定】。

   ![快速转移轨道预报段“Parking Orbit”摄动力设置](./media/3.4.2LEO到GEO快速转移轨道/image78.png '快速转移轨道预报段“Parking Orbit”摄动力设置')

3. 停止条件设置

   - 在“停止条件”中，点击【新建  ![](./media/3.4.2LEO到GEO快速转移轨道/image44.png)】图标，选择“CAsStopDuration”作为停止条件。

   - 设置“触发值”为“7200”sec。

## 机动进入椭圆转移轨道

1. 定义瞄准序列段

   - 点击【新增![](./media/3.4.2LEO到GEO快速转移轨道/image57.png)】按钮添加一个“瞄准序列段![](./media/3.4.2LEO到GEO快速转移轨道/image47.jpeg)”，命名为“Start Transfer”；

   - 点击【新增![](./media/3.4.2LEO到GEO快速转移轨道/image57.png)】按钮在“瞄准序列段![](./media/3.4.2LEO到GEO快速转移轨道/image47.jpeg)”——“Start Transfer”嵌入一个“机动段”，命名为“DV1”。

2. 选择变量

   - 选择“机动类型”——“脉冲”，“推力坐标轴”——“VNC”，坐标类型选择“直角坐标”；

   - 点击“VX”文字段后方的勾选图标![](./media/3.4.2LEO到GEO快速转移轨道/image80.png)将其勾选为设计变量![](./media/3.4.2LEO到GEO快速转移轨道/image81.png)。

   - 右键点击该机动段“DV1”，选择“约束配置…”，双击选择“KeplerianElems”——“CStateCalcRadiusOfApoapsis”作为目标变量，点击【确定】。

3. 设置瞄准器

   选中“Start Transfer”，单击“配置”——【![](./media/3.4.2LEO到GEO快速转移轨道/image51.png) 】按钮，选择“微分修正一”，单击【确定】；双击“配置”——“配置类型”——“微分修正一”，进入瞄准器设置界面。

   ![快速转移轨道瞄准序列段“Start Transfer”瞄准器设置](./media/3.4.2LEO到GEO快速转移轨道/image82.png '快速转移轨道瞄准序列段“Start Transfer”瞄准器设置')

   - 分别点击“控制变量”和“约束”中“使用”栏下的方框勾选使用的变量和约束；

   | 控制变量 | 约束                       |
   | -------- | -------------------------- |
   | ImpulseX | CStateCalcRadiusOfApoapsis |

   - 在“ 约束”——“ 期望值” 一栏中填写远地点地心距的期望值为 84328394m，“摄动量”、“收敛误差”、“最大步长”等参数选择为默认参数；

   - 设置完毕后点击【确定】，然后再进入瞄准器设置界面即可看到用户设置后的结果。

## 设置椭圆转移轨道预报段

1. 定义预报段

   点击【新增![](./media/3.4.2LEO到GEO快速转移轨道/image57.png)】按钮在“瞄准序列段![](./media/3.4.2LEO到GEO快速转移轨道/image47.jpeg)”——“Start Transfer”后添加一个“预报段![](./media/3.4.2LEO到GEO快速转移轨道/image54.png)”，命名为“Ellipse Transfer”，即为过渡的椭圆轨道。

2. 轨道预报器设置

   - 点击“轨道预报器”——【高级设置…】；

   - 选择“中心天体”——“Earth”，“引力”中选择“引力场模型”——“JGM3”，勾选“大气阻力摄动”——“采用”、“太阳光压摄动”——“采用”，勾选“三体摄动”——“太阳”、“三体摄动”——“月球”，并选择“点质量”模型；

   - 点击【确定】。

3. 停止条件设置

   在“停止条件”，点击【新建![](./media/3.4.2LEO到GEO快速转移轨道/image44.png)】图标，勾选“CAsStopRMagnitude”作为停止条件，设置触发值为 42164197m。

## 机动进入目标圆轨道

1. 定义瞄准序列段

   - 点击【新增![](./media/3.4.2LEO到GEO快速转移轨道/image57.png)】按钮在“预报段![](./media/3.4.2LEO到GEO快速转移轨道/image54.png)”——“Ellipse Transfer”后插入一个“瞄准序列段![](./media/3.4.2LEO到GEO快速转移轨道/image47.jpeg)”，将其命名为“Final Transfer”；

   - ![](./media/3.4.2LEO到GEO快速转移轨道/image57.png)】按钮在“瞄准序列段![](./media/3.4.2LEO到GEO快速转移轨道/image47.jpeg)”——“Final Transfer”嵌入一个“机动段![](./media/3.4.2LEO到GEO快速转移轨道/image85.png)”，命名为“DV2”。

2. 选择变量

   - 选择“机动类型”——“脉冲”，“推力坐标轴”——“VNC”，坐标类型选择“直角坐标”；

   - ![](./media/3.4.2LEO到GEO快速转移轨道/image86.png) 将其勾选为设计变量。

   - 右键点击该机动段“DV2”，选择“约束配置…”，双击选择“Keplerian Elems”——“CStateCalcEccentricity”作为目标变量，点击【确定】。

3. 设置瞄准器

   选中“Final Transfer”，单击“配置”——【![](./media/3.4.2LEO到GEO快速转移轨道/image51.png)】按钮，选择“微分修正一”，单击【确定】；双击“配置”——“配置类型”——“微分修正一”，进入瞄准器设置界面。

   - 分别点击“控制变量”和“约束”中“使用”栏下的方框勾选使用的控制变量和约束；

   | 控制变量 | ImpulseX               |
   | -------- | ---------------------- |
   | 控制变量 | ImpulseZ               |
   | 约束     | CStateCalcEccentricity |

   - 在“控制变量”——“最大步长”一栏中更改最大步长为 300，在“约束”——“期望值”一栏中填写偏心率的期望值为 0，在“约束”——“收敛误差”更改偏心率的收敛误差为 0.001，“摄动量”等参数可选择为默认参数；

   - 设置完毕后点击【确定】，然后再进入瞄准器设置界面即可看到用户设置后的结果。

2. 轨道预报器设置

   - 点击“轨道预报器”——【高级设置…】；

   - 选择“中心天体”——“Earth”，“引力”中选择“引力场模型”——“JGM3”，勾选“大气阻力摄动”——“采用”、“太阳光压摄动”——“采用”，勾选“三体摄动”——“太阳”、“三体摄动”——“月球”，并选择“点质量”模型；

   - 点击【确定】。

3. 停止条件设置

3. 运行结果分析

   “DV2”中“VX”和“VZ”的值是负数是因为该案例是转移到一个能量较低的轨道并且减速。

   就脉冲速度变化而言，快速转移的成本更高，但所需时间比霍曼转移少得多。
