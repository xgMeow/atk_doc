# 初轨生成案例

## 案例想定

本案例生成一个晨昏轨道卫星，升交点地方时 6:30。

## 创建任务场景与对象

1. 新建想定

   运行 ATK.exe，点击【新建一个想定文件】新建一个想定 “Morningandusktracks” 。

2. 设置仿真时间

   - 在“ATK：新建想定向导”弹窗中设置时间段。

   | 开始历元                | 结束历元                 |
   | ----------------------- | ----------------------- |
   | 2024-03-18 00:00:00.000 | 2024-03-19 00:00:00.000 |

   - 点击【确定】完成场景建立。

3. 创建卫星对象

   - 点击工具栏【开始】中的【插入 ![](media/3.10初轨生成案例/image.png)】创建卫星对象。

   - 选择“想定对象”——“卫星” ，“选择插入方式”——“轨道生成向导”，点击【插入…】，出现轨道生成向导界面。

4. 使用轨道生成向导设置卫星属性，如图所示

   - “轨道类型”选择“太阳同步轨道”。
   - “轨道高度”设置为 400000 m。
   - “升交点地方时”设置为“06:30:00.000”。
   - 点击“确定”创建卫星。
     ![轨道生成向导页面属性设置](media/3.10初轨生成案例/image-3-10-1.png)

5. 运行场景

   点击“开始<img src="./media/3.10初轨生成案例/image-31.png" style="zoom:80%;" />”运行场景，创建卫星如图所示。

   ![](media/3.10初轨生成案例/image-3-10-2.png)
