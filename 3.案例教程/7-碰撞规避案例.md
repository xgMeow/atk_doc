## 案例想定

本案例想定场景为航天器与单个重点空间目标及多目标库的多圈次碰撞规避分析。内容包括：

1. 基于精密星历与相对轨道动力学模型建立航天器碰撞规避机动评估模型，涵盖自然交会分析、机动规划分析、机动复核功能；

2. 考虑航天器与空间目标多圈周期性接近对规避效果的影响，通过优化控制量，寻找测控圈次内的控制最优解，避免控制后短期内再次出现碰撞风险；

3. 进行机动复核，提高机动规避效果，保证操作的安全性。

## 基本设置

点击 ATK.exe，点击 <kbd>工具</kbd> - <kbd>碰撞规避</kbd>，即可打开【轨控安全性分析】界面。

### 场景目标数据配置

1. 卫星星历-卫星可从场景中选择或从星历中选择。

   - **模式**为**从星历选择**，点击**星历文件**数据框右侧的![](media/3.7碰撞规避案例/image215.png)，读取**CAM**文件夹中在轨航天器精密星历数据文件[state_chaser0805.txt](#PathViewer)；代表选择卫星星历为**2022 年 8 月 2 日 23:00**至**2022 年 8 月 8 日 12:00**中心格式的在轨航天器精密星历数据；

   - 下拉菜单选择 **UTC/BJT** - <kbd>UTC</kbd> 时间格式。

2. 目标星历-目标星可从场景中选择或从星历中选择。

   - 勾选 <kbd>使用</kbd>，选择进行与指定空间目标的碰撞规避计算；

   - **模式**为**从星历选择**，点击**星历文件**数据框右侧的![](media/3.7碰撞规避案例/image215.png)，读取目标精密星历数据文件 [state_target0805.txt](#PathViewer)；代表选择目标星历为**2022 年 7 月 31 日 14:26**至**2022 年 8 月 8 日 14:26**中心格式的在轨航天器精密星历数据；

   - 下拉菜单选择 **UTC/北京时** - <kbd>UTC</kbd> 时间格式。

3. 目标数据库

   - 勾选 <kbd>使用 TLE</kbd>，单击 <kbd>选择…</kbd>，使用 TLE 数据与数据库内所有其他空间目标进行碰撞规避计算；

   - 选择并载入TLE格式数据 [3le20220805.txt](#PathViewer)；表示截止2022年8月5日**SpaceTrack**收集的所有空间目标编号。载入数据后取消勾选 <kbd>使用 TLE</kbd>，在**机动复核**功能时再勾选此按钮；

   - 单击 <kbd>设置</kbd>，输入需排除目标编号后选择 <kbd>添加</kbd>，将目标编号加入列表中，点击 <kbd>确定</kbd> 保存，其中 **SSC** 为五位数的空间目标国际编号；

   - 当不需要该空间目标时，也可在列表中选中之前保存的 SSC 编号，点击 <kbd>删除</kbd> 后，单击 <kbd>确定</kbd> 保存退出。

### 规避条件筛选

1. 设置条件约束

   - 在【交会分析门限】中输入需要规避的分析门限值**100000m**，则计算后结果仅显示小于此次输入的分析门限值 100000m 的数据；

   - 根据航天器与空间目标的相对运动状态，以及任务对计算速度和精度的要求，基于以下表格中的可选项，在【相对轨道预报模型】中选择适用于长时间多圈次的**非线性方程**：

| 名称         | 算法                   | 选择场景                                             |
| ------------ | ---------------------- | ---------------------------------------------------- |
| 线性方程     | C-W 方程               | 相对轨道模型，会损失精度但计算速度较高               |
| 非线性方程   | 解析非线性相对运动方程 | 精度高于 C-W 模型但计算速度低于 C-W 模型               |
| 解析绝对预报 | Vinti 方法             | 绝对轨道模型，精度最高，做大相对运动、较长期预报更适合 |

2. 高级设置

   - 选择【高级设置】中的**过滤器**，根据任务需求，首先勾选使用**轨道历元过期门限**和**远/近地点门限**功能；

   - 对具体内容数值进行设置如下所示。注意，可通过不同时间单位置换设定值。

| 名称             | 值      | 单位 |
| ---------------- | ------- | ---- |
| 轨道历元过期门限 | 2592000 | s    |
| 远/近地点门限     | 50000   | m    |

   - 单击选择【高级设置】中的**等效距离告警门限**；

   - 根据任务需求，设置**黄色告警**和**红色告警**数值如下表所示，单击 <kbd>确定</kbd>。

| 名称           | 值   | 单位 |
| -------------- | ---- | ---- |
| 黄色告警       | 200  | m    |
| 红色告警       | 500  | m    |
| 等效距离系数   | 10   | —    |

## 自然交会条件

根据以上步骤，在主界面上完成了各航天器和空间目标的数据配置和规避条件筛选。

1. 选择【自然交会】功能界面，单击右侧 <kbd>计算</kbd> 按钮，得出主目标与次目标的历次接近时刻对应的时间距离信息；

2. 通过计算筛选，功能界面的上栏处得出在自然交会条件下的**最近等效距离**对应的信息：

| 参数           | 数值                     | 单位 |
| -------------- | ------------------------ | ---- |
| 交会时刻       | 2022-08-05 09:25:54.479 | —    |
| 最近等效距离   | 52.847                   | m    |
| 相对距离       | 412.342                  | m    |
| 径向距离       | 52.847                   | m    |
| 横向距离       | 343.419                  | m    |
| 法向距离       | -222.030                 | m    |
| 接近角         | 65.715                   | °    |

3. 单击 <kbd>另存为</kbd> 可保存计算所得的所有数据。

## 机动规划分析

选择【避撞机动规划】功能界面，根据航天测控跟踪计划和最近等效距离时的自然交会时刻，提前一天进行避撞机动规划，输入控制时刻参数如下：

| 参数                     | 数值                           |
| ------------------------ | ------------------------------ |
| 控制时刻前限（UTC）     | 2022-08-04 09:25:54.479        |
| 控制时刻后限（UTC）     | 2022-08-04 10:25:54.479        |

根据航天器平台机动能力限制和轨道维持约束，输入半长轴控制参数如下：

| 参数                     | 数值   |
| ------------------------ | ------ |
| 半长轴控制量下限（m）     | -100   |
| 半长轴控制量上限（m）     | 100    |

基于以上输入信息，进行避撞机动规划分析操作。

1. 遍历分析

   - 选择遍历分析进行机动规划分析，勾选 <kbd>时间规划</kbd> 设定，<kbd>时间步长</kbd> 为**600s**；

   - 勾选 <kbd>控制量规划</kbd>，设定 <kbd>半长轴控制步长</kbd> 为**20m**；

   - 点击 <kbd>计算</kbd> 按钮；

   - 计算完毕后，单击 <kbd>结果</kbd> 按键，查看遍历分析结果；

![遍历分析结果](media/3.7碰撞规避案例/image220-1.png)

   - 选中需要时刻的**半长轴控制量**，单击右键 <kbd>查看详情</kbd>，查看遍历分析二级详细结果；

   - 根据所得结果，筛选**2022-08-04 09:25:54.479**控制时刻，对应的**半长轴控制量**为**-100.00000m**；

   - 选中该数据，单击 <kbd>载入机动复核</kbd>。

2. 优化分析

   - 选择优化分析进行机动规划分析，输入 <kbd>规避门限</kbd> 为**200m**；

   - 点击 <kbd>计算</kbd> 按钮；

   - 得到最优的等效距离所对应的信息：

| 控制时刻     | 2022-08-04 10:01:41.009 |
| ------------ | ----------------------- |
| 半长轴控制量 | -20.229m                |
| 交会时刻     | 2022-08-05 09:25:54.291 |
| 等效距离     | 200m                    |
| 总距离       | 2000m                   |
| 径向         | 59.150m                 |
| 横向         | -1678.662m              |
| 法向         | 1085.631m               |

   - 计算完毕后，单击 <kbd>结果</kbd> 按键，查看优化分析结果；

   - 根据最优时刻数据，单击 <kbd>载入机动复核</kbd>。

## 机动复核

1. 载入到机动复核

   - 在**避撞机动规划**的**遍历分析**中，将所选时刻数据载入到机动复核后，进入【机动复核】功能界面；

   - 检验 <kbd>控制时刻</kbd> 为2022-08-04 09:25:54.479对应的 <kbd>半长轴控制量</kbd> **-100.00000m**，是否是可行的规避控制策略，勾选 <kbd>使用 TLE</kbd> 按钮，查看机动结果是否会与其他目标发生碰撞；

   - 点击 <kbd>计算</kbd> 按钮。

2. 结果展示

   - 根据计算结果可以得出，在前后多个轨道圈次内，该策略满足规避效果约束；

![机动复核结果界面](media/3.7碰撞规避案例/image222-1.png)

   - 点击 <kbd>另存为</kbd> 功能，可保存计算所得的所有数据。

## 偏差机动复核

1. 载入机动复核

   - 通过机动规划分析后，点击 <kbd>偏差机动复核</kbd> 按键，载入到【偏差机动复核】功能界面；

   - 检验数据。检查 <kbd>控制时刻</kbd> **2022-08-04 09:25:54.479**对应的 <kbd>半长轴控制量</kbd> **-100.000m**，是否是可行的规避控制策略。

2. 估算半长轴偏差

   - 点击 <kbd>半长轴偏差估算</kbd> 按钮，根据具体航天器的性能进行估算，默认输入为以下表格数值：

| 名称              | 均值 | 标准差 3σ |
| ----------------- | ---- | --------- |
| 发动机推力（N）   | 100  | 3         |
| 航天器质量（kg）  | 100  | 0.3       |
| 开机时长（sec）   | 1    | 0.03      |
| 推力方位角（deg） | 0    | 0.003     |
| 推力俯仰角（deg） | 0    | 0.003     |

   - 单击【半长轴偏差估算】页面的 <kbd>计算</kbd> 按钮，得到 <kbd>半长轴标准差3σ（m）</kbd> 结果为**76.7844598057339**；

   - 关闭该页面，计算出的**半长轴标准差 3σ**数值自动载入【偏差机动复核】功能界面 <kbd>半长轴标准差 3σ（m）</kbd> 的输入框中。

3. 控制偏差预报

   - 点击【偏差机动复核】功能界面的 <kbd>计算</kbd> 按钮，计算完毕后，点击 <kbd>另存为</kbd> 功能，存储 txt 格式数据；

   - 根据偏差机动复核结果，单击 <kbd>控制偏差预报</kbd> 按键，设定**预报时长**为 86400s，**预报步长**为 60s；

   - 单击【控制偏差预报】的 <kbd>计算</kbd> 按钮，直接生成相应的**坐标图**和**表格**，查看偏差预报的详细情况；

   - 单击 <kbd>坐标图</kbd>，查看偏差预报坐标图；

![控制偏差预报界面](media/3.7碰撞规避案例/image225-1.png)

   - 可根据需求选择合适的**横坐标**和**纵坐标**。

| 横坐标             | 纵坐标             |
| ------------------ | ------------------ |
| 历元时刻(UTC)       | 历元时刻(UTC)       |
| 偏差均值R(m)        | 偏差均值R(m)        |
| 偏差均值T(m)        | 偏差均值T(m)        |
| 偏差均值N(m)        | 偏差均值N(m)        |
| 偏差标准差R_3σ(m)   | 偏差标准差R_3σ(m)   |
| 偏差标准差T_3σ(m)   | 偏差标准差T_3σ(m)   |
| 偏差标准差N_3σ(m)   | 偏差标准差N_3σ(m)   |

4. 查看结果与存储

   - 单击 <kbd>表格</kbd> 功能，查看控制偏差预报的具体数值；若需重新预报则再次输入数值，即可重新生成坐标图和表格数据；

   - 点击 <kbd>另存为</kbd> 功能，可保存计算所得的所有数据。
