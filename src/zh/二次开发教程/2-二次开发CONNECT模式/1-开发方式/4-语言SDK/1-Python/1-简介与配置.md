# 简介与配置

## 简介

Python SDK 是 ATK 提供的 Python 通信库，允许用户在自己的 Python 开发环境中编写脚本，通过 TCP 网络连接与 ATK 交互，实现场景搭建、参数设置、仿真运行等自动化操作。

作为 CONNECT 模式的核心开发方式之一，Python SDK 与 ATK 内置的 [Python 客户端工具](../../2-Python客户端工具/1-简介与配置.md) 共享相同的通信协议和命令格式，区别在于 Python SDK 运行在用户自建的 Python 环境中，适合需要将 ATK 功能集成到自有项目、或需要利用外部 Python 生态（如 numpy、matplotlib 等第三方库）的场景。

::: tip 开发方式选择
各开发方式的详细对比请参考 [CONNECT 模式概述](../../../README.md#开发方式对比)。
:::

## 环境与配置

### Python 环境

Python 环境需用户自行下载安装。ATK 通信库基于 Python 3 开发，当前版本为 Python 3.12，请使用与之匹配的版本，版本过低将无法导入。

若本机未安装 Python 或版本过低，也可直接使用 ATK 自带的 Python 环境（<PathCopy :entry="bundledPython" />），无需额外安装。

::: warning 注意
使用 Python SDK 发送命令前，必须打开 ATK 软件（不需要打开场景）。若需新建场景，需将已打开的场景关闭。
:::

### 通信库文件

ATK 的 Python 通信库随安装包一同提供，**接口文件与库文件统一位于安装包根目录**下：

<PathViewer :relative-paths="sdkFiles" />

- <PathCopy :entry="pythonModule" />：Python 接口模块，封装了 `atkOpen`、`atkConnect`、`atkClose` 等接口函数。
- <PathCopy :entry="pythonPyd" />：底层扩展模块，是 `ATKConnectPython.py` 的底层实现，当前仅提供 Windows 平台版本（`.pyd`）。
- <PathCopy :entry="connectorDll" />：底层通信动态库，被 `_ATKConnectPython.pyd` 依赖。
- <PathCopy :entry="pythonTest" />：官方示例源码，包含轨道快速转移案例的完整实现。
- <PathCopy :entry="pythonReadme" />：调用流程说明，介绍官方示例的运行方式。

### 配置步骤

以下流程用于在自有 Python 项目中集成 ATK 通信库。

1. 将安装包根目录下的 <PathCopy :entry="pythonModule" />、<PathCopy :entry="pythonPyd" />、<PathCopy :entry="connectorDll" /> 复制到你的 Python 项目工作目录

2. 在 Python 代码中导入所需接口函数：

```python
from ATKConnectPython import atkOpen, atkConnect, atkClose
```

::: warning 注意
`ATKConnectorDll.dll` 需与 `_ATKConnectPython.pyd` 位于同一目录，否则通信库可能因找不到依赖而无法导入。
:::

### 运行官方示例

如果只是想先验证通信库能否正常工作，可以直接运行随安装包发布的官方示例，无需搭建自己的项目。

1. 将安装根目录下的 <PathCopy :entry="helpTest" /> 复制到 ATK 安装根目录

2. 在 ATK 安装根目录执行：

```bash
python ATKConnectPythonTest.py
```

3. Linux 环境若装有多个 Python，需指定具体版本，避免默认版本过低：

```bash
python3.x ATKConnectPythonTest.py
```

4. 若 Windows 电脑未安装 Python 或版本过低，可使用 ATK 自带的 Python 解释器，在 ATK 安装根目录执行：

```bash
Python\_internal\python ATKConnectPythonTest.py
```

::: tip 说明
ATK 自带的 Python 环境版本为 3.12.1，与通信库版本对应，也可以直接使用该环境编写和运行自己的脚本。
:::

## 使用方式

完成上述配置后，即可在代码中调用三组核心 API 操控 ATK。基本流程如下：

```python
from ATKConnectPython import atkOpen, atkConnect, atkClose

# 1. 建立与 ATK 的连接
conID = atkOpen()

# 2. 发送命令（示例：新建一个场景）
atkConnect(conID, 'New', '/ Scenario MyScenario')

# 3. 断开连接
atkClose(conID)
```

详细的 API 参数说明见 [核心 API](./2-核心API.md)，完整案例见 [完整示例](./3-完整示例.md)。

## 与 Python 客户端工具的对比

| 对比项 | Python SDK | Python 客户端工具 |
| :--- | :--- | :--- |
| Python 环境 | 需自行安装和配置 | ATK 内置，无需安装 |
| 库文件 | 需手动复制到工作目录 | ATK 内置，无需配置 |
| 第三方库 | 可使用 numpy、matplotlib 等 | 仅限 ATK 内置标准库 |
| 运行方式 | 外部 IDE 或命令行 | ATK 内置客户端窗口 |
| 适用场景 | 集成到自有项目、复杂开发 | 快速上手、轻量脚本 |

::: tip 模块名区别
Python 客户端工具使用的是 ATK 内置运行时，其模块名为 `ATKConnectModule`；Python SDK 的模块名为 `ATKConnectPython`。两者不是同一个模块，导入语句不可混用。
:::
