# 完整示例

## 说明

以下以**轨道快速转移场景**为例，演示 Python SDK 操控 ATK 的完整流程：将卫星从半径为 6700 km 的近地停泊轨道（LEO）快速转移到半径为 42164.197 km 的地球同步轨道（GEO）。

::: tip 案例详解
本示例侧重展示 Python SDK 的使用流程。更多的案例原理、参数含义及分步截图请参考 [二次开发案例教程](../../../../../02-案例教程/8-二次开发案例/)。
:::

## 示例代码

完整代码随安装包发布，位于 ATK 安装目录的 `Help\Examples\08-二次开发案例\` 下：

<PathViewer :relative-paths="exampleFiles" />

代码按照 **导入模块 → 建立连接 → 创建场景 → 设置初始轨道 → 构建机动规划序列 → 运行仿真 → 保存并断开** 的主线编排，各步骤通过注释分隔，便于逐段理解和复用。

## 如何使用

::: warning 前置准备
- 使用前请确保已完成 [环境配置](./1-简介与配置.md#配置步骤)：将 `ATKConnectPython.py`、`_ATKConnectPython.pyd`、`ATKConnectorDll.dll` 复制到工作目录
- 运行前需先打开 ATK 软件
- 本示例代码中有 `New` 命令新建场景，而 ATK CONNECT 模式仅支持加载一个场景，因此**不要打开任何已有场景**；若已打开请先关闭
:::

1. 将示例文件 <PathCopy :entry="example" /> 复制到已完成环境配置的工作目录

2. 在命令行或 IDE 中运行：

```bash
python ATKConnectPythonTest.py
```

运行过程中，ATK 界面将逐步执行场景新建、卫星创建、轨道参数设置和机动规划运行等操作。

::: tip 官方示例
若只想先验证通信库是否可用，也可直接在 ATK 安装根目录下运行该示例，无需搭建自有项目，详见 [运行官方示例](./1-简介与配置.md#运行官方示例)。
:::
