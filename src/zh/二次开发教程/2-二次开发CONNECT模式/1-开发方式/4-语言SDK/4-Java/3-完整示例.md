# 完整示例

## 说明

以下以**轨道快速转移场景**为例，演示 Java SDK 操控 ATK 的完整流程：将卫星从半径为 6700 km 的近地停泊轨道（LEO）快速转移到半径为 42164.197 km 的地球同步轨道（GEO）。

::: tip 案例详解
本示例侧重展示 Java SDK 的使用流程。更多的案例原理、参数含义及分步截图请参考 [二次开发案例教程](../../../../../02-案例教程/8-二次开发案例/)。
:::

## 示例代码

代码按照 **连接 → 创建场景 → 设置初始轨道 → 构建机动规划序列 → 设置各段参数与瞄准条件 → 运行机动规划 → 查看报告 → 保存并断开** 的主线编排，各步骤通过注释分隔，便于逐段理解和复用。其中 `atkConnect` 的第 4 个参数为保留参数，统一传入空字符串 `""`。

## 如何使用

::: warning 前置准备
- 使用前请确保已完成 [环境配置](./1-简介与配置.md#配置步骤)：将 `ATKConnectJava.jar`、`ATKConnectJava.dll`、`ATKConnectorDll.dll` 复制到工作目录，并按包名放置源码
- 运行前需先打开 ATK 软件
- 本示例代码中有 `New` 命令新建场景，而 ATK CONNECT 模式仅支持加载一个场景，因此**不要打开任何已有场景**；若已打开请先关闭
:::

1. 将示例文件 <PathCopy :entry="example" /> 复制到工作目录的 `com\atk\test` 子目录下

2. 在工作目录下编译源码：

```bash
javac -cp ATKConnectJava.jar -encoding utf-8 com/atk/test/ATKConnectJavaTest.java
```

3. 运行编译生成的类文件：

```bash
java -cp ".;ATKConnectJava.jar" com.atk.test.ATKConnectJavaTest
```

运行过程中，ATK 界面将逐步执行场景新建、卫星创建、轨道参数设置和机动规划运行等操作。
