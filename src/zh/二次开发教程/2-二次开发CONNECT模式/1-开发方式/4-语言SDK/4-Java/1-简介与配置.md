# 简介与配置

## 简介

Java SDK 是 ATK 提供的 Java 通信库，允许用户在自己的 Java 开发环境中编写程序，通过 TCP 网络连接与 ATK 交互，实现场景搭建、参数设置、仿真运行等自动化操作。

作为 CONNECT 模式的核心开发方式之一，Java SDK 通过 JNI 将 ATK 底层通信动态库封装为 `com.atk.connect.ATKConnectJavaModule` 类，对外暴露静态方法，适合需要将 ATK 功能集成到 Java 项目、或需要与已有 Java 工程体系对接的场景。

::: tip 开发方式选择
各开发方式的详细对比请参考 [CONNECT 模式概述](../../../README.md#开发方式对比)。
:::

## 环境与配置

### Java 环境

Java 环境需用户自行下载安装，建议使用 JDK 8 及以上版本，并完成 `JAVA_HOME` 与 `Path` 环境变量配置，配置方法参考 [Java安装与环境配置](../../../../4-二次开发COMPONENT模式/3-Java操作流程/1-Java安装与环境配置.md)。

::: warning 注意
使用 Java SDK 发送命令前，必须打开 ATK 软件（不需要打开场景）。若需新建场景，需将已打开的场景关闭。
:::

### 通信库文件

ATK 的 Java 通信库随安装包一同提供，位于安装包目录下的 <PathCopy :entry="javaDir" /> 文件夹中：

<PathViewer :relative-paths="sdkFiles" />

- <PathCopy :entry="javaJar" />：Java 接口类库，包含 `com.atk.connect.ATKConnectJavaModule` 等类，编译与运行时均需引入。
- <PathCopy :entry="javaDll" />：JNI 本地动态库，由 `System.loadLibrary("ATKConnectJava")` 加载。
- <PathCopy :entry="connectorDll" />：底层通信动态库，被 `ATKConnectJava.dll` 依赖。
- <PathCopy :entry="javaTest" />：官方示例源码，包含轨道快速转移案例的完整实现，需放置在与其包名一致的目录下。

### 配置步骤

1. 新建一个工作目录，将 Java SDK 目录下的 <PathCopy :entry="javaJar" />、<PathCopy :entry="javaDll" />、<PathCopy :entry="connectorDll" /> 复制到该目录

2. 在工作目录下按包名创建子目录 `com\atk\test`，将示例源码 <PathCopy :entry="javaTest" />（或 <PathCopy :entry="helpTest" />，二者内容相同）复制到该目录

3. 在代码中加载动态库并导入接口方法：

```java
import static com.atk.connect.ATKConnectJavaModule.atkOpen;
import static com.atk.connect.ATKConnectJavaModule.atkConnect;
import static com.atk.connect.ATKConnectJavaModule.atkClose;

public class ATKConnectJavaTest {
  static {
    try {
      // 加载 ATKConnectJava 动态库
      System.loadLibrary("ATKConnectJava");
    } catch (UnsatisfiedLinkError e) {
      System.err.println("load dll failed\n" + e);
      System.exit(1);
    }
  }
}
```

4. 在工作目录下编译并运行（Windows 平台）：

```bash
javac -cp ATKConnectJava.jar -encoding utf-8 com/atk/test/ATKConnectJavaTest.java
java -cp ".;ATKConnectJava.jar" com/atk/test/ATKConnectJavaTest
```

::: warning 注意
- `ATKConnectJava.dll` 与 `ATKConnectorDll.dll` 需位于工作目录下，或放置在 `java.library.path` 覆盖的目录中，否则 `System.loadLibrary` 会抛出 `UnsatisfiedLinkError`。
- Linux 平台使用 `:` 作为类路径分隔符，命令为 `java -cp ".:ATKConnectJava.jar" com.atk.test.ATKConnectJavaTest`。
- 源码中包含中文时需以 UTF-8 无 BOM 编码保存，并保留编译命令中的 `-encoding utf-8`。
:::

## 使用方式

完成上述配置后，即可在代码中调用三组核心 API 操控 ATK。基本流程如下：

```java
// 1. 建立与 ATK 的连接
int conID = atkOpen("127.0.0.1", 6655);

// 2. 发送命令（示例：新建一个场景）
atkConnect(conID, "New", "/ Scenario MyScenario", "");

// 3. 断开连接
atkClose(conID);
```

::: info 说明
Java 无默认参数，`atkOpen` 的 IP 与端口需显式传入；`atkConnect` 的第 4 个参数为保留参数，固定传空字符串 `""` 即可。详见 [核心 API](./2-核心API.md)。
:::

详细的 API 参数说明见 [核心 API](./2-核心API.md)，完整案例见 [完整示例](./3-完整示例.md)。
