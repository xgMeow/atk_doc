# 完整示例

## 说明

以下以**轨道快速转移场景**为例，演示 Matlab SDK 操控 ATK 的完整流程：将卫星从半径为 6700 km 的近地停泊轨道（LEO）快速转移到半径为 42164.197 km 的地球同步轨道（GEO）。

::: tip 案例详解
本示例侧重展示 Matlab SDK 的使用流程。更多的案例原理、参数含义及分步截图请参考 [二次开发案例教程](../../../../../02-案例教程/8-二次开发案例/)。
:::

## 完整代码

完整代码按照 **加载通信库 → 连接 → 创建场景 → 设置初始轨道 → 构建机动规划序列 → 运行机动规划 → 查看报告 → 保存并断开** 的主线编排，各步骤通过注释分隔，便于逐段理解和复用。

代码以随安装包发布的 <PathCopy :entry="matlabTest" /> 为蓝本，其中 `atkConnect` 的第 4 个参数为保留参数，统一传入空字符串 `''`。

## 如何使用

::: warning 前置准备
- 使用前请确保已完成 [环境配置](./1-简介与配置.md#配置步骤)：安装 Matlab R2015b 及以上版本与 Java 1.7.0 及以上版本，并将当前路径切换到 `ATKConnectJava.jar`、`ATKConnectJava.dll`、`ATKConnectorDll.dll` 所在的安装包根目录
- 运行前需先打开 ATK 软件
- 本示例代码中有 `New` 命令新建场景，而 ATK CONNECT 模式仅支持加载一个场景，因此**不要打开任何已有场景**；若已打开请先关闭
:::

1. 将随安装包发布的示例源码 <PathCopy :entry="matlabTest" /> 复制到 ATK 安装包根目录

2. 在安装包根目录下启动 Matlab，并将该目录设为当前路径：

3. 在 Matlab 命令行中执行脚本名（不含 `.m` 后缀）：

```matlab
ATKConnectMatlabTest
```

运行过程中，ATK 界面将逐步执行场景新建、卫星创建、轨道参数设置和机动规划运行等操作。
