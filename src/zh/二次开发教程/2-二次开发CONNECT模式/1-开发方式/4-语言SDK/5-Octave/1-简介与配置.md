# 简介与配置

## 简介

Octave SDK 允许用户在自己的 Octave 环境中编写脚本，通过 TCP 网络连接与 ATK 交互，实现场景搭建、参数设置、仿真运行等自动化操作。

Octave 自身不提供专用的通信库，而是通过**内置的 Java 接口**调用 ATK 的 Java 通信库：脚本中先引入 `ATKConnectJava.jar`，再加载其本地动态库，最后创建 `com.atk.connect.ATKConnectJavaModule` 对象并调用其接口方法。因此 Octave 的接口签名与 [Java SDK](../4-Java/1-简介与配置.md) 完全一致，适合已有 Octave 环境、希望用 `.m` 脚本操控 ATK 的场景。

::: tip 开发方式选择
各开发方式的详细对比请参考 [CONNECT 模式概述](../../../README.md#开发方式对比)。
:::

## 环境与配置

### Octave 环境

Octave 环境需用户自行下载安装，建议使用 **Octave 5.2.0 及以上**版本。版本过低时内置 Java 接口可能不可用，脚本将无法加载 ATK 通信库。

### Java 环境

由于 Octave 通过内置 Java 接口调用 ATK 通信库，除 Octave 外还需另行安装 Java 环境，建议使用 **Java 1.7.0 及以上**版本，安装与环境变量配置方法参考 [Java安装与环境配置](../../../../4-二次开发COMPONENT模式/3-Java操作流程/1-Java安装与环境配置.md)。

::: warning 注意
使用 Octave SDK 发送命令前，必须打开 ATK 软件（不需要打开场景）。若需新建场景，需将已打开的场景关闭。
:::

### 通信库文件

Octave 复用 Java 的通信库，随安装包一同提供，位于**安装包根目录**下：

<PathViewer :relative-paths="sdkFiles" />

- <PathCopy :entry="javaJar" />：Java 接口类库，包含 `com.atk.connect.ATKConnectJavaModule` 等类，由脚本通过 `javaaddpath` 引入。
- <PathCopy :entry="javaDll" />：JNI 本地动态库，由 `ATKLibraryLoader` 加载。
- <PathCopy :entry="connectorDll" />：底层通信动态库，被 `ATKConnectJava.dll` 依赖。

### 配置步骤

1. 将安装包根目录设置为 Octave 的当前路径。三个库文件均已位于该目录，无需另行复制；若使用自建工作目录，则需先将上述三个文件复制到该目录。

```matlab
cd 'ATK 安装包根目录'
```

2. 在脚本中加载 ATK 通信库并创建接口对象：

```matlab
if(ispc())
	jarPath = [pwd,'\ATKConnectJava.jar'];
elseif(isunix())
	jarPath = [pwd,'/ATKConnectJava.jar'];
end
if ~any(strcmp(jarPath,javaclasspath()))
	javaaddpath(jarPath);
	javaMethod('loadLibrary', 'ATKLibraryLoader');
end
ATKConnectJavaModule = javaObject('com.atk.connect.ATKConnectJavaModule');
```

::: warning 注意
- `ATKConnectJava.dll` 与 `ATKConnectorDll.dll` 需与 `ATKConnectJava.jar` 位于同一目录，否则加载动态库时可能失败。
- 脚本会从**当前路径**（`pwd`）读取 `ATKConnectJava.jar`，因此运行前务必确认当前路径已切换到库文件所在目录。
:::

## 使用方式

完成上述配置后，即可在脚本中调用三组核心 API 操控 ATK。基本流程如下：

```matlab
% 1. 加载 ATK Java 通信库
if(ispc())
	jarPath = [pwd,'\ATKConnectJava.jar'];
elseif(isunix())
	jarPath = [pwd,'/ATKConnectJava.jar'];
end
if ~any(strcmp(jarPath,javaclasspath()))
	javaaddpath(jarPath);
	javaMethod('loadLibrary', 'ATKLibraryLoader');
end
ATKConnectJavaModule = javaObject('com.atk.connect.ATKConnectJavaModule');

% 2. 建立与 ATK 的连接
conID = ATKConnectJavaModule.atkOpen("127.0.0.1", 6655);

% 3. 发送命令（示例：新建一个场景）
ATKConnectJavaModule.atkConnect(conID, 'New', '/ Scenario MyScenario', "");

% 4. 断开连接
ATKConnectJavaModule.atkClose(conID);
```

::: info 说明
Octave 底层复用 Java 接口，无默认参数，`atkOpen` 的 IP 与端口需显式传入；`atkConnect` 的第 4 个参数为保留参数，固定传空字符串 `""` 即可。详见 [核心 API](./2-核心API.md)。
:::

详细的 API 参数说明见 [核心 API](./2-核心API.md)，完整案例见 [完整示例](./3-完整示例.md)。
