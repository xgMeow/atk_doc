# 覆盖时间

## 定义

覆盖时间表征分析对象在分析时段内处于覆盖状态的累计时长。

将不同覆盖资源产生的覆盖时段进行时间并集后，覆盖时间可表示为：

$$
T_{\mathrm{cov}}
=
\mu\left(
\bigcup_i I_i
\right),
$$

其中 $I_i$ 为各覆盖时段，$\mu(\cdot)$ 表示时段长度。

【覆盖时间】只提供整个分析时段的统计结果，不提供动态值。

## 参数说明

### 计算

【覆盖时间】支持以下计算方式：

| 计算方式 | 含义 | 设置参数 |
|---|---|---|
| **每日最大** | 各 UTC 日覆盖时长中的最大值。 | 无 |
| **每日最大百分比** | 各 UTC 日覆盖时间占当日时间比例中的最大值。 | 无 |
| **每日最小** | 各 UTC 日覆盖时长中的最小值。 | 无 |
| **每日最小百分比** | 各 UTC 日覆盖时间占当日时间比例中的最小值。 | 无 |
| **每日** | 总覆盖时长除以分析时段包含的天数，表示平均每日覆盖时间。 | 无 |
| **每日标准差** | 各 UTC 日覆盖总时长的标准差。 | 无 |
| **百分比** | 总覆盖时长占整个分析时段的百分比。 | 无 |
| **每日百分比** | 平均每日覆盖时间占比。 | 无 |
| **每日百分比标准差** | 各 UTC 日覆盖时间比例的标准差。 | 无 |
| **百分比时间高于** | 统计分析对象被至少指定数量资源同时覆盖的时间占整个分析时段的百分比。 | **最少重数** |
| **总计** | 整个分析时段内的总覆盖时长。 | 无 |
| **总计时间高于** | 统计分析对象被至少指定数量资源同时覆盖的时段长度总和。 | **最少重数** |

### 最少重数

仅当【计算】选择【百分比时间高于】或【总计时间高于】时显示。

设最少重数为 $N$，当前同时覆盖分析对象的资源数量为 $n(t)$，则只有满足：

$$
n(t)\ge N
$$

的时刻才计入对应的覆盖时间统计。

例如设置最少重数为 2：

- 【百分比时间高于】返回双重及以上覆盖时段占整个分析时段的百分比；
- 【总计时间高于】返回双重及以上覆盖时段的累计持续时间。

### 有效条件

启用【有效条件】后，可根据当前【计算】结果设置比较条件和阈值。

阈值的物理含义随计算方式变化：

- 时间类结果使用时间单位；
- 百分比类结果使用百分比；
- 其他结果以界面当前显示的单位为准。
