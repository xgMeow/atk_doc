# 重访时间

## 定义

重访时间表征了分析对象两次被覆盖的时间间隔。

::: tip 注意
为了定义“重访”含义，还需要设定最少重数，其中，最少重数表示其所认为的“被覆盖”所需满足的覆盖资源数量要求。
:::

## 特有参数

- **最少重数**：设置最少重数
- **结尾间隔段**：设置结尾间隔段为忽略或者包括。

## 统计值

|        名称        |                                           含义                                          |
|:------------------:|:---------------------------------------------------------------------------------------:|
|       平均值       |        两次被覆盖间隔的平均值，表示为所有覆盖间隔时段长度之和与覆盖间隔次数的比例。       |
|       最大值       |                                 分析时段内的最大覆盖间隔。                                |
|       最小值       |                                 分析时段内的最小覆盖间隔。                                |
|     百分比低于     |             假设所设比例为X，该统计值为V，在X%的时间范围内，重访时间都低于V。             |
| 间隔时间百分比低于 | 假设所设比例为X，该统计值为V，表示在覆盖间隔的时段内，在X%的时间范围内，重访时间都低于V。 |
|   百分比低于的值   |     假设所设比例为X，该统计值为V，表示在所有覆盖间隔中，有X%数量的覆盖间隔时长低于V。     |
|       标准差       |                               所有覆盖间隔时段长度的标准差。                              |

::: tip 注意
重访时间的计算需要考虑是否将“结尾间隔段”纳入分析范围。当忽略“结尾间隔段”时，自分析起始时刻到第一次进入“覆盖时段”，以及最后一次退出“覆盖时段”到分析结束时刻的两次覆盖间隔不再纳入统计范围。
:::
