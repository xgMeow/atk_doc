# 覆盖间隔次数

## 定义

统计分析对象在分析时段内出现的**未被覆盖时段数量**。
对于每个时刻，覆盖间隔次数为一个逻辑值，当为1时，表示当前时刻处在一个覆盖间隙内，即没有覆盖资源能够对其进行覆盖。

## 统计值

|       名称       |                                      含义                                      |
|:----------------:|:------------------------------------------------------------------------------:|
|   **每日平均**   |              总覆盖间隔次数与分析天数的比例，表征平均每天的覆盖间隔次数。              |
|   **在范围内**   |            在所设定的最小、最大范围内的覆盖间隔数量。            |
| **每日在范围内** | 满足所设定的最小、最大范围的覆盖间隔数量与分析天数的比例，表征平均每天满足条件的覆盖间隔次数。 |
|   **每日最大**   |                        各 UTC 日中，单日覆盖间隔次数的最大值。                        |
|   **每日最小**   |                        各 UTC 日中，单日覆盖间隔次数的最小值。                        |
|     **总计**     |                         在整个分析时段内，覆盖间隔的总次数。                         |

::: tip 说明
- 【总计】统计整个分析时段内出现的所有覆盖间隔次数。
- 【每日平均】、【每日在范围内】、【每日最大】和【每日最小】均按照 UTC 日统计。
- UTC 日从 UTC 零点开始，到下一日 UTC 零点结束。
- 【在范围内】和【每日在范围内】根据设定的最小值和最大值筛选覆盖间隔，只统计满足范围条件的覆盖间隔。
:::
