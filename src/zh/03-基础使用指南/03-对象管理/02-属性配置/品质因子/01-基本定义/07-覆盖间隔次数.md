# 覆盖间隔次数

## 定义

统计分析对象在分析时段内出现的**未被覆盖时段数量**。
对于每个时刻，覆盖间隔次数为一个逻辑值，当为1时，表示当前时刻处在一个覆盖间隙内，即没有覆盖资源能够对其进行覆盖。

## 参数说明

### 计算

【覆盖间隔次数】支持以下计算方式：

| 计算方式 | 含义 | 设置参数 |
|---|---|---|
| **每日平均** | 总覆盖间隔次数除以分析时段包含的天数，表示平均每天的覆盖间隔次数。 | 无 |
| **在范围内** | 统计整个分析时段内，持续时间落在指定范围内的覆盖间隙数量。 | **最小值、最大值** |
| **每日在范围内** | 满足指定持续时间范围的覆盖间隙数量除以分析时段包含的天数。 | **最小值、最大值** |
| **每日最大** | 各 UTC 日覆盖间隔次数中的最大值。 | 无 |
| **每日最小** | 各 UTC 日覆盖间隔次数中的最小值。 | 无 |
| **总计** | 整个分析时段内出现的覆盖间隙总次数。 | 无 |

### 最小值、最大值

仅当【计算】选择【在范围内】或【每日在范围内】时显示。

用于限定参与统计的覆盖间隙持续时间：$
T_{\min}
\le
T_{\mathrm{gap}}
\le
T_{\max}.
$

只有持续时间位于该范围内的覆盖间隙才被计数。

### 有效条件

启用【有效条件】后，可根据覆盖间隔次数统计结果设置比较条件和阈值。

例如设置【大于 0】，表示当分析时段内存在满足当前计算规则的覆盖间隙时，判定为满足该条件。

::: tip 说明

- 涉及“每日”的统计均按照 UTC 日划分，即从 UTC 00:00 到下一日 UTC 00:00。
- 【在范围内】和【每日在范围内】中的范围指**覆盖间隙持续时间范围**。
:::
