# 访问次数

## 定义

统计分析对象被覆盖的次数。存在交叠的不同资源产生的覆盖时段会被合并处理，在进行访问次数统计时，仅统计为1次访问。

## 统计值

|       名称       |                                            含义                                            |
|:----------------:|:------------------------------------------------------------------------------------------:|
|     **每日平均**     |                    总访问次数与分析天数的比例，表征平均每天的覆盖次数。                    |
|     **在范围内**     |                       在所设定的最小、最大时长范围内的覆盖时段数量。                       |
|   **每日在范围内**   | 满足所设定的最小、最大时长范围的时段数量与分析天数的比例，表征平均每天满足条件的覆盖次数。 |
|     **每日最大**     |                           各 UTC 日中，单日访问次数的最大值。                            |
|     **每日最小**     |                           各 UTC 日中，单日访问次数的最小值。                            |
|       **总计**       |                         在整个分析时段内，分析对象被覆盖的总次数。                         |

::: tip 说明
- 【总计】统计整个分析时段内的所有独立访问次数。
- 重叠访问不会被合并。例如同一分析对象同时被两个资源覆盖，即使两个访问时段完全重叠，也会计为两次访问。
- 【每日平均】、【每日在范围内】、【每日最大】和【每日最小】均与分析时段内包含的 UTC 日有关。
- 【在范围内】和【每日在范围内】会根据访问持续时间进行筛选，只统计满足时长范围要求的访问。
:::
