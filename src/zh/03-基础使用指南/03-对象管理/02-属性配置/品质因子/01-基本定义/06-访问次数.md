# 访问次数

## 定义

访问次数统计分析对象与各覆盖资源形成的**独立访问时段数量**。

不同资源产生的访问分别计数，即使多个资源的访问时段在时间上重叠，也不会因为重叠而合并为一次访问。

例如，分析对象分别与两个资源各形成一次访问，即使第二个资源的访问完全包含在第一个资源的访问时段内，总访问次数仍为 2。

## 参数说明

### 计算

【访问次数】支持以下计算方式：

| 计算方式 | 含义 | 设置参数 |
|---|---|---|
| **每日平均** | 总访问次数除以分析时段包含的天数，表示平均每天的访问次数。 | 无 |
| **在范围内** | 统计整个分析时段内，持续时间落在指定范围内的访问数量。 | **最小值、最大值** |
| **每日在范围内** | 满足指定持续时间范围的访问数量除以分析时段包含的天数。 | **最小值、最大值** |
| **每日最大** | 各 UTC 日访问次数中的最大值。 | 无 |
| **每日最小** | 各 UTC 日访问次数中的最小值。 | 无 |
| **总计** | 整个分析时段内所有独立访问的总次数。 | 无 |

### 最小值、最大值

仅当【计算】选择【在范围内】或【每日在范围内】时显示。

二者用于限定参与次数统计的访问持续时间：

$$
T_{\min}
\le
T_{\mathrm{access}}
\le
T_{\max}.
$$

只有访问持续时间位于该范围内的访问才被计数。

可见[访问时长](./02-访问时长.md)

### 有效条件

启用【有效条件】后，可根据访问次数统计结果设置比较条件和阈值。

例如设置【大于 0】，表示只有至少发生一次满足当前计算规则的访问时，才满足有效条件。

::: tip 说明

- 【总计】统计所有独立访问，不因不同资源之间的时间重叠而合并。
- 涉及“每日”的统计均按照 UTC 日划分，即从 UTC 00:00 到下一日 UTC 00:00。
- 【在范围内】和【每日在范围内】中的范围指**访问持续时间范围**，不是访问发生时刻范围。
:::
