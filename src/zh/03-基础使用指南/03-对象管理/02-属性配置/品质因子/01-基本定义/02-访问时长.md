# 访问时长

## 定义

统计在分析时段内，单个资源对分析对象的可用覆盖时间。对于每个时刻而言，访问时间表示包含当前时间的最大覆盖弧段的时间长度。如下图所示，包含当前时刻的时段分别有400 s和240 s两个覆盖弧段，此时，取最大的弧段长度作为该时刻的访问时长，即当前时刻该品质因子值为400 s。当该值为0时，表示对应时刻分析对象未被任何一个覆盖资源覆盖。

![访问时长](./media/访问时长/image.png)

::: tip 说明
计算该指标时，不会合并不同资源的覆盖时段。
:::

## 统计值

|     名称     |                                      含义                                      |
|:------------:|:------------------------------------------------------------------------------:|
|   **平均值**   |                  分析时段内，所有访问时段持续时间的平均值。                  |
|   **最大值**   |                    分析时段内，所有访问时段中的最大持续时间。                    |
|   **最小值**   |                    分析时段内，所有访问时段中的最小持续时间。                    |
| **百分比高于** | 计算一个访问时长阈值，使分析对象在指定百分比的时间内处于持续时间不小于该阈值的访问时段中。 |
|   **标准差**   |                  分析时段内，所有访问时段持续时间的标准差。                  |
|    **总和**    |                  分析时段内，所有访问时段持续时间的总和。                  |

::: tip 说明
- 【平均值】、【最大值】、【最小值】、【标准差】和【总和】均基于整个分析时段内的访问时段计算。
- 【百分比高于】需要指定百分比水平，用于描述访问时长达到某一阈值的时间占比。
- 【总和】表示所有独立访问时段持续时间的累加值，不会因不同资源之间存在重叠而自动合并。
- 若分析对象在分析时段内没有被覆盖，则相关统计结果可能为空值或按系统无效值规则处理。
:::
