# 发射器

发射器用于建立通信系统的发射端模型，通过设置频率、功率、数据速率、天线、调制方式、滤波器及额外损益等参数，描述信号的发射特性，为通信链路分析提供输入。

支持对象：车辆、卫星、传感器、潜艇、舰船、导弹、火箭、地面站和飞机。包含 **基本属性、约束、RF** 三大配置模块。

---

## 基本属性

发射器分为发射机类和转发器类，共支持六种模型。在发射器属性的 **基本 - 定义** 页面，通过顶部的 **类型** 选择所需模型。

| 类别 | 模型类型 | 功能 |
| --- | --- | --- |
| 发射机类 | 简单发射机模型 | 直接指定等效全向辐射功率（EIRP），描述发射端的辐射能力。 |
| 发射机类 | 中等发射机模型 | 分别指定发射功率和发射增益，描述发射端的辐射能力。 |
| 发射机类 | 复杂发射机模型 | 指定发射功率，并通过天线模型描述天线增益及其方向性。 |
| 转发器类 | 简单转发器模型 | 指定饱和EIRP，通过频率转换和功率回退描述转发输出。 |
| 转发器类 | 中等转发器模型 | 分别指定饱和发射功率和发射增益，描述转发输出。 |
| 转发器类 | 复杂转发器模型 | 指定饱和发射功率，通过天线模型确定增益，描述转发输出。 |

### 发射机类

#### 模型选择与页面组成

三种发射机模型主要区别在于功率与天线特性的定义方式，其 **调制器** 、 **滤波器** 和 **额外损益** 设置方法相同。

| 设置项目 | 简单发射机模型 | 中等发射机模型 | 复杂发射机模型 |
| --- | --- | --- | --- |
| 频率、数据速率 | 在 **模型规格** 中设置。 | 在 **模型规格** 中设置。 | 在 **模型规格** 中设置。 |
| 辐射能力 | 输入 **EIRP** 。 | 输入 **功率** 和 **发射增益** 。 | 输入 **功率** ，由天线模型确定增益。 |
| 天线设计频率 | 无独立设置项。 | 无独立设置项。 | 在顶层 **模型规格** 中只读显示。 |
| 天线模型 | 无独立 **天线** 页面。 | 无独立 **天线** 页面。 | 在 **天线** 页面设置“嵌入”或“链接”类型天线。前者需要自定义天线参数，后者引用已有天线，需提前插入 **天线** 在此对象中。 |
| 极化 | 在 **模型规格** 的 **天线极化** 区域设置。 | 在 **模型规格** 的 **天线极化** 区域设置。 | 在 **天线 - 极化** 中设置。 |
| 指向 | 无独立天线指向设置。 | 无独立天线指向设置。 | 选择 **嵌入** 后，可在 **天线 - 指向** 中设置。 |
| 调制器、滤波器、额外损益 | 设置方法见下文 **调制器** 、 **滤波器** 和 **额外损益** 。 | 设置方法见下文 **调制器** 、 **滤波器** 和 **额外损益** 。 | 设置方法见下文 **调制器** 、 **滤波器** 和 **额外损益** 。 |

已知发射端EIRP时，可选择简单发射机模型；已知发射功率和固定天线增益时，可选择中等发射机模型；需要考虑天线方向图及安装指向对通信的影响时，可选择复杂发射机模型。

#### 简单发射机模型

在 **类型** 中选择 **简单发射机模型** 。页面包括 **模型规格** 、 **调制器** 、 **滤波器** 和 **额外损益** 。

**模型规格** 用于设置发射频率、数据速率、EIRP及天线极化。

| 参数 | 含义 | 使用方法 |
| --- | --- | --- |
| 频率 | 发射信号的载波频率。 | 输入发射频率，并通过右侧单位框选择相应频率单位。 |
| 数据速率(Mb/sec) | 发射端单位时间内传输的数据比特数。 | 按通信任务的数据传输要求输入，单位为 Mb/sec 。 |
| EIRP(dBW) | 等效全向辐射功率，用于综合描述发射功率与天线增益形成的辐射能力。 | 直接输入已知的EIRP，单位为 dBW 。 |
| 天线极化 | 发射信号的电场方向及其变化形式。 | 根据需要勾选 **使用** ，设置极化类型及相关参数，详见 **天线极化** 。 |

EIRP与发射机输出功率含义不同。在不计馈线损耗及其他损益时，两者满足：

$$
\mathrm{EIRP}=P_t+G_t
$$

其中，$P_t$为发射功率，单位为dBW；$G_t$为相对于理想全向天线的增益，单位为dBi；EIRP的单位为dBW。简单发射机模型直接使用输入的EIRP，不需要再单独输入发射增益。

**滤波器** 及 **额外损益** 中的设置还会影响链路计算中的发射端功率结果，因此应避免将同一项损耗重复计入EIRP和其他设置项。

#### 中等发射机模型

在 **类型** 中选择 **中等发射机模型** 。页面组成与简单发射机模型相同。

中等发射机模型在 **模型规格** 中以 **功率** 和 **发射增益** 代替简单模型的 **EIRP** 输入，其余设置方法相同。

| 参数 | 含义 | 使用方法 |
| --- | --- | --- |
| 频率 | 发射信号的载波频率。 | 输入发射频率并选择相应单位。 |
| 数据速率(Mb/sec) | 发射端单位时间内传输的数据比特数。 | 按通信任务要求输入数据速率。 |
| 功率(dBW) | 发射机的射频输出功率。 | 输入发射功率，单位为dBW；该项不包含另行设置的发射增益。 |
| 发射增益(dB) | 发射天线的增益，用于与发射功率共同确定发射端的辐射能力。 | 输入天线增益。界面以dB标注；用于EIRP计算时，其物理参考为理想全向天线。 |
| 天线极化 | 发射信号的极化特性。 | 设置方法与简单模型相同，详见 **天线极化** 。 |

该模型使用指定的发射增益进行计算。需要通过天线方向图描述不同方向上的增益时，应选择复杂发射机模型。

#### 复杂发射机模型

在 **类型** 中选择 **复杂发射机模型** 。页面包括 **模型规格** 、 **天线** 、 **调制器** 、 **滤波器** 和 **额外损益** 。

复杂发射机模型通过天线模型描述辐射特性，顶层 **模型规格** 不再单独设置 **发射增益** ；极化设置位于 **天线 - 极化** 。

##### 模型规格

| 参数 | 含义 | 使用方法 |
| --- | --- | --- |
| 频率 | 发射信号的载波频率。 | 输入发射频率并选择相应单位。 |
| 数据速率(Mb/sec) | 发射端单位时间内传输的数据比特数。 | 按通信任务要求输入数据速率。 |
| 功率(dBW) | 发射机的射频输出功率。 | 输入发射功率，天线增益由所使用的天线模型确定。 |
| 天线设计频率 | 所使用天线的设计频率，用于反映天线模型的频率配置。 | 此处为只读显示，不能直接修改；天线参数在相应天线配置中设置。 |

**频率** 表示发射信号的载波频率， **天线设计频率** 表示天线模型的设计频率，两者含义不同，应分别核对。

##### 天线

进入 **天线** 页面，通过 **引用类型** 选择天线的配置方式。该页面包含 **模型规格** 、 **极化** 和 **指向** 三个子页面。

- **嵌入**：在当前发射机内定义天线模型，并设置极化和指向。
- **链接**：引用当前对象中已有的天线，在 **模型规格** 中查看 **天线名称** 及只读的天线模型参数。**天线名称** 仅显示当前链接的天线；如需修改天线模型参数，应进入对应天线对象的属性进行设置。

只有 **引用类型** 为 **嵌入** 时，才能在当前发射机内设置 **指向** 。

**天线 - 模型规格** 对应天线对象的 **基本 - 定义** 页面。天线类型、模型参数及指向的详细说明，请参见 [天线使用说明](./天线.md)。

**天线 - 极化** 用于设置发射信号的极化特性，其参数与简单、中等模型 **模型规格** 中的 **天线极化** 一致，详见本文的 **天线极化** 。

#### 天线极化

极化描述电磁波电场矢量的方向及其随时间变化的形式。发射端与接收端的极化匹配情况会影响通信链路的功率接收效果。

简单和中等模型在 **模型规格 - 天线极化** 中设置；复杂模型在 **天线 - 极化** 中设置。

| 参数 | 含义 | 使用方法 |
| --- | --- | --- |
| 使用 | 是否启用天线极化设置。 | 需要定义极化特性时勾选，并配置相关参数。 |
| 类型 | 发射信号的极化方式。 | 从线极化、水平极化、垂直极化、左旋圆极化和右旋圆极化中选择。 |
| 参考轴 | 定义极化方向所使用的参考坐标轴。 | 在需要参考轴的极化类型下，从X轴、Y轴、Z轴中选择。 |
| 极化角度(deg) | 用于确定线极化方向相对于所选参考方向的偏转角。 | 在对应参数可编辑时输入极化角度，并核对角度单位。 |

| 极化类型 | 含义 |
| --- | --- |
| 线极化 | 电场矢量沿固定方向振动，可通过参考轴和极化角度定义方向。 |
| 水平极化 | 电场振动方向取所用参考定义下的水平方向。 |
| 垂直极化 | 电场振动方向取所用参考定义下的垂直方向。 |
| 左旋圆极化 | 电场矢量按左旋圆极化方式旋转。 |
| 右旋圆极化 | 电场矢量按右旋圆极化方式旋转。 |

选择极化类型后，设置该类型下可编辑的参数。水平、垂直方向应结合所选参考轴理解，不能直接等同于屏幕中的水平、垂直方向。

##### 天线极化损耗计算

极化损耗由发射信号与接收天线的极化状态不匹配引起。以下以$L_p$表示极化损耗，单位为dB，统一采用正值表示损耗。

###### 线极化

需要考虑3-4dB的极化损耗。同方向圆极化考虑0.5-2dB的极化损耗。

###### 水平极化

极化损耗计算公式为：

$$
L_p=-20\log_{10}|\cos\theta|
$$

其中，$\theta$为发射信号与接收天线的极化方向在同一参考平面内的夹角。

###### 垂直极化

极化损耗计算公式为：

$$
L_p=-20\log_{10}|\cos\theta|
$$

其中，$\theta$为发射信号与接收天线之间的极化方向夹角。

###### 左旋圆极化

考虑非理想圆极化的轴比影响时，极化损耗可表示为：

$$
L_p
=
-10\log_{10}
\left\{
\frac{1}{2}
\left[
1+
\frac{
\pm 4X_rX_t
+
(1-X_t^2)(1-X_r^2)\cos(2\alpha)
}{
(1+X_t^2)(1+X_r^2)
}
\right]
\right\}
$$

其中，$X_t$为入射波的轴比，$X_r$为接收天线极化的轴比。轴比为极化椭圆长轴与短轴方向的电场幅值之比，采用线性比值；$\alpha$为两极化椭圆长轴方向的夹角。

按一致的传播方向约定判断旋向，相同旋向取“+”，相反旋向取“−”。理想圆极化的轴比为1。

###### 右旋圆极化

右旋圆极化与左旋圆极化采用相同的轴比损耗公式，公式中的正负号根据收发极化旋向是否一致确定。

#### 调制器

用于发射信号的调制编码方式及频谱描述方式。三种发射机模型的设置方法相同。

##### 调制类型

通过 **类型** 选择调制方式或预置的调制编码组合。

| 类型 | 含义 |
| --- | --- |
| BPSK | 二进制相移键控。 |
| QPSK | 四相相移键控。 |
| 8PSK | 八相相移键控。 |
| 16PSK | 十六相相移键控。 |
| BPSK-BCH-511-259 | BPSK调制与BCH编码的预置组合。 |
| BPSK-Conv-4-3-8 | BPSK调制与卷积编码的预置组合。 |
| PCM FM | 脉冲编码调制与调频相结合的方式。 |
| CPM | 连续相位调制。 |

根据通信系统采用的调制和编码方式选择相应类型。上述类型共用本页面的设置项，切换类型后无需填写额外的专属参数。

##### 信号功率谱密度

信号功率谱密度（PSD）用于描述信号功率随频率的分布。

| 参数 | 含义 | 使用方法 |
| --- | --- | --- |
| 选择信号PSD | 是否采用信号功率谱密度描述发射信号的频谱。 | 勾选后使用信号PSD，下方 **信号带宽** 区域中的全部参数变为只读。 |
| 空频谱数量 | 用于限定信号频谱截取范围的频谱零点数量。 | 使用信号PSD时，设置参与频谱描述的零点数量；该参数会影响所采用的频谱范围。 |

勾选 **选择信号PSD** 后，不能在下方 **信号带宽** 区域手动修改带宽及其上下边界。如需设置该区域，应先取消勾选 **选择信号PSD** ，再根据自动或手动设置方式调整可编辑参数。

##### 信号带宽

**信号带宽** 用于设置发射信号在频域中的范围。

| 参数 | 含义 | 使用方法 |
| --- | --- | --- |
| 自动调整带宽 | 根据调制方式、数据速率等信号参数确定带宽。 | 未勾选 **选择信号PSD** 时，可通过该选项选择自动确定带宽；需要手动指定时取消勾选。 |
| 对称调节 | 控制频谱范围是否相对于载波频率对称。 | 手动设置带宽时，按信号频谱是否对称选择该项。 |
| 高频段截止频率 | 信号频谱相对于载波频率的上边界。 | 参数可编辑时，输入频率上边界并选择单位。 |
| 低频段截止频率 | 信号频谱相对于载波频率的下边界。 | 参数可编辑时，输入频率下边界并选择单位。 |
| 带宽 | 信号频谱上下边界之间的频率跨度。 | 根据当前设置方式查看或设置带宽；只读状态下由软件确定。 |

这里的频谱上下边界以载波频率为参考，不是发射载波的绝对频率。下边界可表示为负频偏，带宽为上边界与下边界之差。对称设置时，上、下边界相对于载波频率互为相反数。

#### 滤波器

**滤波器** 用于对发射机的发射信号功率谱密度（PSD）进行滤波，描述发射信号通过滤波器后的频谱变化及相应损耗。三种发射机模型的设置方法相同。

勾选 **使用** 后，选择滤波器类型并设置参数；取消勾选时，不启用该滤波器设置。支持的类型包括贝塞尔、巴特沃兹、切比雪夫、高斯窗和升余弦。

##### 公共参数

| 参数 | 含义 | 使用方法 |
| --- | --- | --- |
| 使用 | 是否启用滤波器。 | 需要对发射信号进行滤波建模时勾选。 |
| 类型 | 所采用的滤波器模型。 | 从类型下拉列表中选择，页面随之显示相应参数。 |
| 高频段截止频率 | 滤波器频谱计算范围相对于载波频率的上边界。 | 输入高频侧边界并选择单位。 |
| 低频段截止频率 | 滤波器频谱计算范围相对于载波频率的下边界。 | 输入低频侧边界并选择单位。 |
| 带宽 | 高频侧边界与低频侧边界之间的频率跨度。 | 由上下边界确定，为只读显示。 |
| 插入损耗(dB) | 插入滤波器所引入的固定信号功率损耗。 | 按设备参数输入，区别于滤波器频率响应产生的频谱损耗。 |

**高频段截止频率** 和 **低频段截止频率** 规定所采用的频谱范围；部分滤波器另设的 **截止频率** 用于定义其频率响应特征，二者含义不同。

##### 类型与专属参数

| 滤波器类型 | 特点 | 公共参数之外的设置项 |
| --- | --- | --- |
| 贝塞尔 | 注重相位与群时延特性，用于描述有波形保真要求的滤波响应。 | 次数、截止频率。 |
| 巴特沃兹 | 具有平坦的通带幅度响应。 | 次数、截止频率。 |
| 切比雪夫 | 通过允许幅度响应起伏，获得较陡的频率过渡特性。 | 次数、截止频率、脉冲因子。 |
| 高斯窗 | 使用高斯窗形式描述滤波特性。 | 次数、采样频率。 |
| 升余弦 | 使用升余弦形式描述频谱过渡，常用于通信信号成形。 | 滚降因子、符号率。 |

| 参数 | 适用类型 | 含义与使用方法 |
| --- | --- | --- |
| 次数 | 贝塞尔、巴特沃兹、切比雪夫、高斯窗 | 滤波器的阶数参数。按所选滤波器的设计要求设置，用于确定其响应形式。 |
| 截止频率 | 贝塞尔、巴特沃兹、切比雪夫 | 描述滤波器响应由通带向衰减区过渡的特征频率。输入相应频率并选择单位。 |
| 脉冲因子(dB) | 切比雪夫 | 用于控制切比雪夫滤波器幅度响应的起伏，即纹波参数。按所需纹波大小设置，名称沿用界面标注。 |
| 采样频率 | 高斯窗 | 高斯窗滤波器的采样频率参数。按滤波器设计要求设置，并选择相应单位。 |
| 滚降因子(%) | 升余弦 | 控制升余弦频谱的过渡区域及超额带宽。按信号成形要求输入。 |
| 符号率(Mb/s) | 升余弦 | 每秒传输的调制符号数量，与滚降因子共同影响滤波器带宽。根据调制信号的符号速率设置；界面单位标注为Mb/s。 |

符号率与 **模型规格** 中的数据速率含义不同。数据速率按比特计数，符号率按调制符号计数，两者的关系取决于调制方式与编码方式，不能直接视为同一参数。

##### 各类滤波器的计算模型

以下给出各类滤波器的基本数学形式，用于说明其响应特性和参数含义。公式中的$f$表示相对于载波频率的频偏，各频率参数应采用一致的单位。

###### 巴特沃兹滤波器

$n$阶巴特沃兹滤波器的幅度响应可表示为：

$$
|H(f)|
=
\frac{1}
{\sqrt{1+\left(\frac{f}{f_c}\right)^{2n}}}
$$

其中，$n$为滤波器阶数，对应 **次数** ；$f_c$为截止频率，对应 **截止频率** 。

###### 切比雪夫滤波器

切比雪夫滤波器的幅度响应可表示为：

$$
|H(f)|
=
\frac{1}
{\sqrt{1+E^2C_n^2\left(\frac{f}{f_c}\right)}}
$$

其中，$n$为滤波器阶数；$E$为控制通带纹波的设计常数；$C_n(x)$为$n$阶切比雪夫多项式；$f_c$为该原型模型的通带边缘频率。

切比雪夫多项式满足以下递推关系：

$$
C_n(x)
=
2xC_{n-1}(x)-C_{n-2}(x),
\qquad n\geq 2
$$

初始条件为：

$$
C_0(x)=1,
\qquad
C_1(x)=x
$$

###### 贝塞尔滤波器

贝塞尔滤波器的频率响应可采用以下多项式形式表示：

$$
H(f)
=
\frac{K_n}
{B_n\left(\frac{f}{f_b}\right)}
$$

其中，$n$为滤波器阶数；$f_b$为这个滤波器的截止频率；$B_n(x)$为在虚频率轴上表示的贝塞尔多项式；$K_n$为归一化系数。

多项式的递推关系为：

$$
B_n(x)
=
(2n-1)B_{n-1}(x)-x^2B_{n-2}(x),
\qquad n\geq 2
$$

初始条件及归一化系数为：

$$
B_0(x)=1,
\qquad
B_1(x)=1+jx,
\qquad
K_n=B_n(0)
$$

其中，$j$为虚数单位，幅度响应取$|H(f)|$。

###### 高斯窗滤波器

高斯窗滤波器采用高斯函数描述平滑衰减的权重特性。高斯函数的标准形式为：

$$
G(x,y)
=
\frac{1}{2\pi\sigma^2}
\exp\left(
-\frac{x^2+y^2}{2\sigma^2}
\right)
$$

其中，$G(x,y)$为高斯函数；$\sigma$为标准差，控制函数分布的宽度；$x、y$为二维坐标变量。

###### 升余弦滤波器

升余弦滤波器由通带、余弦过渡带和阻带组成。其频率响应为：

$$
H(f)
=
\begin{cases}
T,
&
|f|\leq \dfrac{1-\alpha}{2T},
\\[8pt]
\dfrac{T}{2}
\left[
1+
\cos\left(
\dfrac{\pi T}{\alpha}
\left(
|f|-\dfrac{1-\alpha}{2T}
\right)
\right)
\right],
&
\dfrac{1-\alpha}{2T}
<
|f|
\leq
\dfrac{1+\alpha}{2T},
\\[10pt]
0,
&
|f|>
\dfrac{1+\alpha}{2T}.
\end{cases}
$$

其中，$T$为符号周期，与符号率$R_s$满足$T=1/R_s$；$\alpha$为滚降因子，取值范围为$0\leq\alpha\leq 1$。

#### 额外损益

**额外损益** 用于补充描述发射端的附加增益或损耗。三种发射机模型的设置方法相同。

| 参数 | 含义 | 使用方法 |
| --- | --- | --- |
| 增益/损耗(dB) | 除已单独建模项目外，对发射端施加的附加净增益或净损耗。 | 输入附加损益的代数值，正值表示增益，负值表示损耗。 |

设置时应明确各项损益的归属。已在 **EIRP** 、 **功率** 或 **滤波器** 中计入的同一项损耗，不应再重复计入 **额外损益** 。

#### 配置流程

- 打开发射器属性，在 **基本 - 定义** 页面选择发射机模型类型。
- 在 **模型规格** 中设置频率、数据速率及相应的EIRP或功率参数。中等模型还需设置发射增益。
- 使用复杂模型时，进入 **天线** 页面选择 **嵌入** 或 **链接** ；嵌入方式下配置天线模型及指向，链接方式下核对被引用的天线。
- 根据所选模型，在 **模型规格 - 天线极化** 或 **天线 - 极化** 中设置极化特性。
- 在 **调制器** 中选择调制类型，确定是否使用信号PSD，并设置对应的频谱或带宽参数。
- 根据需要启用 **滤波器** ，设置所选类型的公共参数和专属参数。
- 在 **额外损益** 中设置尚未计入的附加增益或损耗。
- 核对各项参数及单位，点击 **应用** 保存当前设置，或点击 **确定** 保存并关闭属性窗口。

### 转发器类

转发器用于描述接收信号经频率转换和功率调整后重新发射的过程。通过设置饱和通量密度、饱和辐射能力及转换方法，确定转发信号的输出频率和功率。

#### 模型选择与页面组成

三种转发器模型主要区别在于饱和辐射能力与天线特性的定义方式，其 **转换方法** 、 **滤波器** 和 **额外损益** 设置方法相同。

| 设置项目 | 简单转发器模型 | 中等转发器模型 | 复杂转发器模型 |
| --- | --- | --- | --- |
| 饱和通量密度 | 在 **模型规格** 中设置。 | 在 **模型规格** 中设置。 | 在 **模型规格** 中设置。 |
| 饱和辐射能力 | 输入 **卫星 EIRP** 。 | 输入 **功率** 和 **发射增益** 。 | 输入 **功率** ，由天线模型确定增益。 |
| 天线模型 | 无独立 **天线** 页面。 | 无独立 **天线** 页面。 | 在 **天线** 页面设置嵌入或链接类型天线。 |
| 极化 | 在 **模型规格 - 天线极化** 中设置。 | 在 **模型规格 - 天线极化** 中设置。 | 在 **天线 - 极化** 中设置。 |
| 转换方法 | 设置频率转换和功率回退的系数。 | 设置方法与简单模型相同。 | 设置方法与简单模型相同。 |
| 滤波器、额外损益 | 设置方法与发射机相同。 | 设置方法与发射机相同。 | 设置方法与发射机相同。 |

已知饱和EIRP时，可选择简单转发器模型；已知饱和发射功率和固定天线增益时，可选择中等转发器模型；需要通过天线方向图计算通信方向上的增益时，可选择复杂转发器模型。

#### 简单转发器模型

在 **类型** 中选择 **简单转发器模型** 。页面包括 **模型规格** 、 **转换方法** 、 **滤波器** 和 **额外损益** 。

**模型规格** 用于设置饱和通量密度、饱和EIRP及天线极化。

| 参数 | 含义 | 使用方法 |
| --- | --- | --- |
| 饱和通量密度(dBW/m²) | 使转发器达到饱和输出状态所需的输入功率通量密度，是计算输入功率回退的参考值。 | 根据转发器的性能参数输入，单位为dBW/m²。 |
| 卫星 EIRP(dBW) | 转发器在饱和状态下的等效全向辐射功率，综合反映饱和发射功率和天线增益。 | 直接输入已知的饱和EIRP，单位为dBW。 |
| 天线极化 | 转发信号的极化特性。 | 根据需要勾选 **使用** ，设置极化类型及相关参数，方法与发射机类的 **天线极化** 相同。 |

**卫星 EIRP** 为饱和状态下的参考值，实际输出还受 **功率回退** 、 **滤波器** 和 **额外损益** 等设置影响。

#### 中等转发器模型

在 **类型** 中选择 **中等转发器模型** 。页面组成与简单转发器模型相同。

中等转发器模型在 **模型规格** 中以 **功率** 和 **发射增益** 代替简单模型的 **卫星 EIRP** 输入，其余设置方法相同。

| 参数 | 含义 | 使用方法 |
| --- | --- | --- |
| 饱和通量密度(dBW/m²) | 使转发器达到饱和输出状态所需的输入功率通量密度。 | 根据转发器的性能参数输入，单位为dBW/m²。 |
| 功率(dBW) | 转发器的饱和发射功率，不包含另行设置的天线增益。 | 输入饱和发射功率，单位为dBW。 |
| 发射增益(dB) | 发射天线的增益，与饱和发射功率共同确定饱和EIRP。 | 输入天线增益，设置方法与中等发射机模型相同。 |
| 天线极化 | 转发信号的极化特性。 | 设置方法与简单转发器模型相同。 |

该模型使用指定的发射增益进行计算。需要考虑天线方向性时，应选择复杂转发器模型。

#### 复杂转发器模型

在 **类型** 中选择 **复杂转发器模型** 。页面包括 **模型规格** 、 **天线** 、 **转换方法** 、 **滤波器** 和 **额外损益** 。

复杂转发器模型通过天线方向图及通信方向确定天线增益，极化设置位于 **天线 - 极化** 。

##### 模型规格

| 参数 | 含义 | 使用方法 |
| --- | --- | --- |
| 饱和通量密度(dBW/m²) | 使转发器达到饱和输出状态所需的输入功率通量密度。 | 根据转发器的性能参数输入，单位为dBW/m²。 |
| 功率(dBW) | 转发器的饱和发射功率。 | 输入饱和发射功率，天线增益由所使用的天线模型确定。 |

##### 天线

**天线** 页面的参数及设置方法与复杂发射机模型相同，包括 **模型规格** 、 **极化** 和 **指向** 三个子页面。

通过 **引用类型** 选择 **嵌入** 或 **链接** 。选择 **嵌入** 时，在当前转发器内定义天线模型并设置指向；选择 **链接** 时，引用已有天线对象，天线模型参数为只读。如需修改，应进入对应天线对象的属性进行设置。

只有 **引用类型** 为 **嵌入** 时，才能在当前转发器内设置 **指向** 。

**天线 - 模型规格** 对应天线对象的 **基本 - 定义** 页面。天线类型、模型参数及指向的详细说明，请参见 [天线使用说明](./天线.md)。

**天线 - 极化** 的参数及计算方法见发射机类的 **天线极化** 。

#### 转换方法

**转换方法** 用于定义输入信号与转发输出信号之间的频率和功率关系，包含 **频率** 和 **功率回退** 两个子页面。三种转发器模型的设置方法相同。

##### 频率

**转换方法 - 频率** 用于设置频率转换多项式的系数，根据输入频率计算输出频率：

$$
f_{\mathrm{out}}
=a_0+a_1f_{\mathrm{in}}+a_2f_{\mathrm{in}}^2+\cdots+a_nf_{\mathrm{in}}^n
$$

其中，$f_{\mathrm{in}}$为输入频率，$f_{\mathrm{out}}$为输出频率，$a_i$为多项式各项的系数，$n$为多项式阶数。

根据所需的频率转换关系填写系数。常数项用于描述固定频率偏移，一次项用于描述输入频率的比例变化；需要非线性转换时，可设置更高次项。系数应与计算采用的频率单位一致。

##### 功率回退

**转换方法 - 功率回退** 用于设置输入功率回退与输出功率回退之间的转换关系。

输入功率回退量由饱和通量密度与实际输入通量密度之差确定：

$$
\mathrm{IBO}=\Phi_{\mathrm{sat}}-\Phi_{\mathrm{in}}
$$

其中，$\Phi_{\mathrm{sat}}$为 **饱和通量密度** ，$\Phi_{\mathrm{in}}$为实际输入功率通量密度，两者的单位均为dBW/m²；$\mathrm{IBO}$为输入功率回退量，单位为dB。

输出功率回退量通过多项式计算：

$$
\mathrm{OBO}
=b_0+b_1\mathrm{IBO}+b_2\mathrm{IBO}^2+\cdots+b_m\mathrm{IBO}^m
$$

其中，$\mathrm{OBO}$为输出功率回退量，单位为dB；$b_i$为功率回退多项式的系数，$m$为多项式阶数。这里使用$b_i$，以区别于频率转换的系数$a_i$。

根据转发器的输入、输出功率特性填写系数。输出功率回退表示输出相对于饱和状态的降低量，用于确定实际转发输出功率。

##### 系数编辑

**频率** 和 **功率回退** 页面的系数分别设置，编辑操作相同。

| 项目 | 含义与使用方法 |
| --- | --- |
| 索引 | 系数在列表中的序号，用于标识所在位置。 |
| 系数 | 当前转换多项式的系数值。双击单元格后修改数值。 |
| 添加 | 新增一行系数，并填写所需数值。 |
| 删除 | 选中需要移除的行，点击 **删除** 。 |
| 上移 | 选中一行后点击 **上移** ，该行移动到当前位置的上一行。 |
| 下移 | 选中一行后点击 **下移** ，该行移动到当前位置的下一行。 |

按所需转换关系设置各项系数，编辑后核对系数数值及排列顺序。

#### 天线极化

简单和中等转发器模型在 **模型规格 - 天线极化** 中设置；复杂转发器模型在 **天线 - 极化** 中设置。

极化类型、参考轴、极化角度及使用方法均与发射机相同，参数说明与计算公式见发射机类的 **天线极化** 。

#### 滤波器

**滤波器** 用于对转发信号的功率谱密度进行滤波。三种转发器模型的页面参数及设置方法均与发射机相同。

根据需要勾选 **使用** ，选择贝塞尔、巴特沃兹、切比雪夫、高斯窗或升余弦滤波器，并设置公共参数及所选类型的专属参数。参数说明与计算模型见发射机类的 **滤波器** 。

#### 额外损益

**额外损益** 用于补充描述转发端的附加增益或损耗。三种转发器模型的设置方法均与发射机相同。

在 **增益/损耗(dB)** 中输入附加损益的代数值，正值表示增益，负值表示损耗。已通过功率回退、滤波器或其他参数计入的损耗，不应在此重复计入。

#### 配置流程

- 打开发射器属性，在 **基本 - 定义** 页面选择转发器模型类型。
- 在 **模型规格** 中设置 **饱和通量密度** ，并根据模型输入 **卫星 EIRP** 或 **功率** 。中等模型还需设置 **发射增益** 。
- 使用复杂模型时，在 **天线** 页面选择 **嵌入** 或 **链接** ，配置或核对天线参数。
- 根据所选模型，在 **模型规格 - 天线极化** 或 **天线 - 极化** 中设置极化特性。
- 在 **转换方法 - 频率** 和 **转换方法 - 功率回退** 中分别设置系数。
- 根据需要启用 **滤波器** ，并在 **额外损益** 中设置尚未计入的附加增益或损耗。
- 核对参数、单位及系数排列，点击 **应用** 保存当前设置，或点击 **确定** 保存并关闭属性窗口。
