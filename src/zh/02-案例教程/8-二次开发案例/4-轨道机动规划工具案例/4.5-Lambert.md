# 基于 Lambert 瞄准的轨道转移

通过二次开发 Connect 模式，创建 Lambert 瞄准任务，设置初始状态、目标状态、转移时间及求解参数，最后运行机动规划并保存场景。运行过程中必须保持 ATK 为打开状态。具体步骤包括：

1. 加载 ATK Connect 模式 Java 接口库并与 ATK 建立连接。
2. 新建卫星，设置场景分析时间和卫星属性。
3. 在主任务序列中插入 Lambert 瞄准段。
4. 设置初始段、Lambert 目标状态和求解参数。
5. 运行机动规划。
6. 查看运行结果与三维轨迹。
7. 保存场景并与 ATK 断开连接。

## 脚本展示

### 与 ATK 进行连接

<mix-code lang="matlab" langs="matlab">

% 1. 加载 ATK Connect 模式 Java 接口库，并与 ATK 建立连接
% 需先将安装包根目录下的 ATKConnectJava.jar、ATKConnectJava.dll、ATKConnectorDll.dll 复制到当前工作目录
if(ispc())
    jarPath = [pwd,'\ATKConnectJava.jar'];
elseif(isunix())
    jarPath = [pwd,'/ATKConnectJava.jar'];
end
if ~any(strcmp(jarPath, javaclasspath()))
    javaaddpath(jarPath);
    javaMethod('loadLibrary', 'ATKLibraryLoader');
end
ATKConnectJavaModule = javaObject('com.atk.connect.ATKConnectJavaModule');

conID = ATKConnectJavaModule.atkOpen('127.0.0.1', 6655);%连接地址和端口应与 ATK 的实际通信设置一致，本例为 `127.0.0.1:6655`。
</mix-code>

### 新建场景与卫星

<mix-code lang="matlab" langs="matlab">

% 2. 新建场景与卫星
ATKConnectJavaModule.atkConnect(conID, 'New', '/ Scenario Lambert', '');
ATKConnectJavaModule.atkConnect(conID, 'SetAnalysisTimePeriod', '* "5 Nov 2022 00:00:00.000" "8 Nov 2022 00:00:00.000"', '');

% 仿真重置
ATKConnectJavaModule.atkConnect(conID, 'Animate', '* Reset', '');
</mix-code>

### 新建卫星并进行属性设置

<mix-code lang="matlab" langs="matlab">
% 3, 插入卫星
ATKConnectJavaModule.atkConnect(conID, 'New', '/ Satellite SatInclinationChange', '');

% 设置卫星轨迹线宽
ATKConnectJavaModule.atkConnect(conID, 'Graphics', '*/Satellite/SatInclinationChange Basic LineWidth 2', '');

% 将卫星轨道预报器设置为机动规划
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetProp', '');

</mix-code>

### Lambert 任务序列

<mix-code lang="matlab" langs="matlab">

% 4. 在主任务序列末尾插入 LambertTarget 段
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange InsertSegment MainSequence.SegmentList.- LambertTarget', '');

</mix-code>

<mix-code lang="matlab" langs="matlab">

% 5. 设置初始段参数
% 轨道历元
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.Initial_State.InitialState.Epoch 5 Nov 2022 00:00:00.000 UTCG', '');

% 坐标类型
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.Initial_State.CoordinateType "Modified Keplerian"', '');

% 轨道根数
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.Initial_State.InitialState.Keplerian.sma 6570000 m', '');
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.Initial_State.InitialState.Keplerian.ecc 0', '');
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.Initial_State.InitialState.Keplerian.inc 28 deg', '');
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.Initial_State.InitialState.Keplerian.RAAN 0', '');
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.Initial_State.InitialState.Keplerian.w 0', '');
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.Initial_State.InitialState.Keplerian.ta 0', '');

</mix-code>

设置 Lambert 段的停止条件为 `Duration`，转移时间为 `43200 sec`，即 12 小时。将目标状态的位置分量设为 `X = 6700000 m`、`Y = 0 m`、`Z = 0 m`，速度分量 `VX`、`VY`、`VZ` 均设为 `0 m/s`。

<mix-code lang="matlab" langs="matlab">

% 6. 设置 Lambert 段的显示颜色、停止条件和目标状态
% 段颜色参数沿用原代码
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.SegmentColor 4294902015', '');

% 停止条件：Duration；转移时间：43200 sec
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.StoppingConditions Duration', '');
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.StoppingConditions.Duration.TripValue 43200 sec', '');

% Lambert 目标状态的位置分量
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.LambertState.Cartesian.X 6700000 m', '');
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.LambertState.Cartesian.Y 0 m', '');
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.LambertState.Cartesian.Z 0 m', '');

% Lambert 目标状态的速度分量
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.LambertState.Cartesian.VX 0 m/s', '');
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.LambertState.Cartesian.VY 0 m/s', '');
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.LambertState.Cartesian.VZ 0 m/s', '');

</mix-code>

设置求解方法为 `AdaptSpecified`，并按脚本设置 `IterPosErr`、`Perturb`、`IsMajorArc`、`Revolution` 和 `IsLongArc`。

<mix-code lang="matlab" langs="matlab">

% 7. 设置 Lambert 求解方法及相关参数
% 原代码列出的 Method 取值：SpecAll / SpecMin / AdaptSpecified / AdaptMin
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.Method AdaptSpecified', '');

% IterPosErr 沿用原值
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.IterPosErr 0.111', '');
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.Perturb  false', '');

% 以下三项在非 AdaptSpecified 模式下需注释
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.IsMajorArc on', '');
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.Revolution 2', '');
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.IsLongArc off', '');

</mix-code>

### 运行机动规划

通过 `RunMCS` 运行已配置的机动规划任务序列。需要播放动画时，可取消 `Animate` 命令的注释。

<mix-code lang="matlab" langs="matlab">

% 8. 运行机动规划
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange RunMCS', '');
ATKConnectJavaModule.atkConnect(conID, 'Animate', '* Reset', '');
ATKConnectJavaModule.atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange ApplyAllProfileChanges', '');

</mix-code>

### 保存场景后与 ATK 断开连接

<mix-code lang="matlab" langs="matlab">

% 9，想定保存
ATKConnectJavaModule.atkConnect(conID, 'Save', '/ *', '')
% 与ATK断开连接
ATKConnectJavaModule.atkClose(conID)

</mix-code>
