# Access Tool

## Functional Overview

The ATK Access Tool is used to determine whether there is an **unobstructed direct line‑of‑sight path between two points in space**, and to solve for **continuous visibility intervals that satisfy multiple constraint conditions within a specified time period, along with corresponding reports and graphs**.

In missions such as satellite communications, target observation, and command transmission, "access" refers not only to physical line‑of‑sight, but can also represent specific geometric configurations, service performance, or temporal conditions. The tool supports multiple object types including satellites, ships, missiles, vehicles, radars, ground stations, and aircraft, and can incorporate various constraints such as azimuth angle, line‑of‑sight, field‑of‑view, lighting, and communication constraints, adapting to analysis requirements across land, sea, air, space, and electromagnetic domains.

::: tip The Core Role of Access Analysis
Access analysis is a fundamental and core technology for satellite communications, navigation, remote sensing, and other missions. It is used to clarify the spatial relationship of "whether it can be seen," addressing the core questions of whether a mission "can be executed" and "when it can be executed."
:::

## Interface Area Descriptions

The main interface is divided into four core areas:

![](../../../zh/5.专业使用指南/01-可见性与覆盖分析/media/01-可见性工具/image_zy-1776770064692-3.png)

### Object Operations Area

Used to set the access object (initiator) and target objects for the access analysis. **Multiple access objects and target objects can be selected simultaneously**, reducing repetitive operations for multiple access relationships. **Analysis results are still stored and displayed on a per‑object basis.**

|       Element        |                                    Description                                    |                                                                Operation                                                                 |
|:--------------------:|:---------------------------------------------------------------------------------:|:----------------------------------------------------------------------------------------------------------------------------------------:|
|   **Access Object**  |                           The initiator of the access analysis                          |                                   Click <kbd>Select Object...</kbd> to choose from the current scenario object list                                   |
|     **Update**       | Synchronizes scenario configuration changes, resets time settings and analysis step to scenario defaults, and updates the visualization view. | Click after modifying scenario properties;<br/>Use when you want to reset the access analysis period to the default scenario time;<br/>**Updates automatically after saving object property changes; no manual click needed.** |
|     **Clear**        |                   Removes the selected target object and clears its visualization results                   |                                                     Click after selecting the target object                                                     |
|   **Clear All**      |          Clears all visualization results for target objects under the current access object.         |                         Click directly. Only clears the results and displays for the current access object (does not affect other access objects).                        |
|    **Compute**       | Executes the access computation, generates access interval data, and displays it in the 2D and 3D views. |                     Click after configuration is complete. An `*` appears before the object name upon completion.                    |
| **Show Filter**      |                           Filters the object list by type                          |                                           Click the dropdown and check the desired type (default: All Objects)                                           |
|   **Object List**    |                        Displays the target objects that can be added                       |                                                Hold `Ctrl` for multiple selection                                                |

::: warning Clear Results in Time to Free Memory
Undeleted results occupy memory. It is recommended to clear them promptly after use.
:::

### Time Settings Area

Sets the time interval, computation step, and light time delay options for the access analysis.

|        Element        |                                  Description                                 |                                                           Operation                                                           |
|:---------------------:|:----------------------------------------------------------------------------:|:-----------------------------------------------------------------------------------------------------------------------------:|
|  Start Time (UTCG)   |                             Analysis start time                             |                          Format: `YYYY-MM-DD HH:MM:SS.000`                          |
|   Stop Time (UTCG)   |                             Analysis end time                             |                          Format: `YYYY-MM-DD HH:MM:SS.000`                          |
|     Step Size     |                             Report time interval                             |                                                Unit can be switched (default: seconds)                                               |
|   Use Light Time Delay   | Accounts for light propagation time delay, correcting relative positions between objects. | Can be left unchecked for routine LEO analyses;<br/>Recommended for long‑distance scenarios such as cislunar communications and deep‑space exploration. |

::: warning Analysis Period Restrictions
The analysis period must be within the scenario's simulation time range; otherwise, the analysis will fail due to the inability to obtain the corresponding state data.
:::

::: tip Light Time Delay Notes
When **Use Light Time Delay** is checked, the **analysis object is assumed to be the signal‑receiving end** by default. The computation corrects for positional changes of the objects during signal propagation. This effect must be carefully considered in missions such as satellite communications and deep‑space tracking and control.
:::

### Report Output Area

Supports both **Data Reports** and **Chart Reports** with consistent operation logic:

1. Click <kbd>More…</kbd> to view all templates (except the **Link Budget** report).
2. Select a template and click <kbd>Create</kbd>.
3. Custom templates are supported: click <kbd>More…</kbd> - <kbd>Custom</kbd>, check the parameters to display, then click <kbd>OK</kbd>.
4. Once a report or chart window is opened, you can click the <kbd>Refresh</kbd> button to re‑generate the output. After object property modifications and re‑computation, already‑opened reports or charts can also be updated via <kbd>Refresh</kbd>.

::: tip Report Refresh and Step Size Settings
Some reports that output data on a per‑instant basis support setting the output step size directly within the report window. After modifying the step size, click the <kbd>Refresh</kbd> button to regenerate the results at the new step.
:::

#### Optional Parameters for Custom Reports

Custom reports support selecting output parameters based on analysis requirements. Commonly available optional parameters include:

Azimuth Angle, Elevation Angle, Azimuth Rate, Elevation Rate, Range, Range Rate, Angular Rate, Altitude, Sun Elevation Angle, Lunar Elevation Angle, LOS Solar Exclusion Angle, LOS Lunar Exclusion Angle, Line‑of‑Sight Constraint, Local Time, Local Apparent Time.

When a **Sensor** is used as the access object, custom reports also support the following parameters:

BS Solar Exclusion Angle, BS Lunar Exclusion Angle, Field‑of‑View Constraint.

#### Dynamic Data Display

1. Click the <kbd>Graphics Displays…</kbd> button.
2. On the left, check the data items to display; on the right, set the text color, position, background, and border.
3. Click <kbd>OK</kbd> to display the data dynamically in the 2D and 3D views.

::: tip Adjusting Font Display
Font display effects are related to the scene background. You can flexibly adjust font styles and background/border settings to ensure legibility.
:::

### Data Return Area

Configures the visualization effects of access analysis results in the views.

|       Element       |                                                                                                                              Description                                                                                                                              |
|:-------------------:|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------:|
| Show Static Track | In the 2D view, when the access object or target object is mobile (e.g., satellite, vehicle), displays the trajectory projection for all access intervals as a **static thickened line** throughout the analysis period, without changing over time. |
|  Show Animate Line   | In the 2D and 3D views, dynamically draws a **line between the access object and the target object** during access intervals; the line disappears when access is lost. Reflects only the access state at the current time. |

::: tip Difference Between Static Track and Animate Line
- **Static Track** is suitable for quickly reviewing coverage over the entire period, giving a general idea of the proportion of time that is accessible.
- **Animate Line** is suitable for time‑series simulation scenarios, allowing frame‑by‑frame observation of access establishment and loss.
- Both can be checked simultaneously without conflict.
:::

## Complete Workflow

### Set Constraints

To restrict access conditions (e.g., elevation angle range, line‑of‑sight occlusion, lighting constraints, etc.), double‑click the object and go to the **Properties** - **Constraints** tab.

::: tip Constraint Criteria and Parameters
The criteria and parameter meanings of each constraint are described in [Constraints Configuration](../../03-基础使用指南/03-对象管理/03-约束配置/).
:::

### Select Access Object

In the Object Operations area, click <kbd>Select Object…</kbd> to choose the **initiator** of the access analysis from the current scenario object list. Multiple access objects can be selected simultaneously.

### Add Target Objects

In the object list, check the target objects to analyze (hold `Ctrl` or click and drag with the left mouse button to multi‑select), then click <kbd>Compute</kbd>. Multiple target objects can be added simultaneously; analysis results are stored separately for **each individual object**.

### Configure Analysis Period

In the Time Settings area, set the start time, stop time, and analysis step. The analysis period must be within the scenario's simulation time range. For objects with a life cycle shorter than the simulation time (e.g., vehicles, ships, missiles), the actual analysis period is the **intersection** of the object's life cycle and the specified time interval.

### Execute Computation

Click <kbd>Compute</kbd>. Upon completion, an `*` appears before the target object's name.  
After saving object property changes, access results **update automatically** without requiring a manual re‑click of Compute.

### View Results

- **Data Reports**: Click the corresponding report buttons in the Report area, or click <kbd>More…</kbd> to select a template and then click <kbd>Create</kbd>.
- **Chart Reports**: Click the corresponding chart buttons in the Chart area, or click <kbd>More…</kbd> to select a template and then click <kbd>Create</kbd>.
- **Custom Reports**: Click <kbd>More…</kbd> - <kbd>Custom</kbd>, check the parameters to display, then click <kbd>OK</kbd>.
- **Refresh Results**: Once a report or chart window is opened, click the <kbd>Refresh</kbd> button to re‑generate output. For reports that output per‑instant data, you can also reset the step size and then refresh.

### Configure Visualization (Optional)

In the Report Output area, click <kbd>Graphics Displays…</kbd>, check the data items to display dynamically, set text styles, etc., and the data will be displayed in real time in the 2D and 3D views.

### Clear Results

After the analysis is complete, click <kbd>Clear</kbd> to remove the results for an individual target object, or click <kbd>Clear All</kbd> to clear all results under the current access object. Undeleted results will continue to occupy memory.

::: tip Isolation of Multi‑Object Analysis Results
For batch analysis of multiple objects, analysis results for different access objects are independent. The <kbd>Clear All</kbd> operation affects only the currently selected access object.
:::
