# State Control

| Menu Item | Description | Use Case |
|-----------|-------------|----------|
| `Check` | Enable the current object to participate in simulation and display in the view. | Temporarily enable an object for simulation verification. |
| `Uncheck` | Disable the current object; the object will not participate in simulation or display in the view. | Temporarily disable certain objects during batch debugging to simplify the scene. |
| `Reverse Check` | Toggle the check state of all child objects under the current object (checked ones are unchecked, unchecked ones are enabled). | Quickly toggle the enable/disable state of a group of child objects. |
| `Check All` | Check all child objects under the current object, enabling all objects in batch. | Enable all objects at once for a full simulation after debugging is complete. |
| `Uncheck All` | Uncheck all child objects under the current object, disabling all objects in batch. | Quickly disable all objects during scene initialization, then enable them individually as needed. |
