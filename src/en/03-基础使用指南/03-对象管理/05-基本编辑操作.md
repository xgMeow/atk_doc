# Basic Editing Operations

| Menu Item | Description | Use Case |
|-----------|-------------|----------|
| `Copy` | Completely copy the current object along with all its properties and child object configurations, generating an independent object copy. | Quickly reuse the parameter configuration of an existing object to reduce redundant setup. |
| `Paste` | Paste the copied object instance into the current scenario or under the specified object hierarchy to create a new object. | Reuse object configurations across scenarios, or batch‑create objects of the same type. |
| `Delete` | Remove the current object and all its associated child objects from the scenario. A confirmation prompt will appear before deletion. | Clean up redundant objects and obsolete configurations to simplify the scenario structure. |
