# Time Constraints

## Function Description

Temporal Constraints define the allowed access time intervals according to the specified time bases; they filter visibility periods, communication periods, and coverage periods so that only accesses falling within the defined time intervals are retained.

The conditions in Temporal Constraints are independent of one another. The current time satisfies the Temporal Constraints only when all enabled conditions are satisfied.

## Parameter Descriptions

<Entry meta="Format: HH:MM:SS.mmm" name="Local" desc="The time base defined by the position of the mean Sun relative to the local meridian." objects="Receiver,GroundVehicle,Sensor,Missile,Facility,Transmitter,Aircraft,CoverageDefinition,LaunchVehicle,Ship,Submarine,AreaTarget,Antenna,Satellite">

Local Time (LT) is measured by the position of the **mean Sun** relative to the local meridian, that is, the sum of Greenwich Mean Time (GMT) and the time offset of the object's longitude relative to the prime meridian ($0^{\circ}$ longitude).

Select this option and enter the times in the 【Start】 and 【End】 boxes to bound the local time window in which accesses are allowed; enable 【Exclude】 to remove accesses that fall within that window and retain only those outside it.

For the calculation method, see [Local Time](../../../04-理论基础/02-约束配置/03-时间约束.md#_1-local-time).

</Entry>

<Entry meta="Format: HH:MM:SS.mmm" name="GMT" desc="The time base defined by the position of the mean Sun relative to the prime meridian." objects="Receiver,GroundVehicle,Sensor,Missile,Facility,Transmitter,Aircraft,CoverageDefinition,LaunchVehicle,Ship,Submarine,AreaTarget,Antenna,Satellite">

Greenwich Mean Time (GMT) is measured by the position of the **mean Sun** relative to the prime meridian.

Select this option and enter the times in the 【Start】 and 【End】 boxes to bound the Greenwich Mean Time window in which accesses are allowed; enable 【Exclude】 to remove accesses that fall within that window and retain only those outside it.

For the calculation method, see [Greenwich Mean Time](../../../04-理论基础/02-约束配置/03-时间约束.md#_2-greenwich-mean-time).

</Entry>

<Entry meta="Format: HH:MM:SS.mmm" name="Local Apparent" desc="The time base defined by the position of the true Sun relative to the local meridian." objects="Receiver,GroundVehicle,Sensor,Missile,Facility,Transmitter,Aircraft,CoverageDefinition,LaunchVehicle,Ship,Submarine,AreaTarget,Antenna,Satellite">

Local Apparent Time (LAT) is measured by the position of the **true Sun** relative to the local meridian; it is also called local apparent solar time. Because the Sun and the satellite are at the same longitude at noon, this time base is also known as Local Satellite Time (LST).

Select this option and enter the times in the 【Start】 and 【End】 boxes to bound the local apparent time window in which accesses are allowed; enable 【Exclude】 to remove accesses that fall within that window and retain only those outside it.

</Entry>

<Entry meta="Dimension: Time|Unit: s, min, h, day, cd, EarthTU, SunTU, FN, yr" name="Duration" desc="Limits the range of duration allowed for a single access." objects="Receiver,GroundVehicle,Sensor,Missile,Facility,Transmitter,Aircraft,CoverageDefinition,LaunchVehicle,Ship,Submarine,AreaTarget,Antenna,Satellite">

Duration defines the range of duration allowed for a single access.

A minimum and a maximum value can be set separately; accesses whose duration falls outside the specified range do not satisfy the constraint.

</Entry>

<Entry name="Intervals" desc="The time intervals allowed (or excluded) for a single access." objects="Receiver,GroundVehicle,Sensor,Missile,Facility,Transmitter,Aircraft,CoverageDefinition,LaunchVehicle,Ship,Submarine,AreaTarget,Antenna,Satellite">

Intervals are used to manually add or load a number of time intervals. Each interval is defined by a start time and a stop time (UTC), and the 【Add】, 【Load】, 【Remove】, and 【Remove All】 operations are supported.

After enabling 【Use】 in this group, click 【Add】 to create an interval with default start and stop times, whose contents you can edit by clicking the 【Start Time (UTC)】 or 【Stop Time (UTC)】 box; click 【Load】 to load start and stop times from an external interval file (.int); select an existing entry and click 【Remove】 to delete it, or click 【Remove All】 to clear all entries.

【Exclude】 determines whether the specified periods are valid periods that satisfy the constraint or invalid periods to be removed: when enabled, accesses within all the listed periods do not satisfy the constraint; when disabled, accesses within all the listed periods satisfy the constraint.

</Entry>
