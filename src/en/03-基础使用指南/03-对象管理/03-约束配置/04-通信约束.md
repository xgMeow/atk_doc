# Communications Constraints

## Function Description

Communications Constraints are used to analyze whether the communications link between a transmitter and a receiver satisfies the specified conditions. They apply to tasks such as satellite communications, inter-satellite links, ground station communications, telemetry and telecommand, and data transmission. The system evaluates whether the current communications link is usable according to link metrics such as frequency, received power, signal-to-noise ratio, and bit error rate: if the link metric value falls within the specified range, the access satisfies the Communications Constraints; otherwise, it is considered an invalid access.

All parameters support **Min**/**Max** values and can be used together with **Reverse Selection** (exclude accesses within the specified range).

<Entry meta="Dimension: Frequency|Unit: GHz" name="Frequency" desc="The operating frequency range of the communications link." objects="Transmitter,Receiver">

Limits the range of frequencies to which the transmitter or receiver responds. You can select a particular band from the 【Band】 drop-down list, or choose 【Custom】 to specify the frequency range.

Select 【Min】 or 【Max】 and enter a value to specify the value range in which accesses are allowed; enable 【Reverse Selection】 to remove accesses that fall within that range and retain only those outside it.

For the calculation formula, see [Frequency](../../../04-理论基础/02-约束配置/04-通信约束.md#_2-operating-frequency).
