# Multi‑Segment Attitude

## Definition

Combines multiple attitude segments.

## Introduction

Composed of several attitude segments, each of which can use a different attitude type.

## Usage

### Selecting the Attitude Operation

Open the satellite's **Properties**, select **Attitude**, and choose **Multi‑Segment Attitude** as the attitude type.

![Select Attitude](../../../../zh/03-基础使用指南/03-对象管理/07-姿态定义/media/5-多分段姿态/image.png)

### Configuring Parameters

1. **Add Segment**: Add different types of attitude segments.
2. **Remove Segment**: Select an added attitude segment and click to delete it.
3. **Start Time**: The start time of the attitude segment.
4. **Stop Time**: The end time of the attitude segment.
