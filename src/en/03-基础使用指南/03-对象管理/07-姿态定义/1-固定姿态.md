# Fixed Attitude

## Definition

The attitude is fixed relative to the selected reference axes.

## Introduction

Relative to the user-selected coordinate axes, the attitude does not vary with time or orbital motion.

## Tutorial

### Selecting the Attitude Operation

Open the satellite's **Properties**, select **Attitude**, and choose **Fixed Attitude** as the attitude type.

![Select Attitude](../../../../zh/03-基础使用指南/03-对象管理/07-姿态定义/media/1-固定姿态/image-6.png)

### Configuring Parameters

1. **Reference Axes**: Defines the reference axes to which the attitude is fixed.
2. **Qx, Qy, Qz, Qs**: Quaternion components defining the fixed rotational relationship of the object relative to the reference coordinate system.

![Configure Parameters](../../../../zh/03-基础使用指南/03-对象管理/07-姿态定义/media/1-固定姿态/image-5.png)

## Attitude Report

1. **Open Data Report**

Right-click **Satellite1**, select **Report**, and choose **Satellite1**.

![Data Report](../../../../zh/03-基础使用指南/03-对象管理/07-姿态定义/media/1-固定姿态/image-8.png)

2. **Create a New Report**

Click **New**, select the newly created **New Style1**, and click **Properties** to configure it.

![New Report](../../../../zh/03-基础使用指南/03-对象管理/07-姿态定义/media/1-固定姿态/image-9.png)

3. **Configure Properties**

Locate **Attitude Quaternions in Select Axes**, select qs, qx, qy, qz, and click the right arrow **→**.

![Configure Properties](../../../../zh/03-基础使用指南/03-对象管理/07-姿态定义/media/1-固定姿态/image-11.png)

4. **Generate the Report**

Select the configured data report style **New Style1** and click **Generate**.

![Generate Report](../../../../zh/03-基础使用指南/03-对象管理/07-姿态定义/media/1-固定姿态/image-12.png)

5. **Select the Reference Frame**

Using Earth Central Body Inertial as an example, select **Earth** as the central body, choose **Central Body Inertial Axes**, and click **OK**.

![Select Reference Frame](../../../../zh/03-基础使用指南/03-对象管理/07-姿态定义/media/1-固定姿态/image-13.png)

6. **Display the Report**

The attitude report is generated.

![Attitude Report](../../../../zh/03-基础使用指南/03-对象管理/07-姿态定义/media/1-固定姿态/image-10.png)

## Visualization

1. **Add a Coordinate System**

Click **Satellite1**, select **Vector**, click **Add** to add a coordinate system for Satellite1.

![Add Coordinate System](../../../../zh/03-基础使用指南/03-对象管理/07-姿态定义/media/1-固定姿态/image-14.png)

2. **Select the Coordinate System**

In the added component, select **Satellite1** as the object, choose **VVLH(CBF)**, and click **OK**.

![Select Coordinate System](../../../../zh/03-基础使用指南/03-对象管理/07-姿态定义/media/1-固定姿态/image-15.png)

3. **Coordinate System Configuration**

Add Satellite1's body coordinate system in the same manner. Then check **Show** and click **Apply** or **OK**.

![Coordinate System Configuration](../../../../zh/03-基础使用指南/03-对象管理/07-姿态定义/media/1-固定姿态/image-16.png)

4. **3D Visualization**

In the main menu, click **3D View**, select **View From/To**, choose the **Satellite1** viewpoint, and click **▶** to play the animation. The satellite's attitude (i.e., its body coordinate system) will remain fixed relative to the VVLH(CBF) frame.

![3D Visualization](../../../../zh/03-基础使用指南/03-对象管理/07-姿态定义/media/1-固定姿态/image-17.png)
