# Area Target

Area Target properties are used to configure areal targets on the Earth's surface, and include three modules: **Basic Properties, Visualization, and Constraints**.

---

## Basic Properties

Used to define the geometric information of the area target:

- **Boundary**: Set the outline boundary of the area target.
- **Centroid**: Define the center point coordinates of the area target.

## Visualization

Controls the display effect of the area target in the scene:

- Show
- Show Label
- Show Centroid
- Show Boundary Points
- Fill
- Translucency
- Color
- Line Style and Line Width

![Display settings interface](../../../../zh/03-基础使用指南/03-对象管理/02-属性配置/media/区域目标/update2601-134.png)

## Constraints

| Property | Description |
| --- | --- |
| [Basic](../03-约束配置/01-基本约束.md) | Observation geometry conditions that access between the area target and other objects must satisfy (minimum elevation, altitude, line-of-sight constraint, whether to access the whole object, etc.) |
| [Time](../03-约束配置/03-时间约束.md) | Time windows within which access between the area target and other objects must fall (local time/GMT/local solar time/duration/time intervals) |
