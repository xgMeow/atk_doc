# Access Separation

## Definition

Determines whether the **time separation** between multiple coverage intervals of the analysis object falls within a specified range.

Access Separation is a logical metric, typically yielding a result of **1** or **0**. When the separation between intervals from different resources meets the specified range, i.e., in the figure below, satisfying:

$$
\mathrm{dur}_{\min} \le t_{\mathrm{start}}^{(2)} - t_{\mathrm{stop}}^{(1)} \le \mathrm{dur}_{\max}
$$

the metric value is 1; otherwise it is 0.

![Access Separation](../../../../../../zh/03-基础使用指南/03-对象管理/02-属性配置/品质因子/01-基本定义/media/访问间隔/image.png)

## Specific Parameters

|   Parameter   |                              Description                              |
|:-------------:|:---------------------------------------------------------------------:|
| **Minimum**   | The minimum time separation used to determine whether two or more coverage intervals satisfy the access separation condition. |
| **Maximum**   | The maximum time separation used to determine whether two or more coverage intervals satisfy the access separation condition. |

::: tip Note
- Access Separation is used to detect whether multiple coverage intervals are close to each other within a specified time window.
- If the separation between intervals is less than the minimum or greater than the maximum, the condition is typically considered not satisfied.
:::

## Statistics

The Access Separation type has no specific statistical value configuration.
