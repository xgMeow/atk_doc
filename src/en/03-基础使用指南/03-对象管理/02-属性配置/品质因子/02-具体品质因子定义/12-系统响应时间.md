# System Response Time

## Definition

System Response Time represents the time from when coverage of a point (the analysis object) is requested to when data from the coverage resource is acquired.

System Response Time includes the delay in sending the collection request to the coverage resource, the delay in transmitting the collected data to the receive object, and some fixed-duration delays between the two. For a specific moment, the current time is considered the time at which the system receives the data collection requirement; the interval from the current time to when the receive object first obtains the collected data is the System Response Time.

## Specific Parameters

- **System Assets**: Command Object, Receive Object, Allow Crosslink
- **Phase Duration Parameters**: Command Prep Time, Commanding Time, Pre‑Collection Time, Collection Time, Post‑Collection Time, Downlink Time, Time Step

## Statistics

|      Name     |                                                                                   Meaning                                                                                   |
|:-------------:|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------:|
|    **Mean**   |    The mean System Response Time over the entire analysis period. This value is obtained by sampling at a specific step, which is consistent with the analysis step. If the remaining time cannot satisfy the downlink time requirement, no further sampling is performed.    |
|  **Maximum**  |    The maximum System Response Time over the entire analysis period.    |
|  **Minimum**  |    The minimum System Response Time over the entire analysis period. When all delay times are set to 0 and the phases are seamlessly connected, this value is 0.    |
