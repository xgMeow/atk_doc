# Response Time

## Definition

Response Time represents the interval from the current moment to the start of the next coverage interval. As shown in the figure below, the Response Time is expressed as:

$$
V_{rsp} = t_{start}^{(3)} - t_{cur}
$$

![Response Time](../../../../../../zh/03-基础使用指南/03-对象管理/02-属性配置/品质因子/01-基本定义/media/响应时间/image.png)

## Specific Parameters

- **Minimum Multiplicity**: Sets the minimum number of simultaneous coverage resources.
- **End Gap**: Specifies whether the final incomplete gap at the end of the analysis period is ignored or included.

## Statistics

|          Name          |                                       Meaning                                       |
|:----------------------:|:-----------------------------------------------------------------------------------:|
|       **Mean**         |                        The mean Response Time over the entire analysis period.                        |
|     **Maximum**        |    The maximum Response Time over the entire analysis period; this value equals the longest coverage gap duration within the period.   |
|     **Minimum**        |    The minimum Response Time over the entire analysis period; if there is at least one covered instant, this value is 0.    |
|   **Percent Below**    |          Given a percentage X%, returns a value V such that Response Time is below V for X% of the entire analysis period.         |
| **Percent Below Gaps Only** | Given a percentage X%, returns a value V such that, considering only the time spent in coverage gaps, Response Time is below V for X% of that gap time. |

::: tip Note
Minimum Multiplicity further constrains the coverage time. When Minimum Multiplicity is set to a value greater than 1, the Response Time represents the interval from the current moment to the start of the next period that satisfies N-fold coverage.
:::
