# Simple Coverage

## Definition

Analyzes whether the target can be covered by the selected coverage resources, represented by a 0-1 Boolean value.

For a given instant, if at least one coverage resource can cover the analysis object, the dynamic value is 1; otherwise it is 0.

For the whole analysis period, as long as there is at least one instant at which the analysis object is covered, the statistic value is 1; if the analysis object is never covered throughout the analysis period, the statistic value is 0.

## Parameter Descriptions

### Type

After selecting 【Simple Coverage】, the computation rule of this Figure of Merit is fixed. No 【Computation】 method selection is provided, and no other computation parameters need to be set.

### Satisfaction Condition

$$
F_{\mathrm{cov}}(t)=
\begin{cases}
1, & \text{the current instant is covered by at least one coverage resource},\\
0, & \text{the current instant is not covered by any coverage resource}.
\end{cases}
$$

## Result Description

- **Dynamic Value**: whether the analysis object is in a covered state at a given instant.
  - `1`: the current instant is covered;
  - `0`: the current instant is not covered.

- **Statistic Value**: whether coverage ever occurs during the whole analysis period.
  - `1`: there is at least one instant at which the analysis object is covered;
  - `0`: the analysis object is never covered throughout the analysis period.

::: tip Note
【Simple Coverage】 only determines "whether there is coverage". It does not distinguish access duration, the number of coverage resources, or the number of accesses. If these characteristics need to be evaluated further, other Figures of Merit should be selected.
:::
