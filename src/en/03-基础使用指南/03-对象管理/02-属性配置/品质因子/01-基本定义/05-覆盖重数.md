# N Asset Coverage

## Definition

N Asset Coverage represents the number of coverage resources that can simultaneously cover the analysis object at the same instant.

Let there be $M$ coverage resources in total, and define:

$$
c_i(t)=
\begin{cases}
1, & \text{the }i\text{-th resource can cover the analysis object at instant }t,\\
0, & \text{otherwise},
\end{cases}
$$

then the coverage multiplicity is:

$$
N(t)=\sum_{i=1}^{M}c_i(t).
$$

Therefore:

- $N(t)=0$: no resource covers the object at present;
- $N(t)=1$: single coverage at present;
- $N(t)=2$: double coverage at present;
- and so on.

## Parameter Descriptions

### Computation

【N Asset Coverage】 supports the following computation methods:

| Computation Method | Meaning | Parameters |
|---|---|---|
| **Mean** | The average number of resources simultaneously covering the analysis object during the analysis period. | None |
| **Maximum** | The maximum number of resources simultaneously covering the analysis object during the analysis period. | None |
| **Minimum** | The minimum number of resources simultaneously covering the analysis object during the analysis period. | None |
| **Percent Above** | Computes the coverage multiplicity $N$ such that the analysis object is simultaneously covered by at least $N$ resources for the specified percentage of time. | **Percentage** |

### Percentage

It is displayed only when 【Computation】 is 【Percent Above】.

After entering the percentage $X$, the coverage multiplicity $N$ is computed, which means:

> The analysis object is simultaneously covered by at least $N$ coverage resources for $X\%$ of the time.

### Satisfaction Condition

After enabling 【Satisfaction Condition】, you can set a comparison condition and a threshold according to the N Asset Coverage statistic.

For example, setting:

- Condition: 【Greater Than】;
- Threshold: 1;

can be used to filter results whose coverage multiplicity is greater than 1.
