# Access Separation

## Definition

Access Separation determines whether the time separation between two or more coverage intervals falls within the set range.

Let the stop time of the previous coverage interval be $t_{\mathrm{stop}}^{(1)}$ and the start time of the next coverage interval be $t_{\mathrm{start}}^{(2)}$. Then the access separation is:

$$
\Delta t
=
t_{\mathrm{start}}^{(2)}
-
t_{\mathrm{stop}}^{(1)}.
$$

When

$$
\mathrm{dur}_{\min}
\le
t_{\mathrm{start}}^{(2)}
-
t_{\mathrm{stop}}^{(1)}
\le
\mathrm{dur}_{\max}
$$

is satisfied, the access separation condition is satisfied.

【Access Separation】 is a logical Figure of Merit, and its result is usually 1 or 0.

## Parameter Descriptions

### Minimum

Sets the minimum allowed access separation: $
\mathrm{dur}_{\min}.
$

If the separation between two coverage intervals is less than this value, the access separation condition is not satisfied.

### Maximum

Sets the maximum allowed access separation: $
\mathrm{dur}_{\max}.
$

If the separation between two coverage intervals is greater than this value, the access separation condition is not satisfied.

### Computation

The computation rule of 【Access Separation】 is fixed by the type itself, and no separate 【Computation】 method selection is provided.

### Satisfaction Condition

【Access Separation】 itself already gives a satisfied or not-satisfied logical result according to the minimum and maximum values, so the interface does not provide an additional 【Satisfaction Condition】 setting.
