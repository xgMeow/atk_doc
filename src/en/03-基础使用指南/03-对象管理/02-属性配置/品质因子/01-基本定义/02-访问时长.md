# Access Duration

## Definition

Counts the length of the continuous access interval formed by a single resource over the analysis object during the analysis period.

For each instant, the access duration represents **the length of the longest single-resource access interval among all single-resource access intervals that contain the current instant**. As shown in the figure below, if the two access intervals containing the current instant are 400 s and 240 s respectively, the access duration at the current instant is taken as 400 s.

When this value is 0, it indicates that the analysis object is not covered by any coverage resource at the current instant.

![Access Duration](../../../../../../zh/03-基础使用指南/03-对象管理/02-属性配置/品质因子/01-基本定义/media/访问时长/image.png)

::: tip Note
When computing the access duration, coverage intervals produced by different resources are not concatenated into a longer access interval. Even if the accesses of multiple resources overlap in time, they are computed separately according to their own continuous access intervals.
:::

## Parameter Descriptions

### Computation

【Access Duration】 supports the following computation methods:

| Computation Method | Meaning | Parameters |
|---|---|---|
| **Mean** | The average duration of all independent access intervals during the analysis period. | None |
| **Maximum** | The maximum duration among all independent access intervals during the analysis period. | None |
| **Minimum** | The minimum duration among all independent access intervals during the analysis period. | None |
| **Percent Above** | Computes the access duration threshold $D$ such that the analysis object is in an access interval with a duration not less than $D$ for the specified percentage of time. | **Percentage** |
| **Std Deviation** | The standard deviation of the durations of all independent access intervals during the analysis period. | None |
| **Sum** | The cumulative sum of the durations of all independent access intervals during the analysis period. | None |

#### Percentage

**Percentage** is set only when 【Computation】 is 【Percent Above】.

After entering the percentage level $X$, the access duration $D$ is computed, which means:

> The analysis object is in an access interval with a duration not less than $D$ for $X\%$ of the time.

### Contours

After checking 【Show Contours】, you can click <kbd>Contours...</kbd> to open the contour settings page, which maps Figure of Merit values to different colors by levels and displays them on the analysis object or the moving target trajectory.

- **Show Marker Animation Highlight**: when enabled, the object icon is highlighted according to the leveling result of the Figure of Merit heat map.
- **Show FOM Graphics on Vehicle Track**: when enabled, the heat map is displayed on the moving target trajectory according to the Figure of Merit values and the corresponding levels.
- **Ignore Intervals without Coverage**: when enabled, intervals that are not covered do not participate in the heat map display.
- **Ignore FOM values exceeding max contour level**: when enabled, Figure of Merit results greater than the current maximum level value are not displayed according to heat map levels.

#### Level Adding

The heat map establishes several display levels according to the value range of the Figure of Merit. You can select the leveling method in 【Add Method】 and set the corresponding parameters.

When 【Start,Stop,Step】 is selected, the following must be set:

- **Start**: the start value of the levels;
- **Stop**: the stop value of the levels;
- **Step**: the numerical interval between adjacent levels.

When 【Explicit】 is selected, you can directly enter the Figure of Merit level value to be added in 【Level】, and after clicking 【Add Levels】, that level is added to the level list.

After clicking 【Add Levels】, the software automatically generates the corresponding levels according to the settings. For example, when the start value is 300, the stop value is 1200, and the step is 300, levels such as 300, 600, 900, and 1200 are generated.

#### Level Attributes

The levels that have been established are displayed in the 【Level】 list. You can select a level to view and set it, delete the current level through 【Delete】, or clear all existing levels through 【Delete All】.

【Color Method】 is used to set how the colors of different levels are generated.

- When 【Color Ramp】 is selected, the color range is defined through 【Start Color】 and 【End Color】, and the software generates the corresponding color for each level according to its position in the value range;

- When 【Explicit】 is selected, the color can be set separately for each level. After selecting the corresponding level, set the display color of that level through 【Color】. This method is suitable for cases where different Figure of Merit ranges need to be distinguished by fixed colors.

In the 【All Levels】 area, you can also uniformly set the 【Line Style】 and 【Line Width】 of the heat map.

#### Legend

Click <kbd>Legend...</kbd> to set how the Figure of Merit heat map legend is displayed.

You can set the display position of the legend in the 【2D Graphics Window】 and the 【3D Graphics Window】 separately, and adjust the legend position through the `x` and `y` parameters; in the 【Background】 area you can set the background color and translucency.

【Text Options】 is used to set the legend title, the number of decimal digits, the floating point format, and the text color; 【Range Color Options】 is used to set the level order, the number of color squares displayed per row or per column, and the color square width and height. After checking 【Auto compute】, the corresponding color square dimensions are determined automatically by the software.

> **Note**: Contours only change how Figure of Merit results are visualized; they do not change the computed Figure of Merit results. The level values of different Figures of Merit should be set in combination with their physical meaning and units.

### Satisfaction Condition

After enabling 【Satisfaction Condition】, you can set a comparison condition and a threshold for the final Figure of Merit value.

For example, setting:

- Condition: 【Greater Than】;
- Threshold: 300 s;

means that the set quality requirement is judged as satisfied only when the access duration result is greater than 300 s.

## Result Description

【Access Duration】 has a dynamic value and a statistic value:

- **Dynamic Value**: the length of the longest single-resource access interval at the current instant;
- **Statistic Value**: the result obtained by summarizing the access intervals over the whole analysis period according to the selected 【Computation】 method.
