# Number of Coverage Gaps

## Definition

Counts the **number of uncovered intervals** that occur for the analysis object during the analysis period.
For each instant, the number of coverage gaps acts as a logical value: when it is 1, it means that the current instant lies within a coverage gap, that is, no coverage resource can cover the analysis object.

## Parameter Descriptions

### Computation

【Number of Coverage Gaps】 supports the following computation methods:

| Computation Method | Meaning | Parameters |
|---|---|---|
| **Avg Per Day** | The total number of coverage gaps divided by the number of days contained in the analysis period, representing the average number of coverage gaps per day. | None |
| **In Span** | Counts the number of coverage gaps whose duration falls within the specified range during the whole analysis period. | **Minimum, Maximum** |
| **In Span Per Day** | The number of coverage gaps that satisfy the specified duration range divided by the number of days contained in the analysis period. | **Minimum, Maximum** |
| **Max Per Day** | The maximum number of coverage gaps among the UTC days. | None |
| **Min Per Day** | The minimum number of coverage gaps among the UTC days. | None |
| **Total** | The total number of coverage gaps that occur within the whole analysis period. | None |

### Minimum, Maximum

They are displayed only when 【Computation】 is 【In Span】 or 【In Span Per Day】.

They are used to limit the coverage gap durations that participate in the statistics: $
T_{\min}
\le
T_{\mathrm{gap}}
\le
T_{\max}.
$

Only coverage gaps whose duration falls within this range are counted.

### Satisfaction Condition

After enabling 【Satisfaction Condition】, you can set a comparison condition and a threshold according to the Number of Coverage Gaps statistic.

For example, setting 【Greater Than 0】 means that the condition is judged as satisfied when a coverage gap that meets the current computation rule exists within the analysis period.

::: tip Note

- Statistics involving "per day" are all divided by UTC day, that is, from UTC 00:00 to the next UTC 00:00.
- The range in 【In Span】 and 【In Span Per Day】 refers to the **coverage gap duration range**.
:::
