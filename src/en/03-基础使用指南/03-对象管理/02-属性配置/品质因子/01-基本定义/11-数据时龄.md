# Data Age

## 1. Definition

Data Age represents the time elapsed since the end of the most recent valid coverage interval.

When the analysis object is within a valid coverage interval, the latest data is considered available, and Data Age is $0$. After the coverage ends, Data Age increases over time until the next valid coverage begins, at which point it resets to zero. Thus:

- A smaller Data Age indicates that the time since the last valid coverage is short, meaning data updates are more timely;
- A larger Data Age indicates that no new valid coverage has been obtained for a long time, meaning data timeliness is poorer.

> **Note**
>
> Data Age has dimensions of time. If a minimum multiplicity $N$ is set, only intervals satisfying $N$-fold or higher coverage are considered valid coverage. Data Age then represents the time elapsed since the end of the most recent interval that met that multiplicity requirement.

## 2. Computation and Statistics

Let the current time be $t_{\mathrm{cur}}$, and the end time of the most recent valid coverage be $t_{\mathrm{stop}}^{\mathrm{last}}$. When the current time lies within a coverage gap, Data Age is:

$$
V_{\mathrm{age}}
=
t_{\mathrm{cur}}
-
t_{\mathrm{stop}}^{\mathrm{last}}
$$

When the current time lies within a valid coverage interval:

$$
V_{\mathrm{age}}=0
$$

Thus, Data Age varies over the coverage process as follows: zero during coverage intervals, gradually increasing after coverage ends, and resetting to zero at the start of the next coverage.

Data Age supports the following statistics:

| Statistical Method | Meaning |
|---|---|
| Mean | The time‑averaged Data Age over the entire analysis period. |
| Maximum | The maximum Data Age over the entire analysis period; this value equals the longest coverage gap duration within the period. |
| Minimum | The minimum Data Age over the entire analysis period; if there is at least one valid coverage instant, this value is $0$. |
| Percent Below | Given a percentage $X\%$, returns a value $V$ such that Data Age is no greater than $V$ for $X\%$ of the entire analysis period. |
| Percent Below Gaps Only | Given a percentage $X\%$, returns a value $V$ such that, considering only the time spent in coverage gaps, Data Age is no greater than $V$ for $X\%$ of that gap time. |

Let the total analysis duration be $T$, and let Data Age as a function of time be $V_{\mathrm{age}}(t)$. The mean Data Age can be expressed as:

$$
\overline{V}_{\mathrm{age}}
=
\frac{1}{T}
\int_{t_{\mathrm{start}}}^{t_{\mathrm{end}}}
V_{\mathrm{age}}(t)\,dt
$$

"Percent Below" is computed over the entire analysis period, while "Percent Below Gaps Only" is computed solely over the coverage gaps. The statistical time ranges differ between the two.
