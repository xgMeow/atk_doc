# Coverage Time

## Definition

Coverage Time characterizes the cumulative duration during which the analysis object is in a covered state within the analysis period.

After taking the time union of the coverage intervals produced by different coverage resources, the coverage time can be expressed as:

$$
T_{\mathrm{cov}}
=
\mu\left(
\bigcup_i I_i
\right),
$$

where $I_i$ are the individual coverage intervals, and $\mu(\cdot)$ denotes the interval length.

【Coverage Time】 provides only the statistic value for the whole analysis period, and does not provide a dynamic value.

## Parameter Descriptions

### Computation

【Coverage Time】 supports the following computation methods:

| Computation Method | Meaning | Parameters |
|---|---|---|
| **Max Per Day** | The maximum coverage duration among the UTC days. | None |
| **Max Percent Per Day** | The maximum ratio of the coverage time of a UTC day to the duration of that day. | None |
| **Min Per Day** | The minimum coverage duration among the UTC days. | None |
| **Min Percent Per Day** | The minimum ratio of the coverage time of a UTC day to the duration of that day. | None |
| **Per Day** | The total coverage duration divided by the number of days contained in the analysis period, representing the average daily coverage time. | None |
| **Per Day Std Dev** | The standard deviation of the total coverage duration of the UTC days. | None |
| **Percent** | The ratio of the total coverage duration to the whole analysis period. | None |
| **Percent Per Day** | The ratio of the average daily coverage time. | None |
| **Percent Per Day Std Dev** | The standard deviation of the coverage time ratio of the UTC days. | None |
| **Percent Time Above** | The percentage, relative to the whole analysis period, of the time during which the analysis object is simultaneously covered by at least the specified number of resources. | **Minimum Multiplicity** |
| **Total** | The total coverage duration within the whole analysis period. | None |
| **Total Time Above** | The total duration of the intervals during which the analysis object is simultaneously covered by at least the specified number of resources. | **Minimum Multiplicity** |

### Minimum Multiplicity

It is displayed only when 【Computation】 is 【Percent Time Above】 or 【Total Time Above】.

Let the minimum multiplicity be $N$ and the number of resources that are currently simultaneously covering the analysis object be $n(t)$. Then only the instants that satisfy:

$$
n(t)\ge N
$$

are counted in the corresponding coverage time statistics.

For example, setting the minimum multiplicity to 2:

- 【Percent Time Above】 returns the percentage of double or higher coverage intervals relative to the whole analysis period;
- 【Total Time Above】 returns the cumulative duration of double or higher coverage intervals.

### Satisfaction Condition

After enabling 【Satisfaction Condition】, you can set a comparison condition and a threshold according to the current 【Computation】 result.

The physical meaning of the threshold varies with the computation method:

- time-type results use time units;
- percentage-type results use percentages;
- other results use the unit currently displayed in the interface.
