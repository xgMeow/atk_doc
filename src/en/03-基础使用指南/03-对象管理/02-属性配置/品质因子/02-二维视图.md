# 2D Graphics

In the object list, right-click the 【Figure of Merit】 object to open its property settings page. Under the 【2D Graphics】 category, you can configure **Dynamic** and **Static** graphics settings.

At the top of the **Dynamic** graphics settings is the master Figure of Merit display control. Checking 【Show】 displays the coverage area in the 2D/3D views.

![Figure of Merit Master Control](../../../../../zh/03-基础使用指南/03-对象管理/02-属性配置/品质因子/media/基本属性/image0712-1.png)

The difference between the **Dynamic** and **Static** graphics is that Dynamic graphics display the real-time coverage area, while Static graphics display the coverage area over the whole analysis period. The settings pages of the two are exactly the same, but their parameters must be configured independently.

## Contour Property Settings

1. Grid Point Translucency Settings
0 is opaque, 100 is fully transparent. The text box and the slider are linked.

    ![Grid Point Translucency Settings](../../../../../zh/03-基础使用指南/03-对象管理/02-属性配置/品质因子/media/基本属性/image0712-2.png)

2. Display Metric Settings
Satisfaction area display supports **Uniform Color** and **Levels**. The former only requires specifying the color of the satisfaction area; the latter requires configuring the leveling method, level attributes, color method, legend layout, and other parameters.

- **Level Adding**: specify a level; or specify "Start, Stop, Step". Note: the step size cannot be 0, and the total number of levels cannot exceed 100!
- **Color Method**: Color Ramp or Explicit. The former automatically generates a gradient that varies uniformly with the levels; the latter sets the color of each level independently
- **Level Attributes**: displays the levels that have been added; the total number cannot exceed 100. When the color method is Explicit, a level color column is displayed. Each grid cell is filled with the color of the highest level that is less than or equal to its FOM value.
In 【Level Attributes】, the 【Do not show areas where FOM value exceeds max contour level】 checkbox controls whether grid cells whose FOM value exceeds the maximum level are filled; they are shown by default. Note: by default, grid cells whose FOM value is less than the minimum level are not filled.
- **Legend**: clicking <kbd>Legend...</kbd> opens the 【Figure of Merit Legend Layout】 page. You can set the display position in the 2D and 3D views, the background color, and other parameters.
  Display Position: sets the display position through the legend position pixel values, with the upper-left corner of the view as the origin, the downward direction as the y-axis, and the rightward direction as the x-axis.
  Background: sets the background color and translucency of the legend box; 0 is opaque, 100 is fully transparent.
  Text Options: supports a custom title, whose default value is set automatically according to the object name; you can set the number of decimal digits and the floating point format, supporting decimal or scientific notation display; the text color is also the legend border color.
  Range Color Options: you can set the level order, the number of rows and columns, and the color square width/height.

  ![Figure of Merit Legend Layout](../../../../../zh/03-基础使用指南/03-对象管理/02-属性配置/品质因子/media/基本属性/image0712-3.png)

3. Contour Interpolation

- **Contour Interpolation**: performs natural neighbor interpolation on the contour lines of the heat map. Four computation methods are currently supported: Coarse Sampling - the long edge is interpolated to 128 cells; Medium Sampling - the long edge is interpolated to 512 cells; Smooth Sampling - the long edge is interpolated to 1024 cells; Custom - the minimum latitude/longitude region bounding the coverage area, with n*n cells interpolated between each grid cell.
- **Show lines at level boundaries**: displays the boundary lines between different levels; the line width and color can be set. It is unchecked by default, and the color of the higher level grid is displayed. When checked, all of them are displayed in the specified color.
