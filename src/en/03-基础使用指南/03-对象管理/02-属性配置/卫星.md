# Satellite

Satellite properties are the most core and complex object configuration items in ATK, consisting of four modules: **Basic Properties, 2D Graphics, 3D Graphics, and Constraints**. Among these, **Orbit and Attitude** are key to space mission simulation.

---

## Basic Properties

Basic properties cover five parts: **Orbit, Attitude, Mass, Pass Number, and Ground Ellipses**.

### Orbit

Orbit is the most critical configuration for a satellite, supporting multiple **Propagator** types, with configurable coordinate systems, orbital parameters, force models, etc.

#### Propagator Types

| Type | Category | Core Features | Typical Use |
| :----------: | :----------: | :---------------------: | :----------------------: |
| **Two-Body** | Analytical | Point-mass gravity only, very fast computation | Teaching, quick estimation, theoretical analysis |
| **J2 Perturbation** | Analytical | Includes Earth oblateness J2 term | Short-term (weekly) orbit analysis |
| **J4 Perturbation** | Analytical | Includes J2, J4 high-order terms | Long-term (monthly/yearly) orbit propagation |
| **SGP4** | Semi-analytical | Designed for TLE, includes major perturbations | TLE satellite tracking, access analysis |
| **HPOP** | High-precision numerical | Full force model, highest accuracy | Precision orbit determination, rendezvous and docking |
| **Astrogator** | Special model | Supports superimposed thrust maneuvers | Orbit change, mission planning |
| **STK Ephemeris** | External data interface | Import external ephemeris files | High-fidelity trajectory playback |
| **Vinti** | Analytical | Includes J2 + atmospheric rotation effects | Specific academic research |
| **AstroUq** | Analysis tool | Compare trajectories across different models | Model validation, error analysis |

#### General Parameter Settings

After selecting Two-Body/J2/J4/Vinti, configure:

- Start Time, Stop Time, Step Size (check <kbd>Use Scenario Interval</kbd>)
- Coordinate System: ICRF, J2000, Central Body Fixed, True Equator, Mean Equator, etc.
- Coord Type: **Position and Velocity, Keplerian, Spherical**

#### Orbital Element Parameter Combinations

**Describing Orbit Size and Shape**

- Semimajor Axis a + Eccentricity e
- Apoapsis Radius + Periapsis Radius
- Apoapsis Altitude + Periapsis Altitude
- Period T + Eccentricity e
- Mean Motion n + Eccentricity e

**Describing Orbit Position**

- True Anomaly ν
- Eccentric Anomaly E
- Mean Anomaly M
- Argument of Latitude u
- Time Past Periapsis Tp
- Time of Ascending Node
- RAAN Ω
- Longitude of Ascending Node

#### Advanced Model Configuration

::: details HPOP Configuration
- Configurable **Force Model** (gravity field, solar radiation pressure, atmospheric drag, third-body gravity, geomagnetic index, etc.)
- **Integral Method** (integration tolerance, fixed-step ephemeris output)
- **Covariance** (whether to compute covariance)
:::

### Attitude

Supports multiple attitude modes, enabling Earth-pointing, velocity-pointing, target-pointing, fixed attitudes, etc.:

- Aligned/Constrained Attitude, ECF velocity alignment, ECI velocity alignment
- Fixed Attitude, Fixed in CBF, Fixed in CBI
- Multi-Segment Attitude, Real Time Attitude, STK Attitude
- Satellite Legacy Attitude, Spinning Attitude, Targeted Attitude
- VVLH(CBF), VVLH(CBI)

When selecting **Satellite Legacy Attitude**, configure:

- Attitude Mode: Standard, Multi-Segment, STK File
- Attitude Type: ECI/ECF Earth-pointing, velocity-pointing
- Offset Form: Quaternion, Euler Angles, YPR Angles

---

### Mass

Configure satellite dynamics parameters:

- Total Mass
- Centroid Position
- Mass Moment of Inertia Matrix

---

### Pass Number

Define satellite pass numbering rules:

- Latitude, Longitude, Initial Revolution
- Direction: Ascending / Descending
- Coordinate System: Inertial / Fixed

---

### Ground Ellipses

Configuration and display rules are the same as in [Aircraft Property Settings](./飞机.md); not repeated here.

## 2D Graphics

Adds **Custom Mode** on top of general display options:

- Start/Stop Time
- Show toggle, Color
- Show 2D/3D Ground Track
- Show Orbit, Show Label

Other settings are the same as in [Rocket Property Settings](./火箭.md).

## Constraints

| Property | Description |
| --- | --- |
| [Basic](../03-约束配置/01-基本约束.md) | Geometric and line-of-sight conditions that access between the satellite and other objects must satisfy (azimuth, elevation, range, range rate, propagation delay, altitude, line of sight/terrain constraints, etc.) |
| [Sun](../03-约束配置/02-太阳约束.md) | Conditions determined by the relative positions of the Sun and the Moon that access between the satellite and other objects must satisfy (Sun/Moon elevation angle, exclusion angle, additional central body obstruction, etc.) |
| [Time](../03-约束配置/03-时间约束.md) | Time windows within which access between the satellite and other objects must fall (local time/GMT/local solar time/duration/time intervals) |
