## Constraints

**Logical Combination** is used to set how the computation results of individual members are combined when the constellation participates in access, chain, or coverage calculations. A constellation can be computed member by member, or multiple members can be treated as a whole and the constellation judged valid according to "Any", "All", or "at least a specified number of members satisfy the condition".

<Entry name="Computation Mode" desc="Sets whether constellation members use independent computation or packaged computation.">

The following two modes are supported:

| Computation Mode | Description |
|---|---|
| Packaged Computation | Treats multiple members in the constellation as a whole and determines, according to the configured logical combination conditions, whether the constellation meets the computation requirements. |
| Independent Computation | Each member in the constellation participates in the computation separately, without any constellation-level logical combination of member results. |

After selecting 【Independent Computation】, logical combination parameters such as 【Any】, 【All】, and 【At Least】 do not participate in the computation, so the corresponding options cannot be set.

</Entry>

<Entry name="Logical Combination" desc="Sets the number of constellation members that must satisfy the conditions when packaged computation is used.">

When 【Computation Mode】 is set to 【Packaged Computation】, the following logical combination modes can be selected:

| Logical Combination | Description |
|---|---|
| Any | The constellation as a whole satisfies the condition when at least one member satisfies it. |
| All | The constellation as a whole satisfies the condition only when all members satisfy it. |
| At Least | The constellation as a whole satisfies the condition when the number of members that satisfy it reaches or exceeds the specified number. |

</Entry>

<Entry name="Count" desc="Sets the minimum number of valid members required by the 【At Least】 logical combination.">

Used only when the logical combination is set to 【At Least】.

Let the constellation have $N$ members in total and the specified number be $K$; then the number of valid members must satisfy:

$$
N_{\mathrm{valid}}\geq K
$$

where $K$ should be a positive integer no greater than the total number of constellation members.

</Entry>

> **Note**: 【Any】 is equivalent to taking the union of the valid results of all members, and 【All】 is equivalent to taking their intersection; 【At Least】 is used for scenarios in which a certain number of members must be valid at the same time.
> The logical combination only combines the computation results of constellation members; it does not change the access, coverage, or other constraints already defined on the members themselves.
