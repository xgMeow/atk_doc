# Vehicle

Vehicle property settings include five modules: **Basic Properties, 2D Graphics, 3D Graphics, Constraints, and RF**, all of which are configured in the same way as for Aircraft.

## Constraints

| Property | Description |
| --- | --- |
| [Basic](../03-约束配置/01-基本约束.md) | Geometric and line-of-sight conditions that access between the vehicle and other objects must satisfy (azimuth, elevation, range, propagation delay, altitude, etc.) |
| [Sun](../03-约束配置/02-太阳约束.md) | Conditions determined by the relative positions of the Sun and the Moon that access between the vehicle and other objects must satisfy (Sun/Moon elevation angle, exclusion angle, additional central body obstruction, etc.) |
| [Time](../03-约束配置/03-时间约束.md) | Time windows within which access between the vehicle and other objects must fall (local time/GMT/local solar time/duration/time intervals) |

## RF

## RF Environment

| Property | Description |
| --- | --- |
| [Environment](../08-RF/RF.md) | Describes the additional attenuation of RF signal propagation caused by propagation environments such as atmospheric absorption, rain, clouds, and fog, and includes it in communication or radar link performance calculations. |
| [Radar Cross Section](../08-RF/雷达散射截面.md) | Describes the equivalent scattering capability of a target under radar electromagnetic wave illumination, and provides target scattering parameters for radar echo and detection performance calculations through frequency band, RCS computation model, and Swerling fluctuation model. |
