# Transmitter

A transmitter models the transmitting end of a communication system. Parameters such as frequency, power, data rate, antenna, modulation scheme, filter, and additional gains and losses describe the transmission characteristics of the signal and provide inputs for communication link analysis.

Supported objects: vehicles, satellites, sensors, submarines, ships, missiles, launch vehicles, ground stations, and aircraft. Three configuration modules are included: **Basic Properties, Constraints, RF** .

---

## Basic Properties

Transmitters are divided into transmitter and transponder categories, with six models supported in total. On the **Basic - Definition** page of the transmitter properties, select the desired model using **Type** at the top.

| Category | Model Type | Function |
| --- | --- | --- |
| Transmitter | Simple Transmitter Model | Directly specifies the equivalent isotropically radiated power (EIRP) to describe the radiating capability at the transmitting end. |
| Transmitter | Medium Transmitter Model | Specifies transmit power and transmit gain separately to describe the radiating capability at the transmitting end. |
| Transmitter | Complex Transmitter Model | Specifies transmit power and describes antenna gain and its directionality through an antenna model. |
| Transponder | Simple Transponder Model | Specifies saturated EIRP and describes the transponder output through frequency conversion and power backoff. |
| Transponder | Medium Transponder Model | Specifies saturated transmit power and transmit gain separately to describe the transponder output. |
| Transponder | Complex Transponder Model | Specifies saturated transmit power and determines gain through an antenna model to describe the transponder output. |

#### Simple Transmitter Model

Select **Simple Transmitter Model** under **Type** . The pages include **Model Specifications** , **Modulator** , **Filter** , and **Additional Gains and Losses** .

**Model Specifications** is used to set transmit frequency, data rate, EIRP, and antenna polarization.

| Parameter | Meaning | Usage |
| --- | --- | --- |
| Frequency | The carrier frequency of the transmitted signal. | Enter the transmit frequency and select the corresponding frequency unit using the unit box on the right. |
| Data Rate(Mb/sec) | The number of data bits transmitted per unit time at the transmitting end. | Enter the value according to the data transmission requirements of the communication task, in Mb/sec . |
| EIRP(dBW) | Equivalent isotropically radiated power, which describes the combined radiating capability resulting from transmit power and antenna gain. | Directly enter the known EIRP, in dBW . |
| Antenna Polarization | The direction of the electric field of the transmitted signal and how it varies. | Select **Use** as needed and configure the polarization type and related parameters. See **Antenna Polarization** for details. |

EIRP differs from transmitter output power. When feeder loss and other gains and losses are excluded, their relationship is:

$$
\mathrm{EIRP}=P_t+G_t
$$

Here, $P_t$ is the transmit power in dBW; $G_t$ is the gain relative to an ideal isotropic antenna in dBi; EIRP is in dBW. The simple transmitter model directly uses the entered EIRP, so there is no need to enter transmit gain separately.

The settings in **Filter** and **Additional Gains and Losses** also affect the transmitting-end power results in link calculations. Therefore, avoid counting the same loss in both EIRP and other settings.

#### Medium Transmitter Model

Select **Medium Transmitter Model** under **Type** . The page layout is the same as that of the simple transmitter model.

In **Model Specifications** , the medium transmitter model replaces the **EIRP** input of the simple model with **Power** and **Transmit Gain** . The remaining settings are configured in the same way.

| Parameter | Meaning | Usage |
| --- | --- | --- |

| Transmit Gain(dB) | The gain of the transmitting antenna, which determines the radiating capability at the transmitting end together with transmit power. | Enter the antenna gain. The interface labels the unit as dB; when used to calculate EIRP, its physical reference is an ideal isotropic antenna. |
| Antenna Polarization | The polarization characteristics of the transmitted signal. | Configure in the same way as for the simple model. See **Antenna Polarization** for details. |

This model uses the specified transmit gain in calculations. To describe gain in different directions through an antenna pattern, select the complex transmitter model.

#### Antenna Polarization

Polarization describes the direction of the electric field vector of an electromagnetic wave and how it varies over time. Polarization matching between the transmitting and receiving ends affects power reception in the communication link.

For the simple and medium models, configure it in **Model Specifications - Antenna Polarization** ; for the complex model, configure it in **Antenna - Polarization** .

| Parameter | Meaning | Usage |
| --- | --- | --- |
| Use | Whether to enable antenna polarization settings. | Select this option when polarization characteristics need to be defined, and configure the related parameters. |
| Type | The polarization of the transmitted signal. | Select from linear, horizontal, vertical, left-hand circular, and right-hand circular polarization. |
| Reference Axis | The reference coordinate axis used to define the polarization direction. | For polarization types that require a reference axis, select the X, Y, or Z axis. |
| Polarization Angle(deg) | Determines the deflection angle of the linear polarization direction relative to the selected reference direction. | Enter the polarization angle when the corresponding parameter is editable, and check the angle unit. |

| Polarization Type | Meaning |
| --- | --- |
| Linear Polarization | The electric field vector oscillates along a fixed direction, which can be defined by the reference axis and polarization angle. |
| Horizontal Polarization | The electric field oscillates in the horizontal direction under the reference definition being used. |
| Vertical Polarization | The electric field oscillates in the vertical direction under the reference definition being used. |
| Left-Hand Circular Polarization | The electric field vector rotates in a left-hand circular polarization pattern. |
| Right-Hand Circular Polarization | The electric field vector rotates in a right-hand circular polarization pattern. |

After selecting the polarization type, configure the parameters that are editable for that type. Horizontal and vertical directions should be interpreted in relation to the selected reference axis and cannot be directly equated with the horizontal and vertical directions on the screen.

##### Antenna Polarization Loss Calculation

Polarization loss results from a mismatch between the polarization states of the transmitted signal and the receiving antenna. Below, $L_p$ denotes polarization loss in dB, with positive values consistently representing loss.

###### Linear Polarization

A polarization loss of 3-4dB needs to be considered. For circular polarization with the same handedness, consider a polarization loss of 0.5-2dB.

###### Horizontal Polarization

The polarization loss formula is:

$$
L_p=-20\log_{10}|\cos\theta|
$$

Here, $\theta$ is the angle between the polarization directions of the transmitted signal and the receiving antenna in the same reference plane.

###### Vertical Polarization

The polarization loss formula is:

$$
L_p=-20\log_{10}|\cos\theta|
$$

Here, $\theta$ is the angle between the polarization directions of the transmitted signal and the receiving antenna.

###### Left-Hand Circular Polarization

When considering the axial ratio effects of non-ideal circular polarization, polarization loss can be expressed as:

$$
L_p
=
-10\log_{10}
\left\{
\frac{1}{2}
\left[
1+
\frac{
\pm 4X_rX_t
+
(1-X_t^2)(1-X_r^2)\cos(2\alpha)
}{
(1+X_t^2)(1+X_r^2)
}
\right]
\right\}
$$

Here, $X_t$ is the axial ratio of the incident wave, and $X_r$ is the axial ratio of the receiving antenna polarization. The axial ratio is the ratio of the electric field amplitudes along the major and minor axes of the polarization ellipse, expressed as a linear ratio; $\alpha$ is the angle between the major-axis directions of the two polarization ellipses.

Determine handedness using a consistent propagation direction convention. Use "+" for the same handedness and "−" for opposite handedness. The axial ratio of ideal circular polarization is 1.

###### Right-Hand Circular Polarization

Right-hand circular polarization uses the same axial-ratio loss formula as left-hand circular polarization. The positive or negative sign in the formula is determined by whether the transmit and receive polarizations have the same handedness.

**Signal Bandwidth** is used to set the frequency-domain range of the transmitted signal.

| Parameter | Meaning | Usage |
| --- | --- | --- |
| Auto-Adjust Bandwidth | Determines the bandwidth based on signal parameters such as modulation scheme and data rate. | When **Select Signal PSD** is not selected, use this option to determine the bandwidth automatically; clear it to specify the bandwidth manually. |

#### Filter

**Filter** is used to filter the power spectral density (PSD) of the transmitter's transmitted signal, describing the spectral changes and corresponding losses after the signal passes through the filter. The settings are configured in the same way for all three transmitter models.

Select **Use** , then select the filter type and configure its parameters; when this option is cleared, the filter settings are not enabled. Supported types include Bessel, Butterworth, Chebyshev, Gaussian window, and raised cosine.

##### Common Parameters

| Parameter | Meaning | Usage |
| --- | --- | --- |
| Use | Whether to enable the filter. | Select this option when filtering of the transmitted signal needs to be modeled. |
| Type | The filter model to use. | Select a type from the drop-down list, and the page displays the corresponding parameters. |
| High-Frequency Cutoff | The upper limit of the filter's spectral calculation range relative to the carrier frequency. | Enter the high-frequency limit and select the unit. |
| Low-Frequency Cutoff | The lower limit of the filter's spectral calculation range relative to the carrier frequency. | Enter the low-frequency limit and select the unit. |
| Bandwidth | The frequency span between the high-frequency and low-frequency limits. | Determined by the upper and lower limits and displayed as read-only. |
| Insertion Loss(dB) | The fixed signal power loss introduced by inserting the filter. | Enter the value according to the equipment parameters; this differs from the spectral loss caused by the filter's frequency response. |

**High-Frequency Cutoff** and **Low-Frequency Cutoff** specify the spectral range used; the separate **Cutoff Frequency** setting provided by some filters defines their frequency response characteristics. These have different meanings.

##### Types and Type-Specific Parameters

| Filter Type | Characteristics | Settings Beyond the Common Parameters |
| --- | --- | --- |
| Bessel | Emphasizes phase and group delay characteristics to describe filter responses with waveform fidelity requirements. | Order, cutoff frequency. |
| Butterworth | Has a flat passband amplitude response. | Order, cutoff frequency. |
| Chebyshev | Achieves a steeper frequency transition by allowing amplitude response variations. | Order, cutoff frequency, pulse factor. |

| Parameter | Applicable Types | Meaning and Usage |
| --- | --- | --- |
| Order | Bessel, Butterworth, Chebyshev, Gaussian window | The order parameter of the filter. Set it according to the design requirements of the selected filter to determine its response form. |
| Cutoff Frequency | Bessel, Butterworth, Chebyshev | The characteristic frequency describing the transition of the filter response from the passband to the attenuation region. Enter the corresponding frequency and select the unit. |

Symbol rate differs from the data rate in **Model Specifications** . Data rate is measured in bits, while symbol rate is measured in modulation symbols. Their relationship depends on the modulation and coding schemes, so they cannot be directly treated as the same parameter.

##### Calculation Models for the Filter Types

The basic mathematical forms of the filter types are provided below to illustrate their response characteristics and parameter meanings. In the formulas, $f$ denotes the frequency offset relative to the carrier frequency, and consistent units should be used for all frequency parameters.

###### Butterworth Filter

The amplitude response of an $n$-order Butterworth filter can be expressed as:

$$
|H(f)|
=
\frac{1}
{\sqrt{1+\left(\frac{f}{f_c}\right)^{2n}}}
$$

Here, $n$ is the filter order, corresponding to **Order** ; $f_c$ is the cutoff frequency, corresponding to **Cutoff Frequency** .

###### Chebyshev Filter

The amplitude response of a Chebyshev filter can be expressed as:

$$
|H(f)|
=
\frac{1}
{\sqrt{1+E^2C_n^2\left(\frac{f}{f_c}\right)}}
$$

Here, $n$ is the filter order; $E$ is a design constant that controls passband ripple; $C_n(x)$ is the Chebyshev polynomial of order $n$; $f_c$ is the passband edge frequency of this prototype model.

The Chebyshev polynomials satisfy the following recurrence relation:

$$
C_n(x)
=
2xC_{n-1}(x)-C_{n-2}(x),
\qquad n\geq 2
$$

The initial conditions are:

$$
C_0(x)=1,
\qquad
C_1(x)=x
$$

###### Bessel Filter

The frequency response of a Bessel filter can be represented by the following polynomial form:

$$
H(f)
=
\frac{K_n}
{B_n\left(\frac{f}{f_b}\right)}
$$

Here, $n$ is the filter order; $f_b$ is the cutoff frequency of this filter; $B_n(x)$ is the Bessel polynomial expressed on the imaginary frequency axis; $K_n$ is the normalization factor.

The recurrence relation for the polynomials is:

$$
B_n(x)
=
(2n-1)B_{n-1}(x)-x^2B_{n-2}(x),
\qquad n\geq 2
$$

The initial conditions and normalization factor are:

$$
B_0(x)=1,
\qquad
B_1(x)=1+jx,
\qquad
K_n=B_n(0)
$$

Here, $j$ is the imaginary unit, and the amplitude response is $|H(f)|$.

###### Gaussian Window Filter

A Gaussian window filter uses a Gaussian function to describe smoothly decaying weighting characteristics. The standard form of the Gaussian function is:

$$
G(x,y)
=
\frac{1}{2\pi\sigma^2}
\exp\left(
-\frac{x^2+y^2}{2\sigma^2}
\right)
$$

Here, $G(x,y)$ is the Gaussian function; $\sigma$ is the standard deviation, which controls the width of the function's distribution; $x、y$ are two-dimensional coordinate variables.

###### Raised Cosine Filter

A raised cosine filter consists of a passband, a cosine transition band, and a stopband. Its frequency response is:

$$
H(f)
=
\begin{cases}
T,
&
|f|\leq \dfrac{1-\alpha}{2T},
\\[8pt]
\dfrac{T}{2}
\left[
1+
\cos\left(
\dfrac{\pi T}{\alpha}
\left(
|f|-\dfrac{1-\alpha}{2T}
\right)
\right)
\right],
&
\dfrac{1-\alpha}{2T}
<
|f|
\leq
\dfrac{1+\alpha}{2T},
\\[10pt]
0,
&
|f|>
\dfrac{1+\alpha}{2T}.
\end{cases}
$$

Here, $T$ is the symbol period, related to the symbol rate $R_s$ by $T=1/R_s$; $\alpha$ is the roll-off factor, with a range of $0\leq\alpha\leq 1$.

#### Additional Gains and Losses

**Additional Gains and Losses** is used to describe supplementary gains or losses at the transmitting end. The settings are configured in the same way for all three transmitter models.

| Parameter | Meaning | Usage |
| --- | --- | --- |
| Gain/Loss(dB) | The additional net gain or net loss applied at the transmitting end, excluding items already modeled separately. | Enter the algebraic value of the additional gains and losses, with positive values representing gain and negative values representing loss. |

#### Configuration Procedure

- Open the transmitter properties and select the transmitter model type on the **Basic - Definition** page.
- In **Model Specifications** , set the frequency, data rate, and corresponding EIRP or power parameters. For the medium model, also set the transmit gain.
- When using the complex model, open the **Antenna** page and select **Embedded** or **Linked** ; in embedded mode, configure the antenna model and pointing; in linked mode, check the referenced antenna.
- According to the selected model, configure polarization characteristics in **Model Specifications - Antenna Polarization** or **Antenna - Polarization** .
- In **Modulator** , select the modulation type, determine whether to use signal PSD, and configure the corresponding spectrum or bandwidth parameters.
- Enable **Filter** as needed, and configure the common and type-specific parameters of the selected type.
- In **Additional Gains and Losses** , enter supplementary gains or losses that have not yet been accounted for.
- Check all parameters and units, then click **Apply** to save the current settings, or click **OK** to save and close the properties window.

#### Conversion Methods

**Conversion Methods** is used to define the frequency and power relationships between the input signal and the transponder output signal. It contains two subpages: **Frequency** and **Power Backoff** . The settings are configured in the same way for all three transponder models.

##### Frequency

**Conversion Methods - Frequency** is used to set the coefficients of the frequency conversion polynomial, which calculates the output frequency from the input frequency:

$$
f_{\mathrm{out}}
=a_0+a_1f_{\mathrm{in}}+a_2f_{\mathrm{in}}^2+\cdots+a_nf_{\mathrm{in}}^n
$$

Here, $f_{\mathrm{in}}$ is the input frequency, $f_{\mathrm{out}}$ is the output frequency, $a_i$ are the coefficients of the polynomial terms, and $n$ is the polynomial order.

Enter the coefficients according to the required frequency conversion relationship. The constant term describes a fixed frequency offset, while the linear term describes proportional changes in the input frequency; higher-order terms can be configured when nonlinear conversion is required. The coefficients should be consistent with the frequency units used in the calculation.

##### Power Backoff

**Conversion Methods - Power Backoff** is used to configure the conversion relationship between input power backoff and output power backoff.

Input power backoff is determined by the difference between the saturated flux density and the actual input flux density:

$$
\mathrm{IBO}=\Phi_{\mathrm{sat}}-\Phi_{\mathrm{in}}
$$

Here, $\Phi_{\mathrm{sat}}$ is the **Saturated Flux Density** , and $\Phi_{\mathrm{in}}$ is the actual input power flux density, both in dBW/m²; $\mathrm{IBO}$ is the input power backoff in dB.

Output power backoff is calculated using a polynomial:

$$
\mathrm{OBO}
=b_0+b_1\mathrm{IBO}+b_2\mathrm{IBO}^2+\cdots+b_m\mathrm{IBO}^m
$$

Here, $\mathrm{OBO}$ is the output power backoff in dB; $b_i$ are the coefficients of the power backoff polynomial, and $m$ is the polynomial order. Here, $b_i$ is used to distinguish these coefficients from the frequency conversion coefficients $a_i$.

Enter the coefficients according to the transponder's input and output power characteristics. Output power backoff represents the reduction in output relative to saturation and is used to determine the actual transponder output power.

##### Coefficient Editing

The coefficients on the **Frequency** and **Power Backoff** pages are configured separately, using the same editing operations.

| Item | Meaning and Usage |
| --- | --- |
| Index | The sequence number of a coefficient in the list, identifying its position. |
| Coefficient | The coefficient value in the current conversion polynomial. Double-click the cell to edit the value. |
| Add | Add a new row of coefficients and enter the required value. |
| Delete | Select the row to remove and click **Delete** . |
| Move Up | Select a row and click **Move Up** to move it one row above its current position. |
| Move Down | Select a row and click **Move Down** to move it one row below its current position. |

Set the coefficients according to the required conversion relationship. After editing, check the coefficient values and their order.

#### Antenna Polarization

For the simple and medium transponder models, configure it in **Model Specifications - Antenna Polarization** ; for the complex transponder model, configure it in **Antenna - Polarization** .

The polarization types, reference axis, polarization angle, and usage are the same as those for transmitters. For parameter descriptions and calculation formulas, see **Antenna Polarization** under Transmitters.

#### Filter

**Filter** is used to filter the power spectral density of the transponded signal. The page parameters and configuration methods for all three transponder models are the same as those for transmitters.

Select **Use** as needed, choose a Bessel, Butterworth, Chebyshev, Gaussian window, or raised cosine filter, and configure the common parameters and the type-specific parameters of the selected type. For parameter descriptions and calculation models, see **Filter** under Transmitters.

#### Additional Gains and Losses

**Additional Gains and Losses** is used to describe supplementary gains or losses at the transponding end. The settings for all three transponder models are configured in the same way as those for transmitters.

In **Gain/Loss(dB)** , enter the algebraic value of the additional gains and losses, with positive values representing gain and negative values representing loss. Losses already accounted for through power backoff, filters, or other parameters should not be counted again here.

#### Configuration Procedure

- Open the transmitter properties and select the transponder model type on the **Basic - Definition** page.
- In **Model Specifications** , set **Saturated Flux Density** and enter **Satellite EIRP** or **Power** according to the model. For the medium model, also set **Transmit Gain** .
- When using the complex model, select **Embedded** or **Linked** on the **Antenna** page, and configure or check the antenna parameters.
- According to the selected model, configure polarization characteristics in **Model Specifications - Antenna Polarization** or **Antenna - Polarization** .
- Set the coefficients separately in **Conversion Methods - Frequency** and **Conversion Methods - Power Backoff** .
- Enable **Filter** as needed, and enter additional gains or losses that have not yet been accounted for in **Additional Gains and Losses** .
- Check the parameters, units, and coefficient order, then click **Apply** to save the current settings, or click **OK** to save and close the properties window.
