# Aircraft

Aircraft is a typical moving platform object in ATK, with properties covering five complete modules: **Basic Properties, 2D Graphics, 3D Graphics, Constraints, and RF**. It also serves as the reference benchmark for other platform-type objects (Vehicle, Ship, Submarine, etc.).

---

## Basic Properties

- **Route**: Set the aircraft's motion path.
- **Ground Ellipses**: Configure ellipse parameters for ground projection.

## 2D Graphics

Includes five groups of settings: **Show, Ground Track, Contours, Range, and Ground Ellipses**.

### Show

Controls overall visibility, labels, ground track, orbit, colors, markers, line styles, etc.

### Ground Track

Supports four track types:
- Point
- Time
- All
- None

### Contours / Range

- Contours: Elevation Contours, Elevation Ellipse.
- Range: Range Contours.
Both types of contours support level display settings.

## 3D Graphics

Includes **Model, Vector, Attitude Sphere, Proximity, Contours, Range, and Data Display**.

### Model

Load 3D models (ive / 3ds / flt / fbk, etc.) and set scale, Euler angles, offset, translation, etc.

### Vector

Configure display, labels, line thickness, and colors for vectors in various coordinate systems.

### Attitude Sphere

Set attitude sphere display, colors, zero-degree lines, reference coordinate system, scale, and projections.

### Proximity

Configure uncertainty region type, display, colors, line width, and text annotations.

### Contours / Range

Same as in 2D Graphics, supporting elevation contour and range contour display.

### Data Display

Overlay dynamic report data in the 3D scene; set position, font, color, etc.

## Constraints

| Property | Description |
| --- | --- |
| [Basic](../03-约束配置/01-基本约束.md) | Geometric and line-of-sight conditions that access between the aircraft and other objects must satisfy (azimuth, elevation, range, propagation delay, altitude, etc.) |
| [Solar](../03-约束配置/02-太阳约束.md) | Conditions determined by the relative positions of the Sun and the Moon that access between the aircraft and other objects must satisfy (Sun/Lunar elevation angle, exclusion angle, additional central body obstruction, etc.) |
| [Time](../03-约束配置/03-时间约束.md) | Time windows within which access between the aircraft and other objects must fall (local time/GMT/local solar time/duration/time intervals) |

## RF Environment

| Property | Description |
| --- | --- |
| [Environment](../08-RF/RF.md) | Describes the additional attenuation of RF signal propagation caused by propagation environments such as atmospheric absorption, rain, clouds, and fog, and includes it in communication or radar link performance calculations. |
| [Radar Cross Section](../08-RF/雷达散射截面.md) | Describes the equivalent scattering capability of a target illuminated by radar electromagnetic waves, and provides target scattering parameters for radar echo and detection performance calculations through frequency bands, RCS calculation models, and the Swerling fluctuation model. |
