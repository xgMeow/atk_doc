# Radar Cross Section

## Functional Description

The radar cross section (RCS) describes the equivalent scattering capability of an object as a radar target with respect to an incident electromagnetic wave. The larger the RCS, the stronger the radar echo produced by the target under otherwise identical conditions.

ATK allows the RCS to be divided into one or more frequency bands according to the radar operating frequency, and an RCS calculation type and Swerling fluctuation model to be set for each band separately. The RCS calculation types currently supported by the interface include 【Constant】 and 【External File】:

- 【Constant】: uses a fixed RCS value within the corresponding frequency band;
- 【External File】: loads an external RCS data file, used to describe an RCS that varies with conditions such as the target aspect angle.

The total setting range of RCS frequency bands is about 3 MHz to 300 GHz. During a radar calculation, the RCS model of the corresponding frequency band is selected according to the current operating frequency.

> **Note**: RCS is an electromagnetic scattering characteristic of the target and is not equivalent to the actual geometric area of the target. For the physical definition, units, aspect dependence, and Swerling models of RCS, see the accompanying [Radar Cross Section Theory](../../../04-理论基础/03-RF环境/雷达散射截面.md#_1-physical-meaning-of-the-radar-cross-section).

## Parameter Description

<Entry name="Inherit" desc="Use the scenario-level radar cross section settings instead of setting the RCS of the current object separately.">

After 【Inherit】 is selected, the current object uses the RCS model defined at the scenario level, and the frequency bands and RCS parameters on the page no longer take part in editing separately.

After 【Inherit】 is cleared, the frequency range, calculation type, Swerling model, and constant or external file parameters can be set separately for the current object.

> **Note**: When multiple potential radar targets use a uniform RCS assumption, it can be set at the scenario level and inherited by each object; when an object has independent RCS data, inheritance should be cleared and its settings made separately.

</Entry>

<Entry name="Type" desc="Specify that the current RF property uses the radar cross section model.">

Select 【Radar Cross Section】 on the current page to indicate that the RCS property used by radar detection calculations is configured for this object.

</Entry>

### RCS Frequency Bands

The RCS table organizes the target scattering characteristics by frequency interval. Each row represents one frequency band and contains 【Minimum Frequency】, 【Maximum Frequency】, 【Calculation Type】, and 【Swerling Model】.

During a radar calculation, the software selects the corresponding frequency band according to the current radar signal frequency and uses the RCS model set for that band.

<Entry meta="Dimension: Frequency|Unit: MHz, GHz, etc." name="Minimum Frequency" desc="The lower limit frequency of the current RCS frequency band.">

**Minimum Frequency** determines the starting position of the current frequency band. The lower limit of the first frequency band corresponds to the lowest frequency supported by the RCS model, which is about 3 MHz in the interface.

</Entry>

<Entry meta="Dimension: Frequency|Unit: MHz, GHz, etc." name="Maximum Frequency" desc="The upper limit frequency of the current RCS frequency band.">

**Maximum Frequency** determines the ending position of the current frequency band. The upper limit of the last frequency band corresponds to the highest frequency supported by the RCS model, which is 300 GHz, that is, 300000 MHz.

</Entry>

<Entry name="Frequency Band Insertion Parameters" desc="Enter the minimum frequency and maximum frequency of a new frequency band and add it to the RCS frequency band list.">

In the 【Frequency Band Insertion Parameters】 area, enter 【Minimum Frequency】 and 【Maximum Frequency】, confirm the units, and click 【Insert】 to create a new frequency band within the current RCS frequency range.

After a new frequency band is added, its calculation type, Swerling model, and corresponding RCS parameters should be set for that band in 【Frequency Band Properties】.

> **Note**: Frequency bands are used to describe how the target RCS varies with the radar operating frequency. If the target uses the same model over the entire operating frequency range, a single frequency band covering the whole frequency range can be kept.

</Entry>

<Entry name="Insert" desc="Create a new RCS frequency band according to the frequency band insertion parameters.">

After 【Insert】 is clicked, the software updates the frequency band list according to the entered minimum frequency and maximum frequency.

</Entry>

<Entry name="Delete" desc="Delete the currently selected RCS frequency band.">

Select the frequency band to be deleted in the frequency band table and click 【Delete】 to remove that frequency band.

</Entry>

<Entry name="Merge" desc="Merge adjacent RCS frequency bands with identical settings.">

When adjacent frequency bands use the same RCS settings, 【Merge】 can be clicked to combine them into one continuous frequency band, simplifying the frequency band table.

</Entry>

### Frequency Band Properties

After a frequency band is selected in the frequency band table above, its parameters can be viewed or modified in the 【Frequency Band Properties】 area.

When a frequency band lies at the boundary of the total frequency range, the corresponding minimum frequency or maximum frequency may be fixed by the software, and the input box will not be editable.

<Entry name="Swerling Model" desc="Specify the target RCS statistical fluctuation model used by this frequency band.">

ATK supports five models: Swerling 0, I, II, III, and IV.

| Model | Meaning |
|---|---|
| Swerling 0 | Random RCS fluctuation is not considered; a deterministic RCS is used. |
| Swerling I | The RCS remains correlated within one scan and varies between scans; suitable for slowly fluctuating targets without an obvious dominant scattering center. |
| Swerling II | The RCS can vary rapidly from pulse to pulse; suitable for rapidly fluctuating targets without an obvious dominant scattering center. |
| Swerling III | The RCS remains correlated within one scan and varies between scans; suitable for slowly fluctuating targets with an obvious dominant scattering center. |
| Swerling IV | The RCS can vary rapidly from pulse to pulse; suitable for rapidly fluctuating targets with an obvious dominant scattering center. |

If only a fixed RCS is required without considering statistical fluctuation, select 【0】.

> **Note**: The Swerling model affects the statistical fluctuation of the target echo and the subsequent detection probability calculation, and does not change the frequency range of the band itself. For the detailed statistical models, see [Swerling RCS Fluctuation Models](../../../04-理论基础/03-RF环境/雷达散射截面.md#_7-swerling-rcs-fluctuation-models).

</Entry>

<Entry name="Calculation Type" desc="Specify whether the current frequency band uses a fixed RCS or reads the RCS from an external file.">

ATK currently supports:

| Calculation Type | Description |
|---|---|
| Constant | Uses the specified fixed RCS value within the current frequency band. |
| External File | Reads the target scattering data from an external RCS file, which can be used to describe an RCS that varies with factors such as the aspect angle. |

After a different calculation type is selected, the corresponding parameter items are displayed below.

</Entry>

#### Constant

<Entry meta="Dimension: Logarithmic representation of area|Common unit: dBsm" name="Constant" desc="Set the fixed radar cross section for the current frequency band.">

When 【Calculation Type】 is set to 【Constant】, set the RCS of that frequency band in the 【Constant】 input box. A constant RCS is expressed in dBsm. dBsm is a decibel representation relative to 1 m², for example:

- 0 dBsm corresponds to 1 m²;
- 10 dBsm corresponds to 10 m²;
- -10 dBsm corresponds to 0.1 m².

When the Swerling model is 0, this value serves as the deterministic target RCS; when Swerling I to IV is used, this value serves as the reference/average level of the target RCS statistical model in fluctuation modeling.

> **Note**: A very small value such as `1.11103271648744e-311` appearing in the interface should not be used as a physically meaningful default RCS. Before a radar calculation is performed, a valid RCS value should be entered according to the target characteristics.

</Entry>

#### External File

<Entry name="External File" desc="Load an external RCS data file, used to describe the radar cross section of the target as it varies with conditions such as the aspect angle.">

When 【Calculation Type】 is set to 【External File】, specify the path of the RCS data file, or load the file through the file selection button.

An external RCS file can be used to provide more realistic target scattering characteristics than the constant model. For example, when the same aircraft is illuminated by radar from the nose, the side, or the tail direction, the RCS is often different, and an external file can give the corresponding RCS data according to the aspect angle in the target body coordinate system.

Before loading an external file, confirm that:

- The file format conforms to the RCS file format supported by ATK;
- The frequency and angle ranges contained in the file match the current simulation conditions;
- The units and scale of the RCS values are consistent with the file definition;
- The target coordinate axis definition in the file is consistent with the target attitude definition in ATK.

For the aspect angle, the Rho/Theta definition, and the conversion between linear values and dBsm in an external RCS file, see [External RCS File Model](../../../04-理论基础/03-RF环境/雷达散射截面.md#_6-external-rcs-file-model).

</Entry>

## Usage Recommendations

When target pattern data is unavailable and only a preliminary radar performance analysis is required, a 【Constant】 RCS can be used; if the target RCS has been obtained through electromagnetic simulation, experimental measurement, or other tools and the target attitude and aspect angle need to be taken into account, 【External File】 is preferable.

The frequency band division should be consistent with the actual radar operating frequency and the available RCS data. If the same RCS is used for all frequencies, a single complete frequency band covering about 3 MHz to 300 GHz can be kept; if the RCS differs noticeably at different frequencies, multiple frequency bands should be created and set separately.

The Swerling model should be selected according to the target scattering characteristics and the fluctuation time scale. For a basic analysis that only requires a fixed equivalent RCS, Swerling 0 can be used; when a statistical performance analysis such as detection probability is required, select I to IV according to whether the target has a dominant scattering center and whether the fluctuation is scan-to-scan or pulse-to-pulse.
