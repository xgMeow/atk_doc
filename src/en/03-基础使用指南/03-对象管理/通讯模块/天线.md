# Antenna

## Functional Description

An antenna describes the capability of a communication signal to radiate or be received in different spatial directions. The antenna model gives the variation of antenna gain with direction, and the antenna pointing is used to determine the spatial orientation of that pattern relative to the reference frame of the parent object.

In communication link calculations, the transmitting and receiving ends determine the corresponding antenna gain from the direction of the current communication line of sight in the antenna coordinate system, and this gain participates in the calculation of EIRP, G/T, received power, and subsequent link performance metrics.

> **Note**: The antenna model and the antenna pointing together determine the actual gain along the link direction. For clearly directional Gaussian antennas, parabolic antennas, and external antennas, both the antenna parameters and the mounting/pointing relationship should be set correctly.

## Definition

### Gaussian Antenna

A Gaussian antenna uses an analytical Gaussian beam model to describe its pattern. Its main lobe is distributed along the antenna axis, and away from the axis the gain decreases as the off-axis angle increases. This model is suitable for antennas whose directivity is approximated by a smooth main lobe.

| Parameter | Description |
|---|---|
| Design Frequency | The reference frequency of the antenna model, used to determine the wavelength and to participate in the calculation of antenna gain, beamwidth, and other parameters. |
| Efficiency (%) | Antenna efficiency, which reflects the performance reduction of a real antenna relative to an ideal aperture antenna and participates in the antenna gain calculation. |
| Back Lobe Gain (dB) | The gain level in the region behind the antenna. The lower the value, the weaker the backward radiation or reception capability. |
| Diameter (m) | The antenna aperture diameter. The diameter, together with the design frequency, affects the main lobe gain and the beamwidth. |

Let the antenna diameter be $D$, the antenna efficiency be $P_{a}$, the wavelength be $\lambda$, the angle off the antenna axis be $\theta$, and $\theta_{3\mathrm{dB}}$ be the 3 dB beamwidth. The directional gain of a Gaussian antenna can be expressed as:

$$
G(\theta)
=
P_{a}\left(\frac{\pi D}{\lambda}\right)^2
\exp\left[-2.76\right]\left(\frac{\theta}{\theta_{3\mathrm{dB}}}\right)^2
$$

Here, the 3 dB beamwidth can be approximated as:

$$
\theta_{3\mathrm{dB}}\approx70\frac{\lambda}{D}
$$

where $\theta_{3\mathrm{dB}}$ is expressed in degrees. The relationship between the wavelength and the design frequency is:

$$
\lambda=\frac{c}{f}
$$

where $c$ is the speed of light and $f$ is the design frequency.

> **Note**: Increasing the antenna diameter or raising the design frequency generally increases the axial gain while narrowing the main lobe, so the effect of antenna pointing errors on link performance becomes more pronounced.

### Isotropic Antenna

An isotropic antenna uses an idealized model with equal gain in all directions. This model does not use aperture directivity to distinguish communication directions, and is suitable for simplified link analysis that does not need to describe the main lobe pointing characteristics of the antenna.

| Parameter | Description |
|---|---|
| Design Frequency | The reference frequency of the antenna model. |
| Efficiency (%) | The antenna efficiency parameter. |
| Back Lobe Gain (dB) | The backward gain parameter. For an ideal isotropic model, the directional gain itself does not vary with direction. |

The antenna gain and the effective receiving area satisfy:

$$
G=\frac{4\pi A}{\lambda^2}
$$

Expressed in dBi:

$$
G_{\mathrm{dBi}}
=
10\log_{10}\left(\frac{4\pi A}{\lambda^2}\right)
$$

where $A$ is the effective receiving area of the antenna and $\lambda$ is the signal wavelength. For an ideal isotropic antenna:

$$
G=1,
\qquad
G_{\mathrm{dBi}}=0\ \mathrm{dBi}
$$

### Parabolic Antenna

A parabolic antenna uses a circular aperture antenna model to describe the antenna directivity. This model calculates the antenna gain from the design frequency, the antenna efficiency, and the aperture diameter, and is suitable for parabolic reflector antennas with clearly directional radiation characteristics.

| Parameter | Description |
|---|---|
| Design Frequency | The reference frequency of the antenna model, used to determine the wavelength and to participate in the gain calculation. |
| Efficiency (%) | The antenna aperture efficiency, indicating the degree to which the actual effective aperture is utilized relative to the ideal aperture. |
| Back Lobe Gain (dB) | The gain level in the region behind the antenna. |
| Diameter (m) | The aperture diameter of the parabolic antenna. |

The maximum axial gain of a parabolic antenna can be expressed as:

$$
G_{\max}
=
\eta\left(\frac{\pi D}{\lambda}\right)^2
$$

Expressed in dBi:

$$
G_{\max,\mathrm{dBi}}
=
10\log_{10}
\left[
\eta\left(\frac{\pi Df}{c}\right)^2
\right]
$$

where $D$ is the antenna aperture diameter, $f$ is the design frequency, $c$ is the speed of light, and $\eta$ is the antenna efficiency.

> **Note**: At the same efficiency, increasing the aperture or raising the frequency both increase the axial gain of a parabolic antenna. Because this antenna is directional, the actual link gain also depends on how far the communication line of sight deviates from the antenna axis.

### External Antenna

An external antenna defines the antenna gain distribution through an external pattern file. This model can be used when measured patterns, manufacturer-supplied pattern data, or complex patterns that cannot be accurately described by analytical models are available.

| Parameter | Description |
|---|---|
| Design Frequency | The reference frequency corresponding to the external antenna model. |
| External File | The antenna pattern file. Click the 【...】 button on the right to select a file. |

The directional gain of an external antenna can be expressed in general as:

$$
G=G(\theta,\varphi)
$$

where $\theta$ is the angle off the antenna boresight and $\varphi$ is the azimuth angle about the antenna axis. In the ThetaPhi pattern definition used by the development materials:

- $0^\circ\leq\theta\leq180^\circ$, and $\theta=0^\circ$ corresponds to the antenna $+Z$ axis, that is, the antenna boresight;
- $0^\circ\leq\varphi<360^\circ$, and $\varphi$ is defined about the antenna $+Z$ axis, rotating from the antenna $+X$ axis toward the $+Y$ axis;
- Pattern data usually gives the antenna gain in different $(\theta,\varphi)$ directions, and the link calculation obtains the corresponding gain according to the current communication direction.

> **Note**: The angle definition of an external pattern must be consistent with the antenna coordinate system and mounting orientation in ATK. If the coordinate axes, positive angle direction, or zero direction used by the measured pattern differ from the software definition, the corresponding coordinate transformation should be completed before generating the external file; otherwise the pattern will be rotated, mirrored, or have an incorrect main lobe pointing.

> **Note**: The specific format, field order, and available formats of external files are subject to the file specification supported by the current ATK version.

## Pointing

The antenna pointing is used to define **the attitude of the antenna coordinate system relative to the reference frame of the parent object**. The antenna boresight is taken as the $+Z$ axis of the antenna coordinate system. For Gaussian antennas, parabolic antennas, and external pattern antennas, the angle between the communication line of sight and the $+Z$ axis affects the directional gain used in the link.

The current interface provides the following pointing methods:

| Pointing Method | Description |
|---|---|
| Azimuth-Elevation | Specify the direction of the antenna boresight in the reference frame of the parent object by the azimuth and elevation angles, and determine the attitude around the axis through the about-axis setting. |
| Euler Angles | Define the attitude of the antenna coordinate system relative to the reference frame of the parent object by three Euler rotation angles and a rotation order. |
| Quaternion | Define the antenna attitude by the four components of a quaternion. |
| YPR Angles | Define the antenna attitude by the yaw, pitch, and roll angles together with a rotation order. |

### Azimuth-Elevation

Azimuth-Elevation is a relatively intuitive antenna pointing method. The azimuth angle describes the direction of the antenna boresight in the horizontal plane of the reference frame, and the elevation angle describes the elevation of the antenna boresight relative to the reference plane.

According to the general definition of a right-handed coordinate system:

- The azimuth angle is measured from the $+X$ axis of the reference frame, in the $X-Y$ plane, about the $+Z$ axis;
- The elevation angle is measured from the $X-Y$ plane toward $+Z$;
- The antenna $+Z$ axis always coincides with the configured antenna boresight.

The boresight can be either selected or maintained.

> **Note**: The physical meaning of the azimuth direction may differ for different parent object types and reference frames. The coordinate axis definition of the parent object should be confirmed before setting.

### Euler Angles

Euler angles define the antenna attitude through three consecutive coordinate axis rotations. Let the three rotation angles be $\alpha$, $\beta$, and $\gamma$, and specify the rotation order; then the rotation matrix of the antenna coordinate system relative to the reference frame can be expressed as:

$$
\mathbf R
=
\mathbf R_{i_1}(\alpha)
\mathbf R_{i_2}(\beta)
\mathbf R_{i_3}(\gamma)
$$

where $i_1,i_2,i_3$ denote the coordinate axes used in the rotation order. Different rotation orders correspond to different attitudes, so the input Euler angles must be consistent with the selected order.

### Quaternion

【Quaternion】 in the interface corresponds to the quaternion attitude representation. Let the quaternion be:

$$
\mathbf q=
\begin{bmatrix}
q_x & q_y & q_z & q_s
\end{bmatrix}^{\mathrm T}
$$

where $q_x,q_y,q_z$ are the vector part and $q_s$ is the scalar part. A quaternion used to represent a pure rotation should satisfy the unit-length condition:

$$
q_x^2+q_y^2+q_z^2+q_s^2=1
$$

Quaternions are suitable for directly describing a three-dimensional attitude and can avoid the singularity problems of some Euler angle representations.

### YPR Angles

YPR angles consist of the yaw angle, the pitch angle, and the roll angle:

- **Yaw**: rotation about the reference $Z$ axis;
- **Pitch**: rotation about the reference $Y$ axis;
- **Roll**: rotation about the reference $X$ axis.

YPR angles also require a specified rotation order. Different orders correspond to different final attitudes, so when setting the antenna direction from external attitude data, the angle definition, the rotation order, and the reference frame should be kept consistent with the data source.

### Position Offset

<Entry meta="Dimension: Length|Unit: m" name="Position Offset" desc="Set the position offset of the antenna reference point relative to the reference origin of the parent object.">

The position offset is used to describe the mounting position of the antenna on a parent object such as a satellite, an aircraft, or a ground station. By setting the position offset components along each direction, the antenna reference point can be moved from the reference origin of the parent object to the actual mounting position.

When the offsets along all directions are 0, the antenna reference point coincides with the reference origin of the parent object; after a non-zero offset is set, the link calculation and the geometric display use the offset antenna position.

> **Note**: The position offset only changes the mounting position of the antenna, not its pointing.
