# Orbit Transfer Based on Lambert Targeting

Through the secondary development Connect mode, create a Lambert targeting task, set the initial state, the target state, the transfer time, and the solution parameters, and finally run the maneuver planning and save the scenario. ATK must remain open during the process. The specific steps include:

1. Connecting to ATK.
2. Creating a new satellite, and setting the scenario analysis time and the satellite properties.
3. Inserting a Lambert targeting segment into the main mission sequence.
4. Setting the initial segment, the Lambert target state, and the solution parameters.
5. Running the maneuver planning.
6. Viewing the run results and the 3D trajectory.
7. Saving the scenario and disconnecting from ATK.

::: tip About the Example Code
The examples on this page list only the ATK command statement sequence and do not include the code for loading the communication library; click the language tab at the top of a code block to switch between Python / C++ / Java / MATLAB / Octave. The communication library must be prepared before running any language. Among them, MATLAB / Octave are called through the built-in Java interface, so `ATKConnectJava.jar` must be loaded first and an `ATKConnectJavaModule` object must be created. For details, see [Matlab SDK Introduction and Configuration](../../../二次开发教程/2-二次开发CONNECT模式/1-开发方式/4-语言SDK/2-Matlab/1-简介与配置.md) and [Octave SDK Introduction and Configuration](../../../二次开发教程/2-二次开发CONNECT模式/1-开发方式/4-语言SDK/5-Octave/1-简介与配置.md).

## Script Demonstration

### Connecting to ATK

<mix-code lang="python">
# 1, Connect to ATK
# The connection address and port should match the actual communication settings of ATK; in this example they are 127.0.0.1:6655
conID = atkOpen('127.0.0.1', 6655)
</mix-code>

### Creating a New Scenario and Satellite

<mix-code lang="python">
# 2, Create the scenario and the satellite
atkConnect(conID, 'New', '/ Scenario Lambert')
atkConnect(conID, 'SetAnalysisTimePeriod', '* "5 Nov 2022 00:00:00.000" "8 Nov 2022 00:00:00.000"')

# Reset the animation
atkConnect(conID, 'Animate', '* Reset')
</mix-code>

### Creating a New Satellite and Setting Its Properties

<mix-code lang="python">
# 3, Insert a satellite
atkConnect(conID, 'New', '/ Satellite SatInclinationChange')

# Set the satellite track line width
atkConnect(conID, 'Graphics', '*/Satellite/SatInclinationChange Basic LineWidth 2')

# Set the satellite orbit propagator to Maneuver Planning
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetProp')
</mix-code>

### Lambert Mission Sequence

<mix-code lang="python">
# 4, Insert a LambertTarget segment at the end of the main mission sequence
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange InsertSegment MainSequence.SegmentList.- LambertTarget')
</mix-code>

<mix-code lang="python">
# 5, Set the initial segment parameters
# Orbit epoch
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.Initial_State.InitialState.Epoch 5 Nov 2022 00:00:00.000 UTCG')

# Coordinate type
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.Initial_State.CoordinateType "Modified Keplerian"')

# Orbital elements
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.Initial_State.InitialState.Keplerian.sma 6570000 m')
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.Initial_State.InitialState.Keplerian.ecc 0')
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.Initial_State.InitialState.Keplerian.inc 28 deg')
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.Initial_State.InitialState.Keplerian.RAAN 0')
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.Initial_State.InitialState.Keplerian.w 0')
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.Initial_State.InitialState.Keplerian.ta 0')
</mix-code>

Set the stopping condition of the Lambert segment to `Duration` and the transfer time to `43200 sec`, that is, 12 hours. Set the position components of the target state to `X = 6700000 m`, `Y = 0 m`, and `Z = 0 m`, and set the velocity components `VX`, `VY`, and `VZ` all to `0 m/s`.

<mix-code lang="python">
# 6, Set the display color, the stopping condition, and the target state of the Lambert segment
# The segment color parameter follows the original code
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.SegmentColor 4294902015')

# Stopping condition: Duration; transfer time: 43200 sec
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.StoppingConditions Duration')
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.StoppingConditions.Duration.TripValue 43200 sec')

# Position components of the Lambert target state
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.LambertState.Cartesian.X 6700000 m')
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.LambertState.Cartesian.Y 0 m')
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.LambertState.Cartesian.Z 0 m')

# Velocity components of the Lambert target state
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.LambertState.Cartesian.VX 0 m/s')
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.LambertState.Cartesian.VY 0 m/s')
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.LambertState.Cartesian.VZ 0 m/s')
</mix-code>

Set the solution method to `AdaptSpecified`, and set `IterPosErr`, `Perturb`, `IsMajorArc`, `Revolution`, and `IsLongArc` as shown in the script.

<mix-code lang="python">
# 7, Set the Lambert solution method and the related parameters
# Method values listed in the original code: SpecAll / SpecMin / AdaptSpecified / AdaptMin
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.Method AdaptSpecified')

# IterPosErr follows the original value
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.IterPosErr 0.111')
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.Perturb  false')

# The following three items must be commented out in modes other than AdaptSpecified
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.IsMajorArc on')
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.Revolution 2')
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.LambertTarget.IsLongArc off')
</mix-code>

### Running the Maneuver Planning

Run the configured maneuver planning mission sequence through `RunMCS`.

<mix-code lang="python">
# 8, Run the maneuver planning
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange RunMCS')
atkConnect(conID, 'Animate', '* Reset')
atkConnect(conID, 'Astrogator', '*/Satellite/SatInclinationChange ApplyAllProfileChanges')
</mix-code>

### Saving the Scenario and Disconnecting from ATK

<mix-code lang="python">
# 9, Save the scenario
atkConnect(conID, 'Save', '/ *')
# Disconnect from ATK
atkClose(conID)
</mix-code>
