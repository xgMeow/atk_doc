# Complete Example

## Description

The following uses the **fast orbit transfer scenario** as an example to demonstrate the complete workflow of controlling ATK with the Python SDK: the satellite is quickly transferred from a low Earth parking orbit (LEO) with a radius of 6700 km to a geostationary orbit (GEO) with a radius of 42164.197 km.

::: tip Example Walkthrough
This example focuses on demonstrating the usage workflow of the Python SDK. For more on the case principles, parameter meanings and step-by-step screenshots, refer to the [Secondary Development Case Tutorial](../../../../../02-案例教程/8-二次开发案例/).
:::

## Example Code

The complete code is shipped with the installation package and is located under `Help\Examples\08-二次开发案例\` in the ATK installation directory:

<PathViewer :relative-paths="exampleFiles" />

The code is organized around the main flow of **import the module → establish the connection → create the scenario → set the initial orbit → build the maneuver-planning sequence → run the simulation → save and disconnect**. Each step is separated by comments so you can understand and reuse the code section by section.

## How to Use

::: warning Prerequisites
- Before you start, make sure you have completed [Environment Configuration](./1-简介与配置.md#configuration-steps): copy `ATKConnectPython.py`, `_ATKConnectPython.pyd` and `ATKConnectorDll.dll` to the working directory
- Open the ATK software before running
- This example contains a `New` command that creates a scenario, and ATK Connect mode supports loading only one scenario, so **do not open any existing scenario**; close it first if one is already open
:::

1. Copy the example file <PathCopy :entry="example" /> to the working directory whose environment has already been configured

2. Run it on the command line or in an IDE:

```bash
python ATKConnectPythonTest.py
```

During the run, the ATK interface will progressively execute operations such as creating the scenario, creating the satellite, setting the orbit parameters and running the maneuver planning.

::: tip Official Example
If you just want to verify that the communication library works, you can also run this example directly in the ATK installation root directory without setting up your own project. See [Running the Official Example](./1-简介与配置.md#running-the-official-example) for details.
:::
