# Introduction and Configuration

## Introduction

The Python SDK is the Python communication library provided by ATK. It lets you write scripts in your own Python development environment and interact with ATK over a TCP network connection, enabling automated operations such as scenario building, parameter setting and simulation running.

As one of the core development methods in Connect mode, the Python SDK shares the same communication protocol and command format with the [Python Client tool](../../2-Python客户端工具/1-简介与配置.md) built into ATK. The difference is that the Python SDK runs in your own Python environment, which suits scenarios where you need to integrate ATK functionality into your own projects or leverage the external Python ecosystem (such as third-party libraries like numpy and matplotlib).

::: tip Choosing a Development Method
For a detailed comparison of the development methods, refer to the [Connect Mode Overview](../../../README.md#development-method-comparison).
:::

## Environment and Configuration

### Python Environment

You need to download and install a Python environment yourself. The ATK communication library is developed on Python 3, and its current version is Python 3.12. Please use a matching version; an older version will fail to import.

If Python is not installed on your machine, or the installed version is too old, you can also use the Python environment bundled with ATK (<PathCopy :entry="bundledPython" />) without any extra installation.

::: warning Note
Before sending commands with the Python SDK, you must open the ATK software (no scenario needs to be open). To create a new scenario, close any scenario that is already open.
:::

### Communication Library Files

The ATK Python communication library is shipped with the installation package, and the **interface files and library files all live in the root directory of the installation package**:

<PathViewer :relative-paths="sdkFiles" />

- <PathCopy :entry="pythonModule" />: the Python interface module, which encapsulates the interface functions such as `atkOpen`, `atkConnect` and `atkClose`.
- <PathCopy :entry="pythonPyd" />: the low-level extension module; the underlying implementation of `ATKConnectPython.py`. Currently only a Windows version (`.pyd`) is provided.
- <PathCopy :entry="connectorDll" />: the low-level communication dynamic library, which is depended on by `_ATKConnectPython.pyd`.
- <PathCopy :entry="pythonTest" />: the official example source code, containing the complete implementation of the fast orbit transfer case.
- <PathCopy :entry="pythonReadme" />: the usage flow notes, which describe how to run the official example.

### Configuration Steps

The following flow is used to integrate the ATK communication library into your own Python project.

1. Copy <PathCopy :entry="pythonModule" />, <PathCopy :entry="pythonPyd" /> and <PathCopy :entry="connectorDll" /> from the root directory of the installation package to the working directory of your Python project

2. Import the required interface functions in your Python code:

```python
from ATKConnectPython import atkOpen, atkConnect, atkClose
```

::: warning Note
`ATKConnectorDll.dll` must be located in the same directory as `_ATKConnectPython.pyd`; otherwise the communication library may fail to import because it cannot find its dependency.
:::

### Running the Official Example

If you just want to verify that the communication library works, you can run the official example shipped with the installation package directly, without setting up your own project.

1. Copy <PathCopy :entry="pythonTest" /> to the ATK installation root directory

2. Run the following in the ATK installation root directory:

```bash
python ATKConnectPythonTest.py
```

3. On Linux, if several Python versions are installed, specify the exact version to avoid using an outdated default:

```bash
python3.x ATKConnectPythonTest.py
```

4. If your Windows computer does not have Python installed or the version is too old, you can use the Python interpreter bundled with ATK and run the following in the ATK installation root directory:

```bash
Python\_internal\python ATKConnectPythonTest.py
```

::: tip Note
The Python environment bundled with ATK is version 3.12.1, which matches the communication library version. You can also write and run your own scripts directly with that environment.
:::

## Usage

After completing the configuration above, you can call the three core APIs in your code to control ATK. The basic flow is as follows:

```python
from ATKConnectPython import atkOpen, atkConnect, atkClose

# 1. Establish the connection to ATK
conID = atkOpen()

# 2. Send a command (example: create a new scenario)
atkConnect(conID, 'New', '/ Scenario MyScenario')

# 3. Close the connection
atkClose(conID)
```

For detailed API parameter descriptions, see [Core API](./2-核心API.md); for a complete example, see [Complete Example](./3-完整示例.md).

## Comparison with the Python Client Tool

| Comparison | Python SDK | Python Client Tool |
| :--- | :--- | :--- |
| Python environment | Must be installed and configured yourself | Built into ATK, no installation required |
| Library files | Must be copied manually to the working directory | Built into ATK, no configuration required |
| Third-party libraries | Can use numpy, matplotlib, etc. | Only the standard libraries built into ATK |
| Running mode | External IDE or command line | Client window built into ATK |
| Suitable for | Integration into your own projects and complex development | Getting started quickly and lightweight scripts |

::: tip Module name difference
The Python Client tool uses the runtime built into ATK, whose module name is `ATKConnectModule`; the module name of the Python SDK is `ATKConnectPython`. They are not the same module, and their import statements cannot be used interchangeably.
:::
