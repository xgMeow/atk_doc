# AddAttitude File

## Description

Adds attitude data from an attitude file.

## Syntax

```atk-command
AddAttitude <VehObjectPath> File "<FilePath.a>"
```

## Examples

::: details open **Add Attitude Data from an Attitude File**
```
AddAttitude */Satellite/Satellite1 File "C:\atk\User\Data\SpinNadir.a"
```
:::
