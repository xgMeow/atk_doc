# Chain Class

## Class IChain
 
> [!info]
> Class IChain, inherits from IAtkObject

Property Type: Chain

Example: 
```cpp
IChain*plChain=(IChain*)plScen->GetChildren()->New(eChain, "IChain");
```

### GetObjects() 
 
Function Description: Gets the object collection in the chain
 
Return Type: `IObjectLinkCollection*`

Return Description: Object collection in the chain

Example: 
```cpp
IObjectLinkCollection* pIObjectLinkCollection = pIChain->GetObjects(); 
```
 
### GetGraphics()

Function Description: Gets the 2D properties

Return Type: `IChGraphics*`

Return Description: 2D property pointer

Example: 
```cpp
IChGraphics* pIChGraphics = pIChain->GetGraphics(); 
```
