# Star Class

## Class IStar
 
> [!info]
> Class IStar, inherits from IAtkObject

Property Type: Star

Example: 
```cpp
IStar* pIStar = (IStar*)pIScen->GetChildren()->New(eStar, "IStar");
```

### GetLocationRightAscension()

Return Type: `double`

Return Description: Location right ascension (deg)

Example: 
```cpp

```

## Star 2D

### Class IStGraphics

Example:
```cpp
IStGraphics* pIStGraphics = pIStar->GetGraphics();
```

Notes: pIStar is a pointer to the IStar class

#### GetIsObjectGraphicsVisible()

Function Description: Gets whether the object is displayed in 2D

Return Type: `bool`

Return Description: Whether it is displayed


Function Description: Sets whether the object is displayed in 2D

Input Type: `bool`

Input Description: Whether it is displayed

Example:
