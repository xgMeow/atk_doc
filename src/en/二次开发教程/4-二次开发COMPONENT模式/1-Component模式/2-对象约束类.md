# Object Constraint Classes

## Class IAccessConstraintCollection


Example:
```cpp
IAccessConstraintCollection* pIACColl = pISate->GetAccessConstraints();
```
Notes: `pISate` is an `ISatellite` class pointer

 

###  AddConstraint()

Function Description: Adds a constraint by type; returns null if the constraint is already active

Input Type: `EAccessConstraints`

Input Description: Constraint type

Return Type: `IAccessConstraint*`

Return Description: Constraint property pointer

Example:
```cpp
IAccessCnstrAngle* pIACAngle = (IAccessCnstrAngle*)pIACColl->AddConstraint(eCstrLOSSunExclusion);
```
 

###  AddNamedConstraint()

Function Description: Adds a constraint by name; returns null if the constraint is already active
 

Input Type: `std::string`

Input Description: Constraint name

Return Type: `IAccessConstraint*`

Return Description: Constraint property pointer

Example:
```cpp
IAccessCnstrMinMax* pIACMinMax1 = (IAccessCnstrMinMax*)pIACColl->AddNamedConstraint("Range");
```
 

###  AvailableConstraints()

 

Function Description: Names of the constraints supported by the object

Return Type: `std::vector<std::string>`

Return Description: Names of the supported constraints

Example:
```cpp
std::vector<std::string> vecStrACC = pIACColl->AvailableConstraints();
```
 

###  GetActiveConstraint()

 

Function Description: Gets the active constraint by type; returns null if the constraint is not active

Input Type: `EAccessConstraints`

Return Description: Constraint property pointer

Example:

 

###  GetActiveNamedConstraint()
 

Function Description: Gets the active constraint by name; returns null if the constraint is not active

Return Description: Constraint property pointer


###  IsConstraintActive()

Function Description: Determines whether a constraint of this type is active


Input Type: `EAccessConstraints`

Input Description: Constraint type

Return Type: `bool`

Return Description: `true` - the constraint is active

Example:
```cpp
bool bIsAct = pIACColl->IsConstraintActive(eCstrAzimuthRate);
```
 

###  IsConstraintSupported()
 

Function Description: Determines whether the object supports this constraint type

Input Type: `EAccessConstraints`

Input Description: Constraint type

Return Type: `bool`

Return Description: true - the constraint type is supported

Example:
```cpp
bool bIsSup = pIACColl->IsConstraintSupported(eCstrNone);
```

###  Item()

 

Function Description: Gets the `nIndex`-th constraint in the order they were added

Input Type: `int`

Input Description: The `nIndex`-th constraint

Return Type: `IAccessConstraint*`

Return Description: Constraint property pointer

Example:
```cpp
IAccessConstraint* pIACons = pIACColl->Item(0);
```
 

###  GetCount()

 

Function Description: Gets the number of object constraints

Return Type: `int`

Return Description: Number of object constraints

Example:
```cpp

```
