# Ship Class


## Class IShip 
 
> [!info]
> Class IShip, inherits from IAtkObject

Property Type: Ship

Example: 
```cpp
IShip* pIShip = (IShip*)pIScen->GetChildren()->New(eShip, "IShip");
```
 

### GetGreatArcVehicle()

Function Description: Gets the ship propagator

Return Type: `IGreatArcVehicle*`

Return Description: Propagator

Example: 
```cpp
IGreatArcVehicle* pIGreatArcVehicle = plShip>GetGreatArcVehicle();
```
  
### GetGraphics()

Function Description: Gets the 2D properties

Return Type: `IShGraphics*`

Return Description: 2D property pointer

Example:
```cpp
IShGraphics* pIShGraphics = pIShip->GetGraphics();
```
  
### GetVO()

Function Description: Gets the 3D properties

Return Type: `IShVO*`

Return Description: 3D property pointer

Example:
```cpp
IShVO* pIShVO = pIShip->GetVO();
```
