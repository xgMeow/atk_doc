# Utility Classes

## Close Approach Analysis Utility

### Class ICat

Property Type: Close Approach Analysis Utility

Example:
```cpp
ICat* pICat = pIAtkObjectRoot->GetCat();
```

#### SetSatelliteFromScenario()

Function Description: Computes based on satellites and TLE database objects

Input Type: `std::vector<std::string>`, `std::string`, `std::vector<std::string>`

Input Description: Satellite object names, TLE data file path, excluded SSC numbers

Example:
```cpp
pICat->SetSatelliteFromScenario(vecSatelliteName,strTLEFilePath,vecExcSSCNum);
```

#### SetMissOrLauVehFromScenario()

Function Description: Computes based on missile/launch vehicle and TLE database objects

Input Type: `std::vector<std::string>`, `std::string`, `std::vector<std::string>`

Input Description: Missile/launch vehicle object names, TLE data file path, excluded SSC numbers

Example:
```cpp
pICat->SetMissOrLauVehFromScenario(vecObjName,strTLEFilePath,vecExcSSCNum);
```

#### SetInputSSCNumObject()

Function Description: Inputs the target international designators

Input Type: `std::vector<std::string>`, `std::string`, `std::vector<std::string>`

Input Description: Library file SSC numbers, TLE data file path, excluded SSC numbers

Example:
```cpp
pICat->SetInputSSCNumObject(vecSSCNumber,strTLEFilePath,vecExcSSCNum);
```

#### SetAllTLEObjects()

#### GetResults()

Function Description: Gets the computation results

Output Type: `std::vector<std::string>`, `std::vector<std::string>`, `std::vector<double>`, `std::vector<double>`, `std::vector<double>`, `std::vector<double>`, `std::vector<double>`, `std::vector<double>`, `std::vector<double>``std::vector<std::string>`, `std::vector<std::string>`, `std::vector<std::string>`

Output Description: Primary target SSC, secondary target SSC, equivalent distance, relative distance, radial distance, transverse distance, normal distance, close approach angle, relative velocity, time of closest approach, start time, stop time

Example:
```cpp

```

#### CatComponent()

Function Description: Performs close approach analysis computation

Output Type: `std::vector<double>`, `std::vector<std::vector<double>>`, `EVePropagatorType`, `std::string`, `std::string`, `std::string`, `std::string`, `double`, `double`, `std::vector<AsTCatRes>&`

Output Description: Primary target satellite orbital elements, secondary target satellite orbital elements, orbit propagator model corresponding to the satellite object, scenario start time, scenario stop time, analysis interval start time UTC, analysis interval stop time UTC, relative distance threshold, relative velocity threshold, results

Example:
```cpp

```
