# Coverage Definition Class


## Class ICoverageDefinition, inherits from IAtkObject

 

Property Type: Coverage Definition

Example:
```cpp
ICoverageDefinition* plCoverageDefinition = (ICoverageDefinition*)pIScen->GetChildren()->New(eCoverageDefinition,"ICoverageDefinition")
```
 

### GetGrid()

Function Description: Gets the grid

Return Type: `ICvGrid*`

Return Description: Grid

Example: 
```cpp

```
 
 ### GetGraphics()

Function Description: Gets the 2D properties

Return Type: `ICvGraphics*`

Return Description: 2D property pointer

Example:
```cpp
ICvGraphics* pICvGraphics = pICoverageDefinition->GetGraphics();
```
