# Transmitter Class


## Class ITransmitter

Property Type: Transmitter

Example: 
```cpp
ITransmiter*pITransmitter=(ITransmitter*)plFacility->GetChildren()->New(eTransmitter,"ITransmitter");
```
 
### SetModel()

Function Description: Sets the current transmitter model by name

Input Type: `std:string`

Input Description: Transmitter model name (simple model: `"Simple Transmitter Model"`)

Example: 
```cpp
plTransmitter->SetModel("Simple Transmitter Model ");
```
 
### GetModel() 
 
Function Description: Gets the transmitter model

Return Type: `ITransmitterModel*`

Return Description: Transmitter model

Example:
```cpp
ITransmitterModel*plTransmitterModel = pITransmitter->GetModel();
```

## Class ITransmitterModelSimple 
 
> [!info]
> Class ITransmitterModelSimple, inherits from ITransmitterModel

Property Type: `ITransmitterModelSimple*`

Property Description: Model subclass: simple

Example:
```cpp
pITransmitter->SetModel("Simple  Transmitter  Model");
```
