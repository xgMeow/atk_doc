# Scenario Class

## Class IScenario

> [!info]
> Class IScenario, inherits from IAtkObject

Example: 
```cpp
IScenario* pIScen = (IScenario*)pIAtkObjectCollection->New(eScenario, "Scenario1");
```

Notes: `pIAtkObjectCollection` is an `IAtkObjectCollection` class pointer

### SetTimePeriod()

Function Description: Sets the scenario time

Input Type: `std::string`, `std::string`

Input Description: Start time, stop time, e.g. `"2 Jan 2000 00:00:00.000"`

Example: 
```cpp
pIScen->SetTimePeriod("5 Nov 2022 00:00:00.000", "6 Nov 2022 00:00:00.000");
```

### SetStartTime()

Function Description: Sets the scenario start time

Input Type: `std::string`

Input Description: Start time, e.g. `"2 Jan 2000 00:00:00.000"`

Example: 
```cpp
pIScen->SetStartTime("5 Nov 2022 00:00:00.000");
```
 
### GetStartTime()

Function Description: Gets the scenario start time

Return Type: `std::string`


Return Description: Start time

Example: 
```cpp
std::string strStartTime = pIScen->GetStartTime();
```
 
### SetStopTime()

### GetStopTime()
