# AdvCAT Class

## Class IAdvCAT
 
> [!info]
> Class IAdvCAT, inherits from IAtkObject

Property Type: AdvCAT object

Example: 
```cpp
IAdvCAT* pIAdvCAT = (IAdvCAT*)pIScen->GetChildren()->New(eAdvCAT, "IAdvCAT");
```
