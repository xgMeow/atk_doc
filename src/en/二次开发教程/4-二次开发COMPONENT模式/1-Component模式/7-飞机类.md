## Class IVeWaypointsCollection

###  Add()

Function Description: Copies the last element of the Cobj waypoint collection and adds it to the end of the collection; then uses the newly added element of the Cobj waypoint collection to construct the newly added element of the Iobj waypoint collection

Output Type: `IVeWaypointsElement*`

Output Description: Waypoint

Example: 
```cpp
IVeWaypointsElement* pIVeWaypointsElement = pIVePropagatorGreatArc->GetWaypoints()->Add();
```

###  Contains()

Function Description: Determines whether the collection contains the waypoint at the specified time

Input Type: `double`

Input Description: Specified time

Output Type: `bool`

Output Description: Whether the waypoint at the specified time is contained

Example: 
```cpp
bool isContains = pIVePropagatorGreatArc->GetWaypoints()->Contains(wpv[1]->Time);
```
 
###  IndexOf()

Function Description: Determines whether the collection contains the specified waypoint and returns the index of the existing waypoint. An index < 0 indicates a waypoint that does not exist in the collection.

Input Type: `double`

Input Description: Specified time

Output Type: `int`

Output Description: Index of the specified time in the collection

Example: 
```cpp
int index = pIVePropagatorGreatArc->GetWaypoints()->IndexOf(123456);
```
 
###  RemoveAll()

Function Description: Removes all elements from the collection

Example: 
```cpp
pIVePropagatorGreatArc->GetWaypoints()->RemoveAll();
```

###  RemoveAt()

Function Description: Removes an element from the collection using the specified index

Input Type: `int`

Input Description: Index to remove

Example: 
```cpp
pIVePropagatorGreatArc->GetWaypoints()->RemoveAt(1);
```
 
###  ToArray()

Function Description: Returns a 2D array containing the waypoints. Each sub-array represents a selected point. The order of the elements is time, latitude, longitude, altitude, speed, acceleration, turn radius

Output Type: `std::vector<IVeWaypointsElement*>`

Output Description: Waypoint pointer Vector

Example: 
```cpp
std::vector<IVeWaypointsElement*> wpv = pIVePropagatorGreatArc->GetWaypoints()->ToArray()
```

###  GetCount()

Function Description: Gets the waypoint count

Return Type: `int`

Return Description: Waypoint count

Example: 
```cpp
int index = pIVeWaypointsCollection->GetCount(); 
```
  
###  Item ()
 
Function Description: Given an index, returns an element in the collection (extension function)

Input Type: `int`  

Input Description: Index

Output Type: `IveWaypointsElement*`

Output Description: Waypoint pointer

Example: 
```cpp
IVeWaypointsElement* pIVeWaypointsElement = pIVeWaypointsCollection->Item(0);
```
