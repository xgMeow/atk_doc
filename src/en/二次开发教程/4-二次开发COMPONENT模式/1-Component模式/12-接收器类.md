# Receiver Class

## Class IReceiver 
 
> [!info]
> Class IReceiver, inherits from IAtkObject

Property Type: Receiver

Example: 
```cpp
IReceiver* pIReceiver = (IReceiver*)pIFacility->GetChildren()->New(eReceiver, "IReceiver");
```

###  SetModel()
 
Function Description: Sets the current receiver model by name

Input Type: `std::string`

Input Description: Receiver model name (simple model: "Simple Receiver Model")

Example: 
```cpp
pIReceiver->SetModel("Simple Receiver Model");
```
  
###  GetModel() 
 
Function Description: Gets the receiver model

Return Type: `IReceiverModel*`

Return Description: Receiver model

Example: 
```cpp
IReceiverModel *pIReceiverModel = pIReceiver->GetModel(); 
```
