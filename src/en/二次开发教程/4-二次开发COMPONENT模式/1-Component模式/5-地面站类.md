# Facility Class

## Class IFacility
  
> [!info]
> Class IFacility, inherits from IAtkObject

Property Type: IFacility* Facility

Example: 
```cpp
IFacility* plFacility = (IFacility*)pIScen->GetChildren()->New(eFacility,"Facility1");
```
 

### GetPosition()

Function Description: Gets the position

Return Type: `IPosition*`

Return Description: Position pointer

Example: 
```cpp
plFacility->GetPosition();
```
 
### GetGraphics()

Function Description: Gets the 2D properties

Return Type: `IFaGraphics*`

## Class IPosition
 
> [!info]
> Class IPosition, inherits from ILocationData

### Assign()

Function Description: Sets the position

Input Type: `IPosition*`

Input Description: Position information

Example: 
```cpp
plFacility->GetPosition()->Assign(posc);
```

###  AssignCartesian()

Function Description: Sets the Cartesian position

Input Type: `double`, `double`, `double`

Input Description: Cartesian coordinate x, Cartesian coordinate y, Cartesian coordinate z

Example: 
```cpp
pIFacility->GetPosition()->AssignCartesian(-2127, 5266, 3000);
```
  
###  AssignGeodetic()
 
Function Description: Sets the geodetic position

Input Type: `double`, `double`, `double`

Input Description: Geodetic latitude lat, geodetic longitude lon, geodetic altitude alt

Example: 
```cpp
pIFacility->GetPosition()->AssignGeodetic(28, 112, 50);
```
 
###  ConvertTo()

Function Description: Converts the position coordinate type

Input Type: `EPositionType`

Input Description: Conversion type

Output Type: `IPosition*`

Output Description: Pointer to the converted type

Example: 
```cpp
IPosition* posc = pIFacility->GetPosition()->ConvertTo(eCartesian);
```
 
###  QueryCartesian()

Function Description: Gets the Cartesian position

Input Type: `double`, `double`, `double`

Input Description: Cartesian coordinate x, Cartesian coordinate y, Cartesian coordinate z

Example: 
```cpp
pIFacility->GetPosition()->QueryCartesian(x, y, z);
```

###  GetPosType()

Function Description: Gets the coordinate type

Return Type: `EPositionType`

Return Description: Coordinate type

Example: 
```cpp
EPositionType type = pIFacility->GetPosType();
```

## Facility 2D

### Class IFaGraphics

Example: 
```cpp

```

#### GetIsObjectGraphicsVisible()

Function Description: Gets whether the object is displayed in 2D

Return Type: `bool`

Return Description: Whether to display

Example: 
```cpp

```

####  SetIsObjectGraphicsVisible()

Function Description: Sets whether the object is displayed in 2D

Input Type: `bool`

Input Description: Whether to display

Example: 
```cpp
pIFaGraphics->SetIsObjectGraphicsVisible(bIsShow); 
```

#### GetColor()

Function Description: Gets the 2D display color

Return Type: `int`

Example: 
```cpp

```

####  SetColor()

Function Description: Sets the 2D display color

Input Type: `int`

Input Description: 2D display color, e.g. green - 65280

Example: 
```cpp
pIFaGraphics->SetColor(nColor);
```
