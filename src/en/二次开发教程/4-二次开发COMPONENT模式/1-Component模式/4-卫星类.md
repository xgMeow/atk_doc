# Satellite Class

## Class ISatellite, inherits from IAtkObject

Example:
```cpp
IScenario* pIScen = (IScenario*)pIAtkObjectCollection->New(eScenario, "Scenario1");

ISatellite* pISate = (ISatellite*)pIScen->Children->New(eSatellite, "Satellite1"); 
```
Notes: pIAtkObjectCollection is a pointer to the IAtkObjectCollection class
