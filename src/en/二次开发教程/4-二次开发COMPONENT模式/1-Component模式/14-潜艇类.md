# Submarine Class

## Class ISubmarine
 
> [!info]
> Class ISubmarine, inherits from IAtkObject

Property Type: Submarine

Example: 

```cpp
ISubmarine* plSubmarine = (ISubmarine*)plScen->GetChildren)->New(eSubmarine,"ISubmarine");
```

### GetGreatArcVehicle()

Function Description: Gets the submarine propagator

Return Type: `IGreatArcVehicle*`

Return Description: Submarine propagator

Example: 
```cpp
IGreatArcVehicle* pIGreatArcVehicle = plSubmarine->GetGreatArcVehicle();
```
 
### GetGraphics()

Function Description: Gets the 2D properties

Return Type: `ISuGraphics*`

Return Description: 2D property pointer

Example:
```cpp
ISuGraphics* pISuGraphics = pISubmarine->GetGraphics();
```
 
### GetVO()

Function Description: Gets the 3D properties

Return Type: `ISuVO*`

Return Description: 3D property pointer

Example:
```cpp
ISuVO* pISuVO = pISubmarine->GetVO();
```
