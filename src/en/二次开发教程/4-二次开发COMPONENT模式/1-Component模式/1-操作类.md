# Operation Classes

## Class IAtkObject

 ### Unload()


Function Description: Deletes the object

Example:
```cpp
pISate->Unload();
```

### GetAccessConstraints()


Function Description: Gets the object constraints

Return Type: `IAccessConstraintCollection*`

Return Description: Object constraint pointer

Example:
```cpp
IAccessConstraintCollection* pAccCnstrColl = pISate->GetAccessConstraints();
```

Notes: pISate is an ISatellite class pointer

### GetChildren()
 

Function Description: Gets the child objects of the object

Return Type: `IAtkObjectCollection*`

Return Description: Child object pointer of the object

Example:
```cpp
IAtkObjectCollection* pIAtkObjColl = pISate->GetChildren();
```

Notes: pISate is an ISatellite class pointer

### GetOrbitData()
 

Function Description: Gets historical data

Parameter Type: `std::vector<double>&`, `std::vector<CCoord>&`

Parameter Description: Simulation elapsed time, simulation position

Return Type: `bool`

Return Description: Whether the data was retrieved successfully

Example:
```cpp
std::vector<double> vecEpsec;
std::vector<CCoord> vecPos;
bool isSucceed = pISate->GetOrbitData(vecEpsec,vecPos);
```

Notes: pISate is an ISatellite class pointer

## Class IAtkObjectRoot

 
### NewScenario()

Function Description: Creates a new scenario

Input Type: `std::string`

Input Description: Scenario name

Example:
```cpp
pIAORoot->NewScenario("Scenario1");
```
Notes: `pIAORoot` is an `IAtkObjectRoot` class pointer

 
### CloseScenario()

Function Description: Closes the scenario

Example:
```cpp
pIAORoot->CloseScenario();
```
Notes: `pIAORoot` is an `IAtkObjectRoot` class pointer


### LoadScenario()

Function Description: Loads a scenario file

Input Type: `std::string`

Input Description: Scenario file path

Example:
```cpp
pIAORoot->LoadScenario('C:/ATK/Scenario1.xml');
```
Notes: `pIAORoot` is an `IAtkObjectRoot` class pointer

 

### GetObjectFromPath()

 

Function Description: Gets an object by path

Input Type: `std::string`

Input Description: Truncated path, for example: `"Satellite/Satelite1"`

Return Type: `IAtkObject` pointer

Return Description: Object property pointer


Example:

```cpp
ISatellite* pISate2 = (ISatellite*)pIAORoot->GetObjectFromPath("Satellite/Satellite1");
```

Notes: `pIAORoot` is an `IAtkObjectRoot` class pointer

 

### ObjectExists()

 

Function Description: Determines whether the object exists

Input Type: `std::string`

Input Description: Truncated path, for example: `"Satellite/Satelite1"`

Return Type: `bool`

Return Description: `true` - the object exists

Example:
```cpp
bool bRet = pIAORoot->ObjectExists("Satellite/Satellite1");
```

Notes: `pIAORoot` is an `IAtkObjectRoot` class pointer

 

### SaveScenario()

 

Function Description: Saves the scenario

Example:
```cpp
pIAORoot->SaveScenario();
```

Notes: `pIAORoot` is an `IAtkObjectRoot` class pointer

 

### SaveScenario()

### OutputDataReport()

 

Function Description: Outputs a data report

Input Type: `IAtkObject*`, `std::string`, `std::string`, `std::string`

Input Description: Object pointer, report type, start time, stop time

Output Type: `std::string`

Output Description: Output report path

Example:
```cpp
std::string strReportFilePath = pIAORoot->OutputDataReport(pISate, "J2000 Position Velocity", "5 Nov 2022 00:00:00.000", "6 Nov 2022 00:00:00.000");
```

Notes: `pIAORoot` is an `IAtkObjectRoot` class pointer, `pISate` is an `ISatellite` class pointer

Notes: `pIScen` is an `IScenario` class pointer

### New()
 

Function Description: Creates a new object

Input Type: `EATKObjectType`, `std::string`

Input Description: Type of the class of the inserted object, name of the inserted object

Return Type: `IAtkObject` class pointer

Return Description: Object property class pointer

Example:
```cpp
ISatellite* pISate = (ISatellite*) pIAtkObjectCollection->New(eSatellite,"Satellite1");
```
 

### Count()
 

Property Type: int

Property Description: Number of child objects contained

Example:
```cpp
int nCount = pIAtkObjectCollection->GetCount();
```
 

### Item()
 

Function Description: Gets an object

Input Type: `int`/`std::string`

Input Description: Child object index/child object name

Example:
```cpp
ISatellite* pISate = (ISatellite*)pIAtkObjectCollection->Item(0);
```
 

### GetSupportedChildTypes

Property Type: `std:vector<int>`

Property Description: Types of child objects that the object supports adding

Example:
```cpp
std:vector<int> vecTypes  =plAtkObjectCollection->GetSupportedChildTypes();
```
