# Case Introduction

This case implements the maneuver planning design for the fast transfer from a low Earth parking orbit (LEO orbit) with a radius of 6700 km to a geosynchronous orbit (GEO orbit) with a radius of 42164.197 km. The case is based on Component mode calls and is tested and run with embedded Python version 3.8.0.

## This case depends on the following files (all included in the ATK installation package root directory):

- IntegratingWithATK/python-3.8.0-embed-amd64, embedded Python interpreter; Python scripts can be interpreted and run without installing Python on the computer;

- `ATKComponentPythonModule.py`, ATKComponent mode interface file, providing the interface module for all public class objects and functions in Component mode. After importing this module in a Python case script, these public class objects and functions can be called;

- `_ATKComponentPythonModule.pyd`, ATKComponent mode dynamic library, called by the interface module, containing the concrete implementations of all public class objects and functions in Component mode;

- `ATKComponentJava.dll`, ATK Component mode Java interface dynamic library, providing Java calls in Component mode and linking to load other dependent dynamic libraries in the same directory;

- `ATKComponentPythonTest.py`, Python case script, recommended to be created in the ATK root directory. For details, refer to the code in Case Implementation below. It contains the specific implementation process of an orbit fast transfer case. This Python case script is interpreted and run through the embedded Python interpreter. If the script contains Chinese or the directory contains Chinese, first set the file encoding to UTF-8 without BOM, and then edit the case code.
