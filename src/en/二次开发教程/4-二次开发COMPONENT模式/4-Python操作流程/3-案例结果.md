# Case Results

After successfully running the Python case script ATKComponentPythonTest.py, the data report directory is output in the cmd window, as shown in the figure below.

![cmd window output](../../../../zh/二次开发教程/4-二次开发COMPONENT模式/4-Python操作流程/media/3-案例结果/cmd命令框输出_zy.png)

The following are also generated: the satellite data report J2000 Position Velocity.txt and the orbit fast transfer scenario file FastTransfer.xml. All the above files are stored in the output directory Output, as shown in the figure below.

![Generated scenario and data report](../../../../zh/二次开发教程/4-二次开发COMPONENT模式/4-Python操作流程/media/3-案例结果/生成的想定与数据报告_zy.png)

Open ATK to check the generated scenario file, select the orbit fast transfer scenario file FastTransfer.xml, click the "Start" button to run the animation, and drag the timeline at the bottom to view the trajectory effect in the 2D view, as shown in the figure below.

![Orbit fast transfer effect in the 2D view](../../../../zh/二次开发教程/4-二次开发COMPONENT模式/4-Python操作流程/media/3-案例结果/二维视图下的轨道快速转移效果图_zy.png)

Click the ATK "3D View" button to switch to the 3D view and see the 3D effect, as shown in the figure below.

![Orbit fast transfer effect in the 3D view](../../../../zh/二次开发教程/4-二次开发COMPONENT模式/4-Python操作流程/media/3-案例结果/三维视图下的轨道快速转移效果图_zy.png)
