# C++ Interface Description


## Directory Structure Description

Go to the directory `<ATK root directory>/IntegratingWithATK/component`. The structure of this directory is as follows:

:::note
The directory structure differs across operating systems.
:::

```
component
 ├─bin                Binary directory (dynamic library directory)
 ├─include            Include directory (header file directory)
 ├─lib                Link library directory
 ├─src                Sample code
 ├─Java               Java interface source files
 ├─vs2015             Visual Studio 2015 project configuration files
 ├─vs2017             Visual Studio 2017 project configuration files
 ├─vs2019             Visual Studio 2019 project configuration files
 ├─vs2022             Visual Studio 2022 project configuration files
 ├─configure          Used to generate make build configuration
 ├─xmake.lua          xmake build configuration
 └─xmake.sh           xmake build configuration
```


## Build Environment Preparation

### On Windows

To use the Component dynamic library on Windows, you need to install Visual Studio, version 2015 or later.

The download link for Visual Studio is: <https://visualstudio.microsoft.com/>.

### On Linux (Kylin and other systems)

To use the Component dynamic library on Linux, simply use the system's built-in g++ or gcc as the compiler.

Depending on your habits, you can choose any one of the following build tools: `make`, `xmake`, `cmake`, `qt`, `meson`. The `xmake` build tool is recommended.

## Data Preparation

Before running a C++ project, you need to copy the `AstroData` folder in the ATK root directory to `<ATK root directory>/IntegratingWithATK/component/bin`.
