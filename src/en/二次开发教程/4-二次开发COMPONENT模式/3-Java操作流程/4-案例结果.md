# Case Results

1. After successfully executing the Java case script ATKComponentJavaTest.java, the data report directory is output in the cmd window.

![cmd window output](../../../../zh/二次开发教程/4-二次开发COMPONENT模式/3-Java操作流程/media/4-案例结果/cmd命令框输出_zy.png)


2. A satellite data report J2000 Position Velocity.txt and an orbit fast transfer scenario file FastTransfer.xml are also generated. All the above files are stored in the output directory Output.

![Generated scenario file and data report](../../../../zh/二次开发教程/4-二次开发COMPONENT模式/3-Java操作流程/media/4-案例结果/生成的想定文件与数据报告_zy.png)


3. Open ATK to check the generated scenario file, select the orbit fast transfer scenario file FastTransfer.xml, click the "Start" button to run the animation, and drag the timeline at the bottom to view the trajectory effect in the 2D view.

![Orbit fast transfer effect in the 2D view](../../../../zh/二次开发教程/4-二次开发COMPONENT模式/3-Java操作流程/media/4-案例结果/二维视图下的轨道快速转移效果图_zy.png)


4. Click the ATK "3D View" button to switch to the 3D view and see the 3D effect.

![Orbit fast transfer effect in the 3D view](../../../../zh/二次开发教程/4-二次开发COMPONENT模式/3-Java操作流程/media/4-案例结果/三维视图下的轨道快速转移效果图_zy.png)
