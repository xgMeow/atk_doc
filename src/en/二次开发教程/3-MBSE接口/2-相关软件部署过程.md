# Related Software Deployment Process

## MagicDraw Installation

Run the MagicDraw installer and follow the prompts of the installation wizard to complete the installation.

An example of the installation interface is shown below:

![MagicDraw Installation Wizard Interface](../../../zh/二次开发教程/3-MBSE接口/media/2-相关软件部署过程/image1.png)

## Installing the MagicDraw and ATK Co-Simulation Plugin

1. Extract the `IntegratingWithATK\connect\win\MBSE\MagicDrawToATK-Plug` folder.
2. Copy the extracted `MagicDrawToATK-Plug` folder into the `\plugins` folder in the MagicDraw installation directory.

An example of the operation is shown below:

![Copy the Plugin to the plugins Directory](../../../zh/二次开发教程/3-MBSE接口/media/2-相关软件部署过程/image2.png)

3. Start MagicDraw and select `Options` -> `Environment` -> `Plugins` in the menu bar to confirm that the plugin has loaded successfully.

An example of the verification interface is shown below:

![Interface Confirming Successful Plugin Installation](../../../zh/二次开发教程/3-MBSE接口/media/2-相关软件部署过程/image3.png)

## Upgrading the MagicDraw and ATK Co-Simulation Plugin

1. Go to the `\plugins` folder in the MagicDraw installation directory.
2. Delete the old version of the `MagicDrawToATK-Plug` folder.
3. Copy the latest version of the `MagicDrawToATK-Plug` folder into the `\plugins` directory.

An example of the operation is shown below:

![Copy the Plugin to the plugins Directory](../../../zh/二次开发教程/3-MBSE接口/media/2-相关软件部署过程/image2-1776129750019-12.png)
