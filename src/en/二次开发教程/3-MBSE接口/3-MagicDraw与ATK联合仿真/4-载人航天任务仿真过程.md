# Manned Spaceflight Mission Simulation Process

## State Machine Co-Simulation

After completing model construction, script writing, and value property configuration, begin the co-simulation.

### Starting the Simulation

1. Right-click on an empty area of the state machine diagram (State Machine Diagram) and select `Simulation` -> `Run` to open the simulation interface, as shown in the following figure:

![Open the Simulation Interface](../../../../zh/二次开发教程/3-MBSE接口/3-MagicDraw与ATK联合仿真/media/4-载人航天任务仿真过程/image15.png)

2. Click the **Start Simulation** button, and MagicDraw and ATK begin co-simulation, as shown in the following figure:

![Start Co-Simulation](../../../../zh/二次开发教程/3-MBSE接口/3-MagicDraw与ATK联合仿真/media/4-载人航天任务仿真过程/image16.png)

### Parameter Transfer

After the simulation starts, MagicDraw sends the input parameters to ATK, as shown in the following figure:

![Send Input Parameters to ATK](../../../../zh/二次开发教程/3-MBSE接口/3-MagicDraw与ATK联合仿真/media/4-载人航天任务仿真过程/image17.png)

## Activity Diagram Co-Simulation

Using an activity diagram for co-simulation with ATK is similar to using a state machine diagram. The main steps are as follows:

### Step 1: Build the Activity Diagram

First, build the activity diagram, as shown in the following figure:

![Build the Activity Diagram](../../../../zh/二次开发教程/3-MBSE接口/3-MagicDraw与ATK联合仿真/media/4-载人航天任务仿真过程/image18.png)

### Step 2: Edit the ATK Script

Right-click the Action model element and select **Edit ATK Script** to open the ATK script editor, as shown in the following figure:

![Open the ATK Script Editor](../../../../zh/二次开发教程/3-MBSE接口/3-MagicDraw与ATK联合仿真/media/4-载人航天任务仿真过程/image19.png)

### Step 3: Configure Model Properties

After the script is edited, refer to the method in [Script Editing Process](./3-脚本编辑过程.md) to configure the corresponding input and output properties for the activity diagram model.

### Step 4: Start the Simulation

After completing the above configuration, start the co-simulation in the same way as the state machine simulation.
