# Manned Spaceflight Mission Modeling Process

## Creating a New Project

Open MagicDraw and select `File` -> `New Project` to create a new project, as shown in the following figure:

![Create a New Project](../../../../zh/二次开发教程/3-MBSE接口/3-MagicDraw与ATK联合仿真/media/2-载人航天任务建模过程/image4.png)

## Building the System Architecture

Create a BDD (Block Definition Diagram) to build the system architecture, as shown in the following figure:

![Create a BDD to Build the System Architecture](../../../../zh/二次开发教程/3-MBSE接口/3-MagicDraw与ATK联合仿真/media/2-载人航天任务建模过程/image5.png)

## Creating a Behavior Diagram

Right-click the "Next-Generation Manned Spacecraft System" Block and select `Create Diagram` to create a state machine diagram or an activity diagram as needed, as shown in the following figure:

![Create a State Machine Diagram or an Activity Diagram](../../../../zh/二次开发教程/3-MBSE接口/3-MagicDraw与ATK联合仿真/media/2-载人航天任务建模过程/image6.png)

### State Machine Diagram Example

Taking a state machine diagram as an example, create the state machine model shown in the following figure:

![State Machine Example](../../../../zh/二次开发教程/3-MBSE接口/3-MagicDraw与ATK联合仿真/media/2-载人航天任务建模过程/image7.png)

## Starting Simulation Verification

After the model is built, open the ATK tool to perform simulation verification, as shown in the following figure:

![Open the ATK Tool](../../../../zh/二次开发教程/3-MBSE接口/3-MagicDraw与ATK联合仿真/media/2-载人航天任务建模过程/image8.png)
