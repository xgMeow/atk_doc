## Writing the ATK Script

Fill in the ATK script in the **ATK Script Editor** to implement co-simulation, as shown in the following figure:

![ATK Script Editor](../../../../zh/二次开发教程/3-MBSE接口/3-MagicDraw与ATK联合仿真/media/3-脚本编辑过程/image10.png)

### Notes on Script Writing

> **Note**: The way the IP and port are written in the `atkOpen` function differs from MATLAB:
>
> - MATLAB style: two separate parameters
> - ATK style: a complete string parameter joined with a colon, such as `'127.0.0.1:6655'` (works on the local machine)

## Model Property Configuration

> **Important**: Input and output parameters are defined in the script, and these inputs and outputs also need to be defined in the MagicDraw model accordingly.

### Step 1: Create a New Property

Right-click the state machine and select `Create Element` -> `Property` to create a new property, as shown in the following figure:

![Create a New Property](../../../../zh/二次开发教程/3-MBSE接口/3-MagicDraw与ATK联合仿真/media/3-脚本编辑过程/image11.png)

### Step 2: Modify the Stereotype

Change the **Stereotype** of the property to `ValueProperty`, as shown in the following figure:

![Change the Stereotype to ValueProperty](../../../../zh/二次开发教程/3-MBSE接口/3-MagicDraw与ATK联合仿真/media/3-脚本编辑过程/image12.png)

### Step 3: Create Input and Output Properties

Create properties based on the inputs and outputs in the script:

| Type   | Property Name       | Data Type |
| ------ | ------------------- | --------- |
| Input  | X, Y, Z, Vx, Vy, Vz | Real      |
| Output | Dx                  | Real      |
| Output | Epoch               | String    |
| Output | TripV               | String    |

Change the **Type** of the property to the corresponding `Real` or `String`, as shown in the following figure:

![Modify the Property Type](../../../../zh/二次开发教程/3-MBSE接口/3-MagicDraw与ATK联合仿真/media/3-脚本编辑过程/image13.png)

### Step 4: Assign Initial Values to Input Properties

Set initial values for the input properties, as shown in the following figure:

![Assign Initial Values to Input Properties](../../../../zh/二次开发教程/3-MBSE接口/3-MagicDraw与ATK联合仿真/media/3-脚本编辑过程/image14.png)
