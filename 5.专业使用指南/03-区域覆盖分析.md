# 区域覆盖工具

## 功能介绍

主要用于考虑对象可见约束的情况下，实现一个或多个覆盖资源（如卫星、传感器）对全球或特定区域的覆盖分析。本分析模块包含的分析功能如下表所示。

<center>表 - 区域覆盖品质参数</center>

| 序号 | 覆盖品质     | 约束条件                                                     | 有效条件                         |
| :--: | ------------ | ------------------------------------------------------------ | -------------------------------- |
|  1   | 简单覆盖     | 无                                                           | 无                               |
|  2   | 访问时长     | 总值/最大值/最小值/平均值/百分比高于/标准差                  | 大于/大于等于/等于/小于等于/小于 |
|  3   | 访问间隔     | 最大值/最小值                                                | 无                               |
|  4   | 覆盖时间     | 每日最大/每日最大百分比/每日最小/每日最小百分比/每日标准差/百分比/每日百分比/每日百分比标准差/百分比时间高于 | 大于/大于等于/等于/小于等于/小于 |
|  5   | 多重覆盖     | 最大值/最小值/平均值/百分比高于                              | 大于/大于等于/等于/小于等于/小于 |
|  6   | 访问次数     | 每日平均/在范围内/每日在范围内/每日最大/每日最小/总计        | 大于/大于等于/等于/小于等于/小于 |
|  7   | 覆盖间隔次数 | 每日平均/在范围内/每日在范围内/每日最大/每日最小/总计        | 大于/大于等于/等于/小于等于/小于 |

## 使用方法

### 创建场景

首先在【开始】中点击【新建<img src="./media/03-区域覆盖分析/image-2.png" alt="" no-view />】，创建场景，如图所示。

![创建场景](./media/03-区域覆盖分析/image-3_zy.png)

### 场景中添加各类对象

首先添加一颗卫星，在【开始】栏点击【插入】，选择“卫星-插入默认类型”，如图所示。

![插入卫星](./media/03-区域覆盖分析/image0303-1_zy.png)

插入卫星后，在卫星属性中找到【坐标类型】，更改为“轨道根数”后修改卫星轨道倾角属性为 65°，如图所示。

![修改卫星属性](./media/03-区域覆盖分析/image-5_zy.png)

点击【插入】，选择“传感器-插入默认类型”，如图所示。

![插入传感器](./media/03-区域覆盖分析/image0303-2_zy.png)

在弹出的窗口中选择“卫星1”（上一步插入的卫星），点击确定，如图所示。

![选择挂载传感器的卫星](./media/03-区域覆盖分析/image-8_zy.png)

点击【插入】，选择“覆盖定义-插入默认类型”， 如图所示。 

![插入覆盖定义](./media/03-区域覆盖分析/image0303-3_zy.png)

点击【插入】，选择“品质因子-插入默认类型”，如图所示。

![插入品质因子](./media/03-区域覆盖分析/image0303-4_zy.png)

在弹出的窗口中选择“覆盖定义2”，点击确定，如图所示。

![选择品质因子的父对象](./media/03-区域覆盖分析/image0303-5_zy.png)

场景最终展示如图所示。

![区域覆盖场景三维展示](./media/03-区域覆盖分析/image-10_zy.png)

### 进行区域覆盖计算

在【工具】页面，点击【区域覆盖】。分析对象选择“覆盖定义2”，列表中选择所有卫星下挂的传感器，点击【计算】。这一步时长由计算复杂度决定。计算结束后，在“报告”/“图表”功能区即可生成各类报告和图表。

报告包括：区域覆盖报告和品质因子报告。

区域覆盖报告包括：覆盖时段报告、间隔时段报告、部分覆盖时段报告、部分覆盖时段报告（相对时间）、全局覆盖时段报告、全局覆盖时段报告（相对时间）、全局覆盖间隔报告、全局覆盖间隔报告（相对时间）、网格点信息报告、网格点可见对象报告、区域覆盖率报告、单个对象资源覆盖率统计报告、纬度覆盖报告。
品质因子报告包括：各时刻网格FOM统计值报告、网格FOM统计值报告、有效区域百分比报告、各时刻有效区域报告、指定时刻网格点FOM值报告、网格点FOM值报告、各纬度FOM值报告、各经度FOM值报告。

图表包括：区域覆盖图表和品质因子图表。

区域覆盖图表包括：覆盖时段曲线、间隔时段曲线、部分覆盖时段曲线、部分覆盖时段曲线（相对时间）、全局覆盖时段曲线、全局覆盖时段曲线（相对时间）、全局覆盖间隔曲线、全局覆盖间隔曲线（相对时间）、区域覆盖率曲线、纬度覆盖曲线。
品质因子图表包括：各时刻网格FOM统计值曲线、各时刻有效区域曲线、各纬度FOM值曲线、各经度FOM值曲线。

其中，间隔时段曲线如图所示。
