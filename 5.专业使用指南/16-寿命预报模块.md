# 寿命预报功能模块

## 功能介绍

本功能模块对低轨卫星（轨道高度**120km~800km**）进行轨道寿命预报和轨道衰减量计算。
**注意**：当轨道高度超过800km后寿命将多达100年或100年以上（失去寿命预报意义），此时模块预报寿命超过100年将自动停止计算。

### 功能位置

该功能位于 ATK 卫星栏中（需对象视图栏中选中卫星才能显示），具体打开位置如图所示。

### 寿命预报使用方法

创建场景后，在场景中添加一颗卫星，在动态工具栏-卫星中选择“寿命预报”。注意，场景时间设置应包含预报时间。

- 根据卫星的物理属性设置卫星属性参数；反映卫星抵抗阻力的能力；

- 陨落预报参数设置：限制方式为模块计算停止方式，包含三种模式：轨道预报圈数或时间、轨道预报时间、轨道预报圈数；预报时间限制：表示卫星自然衰减的时间；预报圈数限制：指卫星在轨道运行的圈数；陨落高度限制：陨落高度为卫星再入稠密大气层高度，通常定义为60-120km；

- 大气密度设置：提供调用标准大气密度模型和输入预设值两种设置方式。勾选采用插值查表，则使用标准大气模型（包含Exponential,1976StdAtm, NRLMSISE00, MSISE90, MSIS86, Harrispriester, JacchiaRoberts等7种）。 若未勾选采用插值查表，则需要自己输入Ap、F10.7、平均F10.7的预设值；

- 点击轨道寿命预报中的【计算】，可以得到当前卫星对象的陨落时间（陨落至120km稠密大气层）、轨道寿命、及剩余轨道圈数；

- 点击【报告】或【图表】，可以查看卫星陨落衰减的具体报告和图表曲线。

| 区域 | 主要设置项/功能 | 说明 |
| :--- | :--- | :--- |
| **卫星属性设置** | 阻力面积、大气阻力系数、质量 | 反映卫星抵抗大气阻力的物理特性。 |
| **陨落预报参数设置** | 限制方式（轨道预报器或时间）、预报时间限制、预报圈数限制、降落高度限制、衰减量计算停止时间 | 设置轨道衰减计算的停止条件，包括时间、圈数或高度限制。 |
| **大气密度设置** | 大气密度模型（如NRLMSISE00）、是否采用插值查表、Ap/F10.7/平均F10.7预设值 | 选择标准大气模型或手动输入太阳活动参数，用于计算大气密度。 |
| **轨道寿命预报** | 计算、报告、图表；显示轨道寿命、降落时间、剩余轨道圈数 | 计算卫星从当前时刻到陨落至预设高度的寿命，并输出相关结果。 |
| **轨道衰减量计算** | 衰减量计算停止时间设置、计算按钮；显示累计减量 | 计算指定天数内（如30天）的轨道累计衰减量。 |

### 轨道衰减量计算使用方法

前置操作步骤同轨道寿命预报计算一致，在衰减量计算停止时间处输入想要计算的轨道衰减天数（以30天为例），点击右侧轨道衰减的计算按钮，可以得到30天的累计衰减量。
