# 安装向导

本文档详细介绍 ATK 软件的安装流程、注册步骤、兼容性设置及绿色版相关说明，帮助您快速完成软件的部署与使用。

## Windows 系统安装（绿色版）

ATK Windows 平台提供 **绿色免安装版**，无需安装向导与注册向导，解压后即可直接运行。

1. 下载 ATK 绿色版压缩包，解压至本地任意文件夹（**建议路径不含中文、空格及特殊符号**）；
2. 解压完成后，目录中将出现相关文件夹与 ATK 启动图标；
3. 双击启动图标，即可直接运行软件。

> 安装完成后，请继续完成软件注册：[ATK 注册步骤](#atk-注册步骤)

## 麒麟系统安装

请根据计算机 CPU 架构（`x86_64` / `arm64`）下载对应安装包，架构不匹配将导致软件无法启动。

> 安装完成后，请继续完成软件注册：[ATK 注册步骤](#atk-注册步骤)

### deb 安装包

> 安装包后缀：`.deb`

1. 优先双击 deb 安装包，系统将自动启动安装流程；

2. 若桌面无法识别安装包，打开终端并执行：

   ```bash
   dpkg -i <deb文件路径>
   ```

3. 若提示权限不足，添加 `sudo` 以管理员权限安装：

   ```bash
   sudo dpkg -i <deb文件路径>
   ```

4. 安装完成后，软件默认部署至 `/opt/ATK` 目录，并自动在桌面生成快捷方式；

5. 若快捷方式异常，可进入 `/opt/ATK` 目录，参照「压缩包格式」运行方法启动。

### 压缩包格式

> 压缩包后缀：`tar.gz` / `zip` / `rar` 等

1. 将压缩包解压至任意目录（建议路径不含中文、空格及特殊符号）；

2. 打开终端，使用 `cd` 命令进入解压后的 ATK 目录；

3. 执行启动命令：

   ```bash
   ./ATK.sh
   ```

4. 若提示无运行权限，先赋予可执行权限：

   ```bash
   sudo chmod +x ./ATK
   chmod +x ./ATK.sh
   ```

> [!IMPORTANT]
> 为支持多版本共存，不同版本 ATK 不会相互覆盖，旧版本如需清理请手动删除。

## ATK 注册步骤

ATK 采用 **免费使用模式**，但**首次使用必须完成注册**，否则功能将无法正常使用。

1. 双击运行 `ATK.exe`，自动弹出【ATK使用协议】对话框；
2. 仔细阅读协议后，勾选 **我已经认真阅读该协议**，点击 <kbd>同意</kbd>，进入【ATK注册机】界面；

![ATK使用协议](./media/2.2安装向导/image-20260330090751358.png)

3. 注册机界面中**机器码**将自动生成，无需手动修改；

4. 在注册码输入框填写获取到的注册码，点击 <kbd>注册</kbd> 完成激活。

   ![ATK软件注册工具](./media/2.2安装向导/image-20260408191451877.png)

### 注册码获取方式

- **方式一：申请表**
  点击 <kbd>申请表</kbd>，系统将打开 PDF 指引文件，按文档步骤完成注册码申请。

- **方式二：微信小程序**
  打开微信扫码，进入 STK 注册码申请小程序，填写信息后提交申请。

![ATK注册码自助计算小程序](./media/2.2安装向导/image-20260330091449542.png)

获取注册码并填入、点击 <kbd>注册</kbd> 后，提示**注册成功**即可正常使用全部功能。

![ATK软件注册成功界面](media/2.2安装向导/image9.png)

> [!TIP]
> 最新版本 ATK 已新增 **软件注册二维码**，支持扫码直接完成注册，操作更便捷。

## 兼容性设置

ATK 默认适配 **27 寸显示器、1920×1080 分辨率**。在高分屏笔记本等设备上可能出现界面缩放异常，需按以下步骤调整兼容性：

1. 找到桌面 ATK 快捷方式，右键单击，选择 <kbd>属性</kbd>；
2. 在弹出的【属性】对话框中，切换至「兼容性」选项卡；
3. 找到并点击 <kbd>更改高DPI设置</kbd>；
4. 在【高DPI设置】对话框中，勾选 **替代高DPI缩放行为**；
5. 在「缩放执行」下拉菜单中，将默认「应用程序」改为 **系统** 或 **系统增强**；
6. 依次点击 <kbd>确定</kbd> 保存设置，**重启 ATK 软件** 生效。

![ATK 显示兼容性设置](media/2.2安装向导/image-1.png)
