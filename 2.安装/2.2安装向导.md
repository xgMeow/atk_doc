# 安装向导
本文档详细介绍ATK软件的安装流程、注册步骤、兼容性设置及绿色版相关说明，帮助您快速完成软件的部署与使用。

## Windows 系统安装（绿色版）
ATK的Windows版本均为**绿色免安装版**，无需执行复杂安装、注册步骤，解压后即可直接使用，具体操作如下：

1.  下载ATK绿色版压缩包，解压至电脑任意文件夹（建议路径无中文、无特殊符号）；
2.  解压完成后，文件夹内会显示各类 **ATKInput文件** 及ATK启动图标；
3.  双击启动图标，即可直接运行软件。

## 麒麟系统安装
根据电脑CPU芯片架构（如 `x86_64`、`arm64`）下载对应版本的ATK软件（架构不匹配将无法运行），分为两种安装格式，具体操作如下：

### 方式 1：deb安装包

> [!NOTE]
>
> 文件后缀 `.deb`

1.  优先尝试 **双击deb安装包**，系统将自动启动安装程序；
2.  若系统无法识别，打开命令行终端，输入安装命令：
    ```bash
    dpkg -i <deb文件路径>
    ```
3.  若提示“权限不够”，添加`sudo`前缀使用管理员权限安装：
    ```bash
    sudo dpkg -i <deb文件路径>
    ```
4.  安装完成后，软件将自动部署至 `/opt/ATK` 目录，并在桌面生成快捷方式；
5.  点击桌面快捷方式即可运行；若未生成快捷方式或快捷方式无效，进入 `/opt/ATK` 目录，参考「压缩包格式」的运行方式启动软件。

> [!NOTE]
> 为支持多版本共存，不同版本号的ATK不会互相覆盖，旧版本需手动删除。

### 方式 2：压缩包

> [!NOTE]
>
> 文件后缀 `tar.gz`、`zip`、`rar` 等

1.  将压缩包手动解压至任意目录（建议路径无中文、无特殊符号）；
2.  打开命令行终端，使用 `cd` 命令进入解压后的ATK目录；
3.  输入命令运行软件：
    ```bash
    ./ATK.sh
    ```
4.  若提示“无运行权限”，先执行权限赋予命令（权限不足可添加`sudo`前缀）：
    ```bash
    sudo chmod +x ./ATK
    chmod +x ./ATK.sh
    ```

## ATK 注册步骤
ATK为 **免费使用模式**，但 **初次使用必须完成注册**，未注册将无法正常使用所有功能，具体步骤如下：

1.  双击打开ATK.exe，系统自动弹出【ATK使用协议】对话框，仔细阅读协议后，点击 <kbd>同意</kbd>，进入ATK注册机界面；

    ![ATK使用协议](media/2.2安装向导/image77.png)

2.  注册机界面首行将 **自动生成计算机ID**，点击界面中的 <kbd>帮助</kbd> 按钮，在弹出的【ATK序列号申请表】表单中填写相关信息；

    ![ATK软件注册工具](media/2.2安装向导/image8.png)

3.  携带填写完整的申请表，联系 **国防科技大学空天科学学院**，由开发者为您的计算机ID生成专属序列号；
4.  将获取的序列号准确填入注册机界面的对应输入框，点击 <kbd>注册</kbd>，提示注册成功后，即可正常使用ATK所有功能。

    ![ATK软件注册成功界面](media/2.2安装向导/image9.png)

> [!TIP]
> 当前ATK最新版本新增 **软件注册二维码**，可直接扫描二维码完成注册，操作更便捷。

## 兼容性设置
ATK软件默认适配 **27寸显示器、1920×1080像素分辨率**，若您的计算机分辨率与默认配置接近，可实现完美适配；若配置高于默认（常见于笔记本电脑），易出现界面显示异常，需按以下步骤调整：

1.  在电脑桌面找到ATK软件快捷图标，右键单击图标，在弹出的菜单中选择 <kbd>属性</kbd>；
2.  在弹出的【属性】对话框中，切换至「兼容性」选项卡；
3.  向下滑动页面，找到并点击 <kbd>更改高DPI设置</kbd> 选项；
4.  在弹出的【高DPI设置】对话框中，勾选「替代高DPI缩放行为」，点击下方「缩放执行」下拉框；
5.  将默认的「应用程序」选项，修改为「系统」或「系统增强」，点击 <kbd>确定</kbd> 保存所有设置，重启软件即可生效。

    ![ATK 显示兼容性设置](media/2.2安装向导/image-1.png)
